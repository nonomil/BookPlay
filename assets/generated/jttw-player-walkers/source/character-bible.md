# JTTW player-walker character bible

All walkers use the same orthographic camera, full-body framing, dark-brown
outline, warm children’s-storybook rendering, 384×512 cells, and a shared foot
baseline. Props are friendly story cues and must not become weapons or obscure
the face. The 8-frame order is contact → left-foot-forward → passing →
right-foot-forward, repeated once.
