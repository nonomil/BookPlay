七阶段运行素材已由用户授权的 CliproxAPI `gpt-image-2` 生成，经过 `#00ff00` chroma-key 去背并通过 alpha/绿残色质量门。运行时优先使用 `content/assets/companions/white-dragon/stages/*.png`，同名 SVG 仅用于兼容回退；详细提示词、报告和 SHA-256 见本目录的 `generation-prompts.md` 与 `manifest.json`。

## 角色身份

- 名称：小白龙；第 18 集完成后称为白龙马；第 13 辑完成后进入八部天龙庆祝形态。
- 用途：儿童英语学习伙伴，不承担战斗、饥饿、生病或惩罚反馈。
- 观感：温柔、好奇、可靠、带一点顽皮；孩子一眼能认出是同一位伙伴。
- 设定边界：龙蛋和幼龙是产品中的成长想象；第 17 集以后衔接《西游记》正篇角色，不把想象内容当作原著事实。

## 视觉不变量

1. 主色为珍珠白 / 水青 / 深青，点缀暖金；眼睛为深棕，表情友善。
2. 额角一对小金角、耳鳍和云纹保持同一位置；不出现尖锐獠牙、武器、盔甲或恐怖火焰。
3. 龙形四肢短而圆润，马形保留同一双眼睛、额角和水青云纹；不可变成另一只动物。
4. 透明背景、单角色、正面或 3/4 视角；不含文字、Logo、水印、复杂背景。
5. 适合 256px 卡片和 1024px 放大展示，轮廓清晰，边缘不带棋盘格假透明。
