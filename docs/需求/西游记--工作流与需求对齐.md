## 0. 一句话

《西游记》不是又一个故事候选，而是 **BookPlay 的第一条可跑通的内容生产线**：先把 `data/` 里「一集 PDF + 一集 MP3 + 一集视频」收成可翻页的有声绘本，再在同一套页数据上叠学习与分支。PRD 里的 JSON 对话树、检查点、生词本，全部挂在这套「页」上，而不是另起一套 RPG。

## 3. 一条主线（个人使用）

```
data/ PDF + MP3 (+ 可选视频字幕)
        ↓  tools/pipeline_lf_episode.py
demo/assets/lf_ep1/ + demo/data/storybooks/ep1.json
        ↓
浏览器翻页有声绘本 → 点词 / 页末题 → 再加分支
```

| 层 | 来源 |
|---|---|
| 图 | PDF 整页渲染 PNG |
| 文 | PDF 抽英文（修 drop-cap） |
| 音 | 现成 MP3，复制进 `demo/assets/lf_epN/` |
| 字幕 | M0 不做；M0.5 再从视频抽或手补中文 |
| 新立绘（可选） | 美术模板 + Grok Build，不挡 M0 |

`demo/data` 对话树是旁路，不替代第 1 集绘本。

## 4. 工作流（先创建这个，再谈 RPG）

目标产物不是「108 集网站」，而是 **一集可玩的页包**。第 1 集 `The Monkey` 是唯一允许先做的切片。

```
W0 配对清单
   PDF 001 ↔ MP3 001 ↔ 视频 01  →  catalog/ep001.json

W1 抽页图
   每页渲染 PNG（2x）→ work/ep001/pages/pXX.png
   封面/空白页打标，不进入播放

W2 抽正文
   PyMuPDF 抽英文 → 人工修 drop-cap
   一页一段 → work/ep001/pages/pXX.txt

W3 抽时间轴（三选一，按工具齐备度）
   A. 整集 MP3 + 页文本做强制对齐（aeneas / whisperx）→ 每页起止秒
   B. 有 ffmpeg 时从 MP4 抽软字幕/硬字幕 OCR
   C. 先整集播放、按页手动切 10 来个时间点（第 1 集允许）

W4 组装 episode.json
   页序、图路径、英文、可选中文、audio 文件、page_start_sec
   schema 校验

W5 翻页播放器（M0 验收）
   打开一页 = 图 + 文 + 当前句高亮
   点页/点按钮翻页，音频seek到该页
   整集可听完、可停在某一页、刷新后恢复

W6 学习层（PRD F10/F15 的最小版）
   点词：释义 + 再读该词
   页末 1 题（这页在讲什么 / 这个词是什么意思）
   生词本写入 localStorage

W7 交互层（PRD F2 的最小版，仍在第 1 集）
   只在 1–2 个叙事节点插入 2 选 1
   选项写在 episode JSON 上即可，不必另开公版轨道
```

本机现状：有 Python、`pymupdf`、`pypdf`；**没有 ffmpeg / ffprobe**。所以第 1 集默认走 **W1 PDF 渲染 + W2 抽字 + W3-C 手工页时间点**，不把「先装一整套视频工程」当成开工条件。
