# 西游贴纸生图提示词审查（故事锚点版）

## 结论

旧版 `jttw-story-stickers-v1/source/prompt.txt` 把仙石、桃子、瀑布、铃铛、龙等 12 个物件放在同一张混合图集里，再循环复用到 108 集。模型只会“画得像西游”，不会知道这一关发生了什么，因此出现“图好看、剧情不对”的错觉。

运行时已改为“故事场景优先”：每关卡片使用对应 `epNNN.jpg` 场景缩略图，未解锁也可点开看大图；GPT 透明物件仅作为可选的纪念物，不能覆盖故事事实。

## 生成提示词合同

每个生成任务只允许一个主体，且必须填写：

```text
Episode: EP<数字>
Storybook pages: <页码>
Scene beat: <谁 + 在哪里 + 正在做什么>
Collectible: <从该动作中抽取的一个小礼物>
Visual role: <房间摆件 / 玩具 / 动物朋友 / 装备 / 贴纸>
Style: gentle watercolor storybook, rounded child-safe shapes, 7-year-old friendly
Composition: one complete subject, centered, generous margin, readable at 116px
Output: solid #00ff00 staging background; final PNG must be alpha transparent
Avoid: unrelated characters, random weapons, extra scenery, readable text, logo,
       scary gore, sharp fragments, photorealism, generic “Journey to the West” collage
```

## 质量门

- 先核对页面/scene，再写 prompt；不能只写“西游风格”。
- 透明输出必须有 RGBA、四角 alpha=0、无绿边；失败时回退故事缩略图。
- 卡片标题取自本集故事名，解释里显示页码/出处；图像和文字由 UI 分层承担。
- 对 7 岁儿童，惊险元素改为“勇气纪念物”，不改写剧情、不渲染恐惧。
