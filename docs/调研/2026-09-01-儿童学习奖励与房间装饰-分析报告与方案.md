## 0. 这份文档回答什么

1. 五款儿童学习 App 的奖励如何发放、如何进入房间/宠物/收藏、家长如何防过度打扰。  
2. 哪些机制适合书戏（英文原著 + 分集演出 + 答题巩固），哪些会把学习做成购物。  
3. 若做「学完 → 可见物 → 角色房间」，数据模型、状态机、防刷、家长控制和分期落地怎么写。  
4. 开源可借鉴什么结构，不可抄什么玩法。

**给书戏的一句话建议：** 学 Khan Kids 的「课完选一件，立刻进角色房间」；学 Lingokids 的「不同活动才计分 + 日上限」；学 PBS 的「角色本身就是奖励」；**不要**学 ABCmouse 的票券商店；**不要**做死亡/饥饿 Tamagotchi。

## 2. 五款产品对照（只写已核验）

### 2.1 总表

| 产品 | 学完得到什么 | 进房间 / 宠物 / 收藏？ | 家长 / 防打扰 | 经济复杂度 | 主证据 |
|---|---|---|---|---|---|
| Khan Academy Kids | 奖品/收藏物（非金币） | 是。角色房间收藏 bugs / hats / toys / clothes | Grown-Ups Only：隐藏 Videos / Create / 季节主题；隐藏 Learning Path 的 Home，减少中途退出。未见官方内置时长器 | 低 | Zendesk + CSM + App Store |
| Duolingo ABC | mini games + rewards；用户评提到 star | 官方未写房间/宠物 | 无广告、无内购。缺官方家长看板 | 极低 | App Store / iTunes |
| Lingokids | 1 星/不同活动；5 星开贴纸包；日重置 | Sticker Album → Scene Book 贴纸装饰场景 | Parental Gate（出生年）；Plus 可设每日时长；theatre / lessons / Play Together 可限，**Games 始终可用** | 低 | Help Center |
| ABCmouse | Tickets | CSM：avatar / room / fish tank / hamster track；商店文案有 Pet Town / Aquarium / Hamster | CSM：家长可调级别与允许时长。官方细则本轮未打开 | 高 | iTunes + CSM |
| PBS KIDS Games | 无公开货币 | 无房间经济 | Grownups 链；强调安全界面。Video App 自动连播且无法关闭（反面教材） | 无 | iTunes + CSM |

### 2.2 Khan Academy Kids — 最接近书戏的参考

**事实**

- 2–8 岁；100% 免费、无广告、无订阅、COPPA。[App Store](https://apps.apple.com/us/app/khan-academy-kids/id1378467217)  
- 完成课/掌握主题后收集 bugs、hats、toys、clothes，放在首页角色房间。[角色说明](https://khankids.zendesk.com/hc/en-us/articles/360049358751-Learn-more-about-the-characters-inside-Khan-Academy-Kids)  
- 底部角色入口：Ollo 洗澡玩具、Reya 虫子、Peck 衣橱、Sandy 乐器、Kodi 帽子。[入门](https://khankids.zendesk.com/hc/en-us/articles/360006764812-Parent-and-Home-Account-Users-Getting-Started-and-creating-an-account-with-Khan-Academy-Kids)  
- CSM：完成后孩子 **choose a prize** 加入动物朋友收藏。[CSM](https://www.commonsensemedia.org/app-reviews/khan-academy-kids)  
- 家长偏好：隐藏 Videos / Create；隐藏 Home 以防未完成就退出；隐藏季节主题。仅家长版，教师版无。[家长控制](https://khankids.zendesk.com/hc/en-us/articles/360047566151-How-do-I-access-parental-controls)  
- 教师可关 Videos/Create，可要求先做作业再探索。[教师 FAQ](https://khankids.zendesk.com/hc/en-us/articles/13849896234395-FAQ-How-do-I-turn-off-videos-and-coloring)  
- 帮助中心搜 `coins` 为 0。X 账号讨论屏幕时间质量，未见金币帖。[X](https://x.com/khanacademykids)

**推断**

- 奖励是「给角色添一件可见物」，不是货币。  
- 每个角色一个垂直收藏槽，选择负担低。  
- 防打扰优先「挡娱乐入口 + 课中退出摩擦」，不是分钟配额。

**对书戏**

- 西游角色（悟空、唐僧、龙王、土地等）可直接当「房间主人」。  
- 学完一拍/一集，选一件与剧情相关的物什放进对应房间，比通用金币更贴绘本。

### 2.3 Duolingo ABC — 轻奖励上限

**事实**

- 现名 *Learn to Read - Duolingo ABC*；700+ 课；mini games and rewards；无广告无内购；可离线。[商店](https://apps.apple.com/us/app/learn-to-read-duolingo-abc/id1440502568)  
- iTunes：`version=1.96.2`，`currentVersionReleaseDate=2023-08-02`。  
- 官方博客旧 URL 404。  
- 用户评（社区）：孩子说 “I’m getting another star!”；有人嫌庆祝音过多。

**推断**

- 奖励停在课末反馈，没有装修经济。  
- 产品可能已停止迭代，机制只能当「轻量上限」参考，不能当现行路线图。

**对书戏**

- 句级填空/选择答对，给短庆祝即可。  
- 庆祝必须可关（家长或设置）。  
- 不要把 ABC 的「无房间」理解成「房间没用」——它是识字练习器，书戏是演出器。

### 2.4 Lingokids — 防刷与场景装饰

**事实**

- 完成**不同**活动得 1 星；重玩不得星；5 星开贴纸包；星计数每日重置；领取无时限；贴纸进 Album，装饰 Scene Book。[奖励](https://help.lingokids.com/hc/en-us/articles/18393545177874-How-does-the-reward-system-work)  
- Parents Area 在 Parental Gate 后；可设每日屏幕时间（Plus）；可按活动类型限制；**Games 始终可用**。[家长区](https://help.lingokids.com/hc/en-us/articles/115005129325-What-is-the-Parents-Area) / [时长 API 摘要](https://help.lingokids.com/api/v2/help_center/articles/search.json?query=screen%20time)  
- 无广告；COPPA + kidSAFE；支付在 Gate 后。[安全](https://help.lingokids.com/hc/en-us/articles/205124431-Is-Lingokids-safe-for-kids)  
- 「The Lingokids Store」是 Amazon 周边，不是应用内金币店。[Store](https://help.lingokids.com/hc/en-us/articles/24275445185170-The-Lingokids-Store)  
- 搜 Playchamps / coins：0 条。

**推断**

- 日重置同时防刷和制造「明天再来」。  
- 游戏豁免时长 = 安全阀，也是漏洞：孩子可能只玩游戏。  
- 旧金币玩法若存在，官方已不再维护文档。

**对书戏**

- 「本集首次通关才掉落」+「每日最多 N 件」直接可抄。  
- 贴纸贴场景 ≈ 给花果山/龙宫贴装饰，比钱包合适。  
- 若做时长限制，巩固游戏不要默认豁免，或单独配额。

### 2.5 ABCmouse — 完整经济，也是反面教材

**事实**

- 新 App *ABCmouse: Kids Learning Games*（trackId 6460300848）：Tickets and Rewards；Play areas 含 Hamster、Pet Town、Safari、Aquarium、Bot Beats；kidSAFE+ COPPA。[iTunes Search](https://itunes.apple.com/search?term=ABCmouse&entity=software&country=us)  
- CSM：完成活动得 tickets，换服装/宠物等；可买 avatar、room、fish tank、hamster track；界面忙，**学习被购物分心**；家长可调级别与时间。[CSM](https://www.commonsensemedia.org/website-reviews/abcmousecom)

**推断**

- 五款里最接近「学完去商店装修」。  
- 宠物镇是付费探索区的一部分，不是纯学习反馈。

**对书戏**

- 可以有房间，**不要有通用票券商店**。  
- 若以后要「宠物」，用剧情角色陪伴，不要做仓鼠赛道类无叙事玩法。

### 2.6 PBS KIDS Games — 无经济也能留人

**事实**

- 280+ 免费课标游戏；英/西；家长资源（学习目标、本地台）。无金币/房间文案。[iTunes](https://itunes.apple.com/search?term=PBS%20KIDS%20Games&entity=software&country=us)  
- CSM：网站游戏移植；Grownups 小链。[Games 评测](https://www.commonsensemedia.org/app-reviews/pbs-kids-games)  
- PBS KIDS Video：**自动连播且无法关闭**，限时更难。[Video 评测](https://www.commonsensemedia.org/app-reviews/pbs-kids-video)  
- [X @PBSKIDS](https://x.com/pbskids) 2025-01-30：Games app 270+ 游戏。

**推断**

- IP 角色 mini-game 本身就是奖励。  
- 自动连播是儿童产品的明确反模式。

**对书戏**

- 已有 108 集角色与场景，先让「看完/答对」足够爽，再加房间。  
- 混合演出合同已禁止整集 `<video>` 连播，与 CSM 结论一致，必须保持。

## 3. 机制拆解：儿童学习奖励的五种回路

| 回路 | 代表 | 闭环 | 风险 | 书戏适用 |
|---|---|---|---|---|
| A. 课完选物进房间 | Khan | 完成 → 自选 1 件 → 房间立刻可见 | 收藏膨胀；与课无关的炫物 | **首选 MVP** |
| B. 星星攒包装饰场景 | Lingokids | 不同活动 → 星 → 5 星开包 → 贴纸贴场景 | 日重置可能挫败；开包随机 | 第二期，若房间已成立 |
| C. 票券进商店 | ABCmouse | 完成 → 票 → 商店买宠物/家具 | 「为买而学」；CSM 明确批评 | **不做** |
| D. 课末星星/音效 | Duolingo ABC | 完成 → star / 庆祝 | 过刺激；无长期物 | 拍级反馈默认有，可关 |
| E. 角色即奖励 | PBS | 玩角色游戏 | 无长期收集 | 演出本身已覆盖 |

**建议：** MVP = D（每拍反馈）+ A（集末选物进房间）。不做 C。B 仅在 A 验证留存后再加。E 已由混合演出承担。

## 4. 与书戏现有结构如何接

现有三层（`00-总设计.md`）：

1. **大地图**：108 集路径、通关勾。  
2. **场景戏**：一句一拍，sprite / clip / hybrid，可停、可选、可答题。  
3. **巩固页**：生词、章末题。

奖励应挂在这三层上，不另开「商城首页」。

```text
大地图（花果山路径）
  └ 集节点：通关勾 + 该集掉落物缩略图
场景戏（拍）
  └ 答对/看完：短庆祝（D），不掉永久物
巩固页
  └ 本集首次达标：打开「选一件」面板（A）
角色房间（新层，从大地图入口进入）
  └ 按角色分槽：悟空洞府 / 唐僧禅房 / 龙宫 / 花果山公共厅
```

入口建议：

- 大地图角落一个「角色房间」按钮，不要盖住下一集。  
- 选物动画播完后，提供「去房间看看」和「下一集」双按钮；默认焦点在「下一集」，避免奖励劫持学习路径（Khan 用隐藏 Home 防中途退出，书戏用默认焦点防奖励劫持）。

## 5. 推荐方案（产品规格）

### 5.1 目标与非目标

**目标**

- 孩子能指着房间说「这是我学第 1 集拿到的金箍棒模型」。  
- 奖励可见、可复述、与课文绑定。  
- 家长能关庆祝音、能限每日学习分钟数、孩子碰不到任何支付。

**非目标（明确不做）**

- 通用金币 / 票券 / 商店货架。  
- 饥饿/死亡/便便等 Tamagotchi 惩罚。  
- 随机抽卡、稀有度逼肝。  
- 整集视频自动连播当奖励。  
- 用奖励解锁**剧情主线**（剧情按集推进；奖励只装饰，不锁故事。若要对理解做门槛，用巩固题，不用家具）。

### 5.2 掉落规则（防刷）

采用 Lingokids 的「不同活动才计」+ Khan 的「当场选一件」：

| 事件 | 是否掉落 | 说明 |
|---|---|---|
| 本集**首次**看完所有必选拍 | 否 | 只给短庆祝 |
| 本集**首次**巩固题达标（建议 ≥70% 或「必答题全对」） | 是 | 打开 3 选 1 |
| 重看本集 / 重做巩固 | 否 | 可练习，不刷物 |
| 分支选项（非对错） | 否 | 避免「为刷而选」 |
| 每日已掉落 ≥ `daily_drop_cap`（建议 2） | 否 | 提示「明天再来，房间等你」 |

3 选 1 的候选必须：

- 属于本集 `reward_pool`（与剧情相关）。  
- 孩子尚未拥有；若池子耗尽，给「染色/摆放变体」或「纪念贴纸」，不要给空奖励。  
- 选完立即 `owned=true` 并写入房间槽位默认坐标。

### 5.3 房间与角色槽

建议先做 **4 个房间**，对应西游前段高频空间，后续可加：

| 房间 id | 主人 | 收藏维度（学 Khan 的垂直槽） | 例 |
|---|---|---|---|
| `room.huaguo` | 公共 / 众猴 | 山石、果、瀑布纪念品 | 仙石碎片 |
| `room.wukong` | 悟空 | 兵器、冠、洞府小物 | 金箍棒模型 |
| `room.tang` | 唐僧 | 经卷、袈裟、禅杖 | 锦襕袈裟碎片（自绘，非抄 Little Fox） |
| `room.longgong` | 龙王 | 珠、兵器架、水族 | 定海神针座 |

摆放：

- 每个物品有 `slot`（墙 / 架 / 地 / 角色穿戴）。  
- MVP 自动放入预设槽，孩子可在房间里拖到允许网格。  
- 不做自由商城目录。

### 5.4 拍级反馈（D）

每拍答对：

- 角色头像 bounce + 短音效 + 可选粒子。  
- 文案学 Khan：表扬行为（“You found the word *stone*.”），少用空 “Yay!”。  
- 家长可关音效与粒子。  
- **禁止**拍级掉永久物，否则一句一刷。

### 5.5 家长控制（最低集）

学 Khan 的内容闸门 + Lingokids 的 Gate，不抄「游戏豁免」。

| 控制 | 默认 | 说明 |
|---|---|---|
| Parental Gate | 简单算术或出生年 | 进入家长区、任何付费（若将来有） |
| 庆祝音 / 粒子 | 开 | 可关 |
| 每日学习分钟 | 关 | 可选 15/20/30；到点结束在拍边界，不中断一句音频 |
| 房间入口 | 开 | 可隐藏，只留地图+演出 |
| 自动播放下一拍 | 关 | 与 PBS Video 反模式对齐 |

没有支付就不需要商店 Gate；但 Gate 仍要挡住「家长区」。

### 5.6 文案与版权

- 掉落物名称、立绘必须自写自绘，或来自书戏自有资产。  
- 不可用 Little Fox 英文简写、截帧、角色造型作奖励皮肤（见 `docs/需求/DS--调研资料.md` 版权红线）。  
- 公版情节可用：金箍棒、花果山、龙宫作为**概念**，美术重做。

```json
  "progress": {

    "date": "2026-09-01",
    "drops": 1,
    "learning_seconds": 420
  }
}
```

物品目录（内容包，非存档）：

```json
{
  "id": "item.stone_shard",
  "room": "room.huaguo",
  "slot": "shelf",
  "episode": "episode_001",
  "title_en": "Stone Shard",
  "title_zh": "仙石碎片",
  "caption_en": "The rock split. You kept a piece of the story."
}
```

**禁止字段：** `coins`, `tickets`, `rarity`, `hunger`, `death`。

本地可先 JSON；若多设备再迁 SQLite。与现有 vocab DB 分开，避免奖励污染词库发布门。

## 7. 状态机

### 7.1 集奖励

```text
idle
  → episode_playable
  → quiz_available          # 巩固页打开
  → quiz_passed_first_time  # 且 daily.drops < cap
  → choice_open             # 3 选 1
  → item_granted            # inventory.owned = true
  → room_preview            # 可选，2–4 秒
  → next_episode_prompt
```

重入：`quiz_passed` 但 `drop_granted` 已 true → 只显示「你已经把仙石放进花果山了」。

### 7.2 房间

```text
closed
  → open (from map)
  → inspect_item (caption + 英文名朗读)
  → rearrange (optional, grid)
  → closed
```

房间内不掉新物，避免「进房间刷奖励」。

### 7.3 明确不采用的宠物状态机

GitHub `ykhli/AI-tamago` 的 `hunger/happiness/health/poop` + LLM tick + 死亡条件，以及 PyPet 的 violent/starve，**禁止进入儿童学习路径**。若以后要「陪伴」，只用：

- `mood`: `glad | calm | sleepy`（由「今天是否学过」温和变化，不惩罚）  
- 无死亡、无便便、无忽略惩罚

## 9. 分期落地（与混合演出对齐）

不阻塞第 1 集演出。房间是 M2 级，但掉落数据可先写进集方案。

### P0 — 拍级反馈（1–2 天）

- 答对：头像 bounce + 可关音效。  
- 无库存。  
- 验收：家长关音效后无声。

### P1 — 第 1 集 3 选 1 进花果山房间（建议下一迭代）

- `episode_001` 巩固达标后 3 选 1。  
- 单房间 `room.huaguo`，自动入槽。  
- 大地图入口可进房间看 1–3 件。  
- 验收：重看本集不再掉落；房间能朗读物品英文名。

### P2 — 日上限 + 家长分钟数

- `daily_drop_cap = 2`。  
- 可选 15/20/30 分钟，在拍边界停止。  
- 验收：改系统日期再测（开发开关），正式版按本地日历。

### P3 — 多房间 + 轻拖拽

- 悟空 / 唐僧 / 龙宫随剧情解锁房间，不锁剧情。  
- 网格拖拽，不做商店。

### P4 — 仅当 P1 留存数据证明「孩子会主动进房间」

- Lingokids 式贴纸层（给场景贴小贴纸）。  
- 仍无通用货币。

## 11. 风险与度量

| 风险 | 来源 | 缓解 |
|---|---|---|
| 为奖励而赶课、不听音频 | ABCmouse CSM；Lingokids 日重置挫败 | 掉落在巩固后；默认焦点「下一集」；重看不掉 |
| 庆祝过刺激 | ABC 用户评 | 可关音效/粒子 |
| 奖励锁剧情 | 常见游戏化滥用 | 家具不锁主线 |
| 版权 | Little Fox | 自绘自写 |
| 把 GitHub Tamagotchi 当儿童方案 | AI-tamago / PyPet | 方案第 7.3 节黑名单 |

建议只看三个数（有遥测再采，无遥测就观察试用）：

1. 巩固完成后选择「去房间」的比例（期望 20–40%，过高说明奖励劫持）。  
2. 房间停留中位时长（期望 15–45 秒）。  
3. 次日是否仍打开下一集（房间不该替代阅读）。
