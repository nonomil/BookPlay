# 当前状态

## 已有实现

- `storybook.js` 已支持 Minecraft 路由、完整跨页、字幕、点词、生词本、朗读、进度和小测。
- `storybook.css` 已支持桌面左右分栏和 900px 以下上下布局。
- `storybook-route.test.mjs` 已有 7 项 Minecraft 路由/响应式静态合同测试。

## 当前视觉缺口

- 学习栏层级偏平，正文、提示、词义和页导航缺少明确分组。
- glossary 目前只在点击单词后把释义写进一行提示，没有常驻重点词卡。
- 小测验是普通按钮集合，缺题号、选项编号、状态文案与完成感。
- 移动端虽可滚动，但正式视觉需要锁定 44px 触控目标、无横向溢出和焦点可见。

## 保留修改

工作区整体未形成 Git 基线，绝大多数文件显示为未跟踪。所有现状都视为用户工作，禁止清理、回滚或重建。
