> 本包把 T00–T02 的源码与浏览器样板结果交给下一位执行者；真机整局、原声提取和后续集扩展仍未完成。

## 现状一句话

主角和小怪已经改成慢速、四向、`idle / walk / attack` 分离，主角先在屏幕内移动、靠近边缘后地图才平滑滚动；输入中断和对话关闭也已清理。当前只证明了源码契约与 1280×720 浏览器样板，不能代称触屏、TV、离线语音或“移动 → 词球 → 撞击 → NPC → Boss → 返回”的真机通过。

接手第一步：先读本 README、`背景上下文/关键发现.md`、`行动项/下一步行动.md`，再按协议向用户复述需求、证据等级、第一步和禁区；用户确认后，若有设备先安装并核对准确 APK，再跑 T03–T10。

## 当前目标与完成边界

目标是让孩子完成知识巩固后看到“进入降妖记 / 暂时跳过”，进入同集大地图完成词球捡投、六道具、NPC 剧情答题、Boss 对战和返回恢复，并能在断网时播放有证据的语音。**方案完成不等于游戏修复完成**；本包把两者的证据边界分开。

### 已完成（代码/测试/浏览器证据）

- `prj/engine/game-core.js`：4×4 世界、保留摇杆幅度、斜向限幅、横竖视口补偿、边缘镜头纯函数、六道具和 NPC/Boss 规则。
- `prj/engine/game.js`：慢速常量、四向方向切换、主角/小怪 `idle / walk / attack` 独立资源，攻击期间 `moving=false`，边缘平滑镜头，状态恢复和对话关闭清理。
- `prj/engine/game-input.js`：单一 `pointerId`、`pointerup/cancel/lostpointercapture`、`blur/pagehide/visibilitychange` 清理，弹层打开时清零意图。
- `prj/engine/game-audio.js` 与 `content/game/audio/ep1.json`、`ep5.json`：静态索引优先、迟到回调代际令牌、停止/重听；`validate --eps 1,5` 通过。
- `prj/engine/lesson.js`：巩固完成后已有进入游戏/暂时跳过入口；入口是否在真实题目流程中自动弹出仍需现场回归。
- 全仓 `npm.cmd test`：408 pass / 0 fail / 0 skipped；定向 JS 60 pass，定向 Python 37 pass，打包/运行时/音频组合 21 pass。
- 浏览器 1280×720 已观察 ep1、ep5 中央先走、越边缘后滚图，以及攻击时停止移动和对话关闭清理。

- 无 ADB 设备：尚未安装 APK，也没有真实触屏、双指移动+投掷、TV 遥控、WebView 音频、后台恢复、系统音量或真机录屏证据。
- 尚未在现场贯穿移动 → 词球捡投 → 小怪撞击 → NPC 答题 → Boss → 返回恢复；现有契约测试不等于整局操作通过。

- T03–T11（地图点位真实消费、幂等奖励、Boss 回合锁、自动邀请层、三白名单闭包、APK 新装/升级、c01 扩展）仍需后续执行。
