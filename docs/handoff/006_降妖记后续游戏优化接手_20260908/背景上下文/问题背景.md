# 降妖记后续游戏优化背景

> 本轮要把已有大地图样板推进为可验证的整局游戏，而不是继续堆一套新引擎。

## 问题陈述

用户要求大地图玩法完整参考 `word-memory-map`：主角上下左右慢速移动，小怪头顶英文词，捡中文词球并投掷道具；地图内再触发 NPC 对话答题和大 Boss 对战。巩固完成后应自动出现“进入游戏 / 暂时跳过”，学习结果不能丢失。

试玩反馈进一步指出：主角和小怪动作太快、看不清四向走路；走路动作与挥舞兵器混在一起；句子弹窗关闭后仍停留或继续占输入。用户随后要求继续，并把后续优化交给新的 AI。

## 项目背景

当前仓库把大地图放在 `prj/engine/game.js`，纯运动/规则在 `prj/engine/game-core.js`，输入在 `prj/engine/game-input.js`，语音在 `prj/engine/game-audio.js`；Android 实际运行副本在 `android/app/src/main/assets/engine/`。关卡和地图源数据位于被整体忽略但必须保留手写源的 `content/game/`。

大地图不是完全没有接入：已有 `game.html?ep=N` 路由、词球捡投、小怪、NPC、Boss 跳转及 lesson 入口。但设计声明、源码行为和真实设备证据曾不同步，本包只把可证据支持的 T00–T02 结果固化。

## 影响范围

- 体验：移动速度、镜头、四向动画、攻击状态、双指输入、弹层输入锁。
- 游戏闭环：词球 → 小怪撞击/反击 → NPC 题 → 第二波 → Boss → 返回不重开。
- 学习闭环：巩固完成 → 自动选择进入或跳过；跳过不影响学习结果。
- 资源闭环：已有词句静态音频、审核后的原声片段、APK/阶段包三白名单。
- 设备验证：Android WebView、触屏、TV 遥控、后台/音量/断网播放。

## 接手边界

- ✅ 已确认：当前代码和测试确实包含上述运动、输入和语音适配；浏览器样板已看到部分效果。
