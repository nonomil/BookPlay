# 风险与阻塞

## 当前阻塞

### 卡点 1：ADB 当前没有设备

- **影响**：无法安装/启动准确 APK，无法证明触屏、双指、TV、WebView 音频、后台和系统音量。
- **需要的帮助**：连接目标 Android/TV，提供 `adb devices -l` 中的 serial 和可录屏环境。
- **临时绕过方案**：继续浏览器 1280×720 数值断言和契约测试，但所有报告明确写“浏览器样板/待真机”。

### 卡点 2：没有真机录屏与完整链路日志

- **影响**：无法复核用户所说“移动不正常/游戏乱”的视觉断点，也无法确认 NPC/Boss 返回实际顺序。
- **需要的帮助**：允许设备录屏或提供按 V01–V28 的手工录像/事件日志。
- **临时绕过方案**：使用 `BookPlayGameDebug.step` 和 DOM 快照定位逻辑断点；不能把快照称录屏。

### 卡点 3：原声来源和新编台词未完成审定

- **影响**：当前只可声明已有词句静态索引，不能声明视频原声逐句接入。
- **需要的帮助**：提供原视频文件、来源标识、时间段、speaker 和试听确认人/日期。
- **临时绕过方案**：先发布已有静态词句；原声候选保持 pending，新增台词单独配音。

## 重要风险

### 风险 1：70 条未提交修改混在工作区

- **影响**：任何回滚、清理或生成器覆盖都可能破坏其他任务和 `content/game/` 手写源。
- **缓解**：每次操作前后记录 status/diff；只改明确归属文件；不执行 destructive git 命令。

### 风险 2：三白名单漏登记会静默缺资源

- **影响**：源码浏览器可用，但阶段包或 APK 实际消费者缺 JS/JSON/音频。
- **缓解**：逐文件检查 `COMMON_FILES`、APK 内置闭包、`ENGINE_FILES`，并解包检查 `assets/public/engine`；新增测试门禁。

### 风险 3：多套历史口径诱发错误回退

- **影响**：把 347/357 当当前基线、把 3×3 当世界大小或恢复立即居中，会重新引入已修复问题。
- **缓解**：本包采用 408 和 4×4；冲突按“交接包 → 凝蜕 → 定向 transcript”处理，仍不明就问用户。

### 风险 4：把设计/契约测试误当产品通过

- **影响**：NPC/Boss、入口和语音可能在真实顺序或设备上仍断开。
- **缓解**：每项报告区分 `✅ 已验证`、`🔲 待验证`、`❌ 已否决`；不使用 debug 跳关替代正常流程。

### 风险 5：速度参数在不同设备视觉不一致

- **影响**：浏览器约 23 px/s 不代表低端 WebView、不同 DPR 或刷新率同样慢。
- **缓解**：先做实验 1 的同包轨迹；仅基于设备证据调参，保持四向 GIF 与攻击锁分离。

## 停止条件

- 若交接包、凝蜕、transcript 对同一事实冲突，先停主线问用户。
- 若测试低于 408、出现失败或需要跳过旧测试，停止扩玩法，先修回归。
- 若新资源未登记三白名单或包内实际路径不明，停止发布 APK。
