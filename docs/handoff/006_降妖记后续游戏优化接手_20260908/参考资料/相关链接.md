## 参考使用顺序

1. 先读本包和当前验收报告，确定哪些是事实。
2. 再看 `word-memory-map` 的运行行为，记录速度、碰撞和摄像机对照，不先复制代码。
3. 用本项目 `game-core` / `battle-core` 设计最小契约，再参考 pet-battle 的视觉回合。
4. 对话 UI 只取探索地图参考中的播放/焦点经验；字段仍以本项目 `sourceNodeId/speaker/audioRef` 契约为准。
