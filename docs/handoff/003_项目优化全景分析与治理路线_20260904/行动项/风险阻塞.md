## 卡点列表

### 卡点 1：git main 0 提交
- **影响**：全部源码与文档无回滚点；一次误操作（如 `git clean`）不可恢复；P2.5 存储迁移等高风险动作无底线
- **需要的帮助**：无外部依赖，用户点头即可执行 P0
- **临时绕过方案**：无（这正是要消除的卡点）

### 卡点 2：P2 prompts 硬编码过期基线 267
- **影响**：5 个提示词的验收标准与实际 272 冲突，接手会话可能误判"测试坏了"或反向"修"到 267
- **需要的帮助**：无——本包落盘时已将 5 处改为 272（`grep -rn "当前基线" docs/plans/2026-09-04-西游记多形式学习闭环P2/prompts/` 可复核）
- **临时绕过方案**：已解决；若用户不认可改动，`sed -i 's/当前基线 272 个测试/当前基线 267 个测试/'` 一行可回退

### 卡点 3：P2 prompts 约定"不 commit"与基线策略冲突
- **影响**：即使完成 P0，后续特性仍会以无提交状态堆积
- **需要的帮助**：需用户裁决是否把各 prompts 验收标准改为"完成后 commit"
- **临时绕过方案**：会话结束前人工 commit

### 卡点 4：真机验证环境缺失
- **影响**：缺口二（麦克风授权、WebView 实录、遥控器巡检、APK 全链路）只能登记不能闭环；实验 3 无法由 agent 独立完成
- **需要的帮助**：需要用户提供的安卓真机 / 电视与遥控器 / 麦克风，并配合安装测试 APK
- **临时绕过方案**：桌面浏览器实测继续覆盖功能层，真机项持续挂 🔲

### 卡点 5：凝蜕层与 transcript 路径不可用
- **影响**：handoff 技能的"交接包 → 凝蜕 → transcript"三级回溯链在本项目降级为单级
- **需要的帮助**：环境限制（本项目无 `.claude/` 目录）；若需 transcript 回溯，路径要向用户索取
- **临时绕过方案**：交接包按"完整模式"自包含关键证据，降低对回溯链的依赖
