## S2 · 配音工坊 `dub.html/css/js`

- URL：`?ep=N`（jttw，旧链接不变）/ `?series=minecraft&book=N` / `?series=mikey-jj&book=N`；`&node=`（jttw 深链）、`&back=player`。
- 流程：台词本列表 → 逐句（听原声 / 录音【可选"画面伴录"=静音视频对画面配，仅 jttw】/ 听我的=视频压声0.15+童声 / 1-3 星 / 保存·重录·删除）→ 放映厅（`?theater=1` 或按钮）逐场景连播：已配=压原声放童声、未配=原声；无视频系列=插图幻灯片。
- 奖励：每本书首次保存 ≥1 段 → +5SP（幂等），配完全集结束页提示。
- 降级：无麦隐藏录音、IDB 缺失提示"仅本次有效"、quota 提示删旧配音、视频缺失退化插图+音轨。
