## 已知坑

1. IDB 只读事务里先 `await request` 再挂 `tx.oncomplete` 会永远挂起（事件已错过）——先存 `done = txDone(tx)`。
2. MC 页级时间轴漂移（见关键发现 #1）。
3. 静态合同测试会强制：所有 `.html` 引 `tv.css`+`tv-remote.js`；`map.css/map.js` 版本号必须一致且为数字。
4. 内置 Chromium 截图偶发 `capture failed for guest`——等 600ms 重试即可。
