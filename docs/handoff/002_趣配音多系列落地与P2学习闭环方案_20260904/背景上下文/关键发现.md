# 关键发现（已验证 ✅ / 推测 🔲）

## 数据事实（✅ 已验证，读源文件确认）

1. **三系列书结构不同**，是趣配音泛化的核心约束：
   - 西游记 jttw：`prj/data/dialogue_stories/ep{N}.json`，`nodes[]`（`node_id/speaker/text_en/text_zh/illustration/audio_start/end` 秒 + `patterns/puzzles/quiz/official_words`）。
   - 我的世界 minecraft：`prj/data/storybooks-minecraft/book{N}.json`（5 本），`pages[]` + `sentences[]`（句级 `start_sec/end_sec` + **逐句 MP3** `assets/minecraft/*/sentences/*.mp3` + glossary）；**页级时间与句级漂移**（book1 页0 页级 0→38.65s vs 句级 158.35→165.17s）→ 必须句级优先。
   - Mikey & JJ mikey-jj：`prj/data/storybooks-mikey-jj/book{N}.json`（10 本），`pages[]` + `sentences[]`（**毫秒**、`zh`、`speaker.label`、逐句 MP3、词级 `words[]` 时间）——三套数据里配音条件最好的。
2. **阶段包媒体裁剪**：`prj/tools/pack_datapack.py` 的 `SKIP_PREFIXES` 含 `assets/lf_ep*`（西游记整集 MP3）→ 包内 `book.audio` 缺失；`assets/video` 在 INCLUDE_DIRS 里 → **听原声必须回退视频原声**。
3. **两套绘本的播放器与 URL**：`storybook.html?series=minecraft|mikey-jj&book=N&ui=unified-v3`（`storybook-route.js`）；地图 `map.html?series=…`；书架 `shelf.js` 生成链接。
4. **v3 气泡错位根因**：`storybook-v3.css` 曾 `body.sb-ui-v3 #sb-speaking-bubble { display:none !important }`，只显示按 PDF 归一化坐标投影的红框 `#sb-bubble-locator`（`storybook.js updateBubbleLocator` + `storybook-ui.js projectRelativeBox`）——坐标本身不准，故红框错位。
5. **地图小人现状**：非 jttw 系列 `ROUTE_COMPANION_SPRITE_URL=""` → 内联 SVG 黄色占位小人（悟空画风）；且 `placeCompanion` 仅在有进度（`current/done` 节点）或路线解锁时创建。jttw 图集规格：`content/assets/generated/jttw-route-companion/transparent/wukong-walk-atlas.png`，3072×2048 = 8 帧 × 384px，4 向（east/south/west/north）× 512px，CSS `background-size:800% 400%`。
6. **图集合成管线已有**：`prj/tools/build_jttw_route_atlas.py`（抠最大连通域/脚底基线 BASELINE_Y=466 对齐/west 由 east 镜像/打包），源 sheet 是 4 列×2 行的 384×512 网格。本会话已参数化 `--character`（wukong 默认行为不变，mikey → `mikey-jj-route-companion` 目录 + `mikey-walk-*` 文件名 + 支持 east 也来自生成 sheet）。
7. **runtime 路径映射**：dev 服务器 `/data` → `content/`（serve.py），所以地图精灵 URL `/data/assets/generated/...` 对应 `content/assets/generated/...`（jttw 图集所在）。
8. **开源调研结论**（写进方案）：录音 MVP 用原生 MediaRecorder（老安卓 X5 回退 [recorder-core](https://github.com/xiangyuecn/Recorder)，MIT，单文件 mp3 输出）；"保留背景只换人声"两档：卡拉OK压声（已做，video.volume=0.15）与 Demucs 离线人声分离（P3，CPU 5-15min/首量级）。
