# 图解 · 学习闭环与趣配音架构

## 图 1 · 每集五步旅程与本轮落点

一句话结论：趣配音是五步旅程里唯一新增的环节（④ 配），其余环节要么已覆盖、要么列入 P2。

```mermaid
flowchart LR
  subgraph 每集五步旅程
    A[① 看 wala 场景视频切片] --> B[② 学 词卡+内嵌题]
    B --> C[③ 练 知识巩固 quiz]
    C --> D[④ 配 趣配音 · 本轮P0]
    D --> E[⑤ 熏 磨耳朵]
  end
  D -.每书首次 +5SP 幂等.-> SP[(bookplay_sp)]
  D --> F[放映厅: 自己的声音看整本]
  P2[P2 待接入: 词卡跟读 / 听音识景 / 亲子互动卡 / 熏听增强] -.提示词就绪.-> B
  P2 -.-> C
  P2 -.-> E
```

## 图 2 · 趣配音多系列归一与听原声回退链

一句话结论：三套书结构差异被 `normalizeDubBook` 收敛成统一场景模型；所有"放原声"的地方走同一条四级回退链，因此阶段包缺 MP3 也不受影响。

```mermaid
flowchart TD
  J[jttw dialogue_stories nodes 秒] --> N[normalizeDubBook]
  M[minecraft pages+sentences 秒 句级MP3] --> N
  K[mikey-jj pages+sentences 毫秒 句级MP3+zh+speaker] --> N
  N --> S[统一场景 scenes: nodeId/speaker/textEn/textZh/插图/from/to/sentenceAudios]
  S --> U[工坊: 听原声→录音→听我的→星级→保存]
  S --> T[放映厅: 已配=压原声+童声 / 未配=原声; 无视频=插图幻灯片]
  U --> IDB[(IndexedDB bookplay_dub_audio_v1 Blob)]
  U --> LS[(localStorage bookplay_dub_v1 + reward 幂等)]
  subgraph 听原声四级回退链
    L1[① 句级 MP3 MC/MJ] --> L2{有?}
    L2 -- 否 --> L3[② 整集 MP3 切片 jttw dev]
    L3 --> L4{有?}
    L4 -- 否·阶段包 --> L5[③ 视频原声切片 jttw]
    L5 --> L6{有?}
    L6 -- 否 --> L7[④ TTS /api/tts]
  end
```
