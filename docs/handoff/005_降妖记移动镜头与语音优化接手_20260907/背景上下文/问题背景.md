# 问题背景

> 孩子需要一条能进入、能操作、能听懂、能退出的游戏学习流程。

## 起因与业务目标

BookPlay书戏以每集西游记内容承接学习、巩固和游戏。用户期待完成知识巩固后自动询问是否进入游戏，也允许跳过，不影响已经取得的学习结果。

旧004交接描述地图、NPC和Boss已落地，但用户仍找不到完整大地图环节，随后反馈人物移动异常、地图跟着动、游戏缺少语音。当前任务因此从“按旧包真机验收”转为“先定位体验差异并形成优化方案”。

用户要求参考word-memory-map的词球捡投与运动机制，替换地图和角色；NPC剧情参考跨项目对话文档，Boss表现参考pet-battle-template。typing-defense是讨论过的扩展，不是当前触屏主线必做项。

## 会话推进与完成边界

1. 用户要求按顺序读004 README、关键发现、下一步行动，并已确认接手。
2. 早期会话修改过入口和打包相关文件；这些修改在当前工作区仍未提交，不能归入本次文档交付。
3. 用户随后要求“详细的文件夹和计划”，并明确选择边缘平滑镜头。
4. 前轮生成九份优化文档、一个入口索引，并给旧玩法手册增加说明。
5. 本次用户指定handoff技能，草稿确认后生成005包；没有继续改游戏代码。

## 术语与范围

| 术语 | 本项目含义 |
|---|---|
| 地图 | game.html / game.js，角色移动、小怪、词球、NPC与Boss门 |
| Boss | battle.html / battle.js，词汇回合战与结算 |
| c01 | 第1–7集；样板先做ep1和ep5 |
| 三白名单 | 阶段包显式文件、APK内置闭包、APK引擎文件清单 |
| 原声 | 从指定视频/音轨和经审核时间段提取的真实台词，不等于任意TTS |

## 接手边界

目标是改进现有运行链，不新建一套游戏。源码诊断和Node通过不证明真机通过；当前媒体文件存在也不证明APK携带或可播放。
