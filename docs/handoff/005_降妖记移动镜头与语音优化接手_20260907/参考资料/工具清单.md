# 工具清单

> 已执行的只读命令与拟执行命令必须分开记录。

## 本次已用工具

| 工具/命令 | 作用 | 证据边界 |
|---|---|---|
| rg、Get-Content、Get-ChildItem | 定向源码、文档和目录核查 | 源码事实，不是真机行为 |
| git status --short、git rev-parse HEAD | 工作区快照 | 保留脏改动，不提交/重置 |
| node --version、python --version | 运行时版本 | 不证明额外浏览器/FFmpeg已配置 |
| npm.cmd test | 全仓Node测试 | 357通过，见本包实录 |
| Get-FileHash -Algorithm SHA256 | 三个核心源文件和现有APK识别 | 不等于APK与源码闭包完全匹配 |
| apply_patch | 新增交接文件、追加索引 | 只动本包和索引 |
| 可用工具清单及Get-Command zcode | 检查接手接口 | 无可用调用入口，没有派发 |

## 接手后的现有命令

所有命令从G:/Game/BookPlay书戏运行，且接手确认后才执行实验/改造。

```powershell
npm.cmd test
node --test prj/engine/game-core.test.mjs prj/engine/game-page.test.mjs
node --test prj/engine/tv-ui.test.mjs
python -X utf8 prj/tools/build_game_levels.py --eps '1,5' --check
python -X utf8 prj/tools/serve.py --port 8810
```

--check只校验已有派生文件，不生成。build_game_levels的parse_eps已读，支持逗号和范围。内容源修改后先按实施计划生成样板再校验，不盲目覆盖既有手改。

本地服务测试地址为http://127.0.0.1:8810/engine/game.html?ep=1，ep5同理。必须用已有serve.py映射data/assets，而不是仓库根任意静态服务。
