# 解决方案

## 推荐顺序（审查后再执行）

### A. 恢复可开机（P0）

1. 确认 `J:\extlinux\extlinux.conf` 仍是  
   `boot=UUID=2805-2347 disk=UUID=ebd704cf-8f34-408a-82ff-a733c5f9faff`
2. **不要**再改 UUID。
3. 若 Codex 同意修 STORAGE：在 **Linux 或设备自身** 对 p2 做 `e2fsck -p` / `-y` 回放 journal。Windows Cygwin 1.44.5 对本机物理盘权限失败，不建议作为写路径。
4. 插回机器，看 overlay 红字是否消失。

最小反证：若 e2fsck 后 overlay 仍 FAIL，则不是“仅日志”问题，需要串口/`/var/log/boot.log`。

### B. 游戏列表（P1，开机成功之后）

两种布局，选一：

- 把 K: 根下各机种子目录移进 `K:\roms\`（即 `migrate_roms` 的目标结构）
- 或确认 bind 的是整卡根（改 automount 不现实，系统只读 squashfs）

商家卡常见“根即 roms”。`to_jelos.bat` / `to_batocera.bat` 只改目录名（lynx/wswan），不建 `roms/` 包装。

### C. 书戏 Port（P2，开机且 Ports 可见之后）

已就位，真机验收：

- Ports → BookPlay书戏
- 看 `K:\ports\bookplay\log.txt`、`server.log`
- 预期：Servo 非 Chromium；TTS/麦克风可能不可用；1GB RAM 用 `memory_profile=tight` + `swap-tuning.on`

回滚：删 `K:\ports\BookPlay.sh`、`K:\ports\bookplay\`、`K:\ports\Retsurf.sh`（可选保留共享 `K:\ports\retsurf\`）。

## 不推荐

| 方案 | 原因 |
|---|---|
| disk= K: | 已失败 |
| 格式化 STORAGE | 丢掉 `.config`、存档、主题 |
| 重刷整卡 | 可作最后手段，会丢掉 K: 上书戏 5.7G 与预装 ROM |
| 继续拷资源 | 开机都没有，拷了也进不去 |
