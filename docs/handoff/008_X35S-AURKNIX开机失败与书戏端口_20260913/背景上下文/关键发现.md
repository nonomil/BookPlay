# 关键发现

一句话：开机失败是因为 **`/storage` 被指到了不支持 overlay 的文件系统**；书戏 Port 部署在 K: 上，与这次开机崩溃不是同一层。

## 已验证

1. **`tmp-*.mount` 是 overlay，上层必须在 `/storage`**  
   `usr/lib/systemd/system/tmp-assets.mount`：  
   `upperdir=/storage/assets,workdir=/storage/.tmp/assets-workdir`  
   同类还有 cores / database / joypads / overlays / shaders。

2. **exFAT 不能当 overlay upper**  
   对照 [Lakka-LibreELEC #1848](https://github.com/libretro/Lakka-LibreELEC/issues/1848)：同样 `Failed to mount tmp-assets.mount`，内核日志是 `overlayfs: upper fs missing required features`。NFS/exFAT 都缺 tmpfile / RENAME_WHITEOUT / xattr。

3. **本会话确实改过 `disk=`**  
   错误值：`disk=UUID=7BFA-BC4C`（K: exFAT）  
   已回退：`disk=UUID=ebd704cf-8f34-408a-82ff-a733c5f9faff`  
   备份：`J:\extlinux\extlinux.conf.bak`

4. **STORAGE 超级块仍在、UUID 匹配、根目录完整**  
   从 `/dev/sdf2` 读超级块：magic `0xEF53`，label `STORAGE`，uuid 与 `extlinux` 一致，state=1（clean 位），但 **incompat 含 NEEDS_RECOVERY（日志未回放）**。  
   根目录含 `.config`、`.tmp`（含 `assets-workdir` 等）、`assets`、`roms`、`games-internal`、`games-external`、`mod.done`、`.configured`。  
   `es_systems.cfg` 是符号链接 → `/usr/config/emulationstation/es_systems.cfg`（squashfs 里存在，约 89551 字节）。

5. **游戏 ROM 在 K: 根下，不在 `roms/` 子目录**  
   ROCKNIX `usr/bin/automount`：外卡挂到 `/storage/games-external`，再 bind 或 overlay 到 `/storage/roms`。  
   若卡根就是 gba/nes/ports…，automount 期望的是 `games-external/roms/gba`。  
   另：`J:\ms_unsupported` 与 `K:\.ms_unsupported` 存在 → merged-storage overlay 关闭，走 bind。

6. **书戏 Port PC 抽检通过**  
   robocopy：目录 1175（复制 1040 / 跳过 135），文件 50708（复制 49201 / 跳过 1507 / 失败 0）。  
   视频 `ep*.mp4` 108，`lf_ep*` 108，`dialogue_stories/ep*.json` 108，`game/levels` 108。  
   HTTP：`/engine/home.html`、`ep1/50/108` 的 json/mp4/mp3 均为 200。  
   `content-manifest.json` 已改成 `kind: linux-port-full`，episodes 1–108。

## 推测（未闭环）

- 改回 UUID 后仍失败，最可能是 STORAGE **日志未回放 → 内核挂只读 → overlay 仍失败**。未在设备上抓 `dmesg`/`journalctl`，不能升级为已验证。
- 语言选择屏出现，说明 firstboot `update.sh` 认为要设 `system.language`；可能是 STORAGE 只读导致写 `system.cfg` 失败后反复进入。未验证。
- 把 `es_systems.cfg` 实体文件写到 **K:\.config** 对开机 **无帮助**：ES 读的是 `/storage/.config`，即 p2，不是 K:。

## 口径说明

- “K 盘满 / 游戏不识别”和“开机 overlay 失败”要分开。前者是 ROM 布局 + automount；后者是 `disk=` / STORAGE 可写性。
- 占用数字：删 fbneo 前 K: `df` 约 1.2G 可用；删后约 11G；拷书戏后约 12G 可用、used 29G/40G。书戏端口合计约 5.7G（data 5615 MB）。这些来自当时 `df`/`du`，不是精确字节账。
