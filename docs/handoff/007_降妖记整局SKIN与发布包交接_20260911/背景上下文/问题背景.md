# 问题背景

> 一句话：同一套降妖记 FLOW，1–54 只换皮；发布时 APK 轻、数据包重。

## 问题陈述

用户要的是可给孩子玩的整局，不是新引擎。地图要能走、镜头要跟、小怪/Boss 要像这一集的故事，而不是 54 关共用一只绿皮小妖。发布时不能把后面关的立绘全部塞进 APK。

## 项目背景

BookPlay / 豆豆龙英语：离线优先的西游记英语学习播放器。巩固课后进入「降妖记」：

1. `lesson.html` → 进入游戏 / 暂时跳过
2. `game.html` 大地图：捡词球、砸小怪、道具、NPC
3. `battle.html` Boss 问答对战
4. 返回地图，进度只写两枚 localStorage 键

引擎在 `prj/engine/`，数据在 `content/`，Android 壳在 `android/`。
