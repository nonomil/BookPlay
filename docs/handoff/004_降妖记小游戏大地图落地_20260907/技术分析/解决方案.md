# 解决方案：双页架构 + 数据管道 + 打包接线

## 1. 总体架构

```mermaid
graph LR
  subgraph 数据管道（构建期）
    A[content/dialogue_stories<br/>词库/台词/插图] --> D[build_game_levels.py<br/>--v2 派生]
    B[content/game/cast.json<br/>boss/NPC/主题分派] --> D
    C[content/game/maps.json<br/>区域布局] --> D
    D --> E[(content/game/levels/epN.json<br/>+ cast/taunts/sprites)]
  end
  subgraph 运行时（引擎页）
    E --> G[game.html?ep=N<br/>大地图探索]
    E --> B2[battle.html?ep=N<br/>Boss 对战]
    G -- 走近 Boss<br/>skip=intro,preview,waves&wrong= --> B2
    B2 -- from=game 结算返回 --> G
  end
```

## 2. battle.html（v1，Boss 对战模块）

- 阶段机：`intro → preview → waves×2 → boss → quiz → result`；`skip=` 支持 `intro,preview,waves,quiz`。
- 纯逻辑 `battle-core.js`（11 用例）：`buildLevel`（含 v2 map 字段透传）、`buildWaveQuestions`（错词插队）、`reorderBossWords`（Boss 词序错词优先）、`buildOrbSet`（同集干扰+确定性洗牌 seed=ep×1000+7+…）、`judgeHit`（连击 3=comboReady）、`settleRun`（星星三档）、`loadSprites`（注册表→walker GIF→占位三级回退）。
- Boss 表现（pet-battle 借鉴）：主角突进 `.is-lunge` → 120ms 命中闪光 `.game-battle-impact` + Boss 后仰 `.is-recoil` + 伤害浮字 `.battle-dmgpop`；音效 `BookPlayAudio.sfx`。

## 3. game.html（v2 大地图，word-memory-map 移植）

### 3.1 渲染模型（性能关键）

- `#game-world` 300%×300%，背景 `repeat` 3×3；实体绝对定位 `%`（`placeAt`：x/3*100）。
- 镜头：`translate3d(-camX*vw px, -camY*vh px, 0)`，camX=clamp(hero.x-0.5, 0, 2)。
- **rAF 只改 left/top 与镜头 transform，不重建 DOM**；投掷为世界坐标层内逐帧更新的追踪弹（带拖尾 ghost）。
- 看门狗：320ms interval 兜底步进（rAF 节流场景）；`window.BookPlayGameDebug = state; .step = step` 供 E2E 泵帧。

### 3.2 玩法系统

| 系统 | 要点 |
|------|------|
| 波次/区域 | WAVE_REGIONS=[1,7]（3×3 编号），SLOT_MONSTERS/SLOT_ORBS 槽位+抖动；词球=本波每怪中文；清波→横幅进下一区域；全清→Boss 就绪（aura 脉冲） |
| 小怪 AI | 游荡（home 附近随机点 1.2-2.1s）；AGGRO 0.55 内追击至 KEEP 0.17；撞击半径 0.075/CD 1.8s → 盾-1+主角击退+无敌 900ms；盾空=本波重置+盾回 3 |
| 词球 | 接触半径 0.11 自动拾取（**先于怪物 AI 判定**）；投掷不锁世界；命中判定 ARM 0.12s + 半径 0.07；答错=怪 is-wrong+flee 2.4s+词球弹回原地；TTL 2.2s 落地 |
| 支援 | 击杀 35% 掉落：蟠桃（盾+1，满则存）/芭蕉扇（横扫本波）；托盘按钮 data-count 角标 |
| NPC | 扁平游标对话（`state.dlg={npc,lines,idx,retried}`）：intro=本集原文 2 句；quiz=taunt+1 题（错→只禁该项可重试一次→再错揭示答案）；奖励 ⭐⭐+词卡+npcBonus（入第三星判定），npc.done 后 💬→⭐ |
| Boss 门 | 接近 0.14 或点击 → 确认卡 → `battle.html?ep=N&skip=intro,preview,waves&from=game&wrong=<错词>` |
| 输入 | 方向键/WASD 按住移动、摇杆 pointer 拖动、点词球=走过去、点怪=投掷（无球 toast 提示）、OK=交互最近实体、Esc=暂停 |

### 3.3 数据契约

- 关卡 JSON v2 在 v1 字段外新增 `map`（theme/walkable/heroSpawn/monsterSpawns/npcSpots/bossSpot，全部归一化坐标，由 `maps.json[theme]` 布局 + `cast.json npcByEp` 合成；v1 消费方读不到时行为不变）。
- `sprites.json`：`{sprites: {id: {nameZh, gif, walkGifs:{south,west,east,north}}}}`——主角四条 gif 指向 `assets/generated/jttw-player-walkers/<id>/directions/`（APK 内置包有），小怪指向 `assets/game-sprites/`。
- 存储：`bookplay_battle_progress_v1`（stars/clears/wrongWords/npcBonus/npcDone）、`bookplay_battle_collection_v1`（妖怪卡）。

## 4. 入口与数据流

- 入口：`map.html` 节点"⚔️ 打怪"（`battle.html?ep=N`）；battle 结算/暂停按钮经 `mapUrl()`（`from=game` → `game.html?ep=N`）；绘本完成卡"⚔️ 去打怪"。
- 错词闭环：地图找词（辨认）→ 投掷匹配（确认）→ Boss（反向选词）→ quiz（测验）→ 错词落盘 → 下次同集波次/Boss 词序插队。
- 打包接线（三处白名单，见 `../背景上下文/关键发现.md` §2）+ `pack_datapack.py` 新 CLI：`--exclude-episodes/--keep-full-catalogs`（并行会话加）。
