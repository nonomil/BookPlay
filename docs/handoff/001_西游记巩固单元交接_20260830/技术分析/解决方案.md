# 解决方案：整体架构与当前实现

## 数据流

```
content/dialogue_stories/collections.json        13 辑定义（id/index/title/from/to/background/drill）
content/dialogue_stories/drill/c01..c13.json     精简巩固包（预生成，42-102KB）
content/storybooks/catalog.json                  每集标题与封面
content/assets/adv_audio/{sent_en,en}_index.json 句子/单词 → mp3
                    │
                    ▼
prj/engine/map.html  ──► map.js  ──► wala.html?ep=N     （播放器，未改动）
                                └──► drill.html?c=cNN   （巩固单元）
```

URL 前缀 `/data` 映射到 `content/`（`content/` 是 `prj/data/` 的 junction）。

## 已采纳并已实现的设计

### 1. 合辑定义 `collections.json` ✅

```json
{
  "schema_version": 1, "story": "Journey to the West", "count": 13,
  "collections": [{
    "id": "c01", "index": 1,
    "title": { "zh": "花果山出世", "en": "Birth of the Stone Monkey" },
    "from": 1, "to": 7,
    "background": "assets/collections/c01.jpg",
    "drill": { "words": 12, "puzzles": 6, "quiz_per_ep": 3 }
  }]
}
```

放在 `dialogue_stories/` 下以便被 `pack_datapack.py` 自动收录。

### 2. 解锁规则 ✅（已实现、已修签名、已验证）

```js
epDone(n)        = !!progress[n]?.done
colDone(c)       = 本辑每集都 epDone
drillDone(c)     = !!drill[c.id]?.done
colUnlocked(c, prev) = c.index === 1 || (colDone(prev) && drillDone(prev))
epUnlocked(n, c)     = n === c.from || epDone(n - 1)      // 外层已用 isUnlocked 把闸
```

页面渲染策略：`firstLocked` 之后的合辑加 `.beyond` → `display:none`。第一个未解锁的那辑**可见但整页压暗**，显示「🔒 学完上一辑解锁」，节点全锁。

### 3. 升级豁免 ✅（已实现、已验证）

```js
const MIGRATE_KEY = "bookplay_drill_migrated";
function grandfatherDrills() {
  if (localStorage.getItem(MIGRATE_KEY)) return 0;
  const d = readDrill();
  let n = 0;
  for (const c of cols) {
    if (colDone(c) && !d[c.id]) { d[c.id] = { done: true, grandfathered: true, at: Date.now() }; n++; }
  }
  localStorage.setItem(DRILL_KEY, JSON.stringify(d));
  localStorage.setItem(MIGRATE_KEY, "1");
  return n;
}
```

在 `init()` 里 `cols` 赋值之后、`buildPages()` 之前调用一次。

### 4. 巩固包预生成 ✅

`prj/tools/build_drill_packs.py` 读 `collections.json`，对每辑输出：

```json
{
  "schema_version": 1, "collection": "c01",
  "title": { "zh": "...", "en": "..." }, "from": 1, "to": 7,
  "episodes": [{ "episode": 1, "official_words": [], "puzzles": [], "official_quiz": [], "patterns": [] }]
}
```

只留四个字段，**不带** `nodes` / `script_lexicon` / `script_gloss` / `frames`。

### 5. 巩固单元 `drill.html` ✅（实现完成，端到端已验证）

出题量按现有 `bookplay_learn_level`：

| 档 | 单词补全 | 句型排序 | 剧情测验（每集） |
| --- | --- | --- | --- |
| `lite` | 8 | 4 | 1 |
| `std`（默认） | 12 | 6 | 3 |
| `max` | 16 | 8 | 5（全部） |

三种题型：

- **单词补全**：`blankIt(example, term)` 用 `\b` 词边界 + `gi` 把 `term` 换成 `_____`；3 选项（正确 + 2 个同辑近长度干扰项）；选项带中文释义；🔊 读整句
- **句型排序**：`puzzles[].words` 已打乱，渲染成可点按钮，点击移到答案区；判定忽略首尾/多余空格、句末标点、大小写
- **剧情测验**：`official_quiz` 的 `q` + `choices`，`answer` 是下标；「提示」展开 `q_zh` + `choices_zh`

通过判定（`drill.js:383-386`）：

```js
const wPass = wordsTotal   === 0 || wordsRight   >= Math.ceil(wordsTotal   * 0.8);
const pPass = puzzlesTotal === 0 || puzzlesRight >= Math.ceil(puzzlesTotal * 0.8);
const qPass = quizTotal    === 0 || quizRight    >= Math.ceil(quizTotal    * 0.7);
const pass  = wPass && pPass && qPass;
```

通过后写 `drill[cid] = { done: true, words, puzzles, quiz, at }`。
