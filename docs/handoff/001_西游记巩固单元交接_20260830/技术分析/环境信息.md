## 前端缓存陷阱 ⚠️

改了 `map.js` / `map.css` 后必须递增 `map.html` 里的 `?v=`，否则浏览器跑旧缓存，你会以为改动没生效。

当前：`map.css?v=3`、`map.js?v=3`。
**`drill.html` 目前引 `drill.js` / `drill.css` 没带版本号，建议补上。**

项目惯例见 `wala.html`（`wala.css?v=43`）。

## localStorage 调试

清空进度重现「全新用户」：

```js
['bookplay_adv_progress','bookplay_drill','bookplay_drill_migrated'].forEach(k=>localStorage.removeItem(k));
location.reload();
```

造「老用户 1–13 集已学完」重现豁免场景：

```js
const p={}; for(let n=1;n<=13;n++) p[n]={node:9,total:9,done:true};
localStorage.setItem('bookplay_adv_progress', JSON.stringify(p));
localStorage.removeItem('bookplay_drill');
localStorage.removeItem('bookplay_drill_migrated');
location.reload();
```

`map.js` 顶部注释块里也写了这几段。
