# 图解：解锁状态机与渲染流程

## 1. 合辑与集的解锁判定

```mermaid
flowchart TD
    A["打开 map.html"] --> B["fetch collections.json + catalog.json"]
    B --> C["grandfatherDrills()<br/>一次性升级豁免"]
    C --> D["buildPages()"]
    D --> E{"colUnlocked(c, prev)<br/>c.index===1 ?"}
    E -- 是 --> F["合辑解锁"]
    E -- 否 --> G{"colDone(prev)<br/>且 drillDone(prev) ?"}
    G -- 是 --> F
    G -- 否 --> H["合辑锁定"]
    H --> I{"是第一个未解锁的辑 ?"}
    I -- 是 --> J["可见但压暗<br/>显示 学完上一辑解锁"]
    I -- 否 --> K[".beyond → display:none"]
    F --> L{"逐集: epDone(n) ?"}
    L -- 是 --> M["node.done<br/>可点，可重看"]
    L -- 否 --> N{"n===c.from<br/>或 epDone(n-1) ?"}
    N -- 是 --> O["node.current<br/>可点，本集待学"]
    N -- 否 --> P["node.locked<br/>不可点，点了抖动+toast"]
    F --> Q{"colDone(c) ?"}
    Q -- 是 --> R["★巩固 可点<br/>→ drill.html?c=cNN"]
    Q -- 否 --> S["★巩固 锁定"]
```

关键点：`epUnlocked` **不再**自己判合辑是否解锁 —— 外层 `nodesHTML(c, isUnlocked)` 已经用 `isUnlocked` 把过闸了。这是根因分析里那两处崩溃的修法。

## 2. 巩固通关闭环（P0 要验的就是这条链）

```mermaid
sequenceDiagram
    participant U as 孩子
    participant M as map.html
    participant D as drill.html
    participant LS as localStorage

    U->>M: 学完本辑最后一集
    M->>LS: 读 bookplay_adv_progress
    M->>M: colDone(c) 为真 → ★巩固 变可点
    U->>D: 点 ★巩固 → drill.html?c=c01
    D->>D: fetch drill/c01.json (59KB, 单次请求)
    D->>LS: 读 bookplay_learn_level 决定出题量
    U->>D: 单词补全 12 题
    U->>D: 句型排序 6 题
    U->>D: 剧情测验 21 题
    D->>D: pass = 词≥80% 且 句≥80% 且 测≥70%
    D->>LS: 写 bookplay_drill.c01 = {done:true, ...}
    D->>U: 显示 本辑巩固通过！下一辑已解锁
    U->>M: 返回地图
    M->>LS: 读 bookplay_drill
    M->>M: drillDone(c01) 为真 → colUnlocked(c02) 为真
    M->>U: 第 2 辑解锁，第 8 集可点
```

**"写 bookplay_drill"到"第 2 辑解锁"这一段一次都没跑通过。** 前面被 `map.js` 的崩溃阻断，崩溃修了但这条链仍未验证 —— 这就是 P0。

## 3. 升级豁免的时间线

```mermaid
flowchart LR
    subgraph 升级前["0.1.5（线上）"]
        A1["home.html → shelf.html<br/>108 集平铺，无解锁"]
        A2["孩子已学完 1..N 集"]
    end
    subgraph 首次打开新地图["0.1.6 首次启动"]
        B1["grandfatherDrills()"]
        B2["扫 13 辑：colDone 为真且无 drill 记录<br/>→ 标 done + grandfathered"]
        B3["置 bookplay_drill_migrated = 1"]
    end
    subgraph 之后["之后每次"]
        C1["标记位已存在 → 直接 return 0"]
        C2["新学完的合辑必须真做巩固"]
    end
    A2 --> B1 --> B2 --> B3 --> C1 --> C2
```

设计意图：**只豁免升级那一刻的历史进度**，之后一视同仁。这样既不惩罚已经学过的孩子，也不让巩固形同虚设。
