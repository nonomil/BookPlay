# 问题背景

## 用户要什么

原话（2026-08-30）：

> 西游记的首页设计可以优化，进入后是背景图片，然后自动切换到地图界面，参考瓦拉英语的附图，生成 GPT 生成多个背景图（对应后续的合辑），一个路线图，可以左右滑动切换，学完一集才能解锁下一集，没解锁的不能点击，你把某些集作为一个合辑，比如大闹天宫一个部分，可以有几集，学完一个部分才能解锁下一个部分，然后一个合辑部分结束了可以有巩固提高的单元部分，把所有的测验题目一起全部做一下，或者你把侧边的一些单词也放进去，做成题目，可以有单词补全、句子顺序点击补全，参考附图

拆成六条：

1. 进场先显示背景图，自动切到地图
2. 路线图可左右滑动切换合辑
3. 学完一集才解锁下一集，未解锁不可点
4. 按剧情分合辑（「大闹天宫」是用户点名的例子）
5. 学完一辑才解锁下一辑
6. 每辑末尾有巩固单元：把测验题全做一遍 + 侧边生词做成题；题型要有单词补全、句子顺序点选

## 改造前的样子

`prj/engine/home.html` → `shelf.html` → 108 集平铺网格（封面 + 标题 + 「未开始/读到第 N 页」）。没有关卡、没有解锁、没有分组、没有巩固。

## 参照对象

瓦拉英语的 Unit 地图（星形节点 + 蜿蜒路线 + 分单元）、知识巩固页（顶部多标签 + 倒计时继续）、单词补全（句子挖空 + 3 选项）、句型点选（打乱词按钮拼句）。用户提供了截图作为参照。

## 项目基本情况

- 名称：豆豆龙英语（包名 `com.nonomil.storyhall`），Capacitor 套 Web
- 内容：西游记 108 集对话故事 + Minecraft 分级读物
- 当前版本 0.1.5（`release/v0.1.5/`，2026-08-30 20:11 打的）
- 播放器入口 `wala.html?ep=N`
- 本地服务 `启动服务.bat` → 127.0.0.1:8810（**不要用 `python -m http.server`**，`/api/tts` 和 `/data` 映射都在自定义 server 里）
- 真实消费者是用户的孩子，不是开发者自己 —— 所以「被卡住」是真实伤害，不是抽象风险

## 这次交接的触发点

第 1 切片（地图页）和第 2 切片（巩固单元）都由 DSH（`opencode-go/deepseek-v4-flash`）执行完毕，文件已落盘。用户决定巩固单元的**收尾和验证**交给 Codex 继续。
