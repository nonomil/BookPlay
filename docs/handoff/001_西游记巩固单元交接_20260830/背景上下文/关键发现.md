# 关键发现

三条会直接改变做法的事实。前两条已经落实到代码里，第三条是历史债。

## 发现 1：巩固单元的题库已经全在数据里，一道题都不用生成 ✅已验证

原以为要靠 GPT 造题。实测 `content/dialogue_stories/ep*.json` 每集都自带官方素材：

| 字段 | 每集 | 全 108 集 | 结构 | 对应题型 |
| --- | --- | --- | --- | --- |
| `official_quiz` | 5 | **540** | `q` / `choices[]` / `answer`(下标) / `q_zh` / `choices_zh[]` | 剧情测验 |
| `official_words` | 20–41（中位 28） | **3027** | `term` / `zh` / `example` | 单词补全（挖空 `example` 里的 `term`） |
| `puzzles` | 2 | **216** | `sentence` + 已打乱的 `words[]` | 句型排序（直接用，不用自己打乱） |
| `patterns` | 3 | **324** | `pattern` / `term` / `zh` | 知识回顾卡 |
| `script_gloss` | 48–141 | 11518 | 词 → 中文 | 干扰项词库 |

音频也是现成的：`assets/adv_audio/sent_en_index.json`（整句→mp3）、`en_index.json`（单词→mp3），未命中回落 `/api/tts`。

**结论：巩固单元是纯界面活，不需要内容生成、不需要跑 TTS 批量任务。**

验证方式：`python -X utf8 -c` 遍历 108 个 ep json 统计字段数量（见 `测试分析报告.md`）。

## 发现 2：整辑全量加载 2.8MB，精简后 59KB —— 差 48 倍 ✅已验证

最初设想 `drill.js` 直接 fetch 本辑的 12 个 `ep*.json`。实测：

| 方案 | 体积 |
| --- | --- |
| 12 集 ep json 全量 | **2.8 MB** |
| 只留 `official_words`/`puzzles`/`official_quiz`/`patterns` | **59 KB** |

膨胀来自 `nodes`（逐句台词 + 时间轴）、`script_lexicon`、`script_gloss`、`frames`。

**决定：加预生成步骤 `prj/tools/build_drill_packs.py`，输出 `content/dialogue_stories/drill/c01..c13.json`，`drill.js` 只发一个 fetch。**

实测 13 个包 42–102KB（最大 c11，12 集）。放在 `dialogue_stories/` 下是因为 `pack_datapack.py` 的收录白名单包含该目录，新子目录会被自动打进数据包，不用改打包脚本。

## 发现 3：测验选项里残留 10 处中英混写，已修 ✅已验证

上一轮修专有名词机翻时，`restore_en_mixed_zh.py` 的 `EN_KEYS` 写了 `"choice"`（单数），而实际字段名是 `"choices"`（复数），导致选项数组整个被跳过。残留样例：

```
ep3.json  : Monkey found 菩提祖师's temple.
ep38.json : Bajie met 金角.
ep49.json : 红孩儿 punched himself.
ep51.json : Guanyin was angry at 红孩儿.
ep53.json : Swords didn't scare 红孩儿.
```

补上 `"choices"` 和 `"words"` 后重跑，修了 **16 个文件 64 个字段**。现在全库 `official_quiz` / `quiz` 的英文题面和选项零中文残留（`choices_zh` / `q_zh` 是中文字段，不受影响）。

⚠️ **`release/v0.1.5/豆豆龙数据包-0.1.5.zip` 是这次修复之前打的，仍带这 10 处。** 下次重打包会带上修复。

## 附带发现：`epUnlocked` / `drillUnlocked` 的签名缺陷是潜伏 bug

不是新引入的。第 1 切片就写错了，但被 `||` 和 `&&` 的短路掩盖，直到第 2 切片接线巩固节点才炸出来。详见 `技术分析/根因分析.md`。

**教训：这类"辅助函数少传一个参数、靠短路侥幸不炸"的写法在本文件里还可能有别处。改 `map.js` 时留意。**
