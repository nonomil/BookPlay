| 前端改动不生效 | 递增 `map.html` / `drill.html` 里的 `?v=` |
| 抓前端异常栈 | 控制台跑 `try{ buildPages(); }catch(e){ console.log(e.stack) }`，别只读代码 |

## Windows / PowerShell 注意

- 跑 Python 前设 `$env:PYTHONIOENCODING='utf-8'` 并加 `-X utf8`，否则中文输出乱码或 GBK 报错
- 多行内联 Python 用 `@'...'@` here-string，别用 `-c "..."` 拼引号
- 用户名含单引号（`No'mi'l`），路径一律用双引号包，必要时 `-LiteralPath`
- `rg` 可用；搜中文时注意文件编码可能是 `utf-8-sig`

## DSH 派发（若还要交给 DSH 做）

```powershell
# 模型路由（FULL 档会选 glm-5.3-flash，但本机不可用）
& "$env:USERPROFILE\.codex\skills\dsh-handoff\scripts\Select-DshModelRoute.ps1" -Mode BOUNDED -Lifecycle CONTINUE

# 会话路由（deepseek-v4-flash 有两个 provider，必须显式指定 opencode-go）
& "$env:USERPROFILE\.codex\skills\dsh-execute\scripts\Select-DshSessionRoute.ps1" `
  -Workspace 'G:\Game\BookPlay书戏' `
  -TopicQuery @('巩固单元','解锁','drill') `
  -Model 'deepseek-v4-flash' -Provider 'opencode-go' -Permission 'workspace-write'

# 合同校验
& "$env:USERPROFILE\.codex\skills\dsh-execute\scripts\Test-DshContractRevision.ps1" `
  -TaskCardPath '<任务卡>' -ExpectedContractRevision 2 `
  -EnvironmentManifestPath 'G:\Game\BookPlay书戏\.agent-control\env\bookplay-web\environment.json' `
  -ExpectedEnvironmentRevision 1

# 续接（同模型）
& "$env:USERPROFILE\.codex\skills\dsh-web-worker\scripts\dsh-web.ps1" -Action ContinueTask `
  -SessionId 'session-8ce509cd-7152-4e65-b999-18b071aec2f7' `
  -Provider 'opencode-go' -Model 'deepseek-v4-flash' -Permission 'workspace-write' -Prompt '<...>'
```

已知坑：
- `glm-5.3-flash` → `MODEL_ROUTE_MISMATCH`（本机 DSH 没这个模型）
- 只传 `-Model deepseek-v4-flash` → `MODEL_PROVIDER_AMBIGUOUS`（`deepseek-official` 与 `opencode-go` 都有）
- `-Workspace` 与 `-WorkspaceId` 只能给一个，否则 `DSH_WORKSPACE_INPUT_CONFLICT`
- `Measure-DshTaskEfficiency.ps1` 没有 `-TaskRoot` 参数（技能文档与实现不一致），失败不阻断派发
- `Update-DshTaskCheckpoint.ps1` 的 `-LastEventSeq` 是必填
