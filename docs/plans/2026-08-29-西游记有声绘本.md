# 西游记有声绘本 实施计划

> **给 Claude:** 本会话直接执行。个人使用，`data/` 资产可用。

**目标：** 把 108 集 PDF+MP3 收成可翻页、可听、可学生词的本机有声绘本，学习与简单交互挂在页上。

**架构：** 离线流水线把每一集收成 `epN.json` + 页图 + mp3；浏览器只读 JSON。首页目录 → 翻页播放器 → 生词本/章末测验。对话 VN demo 保留为旁路。

**技术栈：** Python + PyMuPDF；零构建静态页（HTML/CSS/JS）；localStorage 存进度和生词本。

**完成定义（本项目按此收口，不做 3D/战斗/108 集手写释义）：**

1. `python demo/tools/pipeline_lf_episode.py --all` 能产出 108 份 `epN.json` 和目录 `catalog.json`
2. 首页能列出全部集、打开任一集
3. 播放器：翻页、整集朗读、按页粗同步、点词、生词本、章末题、下一集
4. 第 1 集保留人工 glossary/quiz；其余集自动抽词出题
5. `pytest demo/tests` 与校验脚本通过
