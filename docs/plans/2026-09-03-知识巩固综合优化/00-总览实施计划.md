# 知识巩固综合优化实施计划

> 执行状态：已完成实施与回归；验收证据见 `docs/reports/2026-09-03-知识巩固综合优化验收.md`。

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 将每集单词学习、测验、复习、进度和奖励统一为可学习、可恢复、可验证的闭环。

**架构：** 以 `lesson-core.js` 负责纯数据选择、session 和通过判定，以 `lesson.js` 负责页面状态、门禁、语音和奖励；单词页与测验页通过版本化 localStorage session 共享目标词。数据校验脚本在打包前过滤无效/污染卡片，CSS 将 TV 命中区与圆形喇叭视觉尺寸解耦。每个任务先补失败测试，再做最小实现，最后执行 Node/Python/浏览器验收。

**技术栈：** 原生 JavaScript、HTML/CSS、localStorage、Edge-TTS `/api/tts`、Node `node:test`、Python `pytest`、Playwright/浏览器手测。
