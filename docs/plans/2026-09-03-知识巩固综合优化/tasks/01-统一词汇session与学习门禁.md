# Task 01：统一词汇 session 与学习门禁

**状态：已完成并通过回归**

## 目的

让单词学习页和测验页使用同一批目标词，并阻止未完成单词学习的直接跳转。

## 输入与输出

- 输入：`lesson.json` 的 `word_review` 卡片、当前 episode、年级/强度设置。
- 输出：版本化 `bookplay_lesson_session_v2`，包含 episode、目标词 ID/term、创建时间、学习完成时间、测验状态。

## 完成条件

- 学习页和测验页的目标词集合完全一致。
- 直接访问测验页时，未完成学习显示门禁，不创建完成记录。
- 重复测验不会清空已学习词；换 episode 或设置版本变化会安全重建 session。
- 覆盖纯函数测试和浏览器门禁测试。
