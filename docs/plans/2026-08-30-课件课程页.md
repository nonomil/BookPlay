# 课件课程页实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 将 `data/西游记课件` 中可复用的教学内容先整理为可复核的图片、文字、Markdown 和 JSON 内容包；孩子完整看完一集后，再进入独立的“知识巩固”界面，由豆豆龙担任侧边教师角色。

**架构：** 原始 PPTX/PDF 永远只读，提取器把课件转成 `content/lesson_guides/epNNN/` 伴随内容包；播放器通过独立的 `lesson-cards.js` 加载可选巩固卡，不扩写现有 `dialogue_stories/epN.json`。逐句播放期间不插入课程页；最后一句完成并触发 `episode_complete` 后，先显示整集知识巩固，完成或明确跳过后才进入本集结束/下一集界面。

**技术栈：** Python 3、PPTX/ZIP XML、图片提取与 OCR 适配层、Markdown、JSON Schema、原生 HTML/CSS/JavaScript、现有 Python/Node 测试入口。

---

## 执行顺序

1. T01：冻结来源清单、重复关系和第 42/61/97 集版本分歧。
2. T02：只做第 1 集内容资产包，产出图片、文字、嵌图 Markdown 和来源收据。
3. T03：冻结 `lesson_guides` JSON 合同、校验器和 EP1 数据。
4. T04：实现整集结束后的知识巩固状态机。
5. T05：把豆豆龙接为教师形象，完成响应式和反馈状态。
6. T06：EP1 验收后才允许扩到 108 集。
7. T07：最后才进入 Android 数据包和发布。
