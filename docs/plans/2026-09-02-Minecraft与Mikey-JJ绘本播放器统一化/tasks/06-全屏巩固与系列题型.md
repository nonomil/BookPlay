## 步骤 2：定义练习状态纯函数

`storybook-practice.js` 使用 UMD，导出：

```js
return {
  buildReviewWords,
  normalizeQuestion,
  createPracticeState,
  answerQuestion,
  practiceSummary,
};
```

写失败测试：

- review words 按首次出现去重，优先错词/已点词，最多首屏 6 个。
- question answer 必须在 choices 范围。
- 重复提交同题不重复计分。
- summary 返回 total/correct/wrongIds/percent。
- 无有效题时返回安全空态，不抛异常。

运行：

```powershell

```

预期先失败，再最小实现。

## 步骤 3：定义向后兼容题目合同

保留现有：

```json
{"q": "...", "choices": ["..."], "answer": 1}
```

新字段可选：

```json
{
  "id": "mc-b1-q01",
  "type": "meaning-choice",
  "source_sentence_id": "mc-b1-p02-s01",
  "prompt_en": "What does loyal mean?",
  "prompt_zh": "loyal 是什么意思？",
  "choices": ["勇敢的", "忠诚的", "安静的"],
  "answer": 1,
  "explanation": "loyal 表示忠诚的。"
}
```

`normalizeQuestion` 把旧题映射成 `type=multiple-choice`；播放器不能要求所有旧数据一次迁移。

## 步骤 4：增加题目数据合同测试

Python 测试：

- 每题唯一 id（迁移后）。
- 2–4 个非空选项，answer 有效。
- 选项去重且没有西游记污染词。
- `source_sentence_id` 存在时必须能在本书找到。
- `speaker-choice` 只用于真实 speaker 数据。
- `audio-choice` 必须有可信 source sentence audio。
- 缺数据时减少题数，不填占位答案。

先让新字段合同在选定 pilot book 上失败，再只迁移 pilot；全量迁移按逐书验证推进。

## 步骤 5：阅读完成状态

最后一句自然结束或用户点“下一句”时：

1. 停止所有句/词音频。
2. 显示全屏 review stage，而不是立即第一题。
3. 展示本书重点词快速复习（首屏最多 6 个）。
4. 提供“再听本页”和“开始小测”。
5. Escape/返回键可以回阅读页，保持最后一句。

review stage 不显示右侧栏、stage、topbar；保留明确的关闭/返回控制。

## 步骤 6：单题全屏渲染

每次只渲染一道题：

- 顶部：书名、`第 N / M 题`。
- 中部：题干和必要媒体。
- 底部：2–4 个大选项。
- 回答后：正确/错误文字、正确答案、解释、下一题。
- 正误使用图标 + 文本 + 边框，不只红绿。
- 选项回答后禁用，防重复计分。

已有 Minecraft/Mikey quiz 背景可继续使用，但背景不能降低题干对比度；不要在本任务新增在线生图依赖。

## 步骤 7：系列题型

Minecraft P1：

- `meaning-choice`：英文选中文。
- `listen-word`：有可信音频/TTS 时听音选词义。
- `cloze-choice`：从真实句子挖一个重点词。

Mikey P1：

- `speaker-choice`：谁说了这句话。
- `listen-sentence`：听句子选中文。
- `meaning-choice`：重点词义。
- `sentence-order`：最多 5 个块，使用真实短句。

题型 renderer 不支持时回退 `multiple-choice`，不能显示空白。

## 步骤 8：结果与错题

完成后显示：

- `答对 X / Y` 和百分比。
- 错题词/句，支持点读。
- “重做错题”“回到本书”“下一本”“返回目录”。

成绩写入现有 `bookplay_story_progress` 对应 `progressKey` 的扩展字段，不覆盖 page/beat/choices：

```json
{
  "practice": {
    "attempts": 1,
    "best_correct": 4,
    "total": 5,
    "last_wrong_ids": ["mc-b1-q03"],
    "updated_at": "..."
  }
}
```

旧存档安全回退；重复完成不得减少 best score。

## 步骤 9：焦点与电视

- 打开全屏 stage 后焦点进入标题或第一选项。
- 回答后焦点移动到反馈/下一题按钮，但不突然滚动。
- 电视选项至少 64px，方向键顺序按视觉排列。
- 关闭后焦点返回“开始小测”或最后的下一句按钮。
