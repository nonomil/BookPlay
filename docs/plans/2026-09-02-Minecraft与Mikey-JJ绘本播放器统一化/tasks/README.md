# 任务子目录说明

本目录是 `../00-总览.md` 的逐任务执行包。任务按编号推进；共享文件必须串行修改，不能跳过失败测试、真实消费者验收或 promotion 门槛。

| 编号 | 任务 | 核心出口 |
|---|---|---|
| 01 | 基线合同与 V3 预览开关 | `ui=unified-v3` 与 `ui=legacy` 可独立访问 |
| 02 | 统一骨架与剧情/精学模式 | 顶栏、模式、授权和稳定语义 DOM |
| 03 | 学习栏与逐词点读合同 | 普通词/重点词/暂停恢复/快速点击均可靠 |
| 04 | Minecraft 画布与内容数据 | 完整跨页、中文、精确同步门槛、缺音频降级 |
| 05 | Mikey 画布、说话人与气泡定位 | 不复制文字的原气泡描边准确 |
| 06 | 全屏巩固与系列题型 | 词卡复习、单题测验、结果与错题回看 |
| 07 | 移动端、TV 与 Android | 五档视口、遥控器、数据准备无回归 |
| 08 | 端到端验收、默认切换与回滚 | 用户确认后 promotion，legacy 可回退 |

每个任务文件包含：目标、依赖、精确文件、TDD 步骤、实现细节、验证命令、完成证据和回滚边界。
