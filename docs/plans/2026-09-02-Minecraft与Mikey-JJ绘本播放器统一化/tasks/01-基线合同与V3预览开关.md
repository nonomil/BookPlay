## 步骤 2：为 v3 路由写失败测试

在 `storybook-route.test.mjs` 增加：

```js
test("storybook route resolves explicit UI variants without changing progress identity", () => {
  const v3 = resolveStorybookRequest("?series=minecraft&book=1&ui=unified-v3");
  const legacy = resolveStorybookRequest("?series=minecraft&book=1&ui=legacy");
  assert.equal(v3.uiVariant, "unified-v3");
  assert.equal(legacy.uiVariant, "legacy");
  assert.equal(v3.progressKey, legacy.progressKey);
});
```

运行：

```powershell
node prj/engine/storybook-route.test.mjs
```

预期：新增断言失败，提示 `uiVariant` 未定义；现有测试仍能执行。

## 步骤 3：实现最小路由解析

在 `resolveStorybookRequest()` 中只接受：

```js
const uiParam = params.get("ui");
const uiVariant = uiParam === "unified-v3" ? "unified-v3" : "legacy";
```

把 `uiVariant` 加到三种 series 的返回对象；不得把 UI variant 写入 `progressKey`。

重新运行路由测试，预期通过。

## 步骤 4：为纯函数模块写失败测试

`storybook-ui.test.mjs` 至少覆盖：

```js
test("containedRect centers a portrait image inside a landscape box", () => {
  assert.deepEqual(
```

运行：

```powershell

```

预期：失败，提示模块或函数不存在。

## 步骤 5：创建 `storybook-ui.js`

使用与 `storybook-route.js` 相同的 UMD 暴露方式，导出：

```js
return {
  containedRect,
  projectRelativeBox,
  formatUnitProgress,
  seriesCapabilities,
  readPreferences,
  writePreferences,
};
```

最小规则：

- `containedRect` 对非法/零自然尺寸返回 `null`。
- `projectRelativeBox` 对 `null` rect 或不完整 bubble 返回 `null`。
- `formatUnitProgress` 使用 1-based 输入，不输出 `undefined`。
- `seriesCapabilities` 只依据真实字段和 series，不猜 speaker/bubble。
- preferences JSON 损坏时返回默认值；写入只修改指定 series。

## 步骤 6：接入候选 CSS 和脚本

在 `storybook.html`：

- `storybook.css` 后加载 `storybook-v3.css?v=1`。
- `storybook-route.js` 后、`storybook.js` 前加载 `storybook-ui.js?v=1`。

`storybook-v3.css` 第一条实际规则必须以 `body.sb-ui-v3` 开头；首版只加不影响布局的 CSS token，不修改 legacy。

在 `storybook.js` 读取 `request.uiVariant`：

```js
if (request.uiVariant === "unified-v3") document.body.classList.add("sb-ui-v3");
```

不得在任务 01 创建新布局或改变默认 series 样式。

## 步骤 7：增加静态合同测试

在 `storybook-route.test.mjs` 断言：

- `storybook-v3.css` 在旧 CSS 之后。
- `storybook-ui.js` 在 `storybook.js` 之前。
- v3 CSS 没有未作用域的 `#sb-panel`、`.sb-app` 核心覆盖。
- controller 只在 `unified-v3` 时添加 `sb-ui-v3`。

## 完成证据

- 测试先失败后通过的输出摘要。
- 两组 URL 的 body class 与 console 结果。
- `progressKey` 在 v3/legacy 下相同。

## 回滚边界

- 从 HTML 移除新 CSS/JS 引用即可恢复；不得清除用户进度。
- 若 route 解析失败，默认回到 legacy，不猜 v3。
