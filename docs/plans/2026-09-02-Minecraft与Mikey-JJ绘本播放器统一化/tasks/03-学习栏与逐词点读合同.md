## 步骤 2：固定学习栏渲染顺序

重构 `renderPage()`，每次句变化按同一顺序更新：

1. `#sb-unit-progress`。
2. `#sb-speaker-chip`（无真实 speaker 时 hidden）。
3. `#sb-text` 逐词 DOM。
4. `#sb-zh`。
5. `#sb-glossary`。
6. `#sb-feedback` / notice。
7. `#sb-nav`。

不得继续动态创建多个 `.sb-section-label` 造成 DOM 顺序漂移；旧 `captionLabelEl` / `zhLineEl` 分支要么迁移到静态 DOM，要么只留 legacy 路径。

## 步骤 4：拆分句音频与词音频 generation

当前共享 generation 容易让快速点击的旧异步链继续播放中文。改为：

```js
const playbackState = {
  navigationGeneration: 0,
  wordGeneration: 0,
  pendingWordResolve: null,
  wordSpeaking: false,
  resumeAt: 0,
};
```

新增：

```js
function cancelWordPlayback() {
  playbackState.wordGeneration += 1;
  if (playbackState.pendingWordResolve) playbackState.pendingWordResolve({cancelled: true});
  playbackState.pendingWordResolve = null;
  wordAudio.pause();
  wordAudio.removeAttribute("src");
  playbackState.wordSpeaking = false;
}
```

每次点词：

1. 调 `cancelWordPlayback()`。
2. 记录新的 `wordGeneration` 和当前 `navigationGeneration`。
3. 记录主句是否在播与 `currentTime`。
4. 播英文；await 后检查两个 generation。
5. 只有重点词且 token 未过期才播中文。
6. 只有原来正在播放、仍是同一句、仍是同一次点词才恢复主句。

页面/句子变化、mode 切换、pagehide、beforeunload 都调用 cancel 并增加 navigation generation。

## 步骤 6：重点词卡改为单列

`renderGlossaryCards()` v3 合同：

- 0 项：`#sb-glossary.hidden=true`，不渲染提示段落。
- 1–4 项：单列卡片。
- 第一行 term、IPA、POS、独立点读图标/文本。
- 第二行中文。
- 第三行真实当前句例句；窄屏两行并提供展开。
- 整卡点击与点读按钮行为一致，但嵌套按钮不得产生双击事件。

建议卡片本身保持 `role=button`，或改用单一真实 `<button>` 包装内容；不要在 button 中再嵌 button。

## 步骤 7：反馈状态

把反馈分为：

- `success`：加入生词本，2 秒后清除或卡片勾选。
- `info`：句子播放完成，可被下一操作替换。
- `error`：缺音频/TTS 失败，保留到下一次明确操作。

实现 `setFeedback(message, {kind, transient})`，并给容器 `data-kind`。timer 在句变化时清除。

## 步骤 8：播放高亮

- 精确 word timing 存在时使用 `start_ms/end_ms`。
- 不存在时加 `data-sync="estimated"`，使用弱视觉；句结束全部清除。
- active 状态使用底色 + 2px 下划线，不能只变颜色。
- done/wait 不把文本降到不可读对比度。

## 步骤 9：键盘与触控

- 每词 focus ring 3px，offset 2px。
- `touch-action: manipulation`。
- 移动端相邻短词视觉可以连续排版，但可点击区域上下 padding 至少 6px；不能强制每词 44px 宽导致句子碎裂。
- Space 在词上只点读，不触发下一句。
- 全局左右箭头在输入/按钮/词卡聚焦时不得抢占。
