## 步骤 3：Minecraft 真实链路

在 `ui=unified-v3`：

1. book 1 进入剧情模式，用户手势解锁后连续播放两句。
2. 切精学，确认停在当前句。
3. 播放中点普通词，检查 en-only 和恢复时间。
4. 播放中点重点词，检查 en→zh→恢复。
5. 快速点重点词再普通词，旧中文不得串入。
6. 切到无重点词句，区域隐藏。
7. 检查中文整句与专名。
8. book 3 无原音但词 TTS 可用。
9. book 4 缺句不继承上一句 src。
10. 完成阅读 → review → quiz → result → 返回/下一本。

记录 URL、sentence id、audio src 顺序、currentTime 前后、DOM 状态和 console。

## 步骤 7：最小 promotion 实现

`storybook-route.js`：

```js
const requestedUi = params.get("ui");
const modernSeries = series === "minecraft" || series === "mikey-jj";
const uiVariant = requestedUi === "legacy"
  ? "legacy"
  : requestedUi === "unified-v3" || modernSeries
    ? "unified-v3"
    : "legacy";
```

不要改变 progressKey、book id、shelf URL 或西游记默认消费者。

重新运行路由与全套测试。
