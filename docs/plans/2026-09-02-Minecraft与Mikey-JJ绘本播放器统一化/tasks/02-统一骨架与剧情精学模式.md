## 步骤 4：实现模式状态

在 `storybook.js` 新增单一状态：

```js
const readerState = {
  mode: "study",
  translation: true,
  audioUnlocked: false,
  autoAdvancePending: false,
};
```

初始化顺序：

1. 加载 book。
2. 计算 series capabilities。
3. 读取该 series 偏好。
4. 渲染模式按钮 `aria-pressed`。
5. 渲染当前句，但不因初始化重复播放两次。

模式切换只改变 UI 和结束后的推进策略，不改变 `idx` / `sentIdx` / `progressKey`。

## 步骤 5：实现剧情/精学结束行为

在句音频 `ended` 中：

- 总是清理播放按钮、词高亮和 locator。
- 精学：显示“这一句读完了”，保持当前句。
- 剧情且已解锁、有下一句：排队进入下一句并播放。
- 当前句缺音频：停止自动推进并显示原因。
- 已是最后一句：进入“阅读完成”状态，不直接瞬间弹测验。

使用 generation/token 取消旧异步推进；切换模式、手动上一句/下一句、pagehide 时必须递增 token。

## 步骤 6：移动首次播放授权

v3 下 `#sb-autoplay-unlock` 不再位于画面中央：

- 首次 `NotAllowedError` 时在 `#sb-reader-notice` 内显示“点击开始有声阅读”。
- 点击后设置 `audioUnlocked=true`，隐藏 notice，播放当前句。
- 其它播放错误显示“本句暂时无法播放”，不能误标为权限问题。
- legacy 保持旧行为直到任务 08 promotion。

## 步骤 7：实现 v3 顶栏与学习栏网格

所有规则使用 `body.sb-ui-v3` 前缀：

- 桌面 grid：`minmax(0, 1fr) clamp(380px, 32vw, 480px)`。
- 顶栏高度 60–68px，模式分段按钮位于标题与播放之间。
- stage 不出现字幕卡/词卡。
- panel 使用 `display:flex; flex-direction:column`，nav `margin-top:auto`。
- 保留 `object-fit:contain`。
- 模式按钮 active/hover/focus 不引起布局位移。

## 步骤 8：键盘与焦点

- 模式按钮 Enter/Space 原生触发。
- 切模式后焦点留在触发按钮。
- 全局 Space 快捷键不得在按钮或逐词元素上触发下一句。
- `aria-pressed` 与视觉 active 一致。
- 切页后焦点不强制跳到正文；电视遥控器仍可顺序进入。
