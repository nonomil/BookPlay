## 1. 一局怎么接

一集 = 一条线。孩子从绘本地图点「打怪」进 `game.html?ep=N`，不切玩法、不新开存档键。

```
map.html「⚔️ 打怪」→ game.html?ep=N
  ① 开场 NPC（走近自动弹一次，本集原文 2 句）
  ② 大地图捡投（主玩法，对齐 word-memory-map）
  ③ 小 Boss NPC（清完第一波或走到点上：剧情 + 1 题）
  ④ 走近大 Boss 区 → battle.html 只打 Boss
  ⑤ 结算回 game.html?from=battle
```

打字不进主线。7 岁是触屏和电视遥控；追击已经提供时间压力。`typing-defense` 只留「听音选怪」作以后加料。

学习分三遍，不靠快卡：

| 环节 | 孩子在做什么 |
|------|----------------|
| 大地图 | 手里的中文词球 ↔ 头顶英文小怪 |
| 小 Boss NPC | 听一句剧情，选中文意思 |
| 大 Boss | 选英文词攻击，错词优先 |

## 2. 大地图：运动、捡投、道具

参考：`G:\StudyCode\小游戏项目\games\word-memory-map`  
只换地图和角色，玩法与人物运动对齐参考。现有 3×3 世界 / 镜头跟随 / 摇杆 / 方向键骨架保留，不重写。

### 2.1 运动

- 按住方向键、WASD 或摇杆连续走；斜向 `hypot` 归一，不加快。
- 朝向只看主轴：`|dx| >= |dy|` 定左右，否则定上下；切已有四向 `walkGifs`。
- 补起步扬尘、投掷时的攻击姿势（用现成 walker act 帧，不新画）。
- 点中文词球 = 先走过去再捡；点小怪 = 有球就扔，没球只提示。
- 电视：方向键直接移动，OK 交互最近实体，Esc 暂停。
- 边界继续 clamp，不做墙体系统。

### 2.2 捡投

- 地面刷本波中文词球，走近自动捡起；有 TTS 则读中文，没有则 toast。
- 对准对应英文怪投掷：短前摇 → 追踪弹。
- 对上：爆碎、掉星星和道具、连对 3 横扫本波。
- 扔错：词球弹回原地，怪变红加速逃几秒。
- 大地图不弹快卡。

### 2.3 小怪

保持现有：游荡 / 靠近追 / 贴身撞 / 扣盾击退 / 盾碎本波重置。参数先不动，真机再调 `MONSTER_CHASE`。怪头顶英文词牌，目标怪高亮。

波次仍是两块区域（`WAVE_REGIONS = [1, 7]`）清完 → Boss 门开。

### 2.4 道具（6 种效果，只换西游皮）

| 参考效果 | 西游名 | 做什么 |
|----------|--------|--------|
| 补盾叶 | 蟠桃 | 下次被撞挡一次，或立刻 +1 盾 |
| 减速钟 | 芭蕉扇 | 小怪慢几秒 |
| 瞄准星 | 紫金葫芦 | 接下来 2 发自动找对怪 |
| 加速鞋 | 筋斗云 | 主角快跑一小段 |
| 词卡提示 | 紧箍咒 | 提示目标怪首字母 |
| 连击加成 | 金箍棒 | 下一次打对额外 +1 盾 |

击杀掉落、走过捡起、右上角托盘可点。第一版继续用 emoji / 现有图标；道具 sheet 不挡玩法，另开 P1。

### 2.5 明确不做

选世界包、选英雄、分类词库、九宫格换图块（背景继续整图 repeat）。

## 3. NPC 与 Boss

参考：`G:/StudyCode/宠物积分系统/docs/参考/探索地图对话剧情系统-跨项目参考.md`、`G:\StudyCode\小游戏项目\games\pet-battle-template`

对话不新开一页，不整包移植对话引擎。人还在大地图上，走近弹层，播完回探索。只学播放方式：台词数组 + 游标、一句一句推、选择题没答完不能翻下一句、左侧立绘 + 底部对话框。配音索引、世界 tab、节点图都不做。

### 3.1 开场 NPC（每集一个，出生点附近）

走近自动弹一次。2 句本集原文（中英），立绘用本集角色精灵。点「继续」翻句，最后一句变「出发」。`from=battle` 回来不重弹。

### 3.2 小 Boss NPC（每集一个，第二波附近）

清完第一波或走到点上才可对话（没到就头顶「…」）。流程：一句嘲讽 → 1 题三选一（英文 + IPA，选项中文）。

- 答对：词卡 + ⭐⭐（`npcBonus`，第三颗星用）。
- 答错：只禁用点错的项，可再试一次；两次都错揭示答案并带读，不扣盾。
- 每集奖励只发一次（`npcDone`）。
- 电视：方向键选选项，OK 确认。

### 3.3 大 Boss（地图上不打）

第二波清完，Boss 区亮起来。走近出确认卡，可先逛。开战：

`battle.html?ep=N&skip=intro,preview,waves&from=game&wrong=错词`

对战页只打 Boss：血条 = 词数，选词攻击，错词优先。表现按 pet-battle 补齐，不引入 2v2、换人、技能 CD：

- 答对：主角突进 → 命中闪光 → Boss 后仰 +「−1 单词」浮字
- 血条用宽度过渡，不要瞬间跳格
- 左下角最近 3 条战报（打中 / 打偏 / 被反击）
- 答错 = Boss 回合，扣盾
- 打赢：妖怪卡 + 结算 → 回 `game.html?from=battle`

关底测验仍留在战斗页，作为错词最后一遍。
