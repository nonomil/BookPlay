# 单词学习与测验分屏实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 将每集知识巩固拆成独立的单词学习页和紧凑测验页，降低测验选项的视觉占用，并为单词学习页接入 GPT 生成的背景图。

**架构：** 播放器结束后的入口先进入 `lesson-words.html?ep=N`。单词页复用现有 lesson 数据与 Edge TTS，展示本集词卡并由明确按钮进入 `lesson.html?ep=N`；测验页只负责题目与评分，不再携带顶部词汇网格。大屏样式取消测验卡片的固定高度，选项使用紧凑但可操作的尺寸。

**技术栈：** 原生 HTML/CSS/JavaScript、现有 LessonCore/WalaVoice、GPT Image Pipeline（gpt-image-2/Cliprox）。
