# 01 玩法设计：每集一关的"降妖记"

## 1. 一句话定位

读完一集故事后，孩子进入本集的战斗场景：**妖怪头顶顶着英文单词，捡起正确的中文词球扔过去**消灭它们，最后打败本集反派 Boss。玩的过程就是把本集单词复习了四遍。

## 2. 单局流程（3-5 分钟，六阶段）

```
开场剧情 → 战前预习 → 小怪波×2 → Boss战 → 关底测验 → 结算
 (30s)     (可跳过)    (英→中)     (中→英)    (复用quiz)  (星星+收集)
```

| 阶段 | 内容 | 数据来源 |
|---|---|---|
| ① 开场剧情 | 2-3 句本集原文对白（对话框 + 说话人立绘 + 插图），交代"这集打谁" | `nodes` 前 2-3 个节点 |
| ② 战前预习 | 8-12 个核心词闪卡（词 + IPA + 中文 + 插图 + TTS），可随时跳过 | `official_words` + 节点 `vocab` |
| ③ 小怪波 ×2 | 每波 3-5 只小怪从右侧进场，头顶英文词；下方刷 3 个中文词球，捡球→投掷→命中消灭。答错扣一格护盾 | 波次词表见 02 文档 |
| ④ Boss 战 | 本集反派（四向资产角色），血条 = 单词数；**反向出题**（显示中文，捡英文词球）；每掉一格血 Boss 说一句台词；击倒掉落"妖怪卡" | cast 映射 + 台词模板库 |
| ⑤ 关底测验 | 跳转/内嵌现有 `episode-vocab-quiz`（通过率 0.7），通过得满星资格 | `official_quiz` |
| ⑥ 结算 | 星星（1-3）+ 词卡掉落展示 + 错词清单 + 妖怪卡入图鉴 + 下一集按钮 | 见结算规则 |

## 3. 核心交互（移植自 word-memory-map，砍掉大地图探索）

- **单屏遭遇战**，不做 9 宫格大地图：背景一张（本集场景图），主角在左侧，小怪从右侧成波进场。理由：每集资产成本最低、电视遥控器和触屏都好操作、故事节奏就是"遇怪→打"。
- 词球刷新在底部词球栏（3 个中文 + 若干干扰），点击/OK 键选中后自动飞向当前聚焦的怪物；也可先点怪再点球。命中判定：词球的中文释义与怪物头顶英文词匹配。
- 护盾 3 格（袈裟图标）；错一次扣一格，扣完不死，只重置当前波（温和不挫败）。
- 连击：连续答对 3 次触发金箍棒特效，本波剩余怪物全灭（奖励节奏感）。
- 道具掉落（P1）：蟠桃=回护盾、芭蕉扇=清波、紫金葫芦=吸走一个词球错误项。

## 4. 单词复习闭环（这是游戏的灵魂）

```
预习(认) → 小怪波(英→中 辨认) → Boss战(中→英 回忆) → 关底quiz(测验) → 错词队列(下次优先复现)
```

- 词库每集天然不同（`official_words` 优先，缺则用节点 `page_words` 高频词补足到 12 个）。
- **错词记录**：战斗中每次答错写入 `bookplay_battle_progress_v1` 的 `wrongWords`；下次进入同一集时，错词必进波次词表并替换已掌握词。
- 与现有 `review-queue.js` / `bookplay_adv_vocab_stat` 的打通放 M2，P0 先自闭环。

## 5. 角色与台词

- **主角**：固定孙悟空（c01）；后续章节可按 walker-cast 换主役。
- **Boss**：`walker-cast.resolve(book)` 的结果即本集反派（ep4 菩提=试炼关、ep6 龙王=借宝关，打"切磋"不打"善恶"，文案写成"赢过师父/龙王"）。
- **小怪**：每集 1-2 种小角色（资产清单见 03 文档），波次里同一小怪重复出现。
- **台词**：开场/Boss 原句从 `nodes` 自动抽取；另建**角色台词模板库**（`content/game/taunts.json`，按角色 id 各 3-5 条中英双语趣味台词，如八戒"猴哥，这个词俺老猪认识……的中文！"），战斗中随机触发。台词库人工一次性写好，全关卡共享。

## 6. 结算规则

- 星星：⭐ 通关即得；⭐⭐ 护盾剩余 ≥2 或 quiz 通过；⭐⭐⭐ 护盾满 且 quiz 通过（0.7）。
- 奖励：本集 Boss 妖怪卡（图鉴收集，M2 接 stickers/medals）；金币/贴纸等既有体系不动。

## 7. 操作与适配

- 触屏：点词球、点怪物即可。
- 电视 D-pad：`tv-remote.js` 焦点移动，词球栏与怪物均为可聚焦元素；OK=选中/投掷；返回键=暂停面板。
- 每阶段转换有 0.5s 过渡动画；`prefers-reduced-motion` 时关闭飞行动画（tv 合同）。
