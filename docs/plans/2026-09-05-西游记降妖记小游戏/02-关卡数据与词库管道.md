# 02 关卡数据与词库管道

目标：**108 集关卡零手写**。写一个派生脚本，从既有 `dialogue_stories` / `storybooks` / `walker-cast` 自动生成本游戏的关卡配置；人工只维护"反派映射表 + 小怪分派表 + 台词模板库"三张小表。

## 1. 产物

- 脚本：`prj/tools/build_game_levels.py`（Python + 仅标准库，风格参照 `pack_datapack.py`）
- 数据：`content/game/levels/ep{n}.json`（新目录，**只增不改**）
- 同步：脚本同时把产物复制到 `prj/data/game/levels/` 与 `data/game/levels/`（引擎开发态直接可读）
- 共享表：`content/game/cast.json`（反派/小怪映射 + 背景主题）+ `content/game/taunts.json`（台词模板库）

```bash
python -X utf8 prj/tools/build_game_levels.py --eps 1-7        # c01 试点
python -X utf8 prj/tools/build_game_levels.py --eps 1-108      # 全量
python -X utf8 prj/tools/build_game_levels.py --check          # 只校验不写出
```

## 3. 派生规则（脚本逻辑）

1. **词表**：`official_words` 过滤（term 长度 ≤ 14、zh 非空、去专名）取前 12；不足从节点 `page_words` 按"节点出场次数 × 词频"补足；仍不足（低集数可能）就把 `vocab_pool` 按字母序补齐。同一集重复生成必须**字节级一致**（排序 + 稳定 tie-break，不使用随机）。
2. **波次切分**：12 词 = 预习 12 + 两波各 4（小怪波允许重叠预习词，覆盖 6-8 个不同词）+ Boss 4 词。Boss 词取词表中后段（通常是更难的词）。波次词表里每只怪附 `sprite`（该集小怪 id）。
3. **干扰词球**：不写进关卡 JSON——运行时由 battle-core 从**同集其他词的 zh** 取干扰项（保证强相关、可辨），core 里做确定性洗牌。
4. **开场剧情**：取 `nodes` 中前 2 个有 `illustration` 的节点；若是反派集（cast 表有 boss），再从 `nodes` 找 `text_en` 命中 boss 别名的第一句作为 Boss 出场引子。
5. **cast 解析**：hero 固定 wukong（P0）；boss 用 `walker-cast.resolve` 结果对照 `cast.json` 的反派白名单（resolve 出正面角色如观音/唐僧时，改用 cast.json 里该集的手工 fallback，如 ep4 菩提写明"切磋关"）；minors 查 `cast.json` 的每集小怪分派表，缺省用通用小妖 `imp`（占位由 T5 资产补）。
6. **背景**：`cast.json` 每集一个 `theme` key；P0 渲染时 theme 未命中就回退本集第一张 `adv_frames` 插图。生成好的主题背景在 T5 落地后，把映射补进 `cast.json` 即可，关卡 JSON 不用重生成（背景运行时解析）。
