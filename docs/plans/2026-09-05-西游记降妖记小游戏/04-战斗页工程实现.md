## 2. battle-core API（TDD，先写测试再实现）

```js
BookPlayBattleCore = {
  buildLevel(rawLevel, options)            // 校验 schema → 内部运行时结构；缺词/缺图降级
  buildWaveQuestions(level, waveIndex, wrongWords) // 错词优先插队；返回 [{term,zh,sprite}]
  buildOrbSet(question, allWords, rng)     // 3 中文球（1 正确 + 2 同集干扰）+ 确定性洗牌
  judgeHit(orb, monster)                   // → {correct, combo}
  settleRun(runState)                      // → {stars, wrongWords, cleared}（星星规则见 01 文档）
  loadSprites(registry)                    // 解析 content/game/sprites.json 注册表 → id→帧路径；缺帧回退 walker GIF
}
```

- 全部函数确定性（rng 由 seed 派生，seed = ep × 1000 + wave），保证同集两次构建一致（测试断言）。
- 空数据/坏数据不抛异常，返回降级结构（测试覆盖：空 level、词数不足、缺 sprite）。

## 3. 页面结构（T3）

- 阶段机：`intro → preview → wave1 → wave2 → boss → quiz → result`；URL `battle.html?ep=N`，支持 `&skip=intro,preview` 调试参数。
- 布局：全屏场景背景（theme 图 + 压暗渐变）→ 左侧主角（四向帧，idle 用 south-walk 循环）→ 右侧怪物进场（CSS transform，`prefers-reduced-motion` 降级为淡入）→ 底部词球栏 3 槽 → 顶部 HUD（护盾×3 / 进度 / 连击 / 退出）。
- 对话框：底部 1/3 面板，说话人立绘 + 中英双语（默认英文大字 + 中文小字，可在暂停面板切"只中文"）。
- Boss：血条格 = 词数；受击闪红 + 台词气泡（taunts.json）；倒地淡出 → 妖怪卡弹出。
- 测验阶段：**内嵌复用** `episode-vocab-quiz`（不跳页，避免打断；quiz 完成回调进 result）。若集成成本高，回退方案=跳转 `lesson.html?ep=N` 完成后返回，P0 二选一取简单者。
- 存储（唯一两个新键，JSON 读写容错）：
  - `bookplay_battle_progress_v1`：`{ [ep]: { stars, clears, wrongWords: {term: count}, updatedAt } }`
  - `bookplay_battle_collection_v1`：`{ [bossId]: { cardLevel, firstClearAt } }`（妖怪图鉴，M1 只记录不展示页）
- TTS：单词朗读复用 `voice.js` 现有 speak 接口；无语音环境静默降级。

## 4. TV 合同与输入（T3 强制）

- `battle.html` 按 `script` 顺序引入：`tv.css`（link）→ `tv-remote.js` → `battle-core.js` → `battle.js`（带 `?v=` 版本参数）。
- 所有可点元素 `tabindex` + 焦点样式走 `tv.css` 焦点环；D-pad 在词球栏 ↔ 怪物区 ↔ HUD 间移动，OK=确认。
- 64px 最小命中高度、safe-area padding、`prefers-reduced-motion` 全部沿用 tv.css。
