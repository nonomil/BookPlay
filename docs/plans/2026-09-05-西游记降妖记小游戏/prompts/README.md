# prompts 使用说明

每个 `.md` 是一段自包含提示词，新开对话整段粘贴即可执行。顺序与依赖：

1. `01-关卡数据管道.md`（T1，先行，产出 schema 与 ep1-7 数据）
2. `02-battle-core.md`（T2，依赖 T1 schema；可与 03 并行）
3. `03-battle页面.md`（T3，依赖 T2）
4. `04-资产生成-c01小角色.md`（T5，**独立可并行**；生图子任务，支持多子代理分角色并发）
5. `05-入口打包与验收.md`（T4+T6，收口，依赖 T1-T5）

执行前先读 `../00-总览.md` 的工程约定。完成后更新 `../00-总览.md` 状态表。
