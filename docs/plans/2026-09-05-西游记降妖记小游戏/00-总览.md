# 西游记·降妖记 小游戏 · 总览

> 目标：给西游记绘本动线加一个**故事驱动的打怪收词小游戏**（每集一关），把"读故事 → 预习单词 → 打怪复习 → 关底测验 → 收集图鉴"串成闭环。参考玩法原型：`G:\StudyCode\小游戏项目\games\word-memory-map`（捡中文词球投掷英文单词怪）。
> 理念：游戏是复习的糖衣，不是又一个学习页。单局 3-5 分钟，答错不惩罚、只有变慢，通关必得奖励。

## 2. 全部任务共享的工程约定

- 零第三方依赖：原生 JS IIFE + `"use strict"`；模块同时挂 `module.exports` 与 `window.BookPlayBattle*`；测试 `node:test`（`prj/engine/*.test.mjs`）。
- 纯逻辑（battle-core）与浏览器网关（battle.js）分离。
- 存储键一律 `bookplay_battle_` 前缀 + `_v1` 版本号（详见 04 文档存储合同）。
- **数据只增不改**：`content/game/` 为新增目录，绝不修改 `content/` 既有文件与 `data/`。
- 新 `.html` 必须引入 `tv.css` 与 `tv-remote.js`（`tv-ui.test.mjs` 强制）；布局需适配电视 D-pad 焦点与触屏。
- 打包：`scripts/prepare-mobile.mjs` 整目录拷贝 `prj/engine/`，新页面无需登记；`content/game/` 需在 `pack_datapack.py` 的 `INCLUDE_DIRS` 登记一行。
- 完成标准：`npm test` 全绿零失败（测试只增不减）+ `node --check` 新改 js + 更新本总览状态表 + `docs/reports/` 验收报告。
- 不 git commit（由用户决定）。

## 4. 提示词使用说明

`prompts/` 目录下每个 `.md` 是一段自包含提示词，**新开对话时整段粘贴**即可执行对应任务。提示词已包含项目路径、必读方案文档、TDD 步骤、硬性约束和验收命令，不依赖本对话的任何上下文。按第 1 节顺序执行；T5 与 T2/T3/T4 相互独立可乱序。
