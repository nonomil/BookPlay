# 04 · 熏听清单与睡前模式（增强既有磨耳朵）

## 目标

参考材料：熏听要"碎片化时间播放 2-5 遍，假期累计 1-2 小时/天"。现有磨耳朵只支持单集 1-3 遍。本特性加：**多集连播清单**（本集播完自动接下一集，audio-only）、**睡前模式**（N 集 + 定时淡出停止）、**累计熏听时长**（给家长看坚持，不给压力）。

## 现状与数据基础

- `listen-mode.js`：`createListenSession({loops(1-3), subtitle(en/enzh), autoStop, beforeIndex})`，纯状态机（advance/loop/done），wala.js 消费（`mode=listen&visual=audio` 入口，地图节点直达）。
- 各集音频：`dialogue_stories/ep{N}.json` 的 `audio`（整集 MP3）+ 每节点 `audio_start/audio_end`；wala 磨耳朵按节点切片连播。
- 集解锁状态：`map.js` 的 progress（`bookplay_adv_progress`）只读参考；睡前模式允许"已解锁的集"连播（不越权解锁新集）。

## 产品设计

- **清单连播**：磨耳朵结束页（现"再来一遍/返回"处）新增"连播下一集 ▶"默认勾选项；开启后本集 done → 自动加载下一集 audio-only 模式，直到手动退出或达到集数上限（默认 3 集）。深链支持 `wala.html?ep=N&mode=listen&queue=3`（从 ep 起连 3 集）。
- **睡前模式**：`queue=bedtime`（或地图磨耳朵长按/入口选择）：连播已解锁集 + 每集循环 1 遍 + 结束后**音量渐弱 30 秒停止**；屏幕自动进入暗色（已有 audio-only 遮罩调暗即可）。
- **累计时长**：新增 `bookplay_listen_stat_v1 = { "2026-09-04": seconds, ... }`（按天累计，只记磨耳朵播放中的秒数，暂停/退出不记）。展示两处：磨耳朵结束页"今天已听 X 分钟"；`companion.html`（驿站/伙伴页）家长角"最近 7 天累计"。**不做**签到/断连惩罚/目标未达提示。

## 技术设计

| 文件 | 改动 |
|---|---|
| 新 `listen-queue.js` | 纯逻辑：`createListenQueue({ episodes:[ep...], loops, bedtime })` → `next()` / `snapshot()` / `done`；bedtime 的 30s 淡出计时与音量曲线（0..1 步进可注入）；不碰 DOM |
| 新 `listen-queue.test.mjs` | 队列推进/耗尽、上限钳制（1-5 集）、bedtime 淡出步进、空队列 |
| `wala.js` | 磨耳朵 done 分支接队列：解析 `queue` 参数（数字或 bedtime）；跨集加载下一集 book/audio（复用现有加载函数）；时长统计 tick（播放中每秒 +1，写入 `bookplay_listen_stat_v1`，JSON 读写容错，只保留近 30 天） |
| `listen-mode.js` | 不改状态机本身（保持纯）；如需把"整集完成"事件暴露，新增只读 helper，旧合同不变 |
| `wala.html` / `map.js` | 版本 bump；地图磨耳朵入口 title 提示"连播：结束页可开"；不做新节点（保持地图干净） |
| `companion.js` | 家长角最近 7 天累计（读 stat 键，纯展示） |

**回退**：下一集未解锁/加载失败 → 停在结束页并提示，不自动跳集。
