## 2. 全部特性共享的工程约定

- 零第三方依赖：原生 JS IIFE + `"use strict"`；模块同时挂 `module.exports` 与 `window.WalaXxx`；测试用 `node:test`（`prj/engine/*.test.mjs`），注入假 env/IDB，不依赖真实浏览器。
- 纯逻辑与浏览器网关分离（参考 `voice-core.js` / `voice.js` 的分层）。
- 存储合同：新键一律 `bookplay_` 前缀 + 版本号；`bookplay_sp` 等既有键只读不改。音频/大对象进 IndexedDB，不进 localStorage。
- 不修改：`content/`、`data/`（`dialogue_stories` 只读）、视频/图片/音频资产、既有进度与奖励判定。
- 新增 `.html` 页面必须引入 `tv.css` 与 `tv-remote.js`（`tv-ui.test.mjs` 合同强制）。
- 打包：`scripts/prepare-mobile.mjs` 整目录拷贝 `prj/engine/`，新文件无需登记；`npm run android:prepare` 后需在 `dist/engine/` 目检。
- 每个特性完成标准：`npm test` 全绿 + `node --check` 新改文件 + 更新本总览状态列 + 在 `docs/reports/` 落验收报告（区分"已验证/真机待验"）。
