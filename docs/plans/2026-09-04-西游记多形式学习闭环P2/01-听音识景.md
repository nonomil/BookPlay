# 01 · 听音识景（对应 WowEnglish"听音识图"，低幼最推荐）

## 目标

巩固页新增"听一句原声 → 从 3-4 张本集场景插图中选出对应画面"的题型。孩子说不出来不代表没听懂——图片选对就是懂。零新资产：插图与音频全部来自本集既有数据。

## 现状与数据基础

- `lesson.js`（知识巩固页，`lesson.html?ep=N`）已加载 `../data/lesson_guides/{epKey}/lesson.json`，缺失时回退 `../data/dialogue_stories/ep{N}.json`（`lesson.js:1110` 附近）。book.nodes 每节点带 `illustration`（`assets/adv_frames/ep{N}/f*.jpg`）与 `text_en`。
- `lesson-core.js` 现有题型：`word_choice / sentence_choice / word_review / sentence_order / sentence_fill`，均为文字选项；出题入口 `prepareEpisodeQuiz / quizQuestions`（`lesson.js:276-326`）。
- 音频播放可复用原声切片：`book.audio` + `audio_start/audio_end`（与 `dub.js` 的 `playSliceOn` 同构）；无切片时回退 Edge-TTS 句子音频（`/api/tts`）。

## 产品设计

- 出现在每集巩固题列的前 1-2 题（低幼等级 g1_2 可到 3 题；`bookplay_lesson_settings_v1.gradeBand` 控制数量）。
- 题面：▶ 自动播放一句原声（可点重听，最多不限）；选项为 2×2 四张本集插图（g1_2 为 2 张），正确项 = 该句所属节点插图，干扰项 = 同集其他节点插图（优先选画面差异大的：按 node 间隔取远端节点）。
- 交互：点图即答；答对礼花短反馈，答错"再听一遍"重选（不判负、不计入错题统计压力，但记录一次作答事实）；家长提示文案"图片对了就是懂"。
- 电视版/无音频：自动播放失败时显示"点喇叭听"按钮，不阻塞。

## 技术设计

| 文件 | 改动 |
|---|---|
| `lesson-core.js` | 新增纯逻辑 `buildListenPictureQuestions(book, { count })`：从 `nodes` 过滤（有 text_en + illustration + 切片），确定性（同集同 seed 稳定出题，沿用现有 `stableCards` 思路）选出题句与干扰插图；返回 `[{ kind:"listen_picture", audio:{from,to}|tts, textEn, correctNode, options:[nodeId...] }]`。选项顺序用可复现洗牌 |
| `lesson.js` | 装配新题型卡：渲染插图选项（懒加载 `<img>`）、播放切片、判定、`recordQuizAnswer` 接入（计对错但 `aria-live` 文案温和）；语音/音频失败回退重听按钮 |
| `lesson.css` | 插图选项网格样式（TV 侧由 tv.css 放大命中区） |
| `lesson-core.test.mjs` / 新 `lesson-listen-picture.test.mjs` | 出题数量钳制、干扰项不与正确项重复且来自同集、无插图/无台词节点被剔除、确定性（两次构建同序）、切片缺失回退 tts 字段 |
| `lesson.html` | 版本号 bump |

**不新增**存储键（复用 `bookplay_lesson_progress_v1` 的题记录结构，新增 kind 字段向后兼容：旧存档读不到 kind 的题按原逻辑处理）。
