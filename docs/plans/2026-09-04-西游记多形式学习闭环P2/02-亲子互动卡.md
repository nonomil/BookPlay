# 02 · 亲子互动卡（对应 WowEnglish"亲子互动卡"Ask & Answer）

## 目标

解决家长"不知道问什么"：把每集核心句变成大字问答卡。家长照中文问一句，孩子指图或说出来都算对。把练习当互动，不是当考试——所以不做判定、不记对错。

## 现状与数据基础

- `dialogue_stories/ep{N}.json` 已有：
  - `patterns`：每集约 3 条 `{pattern(英文句), term, zh(词义)}`；
  - `nodes[]`：`text_en/text_zh/illustration/speaker/audio_start/audio_end`；
  - `vocab`（节点级词卡，含 `term/zh/phrase_en/phrase_zh/ipa/pos/def`）与 `official_words`（每集约 30 条）。
- 单靠 `patterns` 每集只有 3 张卡太薄，需自动生成补充卡（见下）。数据全部只读，前端组装即可，**无需任何内容加工**。

## 产品设计

新页 `parent.html?ep=N`（家长引导式界面，孩子可坐在旁边指图）：

- 卡片分两类：
  1. **句型卡**（来自 patterns + 含该 term 的节点句）：正面"家长问：…中文提示…"（由 `zh` + 模板生成，如"小猴子在哪里游泳？用英语说说什么在水上滚动"），背面/点开显示英文原句 + ▶ 播放原声切片；配该句插图。
  2. **指图卡**（自动生成，来自节点 vocab）：正面"家长问：XX（中文）在哪里？指给爸爸妈妈看"，配插图；点击插图高亮 + 播放该词英文原音（复用 `word-token-audio` / TTS）。
- 交互只有三个：▶ 听原声、翻卡看答案、-button："我说出来啦 ⭐"（点亮星星，纯鼓励，本地计数 `bookplay_parent_card_v1[ep] = {stars, date}`，无对错、无奖励发放——奖励语义保留给测验与配音）。
- 顶部家长须知三条（照参考材料）：照中文问就行；指图也算回应；答不上来很正常。
- 入口：`lesson.js` 巩固完成页加"亲子时间"按钮 + `map.js` 节点悬浮（与 🎙 同排可选，若地图拥挤则只放 lesson 页）。

## 技术设计

| 文件 | 改动 |
|---|---|
| 新 `parent-core.js` | 纯逻辑 `buildParentCards(book)`：patterns 句型卡（找到 pattern 在 nodes 中的匹配节点取插图与切片，匹配用归一化包含；找不到则无图卡）；vocab 指图卡（每节点取 `vocab[0..2]` 且词在 `page_words` 中、节点有插图；全集钳制 ≤10 张）；卡片确定性排序（句型卡在前）。中文问句模板表 |
| 新 `parent.html/css/js` | 渲染卡片流（上一张/下一张、缩略进度点）；播放切片复用 dub.js 的 `playSliceOn` 模式（可提为共享小工具或复制 20 行实现，避免为复用而过度抽象）；星星计数写 `bookplay_parent_card_v1` |
| `parent-page.test.mjs` | 静态合同（脚本引入顺序含 tv-remote/tv.css、存储键、无 eval） |
| `parent-core.test.mjs` | 卡片数量钳制、句型卡匹配失败降级无图卡、指图卡词/图配对、确定性 |
| `lesson.js` / `lesson.html` | 完成页入口按钮（版本号 bump） |
