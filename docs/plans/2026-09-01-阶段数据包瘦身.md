# 阶段数据包瘦身实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 生成一个可配置的阶段数据包，显式选择 c01（可扩展到 c02）时只带公共索引/公共音频、已发布的 Mikey & JJ 与 Minecraft 绘本及所选西游记资源，避免把 108 集视频和全部共享音频重复带入；无选择器时保留旧的全量打包兼容行为。

**架构：** 打包器先根据 `collections.json` 将合辑 ID 解析为集号，再按 JSON 实际引用收集选中集的对话、巩固、视频、adv_frames、每集词汇音频和共享句子音频。公共索引保留完整索引文件但只写入被选内容，发布绘本按 catalog 和 JSON 引用闭包收集对应 JSON、图片、整本音频和句级音频。ZIP 内加入 `pack-manifest.json`（文件清单、SHA-256、大小、集合和版本），桌面/Android 现有单 ZIP 读取路径不变。

**技术栈：** Python 3 标准库（argparse、json、hashlib、zipfile、pathlib）、pytest。

### 任务 2：实现选择性文件收集与共享音频闭包

**文件：**
- 修改：`prj/tools/pack_datapack.py`

**步骤 1：解析选项**

新增 `--collections`（逗号分隔，阶段模式示例 `c01` 或 `c01,c02`）、`--published`（`none`、`mikey-jj`、`minecraft`、`all`）和 `--version`。保留无参数全量模式的兼容入口，阶段模式显式使用选择器。

**步骤 2：实现集合解析**

从 `dialogue_stories/collections.json` 读取 `id/from/to`，去重并排序集号；选择 c01/c02 时同时保留过滤后的 `collections.json`，避免地图显示不存在的其它合辑。

**步骤 3：实现 JSON 引用闭包**

递归扫描选中 `dialogue_stories/epN.json`、`drill/cNN.json`、已发布绘本 JSON 的字符串字段；仅收录存在且位于 content 根目录内的 `assets/...` 引用。对共享索引（`sent_en_index.json`、`sent_zh_index.json`、`en_index.json`、`zh_index.json`、quiz 索引）保留索引文件，但只把被选闭包命中的媒体写入 ZIP；每集 `adv_audio/epN/index.json` 与其词汇音频完整收录。

**步骤 4：保护路径与缺失引用**

拒绝 `..` 穿越和 content 外绝对路径；对缺失引用收集警告并写入 manifest，不静默误打包整个目录。公共 UI、cast、companions、achievements、地图背景等小型运行时依赖按固定白名单收录。

### 任务 3：写入清单、生成阶段 ZIP 和体积报告

**文件：**
- 修改：`prj/tools/pack_datapack.py`
- 创建：`prj/tools/report_stage_pack.py`
- 修改：`打包数据包.bat`
- 修改：`.gitignore`（只增加阶段 ZIP/报告输出忽略规则，不放宽媒体入 Git）

**步骤 1：生成 manifest**

在 ZIP 根目录写入 `pack-manifest.json`，字段包含 schema_version、pack_id、version、created_at、collections、episodes、published_books、file_count、total_bytes、files（path/size/sha256）、warnings。manifest 的哈希清单不包含自身，避免自引用。

**步骤 2：生成两个可复用命令**

```powershell
python -X utf8 prj/tools/pack_datapack.py --collections c01 --published all --version 0.1.6 --out release/西游记数据包-01-c01.zip
python -X utf8 prj/tools/pack_datapack.py --collections c01,c02 --published all --version 0.1.6 --out release/西游记数据包-01-c01-c02.zip
```

默认先生成 c01 包；c01+c02 命令作为下一阶段复用模板。脚本输出原始字节、ZIP 字节、压缩比例和按顶层目录统计。

**步骤 3：生成报告**

`report_stage_pack.py` 读取 manifest 与 ZIP，输出 `docs/reports/2026-09-01-阶段数据包体积.md`，记录文件数、体积、最大目录、排除项和校验结果。媒体、ZIP、APK 仍由 `.gitignore` 忽略，不执行整体 `git add`。
