# 跨绘本题目知识点绑定与学习闭环实施计划

**目标：** 为 Mikey & JJ、我的世界分级读物以及后续所有绘本建立一套可验证、可复用的“故事播放 → 学习 → 精学回放 → 测验 → 补救 → 奖励”数据与播放器规范，确保每一道题都能回到真实句子、场景或明确的剧情概念。

**架构：** 保留现有 `storybook.html` / `storybook.js` 作为统一消费者，内容包通过稳定的 `sentence_id`、`scene_id`、`term` 和 `concept_id` 提供证据。词汇题、听力题和剧情理解题使用不同的题型合同；运行时只消费已审核的绑定，不再从题干猜词。系列差异只放在 renderer、内容和音频适配层，学习状态、测验状态、补救和奖励保持共用。

**技术栈：** 原生 HTML/CSS/JavaScript、JSON 内容包、HTMLAudioElement、Edge TTS 预生成音频、本地 Node `node:test`、Python `pytest`、ffmpeg 解码验证；需要背景或奖励插画时，使用 `gpt-image-pipeline` 生成并保存 prompt、response、manifest 和最终 PNG/WebP。

## 2. 产品原则

1. **统一流程，系列化画布。** 两个系列使用同一学习闭环，但不强行使用同一套漫画布局。
2. **交互与教学分离。** 每个英文 token 都可点读；重点词只是经过审核的教学子集；测验只考有证据的教学点或剧情概念。
3. **题目不猜。** 若没有证据绑定，题目进入待修复报告或被移出发布包，不允许运行时 substring 猜测。
4. **先语境后卡片。** 词卡必须显示该词所在的真实英文句、中文句和句音频；理解题必须能回放相关句子/场景。
5. **失败可补救。** 低于 70% 时自动回放错题证据对应的小节，只重做错题；第二次失败不循环阻塞。
6. **奖励可解释。** 奖励和当前故事、场景或主题有关，生成图只承担视觉表达，不承担事实证据。
7. **证据优先于数量。** 题目不足时减少题数，不用无关干扰项凑满数量。
8. **缺音频可降级。** 句音频缺失时保留字幕、逐词 Edge TTS 和手动播放提示，不伪造时间戳。

## 3. 统一学习闭环

```text
完整故事播放
  ↓
精学入口（只回放含教学点的小节）
  ↓
句子学习：英文句 + 中文句 + 每词点读
  ↓
重点词卡：词形 / 音标 / 中文 / 原句 / 英文与中文音频
  ↓
本集测验：一题一屏，英文主界面，“提示”显示中文
  ↓
通过：完成卡 + 礼花 + SP/贴纸/房间物品
失败：错题证据小节 → 只重做错题
```

### 3.1 模式与状态

播放器必须区分以下状态，状态变化不能依赖 DOM 文案：

```text
story         故事播放
study         句子/重点词学习
replay        精学小节回放
quiz          全屏测验
remediation   错题补救
complete      结果、奖励和下一集入口
```

每集进度至少保存：

```json
{
  "story_completed": true,
  "study_seen_terms": ["river"],
  "mastered_terms": ["river"],
  "quiz_attempts": 1,
  "last_quiz_score": 80,
  "wrong_question_ids": ["q03"],
  "replay_completed": true,
  "reward_claimed": true
}
```

`seen` 只代表看过/听过，`mastered` 只能由测验答对或明确的掌握动作产生。奖励使用现有幂等逻辑，重复复习不得重复发放大件奖励。

## 4. 内容包合同

### 4.1 页面、句子、词卡

```json
{
  "schema_version": 2,
  "storybook_id": "minecraft_escape-from-the-nether",
  "series": "minecraft",
  "pages": [
    {
      "page_no": 11,
      "image": "assets/minecraft/escape-from-the-nether/pages/p11.webp",
      "sentences": [
        {
          "id": "mc-b1-p11-s06",
          "text_en": "They could see a portal on the other side of a river of lava!",
          "zh": "他们看见岩浆河对面有一座传送门！",
          "start_sec": 401.20,
          "end_sec": 405.70,
          "audio": "assets/minecraft/escape-from-the-nether/sentences/page-11-sentence-06.mp3",
          "glossary": [
            {
              "term": "river",
              "ipa": "ˈrɪvər",
              "pos": "N",
              "zh": "河流",
              "example_en": "a river of lava",
              "example_zh": "一条岩浆河"
            }
          ],
          "words": []
        }
      ]
    }
  ]
}
```

规则：

- `sentence.id` 在翻译、音频、词卡、题目和回放中始终稳定。
- 词卡中的 `term` 必须在该句英文中以完整词或已登记短语出现；词形变化要显式记录 lemma/表面词形，不能用 substring。
- 页面级 glossary 只能作为导入暂存；发布前必须合并到实际包含它的句子，或标记为 `scope: page` 并禁止作为句级题目来源。
- `words` 有真实 ASR 边界时用于逐词高亮；没有边界时仍可逐词点读，但不得宣传为精确同步。

### 4.2 题目合同

#### 词汇题

```json
{
  "id": "mc-b1-q01",
  "type": "meaning-choice",
  "term": "river",
  "source_sentence_id": "mc-b1-p11-s06",
  "scene_id": "scene-04",
  "prompt_en": "What does “river” mean in this sentence?",
  "prompt_zh": "在这句话中，“river”是什么意思？",
  "choices_en": ["光", "河流", "小溪"],
  "choices_zh": ["light", "river", "stream"],
  "answer": 1,
  "explanation_en": "A river is a large natural flow of water.",
  "explanation_zh": "river 指较大的自然水流。"
}
```

硬约束：`term` 必须存在于 `source_sentence_id` 的 glossary 或经过审计的句内词库；题目播放使用该句音频或该词 Edge TTS。

#### 听力题

```json
{
  "id": "mc-b1-q02",
  "type": "listen-choice",
  "source_sentence_id": "mc-b1-p11-s06",
  "prompt_en": "Listen and choose the word you hear.",
  "audio": "assets/minecraft/escape-from-the-nether/sentences/page-11-sentence-06.mp3",
  "choices_en": ["portal", "river", "helmet"],
  "answer": 1
}
```

硬约束：必须有可播放音频；音频来源必须能回到 sentence/page 记录。

#### 剧情理解题

```json
{
  "id": "mikey-b6-q03",
  "type": "comprehension",
  "concept_id": "escape-through-rooftop-helicopter",
  "source_sentence_ids": ["mj-b6-p08-s02", "mj-b6-p08-s03"],
  "scene_id": "scene-07",
  "source_text_en": "They climbed to the roof and found a helicopter.",
  "prompt_en": "How do Mikey and JJ escape?",
  "prompt_zh": "Mikey 和 JJ 是怎样逃脱的？",
  "choices_en": ["By helicopter", "By boat", "By train"],
  "choices_zh": ["乘直升机", "乘船", "乘火车"],
  "answer": 0
}
```

硬约束：理解题不强行写 `term`；必须至少有一个 `source_sentence_id` 或 `scene_id`，并能从该证据生成回放入口。

### 4.3 场景合同

```json
{
  "id": "scene-04",
  "sentence_ids": ["mc-b1-p11-s05", "mc-b1-p11-s06"],
  "label_en": "The portal across the lava river",
  "label_zh": "岩浆河对面的传送门",
  "start_sec": 398.10,
  "end_sec": 408.20,
  "learning_term_ids": ["river", "portal"],
  "reward_hint": "portal-shard"
}
```

场景是题目回放和奖励关联的最小剧情单元，建议 2–4 句、3–8 秒；没有可靠场景时可由连续 sentence id 派生，但发布前要写入稳定 `scene.id`。

## 5. 播放器与学习交互规范

### 5.1 故事层

- 完整显示原书/漫画页，不裁切、不复制气泡、不用悬浮窗遮挡原图。
- 底部固定字幕带：英文句在上、中文句在下；默认一次显示一句。
- 每个 token 都渲染为可点击元素；点击时停止当前词音频，播放该词英文；重点词额外按“英文 → 中文”播放。
- 当前播放句高亮；词级高亮只有在 `words` 有真实边界时才启用，否则使用句级状态。
- 只在音频播放期间显示说话人提示；暂停或停止立即隐藏。

### 5.2 学习层

- 学习栏只展示当前句的词卡，不把一整页几十个词挤成右栏。
- 词卡包含：`term`、音标、中文义、原句、词性、播放按钮、已学习状态。
- 进入精学回放时，先播句子，再显示目标词卡；不新增视频文件，复用 sentence/scene 时间轴。
- 没有目标词的小节不重复；每小节最多 1–3 个重点词。

### 5.3 测验层

- 一题一屏、题目和选项默认英文；中文通过“提示”按钮显示，不能默认挤在右侧。
- 题干、选项和发音按钮均可读；听力题先播音频再显示选项。
- 答题后显示英文解释，中文解释只在提示或答错时出现。
- 题目卡必须带内部 evidence，不允许仅依赖显示文本查找来源。

### 5.4 补救与奖励

- 低于 70%：结果停留约 1.3 秒，自动进入错题对应的 sentence/scene；精学完成后只重做错题。
- 第二次仍未通过：显示“再学一次”和“稍后复习”，不自动循环。
- 通过：完成卡显示掌握数、礼花 1–1.5 秒、SP/贴纸；首次通过可掉落一个与本集场景相关的房间物品。
- 奖励背景、完成卡、房间物品可用 GPT 生图，但必须随包保存 prompt、response、manifest 和尺寸/透明度检查结果；生成图不改变题目证据。

## 6. 通用数据流水线

```text
原书/PDF/视频/字幕
  ↓
页面与句子清单（稳定 sentence_id）
  ↓
句级翻译、词卡、词音频、句音频
  ↓
scene 清单（sentence_ids + 时间轴）
  ↓
题目作者/生成器写入 evidence 字段
  ↓
严格 validator（未绑定即失败）
  ↓
storybook.js 只消费已验证题目
```

音频约束：

- 故事原音优先；没有原音时使用 Edge TTS 生成单词/句子音频，并在 manifest 标记 `tts_provider`。
- 句子 clip 必须有 `start_sec/end_sec` 或独立文件；边界不能来自模糊猜测。
- 运行时静态音频失败才回退 `/api/tts`，不把网络 TTS 当作内容证据。

## 7. 题目绑定验证器

新增建议入口：`prj/tools/validate_storybook_quiz_evidence.py`。

验证项目：

1. 每道题有唯一 `id` 和合法 `type`。
2. `meaning-choice` 有 `term` + `source_sentence_id`，且 term 在该句 glossary/句内词库中。
3. `listen-choice` 有可解码 `audio` 和来源句/场景。
4. `comprehension` 有 `concept_id` + `source_sentence_id(s)` 或 `scene_id`。
5. 所有来源 id 存在，题目选项和 answer 合法。
6. 不允许依赖 `questionTerm()` 的题干 substring 推断作为发布证据。
7. 题目来源句存在中文时，检查中文提示；不存在时报告但不伪造翻译。
8. 测验 term 必须出现在学习计划或可由 source sentence 生成的回放队列中。

失败报告至少包含：series、book、question id、type、缺失字段、source id、term、最近似句子和建议修复动作。

## 12. 回滚策略

- 题目迁移失败：保留原 JSON 备份，active quiz 回退为空或 legacy 只读模式，不恢复题干猜词。
- UI 回归失败：路由回退 `ui=legacy`，不删除 V3 资源和学习进度。
- 音频缺失：保持句级字幕和 Edge TTS 词读，标记缺失原因，不伪造边界。
- 生图失败：使用纯 CSS 完成卡或既有背景，不能阻塞题目证据和学习流程。

## 13. 完成定义

“完成”不是文档写完，而是用户在真实页面可以看到并走通：

```text
打开任一已迁移绘本
→ 看到一句英文和中文
→ 点击句中任意词可听音
→ 进入精学只看到该小节目标词
→ 测验题能回到源句/场景
→ 答错自动回放相同证据
→ 通过后得到与故事相关的完成卡和奖励
```
