# 播放器与豆豆龙教师 UI

## 1. 参考图转译

参考：

- `data/参考图片 -- 瓦拉英语/微信图片_20260829120616_342_4.jpg`
- `data/参考图片 -- 瓦拉英语/微信图片_20260829120617_343_4.jpg`

借鉴：顶部阶段导航、教师在侧、中央深色题板、单题一页、明确确认按钮。

不复制：紫色底纹、原教师角色、卡册图标、具体按钮造型和瓦拉品牌文本。

## 2. 豆豆龙视觉

第一版复用：`content/assets/ui/doudou-loong-icon.png`。

课程页建议资产合同：

```text
content/assets/ui/teacher/
  doudou-idle.webp
  doudou-ask.webp
  doudou-correct.webp
  doudou-encourage.webp
```

若新表情尚未生成，全部回退 `doudou-loong-icon.png`，用 CSS 的轻微呼吸、点头和提示气泡表达状态。动画每屏最多 1–2 个元素，并支持 `prefers-reduced-motion`。

## 3. 配色

- 主色：豆豆绿 `#58B368`；
- 辅色：奶油黄；
- 点缀：草莓橙；
- 题板：深墨绿/深蓝黑，不使用参考图的品牌紫；
- 正文：高对比奶白；
- 正确：绿色 + 对勾 + 文本；
- 错误：橙红 + 图标 + 文本，不只依赖颜色。

## 4. 桌面布局

```text
┌ 本集 · 巩固进度  [本集回顾][单词][句型][挑战]  稍后巩固 ┐
│ 豆豆龙教师 │          中央课程题板              │
│ 提示气泡   │  图片 / 题目 / 选项 / 排序         │
│            │          主要操作按钮              │
└─────────────────────────────────────────────┘
```

豆豆龙占宽约 22%，题板约 68%，保留安全边距；顶部阶段只显示本轮实际卡数，不伪造锁定内容。

## 5. 移动布局

- 顶部阶段导航可横向滚动；
- 豆豆龙缩为左下角 96–128px 教师头像；
- 提示气泡在题板上方；
- 选项改单列；
- 触控目标至少 44×44px；
- 不为移动端复制另一套 DOM。

## 6. 状态机

新增模块：`prj/engine/lesson-cards.js`。

```text
PLAY_SENTENCE
  → SENTENCE_END
  → NEXT_SENTENCE（普通句）
  → EPISODE_COMPLETE（最后一句）
  → CONSOLIDATION_ENTER
  → CONSOLIDATION_ACTIVE
  → CONSOLIDATION_FEEDBACK / NEXT_CARD
  → CONSOLIDATION_RESULT
  → EPISODE_END / NEXT_EPISODE
```

硬规则：

- 普通字幕结束后只进入下一句，不查询、不渲染课程卡；
- 最后一句结束后调用现有停止逻辑，再进入知识巩固；
- 知识巩固未完成或未明确跳过时，本集结束/下一集按钮不得穿透；
- `free_talk` 可以明确跳过；
- 答错允许继续选，不自动退出；
- 退出后只能进入本集结束一次，防止媒体回调和按钮双重结算；
- 故事遍和精学遍都不在句间调度课程卡；
- lesson 文件缺失时直接进入既有本集结束界面，零行为变化。

## 7. 可访问性

- 课程页使用 `role="dialog"` 或明确的主区域语义；
- 进入时焦点移动到标题，退出后移动到本集结束/下一集主操作；
- 错误信息用 `aria-live`；
- 图片有教学意义时必须有 alt；
- 键盘支持方向键/数字键选择和 Enter 确认；
- CSS 支持 `prefers-reduced-motion: reduce`。
