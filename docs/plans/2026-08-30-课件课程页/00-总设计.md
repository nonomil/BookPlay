# 总设计

## 1. 用户结果

孩子先连续看完整集，不在每句字幕后被题目打断。最后一句结束后进入一张清晰的“知识巩固”全屏页；左侧/侧下方由豆豆龙提示任务，中间每次只完成一个学习动作，完成后进入本集结果与下一集。

## 2. 内容来源取舍

| 来源 | 使用方式 | 不做什么 |
| --- | --- | --- |
| `3.3西游记...PPT课件` | 主课程源：热身、词汇、故事精讲、语法、写作、排序、题目、答案 | 不直接嵌 PPT；不把整页永久当唯一 UI |
| `G092...108章PPT课件` | 105 集哈希相同，只作去重校验；42/61/97 作版本候选 | 不重复导入 105 集 |
| `西游记-外教课动画截图` | 场景匹配、图片题、关键帧候选 | 不把约 5000 张截图全部塞入数据包 |
| `西游记外教培训11集课件` | 教师目标、追问、完整句提示、Free Talk | 不伪造其余 97 集官方教师内容 |
| `西游记外教课pdf` | 来源比对和场景图备查 | 不作为主导入源 |

## 3. 课程卡类型

首期只支持七种稳定类型：

- `word_review`：单词、英文释义、中文释义、原句、图片；
- `image_choice`：看图选择；
- `sentence_choice`：句子/剧情选择；
- `sequence`：事件排序；
- `grammar`：语法对照与一题练习；
- `expression`：仿写、修辞、句型；
- `free_talk`：开放表达，可跳过，不判错。

每张课程页只承担一个学习动作。课件里的三道题需要拆成三张交互卡，而不是照搬成密集静态图。

## 4. 课程节奏

- `warmup`：进入本集前，可选，首期不实现；
- `episode_complete`：最后一句结束后进入一次本集知识巩固；
- `teacher_only`：教师/家长模式，不进入儿童默认流程。

首期只实现 `episode_complete`。课程卡按 `order` 排序，不再绑定某个字幕 node。

## 5. 来源与版权

所有课件仅限现有个人学习用途。生成物保留来源路径、文件哈希、页码和提取方式；不写入公开代码仓库，不进入对外发布渠道。

## 6. 失败回退

- `lesson.json` 不存在：完全沿用当前播放器；
- 单卡 schema 非法：跳过该卡并记录控制台错误；
- 图片缺失：显示文字卡，不阻塞巩固流程；
- OCR 低置信度：进入 `needs_review`，禁止成为正式互动题；
- 题目答案未从 Answer Key 反校验：只能以预览形式出现。
