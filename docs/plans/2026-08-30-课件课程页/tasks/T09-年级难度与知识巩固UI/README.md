# T09 年级难度与知识巩固 UI

**目标：** 每集最后一句结束后进入一次豆豆龙知识巩固页，并按年级段和巩固强度稳定选择题目。

**设置：**

- 年级段：`g1_2 | g3_4 | g5_6`
- 巩固强度：`light | standard | challenge`
- 默认：`g3_4 + standard`
- 存储：`bookplay_lesson_settings_v1`

**基准题量：** 一二年级 4 题、三四年级 7 题、五六年级 10 题；强度再乘 0.7/1.0/1.3，并受已验证卡数限制。

**硬门禁：**

1. 普通字幕结束不读取、不显示课程卡。
2. `episode_complete` 每集只触发一次。
3. 完成或明确跳过前，下一集入口不可穿透。
4. 设置只筛选展示，不改变完整题库。
5. `lesson.json` 缺失时播放器沿用旧结束路径。
6. 课程存储、媒体、学习计划和测验逻辑逐步移出 `wala.js`，且每步有回归测试保护。
7. 每集巩固不得替换每辑 `drill.html` 门禁，不改变 `bookplay_drill`、`colUnlocked`、`epUnlocked` 的既有语义。
8. 修改本任务 UI 前，先完成 `docs/handoff/001_西游记巩固单元交接_20260830/` 的 c01 真实通关闭环 P0。
