# T05 豆豆龙教师 UI

**目标：** 用豆豆龙替代参考图中的外部教师角色，形成项目自己的整集知识巩固页视觉。

**文件：**

- 修改：`prj/engine/wala.html`
- 修改：`prj/engine/wala.css`
- 修改：`prj/engine/lesson-cards.js`
- 读取：`content/assets/ui/doudou-loong-icon.png`
- 可选生成：`content/assets/ui/teacher/*.webp`

**步骤：**

1. 先用现有豆豆龙图标做功能版，不阻塞交互。
2. 实现 idle/ask/correct/encourage 四状态回退合同。
3. 使用豆豆绿、奶油黄、草莓橙和深墨绿题板。
4. 实现桌面侧栏与移动左下教师头像。
5. 增加 focus、aria-live、键盘、44px 触控目标。
6. 增加 reduced-motion。
7. 在 320/768/1280/1920 宽度检查截图。

**禁止：** 复制参考图教师角色、紫色皮肤、品牌图标或直接使用 emoji 作为课程导航图标。
