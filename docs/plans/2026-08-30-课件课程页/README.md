# 课件课程页方案包

本方案把课件导入分成“内容生产”和“运行时消费”两条车道。先得到可人工复核的内容包，再接入播放器，避免 OCR 结果直接污染 108 集正式数据。

## 文件导航

| 文件 | 内容 |
| --- | --- |
| `00-总设计.md` | 产品边界、学习流程、来源取舍与阶段门禁 |
| `01-数据合同.md` | lesson guide、课程卡、进度与来源字段 |
| `02-内容资产流水线.md` | PPTX/PDF 图片、文字、OCR、Markdown 和 JSON 生产流程 |
| `03-播放器与豆豆龙教师UI.md` | 整集结束后的知识巩固状态机、参考图转译、响应式和无障碍 |
| `04-验证与发布门禁.md` | 单测、数据校验、视觉检查、Android 与批量门禁 |
| `tasks/` | T01-T09 可独立执行的任务卡 |

## 核心决定

1. 不把 PPTX/PDF 作为播放器页面直接打开。
2. 不把课件字段直接塞进 `dialogue_stories/epN.json`。
3. 生成内容位于 `content/lesson_guides/`，不进入 Git。
4. 代码、schema、测试和计划进入 Git；媒体继续排除。
5. 第 1 集是黄金样本；未通过 EP1 验收前不批量处理 108 集。
6. 参考图只借鉴“阶段导航 + 教师侧栏 + 中央题板 + 单题一页”的信息架构，不复制瓦拉角色、紫色皮肤或品牌素材。
7. 豆豆龙使用项目现有形象，第一版允许复用圆形图标；新表情资产是独立任务，不阻塞数据与交互闭环。
8. 官方测试题共 540 道，完整入库但必须重建答案证据；现有启发式答案不得直接视为正式答案。
9. 年级段与巩固强度只决定本轮展示子集，不删除完整题库。

## 可见学习流程

```text
逐句视频/字幕连续播放
  → 普通句结束：直接下一句
  → 最后一句结束：触发 episode_complete
  → 切到豆豆龙“知识巩固”页
  → 本集单词 / 句型 / 图片题 / 排序题 / 自由表达
  → 显示本集巩固结果，或明确“稍后巩固”
  → 进入本集结束 / 下一集
```

故事遍和精学遍的逐句播放都保持连续；只在整集结束时进入一次知识巩固。`lesson.json` 缺失时直接沿用现有本集结束流程。
