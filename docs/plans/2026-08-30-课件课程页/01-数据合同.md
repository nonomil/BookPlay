## 4. 规则

- `card_id` 全集唯一且稳定；
- 所有儿童默认卡的 `stage` 必须为 `episode_complete`，不得绑定字幕 node；
- 同一集 `order` 必须唯一且从 1 稳定递增；
- 选择题 `answer` 必须引用有效 choice id；
- 客观题必须有 `answer_evidence`；旧脚本推断答案不能直接作为真值；
- `difficulty` 为 1–5，`grade_bands` 只决定展示范围，不得从完整题库删除卡；
- `free_talk` 不允许带正确答案；
- `needs_review` 卡不得进入默认运行 catalog；
- 来源页与哈希不可缺失；
- 与 `official_quiz` 语义重复的题保留一个 UI 实例，但来源数组可合并。

## 5. 存储合同

新增 `localStorage` 键：

```text
bookplay_lesson_progress_v1
```

值：

```json
{
  "1": {
    "seen": ["card-id"],
    "right": ["card-id"],
    "wrong": ["card-id"],
    "skipped": ["card-id"]
  }
}
```

不改变已有 `bookplay_adv_progress`、`bookplay_adv_vocab_stat` 和 `bookplay_sp` 结构。答对课程题是否加 SP 由卡字段显式决定，且每卡最多结算一次。

设置另存为 `bookplay_lesson_settings_v1`：

```json
{"grade_band":"g3_4","challenge_level":"standard"}
```
