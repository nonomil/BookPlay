# 验证与发布门禁

## 1. 内容门禁

- EP1 图片页数与源 slide 数一致；
- Markdown 图片顺序与原课件一致；
- 每个结构化字段可追溯到 source file + slide；
- OCR 低置信度字段标记 `needs_review`；
- 选择题答案经 Answer Key 校验；
- 所有儿童默认卡均为 `episode_complete`，且 `order` 唯一稳定；
- 和官方题重复时只展示一次。
- 108 集官方测试题必须正好 540 道，且所有可运行答案都有台词证据；
- 216 份带标注精读 PDF 必须按 108 集上/下成对并留下来源收据；
- 设置只改变本轮题量/题型，不得修改完整题库。

## 2. 代码门禁

```powershell
python -m pytest prj/tests -q
node --test prj/engine/*.test.mjs
python -X utf8 prj/tools/validate_data.py
python -X utf8 prj/tools/validate_storybooks.py

```

## 3. 行为验收

EP1 至少验证：

1. 剧情遍和精学遍逐句连续播放，任何普通字幕结束后都不出现巩固页；
2. 最后一句结束后恰好进入一次知识巩固页；
3. 单词、选择、排序和自由表达各有一张可用卡；
4. 答错不退出，答对只加一次分；
5. 完成或明确跳过后恰好进入一次本集结束/下一集界面；
6. 刷新后已完成课程卡不会重复结算；
7. 删除/改名 lesson JSON 后播放器仍正常；
8. 320px、768px、1280px、1920px 无横向滚动或遮挡；
9. reduced-motion 下无持续呼吸/弹跳。

## 4. 批量门禁

只有 EP1 内容、UI、回退和存档全部通过后，才运行 `--all`。批量时先 2–10 集小批，再 108 集。

第 42、61、97 集必须在 source manifest 中有显式版本选择，不允许脚本按目录顺序猜。

全量最低数量门禁：108 个 lesson guide、540 道官方测试题、216 份带标注精读来源收据；每集至少存在一套可运行巩固卡池或明确的 `needs_review` blocker。

## 5. Android 门禁

首个 Web 验收不修改 APK。进入 Android 阶段后才更新：

- 数据包 include 规则；
- lesson guide manifest；
- DataPack ready 校验；
- ZIP Range/图片读取测试；
- 真实手机横屏与竖屏检查。

未完成真机测试不得称发布完成。

## 6. 既有每辑巩固门禁

新增每集知识巩固前，必须保留 `drill.html?c=cNN` 的每辑门禁语义。打 APK 前按 `docs/handoff/001_西游记巩固单元交接_20260830/行动项/下一步行动.md` 完成 c01 端到端验证：三种题型完成、出现通过卡、写入 `bookplay_drill.c01.done=true`、返回地图后 c02 和第 8 集真实解锁。只验证到“能出题”不算通过。
