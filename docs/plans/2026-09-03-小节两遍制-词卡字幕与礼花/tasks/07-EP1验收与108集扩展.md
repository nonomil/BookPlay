# 任务 07：EP1 验收与全量扩展

**目标：** 先用三个系列的第 1 集证明闭环，再按数据质量门槛扩展到西游记 108 集、Minecraft 5 本和 Mikey & JJ 已发布书目。

## 文件与入口

- 浏览器：`prj/engine/storybook.html`
- 数据目录：`prj/data/storybooks/`、`prj/data/storybooks-minecraft/`、`prj/data/storybooks-mikey-jj/`
- 校验：`prj/tools/validate_storybooks.py`
- 现有测试：`prj/tests/`、`prj/engine/*.test.mjs`
- 验收记录：`docs/generated/storybooks/acceptance/2026-09-03-ep1.md`

## 步骤

1. 运行现有回归：

   ```powershell
   node --test prj/engine/episode-reward.test.mjs prj/engine/storybook-ui.test.mjs prj/engine/storybook-route.test.mjs
   pytest -q prj/tests/test_storybook_learning.py prj/tests/test_storybook_text.py prj/tests/test_minecraft_storybook_pipeline.py prj/tests/test_minecraft_vocab_audio.py
   ```

2. 启动本地 8810 服务，分别打开 Minecraft Book1、Mikey & JJ Book1、JTTW EP1，录下完整播放→精学→测验→奖励的证据。
3. 按验收表逐项勾选：连续剧情、scene 队列、全词点读、词卡中英文、错词回放、分级题量、70% 通过、完成卡、幂等奖励、刷新恢复、移动端。
4. 修复 EP1 阻塞项并重新跑回归；未通过不得扩展批量数据。
5. 批量生成 scene/quiz/visual manifest；每批先跑 schema、时间轴、音频解码、图片引用扫描，再进入下一批。
6. 生成全量报告：缺失字幕、缺失词音频、缺失图片、无证据奖励、不可播放媒体均列出，不以“文件存在”代替可用性。

## 批量门槛

- 西游记：108 个 `ep*.json` 可解析，已有奖励目录不回归。
- Minecraft：5 个 book JSON 与 `vocab/index.json` 通过；全词静态音频索引不出现悬空路径。
- Mikey & JJ：catalog 中已发布书目全部有页面、句子、音频 manifest；未匹配视频继续标记为未发布，不强行生成。
- 所有生图资产 manifest 的 source evidence、尺寸、hash、运行时路径完整。

## 验收标准

- 三系列 EP1 全流程成功率 100%，无控制台错误、无横向滚动、无奖励重复。
- 全量报告中阻塞项为 0；非阻塞 fallback 有明确数量、原因和后续任务。
- 旧 URL/旧数据在 feature flag 关闭时仍可打开。

## 回滚边界

批量扩展按系列/批次提交；某一系列失败只回滚该系列新增 manifest/scene，不回滚已验收的其他系列或源媒体。
