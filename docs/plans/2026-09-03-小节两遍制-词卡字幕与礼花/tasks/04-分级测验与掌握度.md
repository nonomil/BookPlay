## 步骤

1. 写失败测试：一二年级 3–5 题、三四年级 5–9 题、五六年级 7–14 题；题目携带 term、句子、音频和正确选项；得分达到 0.7 才通过。
2. 运行 `node --test prj/engine/episode-vocab-quiz.test.mjs`，预期失败。
3. 实现确定性题目生成器：干扰项优先同集词池；固定随机种子方便重放；听音、认词、语境填空按难度开启。
4. 接入错词队列和重测逻辑；跟读/语音识别作为可选记录，不改变必过结果。
5. 运行单测和现有 drill 测试：`node --test prj/engine/storybook-practice.test.mjs prj/engine/drill-voice.test.mjs`。

## 验收标准

- UI 同时显示“已学习 X/Y”和“已掌握 X/Y”。
- 首次答错显示正确答案并进入错词回放；不会扣除旧掌握词。
- 通过后再次测验可更新最好成绩，但不重复发放奖励。
- `drill.html` 的独立解锁测试保持通过。

## 回滚边界

题库缺失时使用现有基础选择题；若题目生成失败，保留完整播放和词卡学习进度，隐藏测验按钮，不伪造通过。
