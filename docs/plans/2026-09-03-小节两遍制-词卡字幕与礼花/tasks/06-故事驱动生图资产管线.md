# 任务 06：故事驱动生图资产管线

**目标：** 每集从 PDF 页面、书本 JSON、字幕和 MP4/MP3 生成可回溯的完成卡、测验背景、贴纸和房间奖励视觉资产，禁止泛化背景和图内文字。

- 创建：`prj/tools/storybook_visual_manifest.py`

- 创建：`docs/generated/storybooks/<series>/ep<NNN>/references/evidence.json`
- 创建：`docs/generated/storybooks/<series>/ep<NNN>/prompts/*.prompt.txt`
- 输出：`docs/generated/storybooks/<series>/ep<NNN>/final/*`

## 步骤

1. 写失败测试：没有 source page/video evidence 时拒绝生成；manifest 缺 source、ratio、sha256 或 prompt hash 时校验失败；OCR 命中可读文字时标记失败。
2. 运行 `pytest -q prj/tests/test_storybook_visual_manifest.py`，预期失败。
3. 实现证据收集器：读取三系列 JSON，生成页面缩略图；若有 MP4，用 ffmpeg 抽取与 scene 时间轴重合的代表帧；没有视频时明确记录 `fallback: page_image`。
4. 生成事实表和 prompt：书名、集数、角色、地点、动作、道具、重点词、构图安全区、比例、负面词全部来源可追溯。
5. 按现有 Cliprox CA 固定流程生成，命令示例：

   ```powershell
   python -X utf8 C:\Users\No'mi'l\.codex\skills\gpt-image-workflow\scripts\bee_image_workflow.py generate `
     --prompt-file .\docs\generated\storybooks\minecraft\ep001\prompts\quiz-background.prompt.txt `
     --out .\docs\generated\storybooks\minecraft\ep001\final `
     --prefix quiz-background --size 1536x1024 --provider cliprox
   ```

6. 校验尺寸、alpha、OCR、SHA-256 和证据回溯；通过后复制到 `prj/assets/generated/storybooks/...` 并更新运行时 manifest。
7. 运行 `pytest -q prj/tests/test_storybook_visual_manifest.py`，再做浏览器资源加载抽样。

## 系列风格约束

- Minecraft：方块化材质、来自本集生物群系/工具/装备；不生成泛化“游戏背景”。
- Mikey & JJ：沿用漫画角色比例、线条和本集动作/地点；普通奖励也必须来自剧情道具。
- 西游记：沿用现有国风绘本视觉与 `prj/data/rewards/jttw.json` 主题，不混入另外两个系列。

## 资产验收标准

- 每个资产至少关联一个页码或视频时间点，并能在 `evidence.json` 找到。
- 横版实际宽高比 ≥1.4；低于阈值自动删除并重试。
- 图内无英文、中文、Logo、水印；文字全部网页叠加。
- 生成失败时 manifest 写 `fallback`，播放器可继续使用默认背景。

## 回滚边界

只回滚 `prj/assets/generated/storybooks/<series>/ep<NNN>/` 和 manifest 引用，不删除源 PDF、MP4、MP3 或原始页面图；资产失败不影响剧情播放和测验。
