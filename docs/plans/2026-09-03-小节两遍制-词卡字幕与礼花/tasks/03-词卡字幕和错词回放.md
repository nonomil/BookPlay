# 任务 03：词卡字幕、全词点读与错词回放

**目标：** 每句话的每个英文单词都可点读；精学时在原字幕位显示词卡；错题只回放关联 scene。

## 步骤

1. 写失败测试：标点、缩写、Mikey、JJ 等 token 化；优先静态词音频，其次句子时间轴 seek，最后 `/api/tts` 兜底；没有音频时显示不可用状态而不是假成功。
2. 运行 `node --test prj/engine/word-token-audio.test.mjs`，预期失败。
3. 实现 token 渲染和音频解析，点击 token 时只播放该词/邻近短片段；目标词增加中文释义和 IPA，普通词不增加浮窗。
4. 增加精学字幕模式：英文原句保持一行，高亮当前 term，下方词卡按顺序轮播；中英文播放按钮复用已审核音频。
5. 实现 `wrong_terms → scene_ids` 索引，错词回放后只重测错词。
6. 运行 Node 单测；检查 Minecraft 1000 个静态词音频、Mikey & JJ 重点词音频解码。

## 验收标准

- 任意一句话中的任意英文 token 均能触发读音。
- 词卡播放一次只记 `seen/learned`，不记 `mastered`。
- 普通词无重点样式但可点读；重点词有高亮、中文、发音按钮。
- 错词回放不从集首重新播放，也不清空已掌握词。

## 回滚边界

静态词音频缺失时保留 `/api/tts` 兜底；若 token 层报错，回退为整句字幕和整句音频，不阻塞剧情播放。
