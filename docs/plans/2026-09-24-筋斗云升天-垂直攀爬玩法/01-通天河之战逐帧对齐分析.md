## 1. 逐帧拆解（方法提炼）

### 1.1 frame_6 大厅
| 元素 | 方法 |
|---|---|

| 中央大立绘 | 章节主角占屏 1/3，制造"这是大游戏"的第一印象 |

| 右侧玩家卡：头像/齐天大圣/Lv.36/经验条 5280/9800/VIP3 | 身份与成长外显 |
| 右下 6 宫格功能：邮件/背包/任务（带红点）/设置/好友/排行 | 红点=留存钩子 |
| 右下大黄按钮「开始游戏 START ADVENTURE」 | 全页唯一主动作，双语副标 |

**方法**：大厅不是菜单，是"游戏世界观客厅"——内容未做也要摆出来（上锁），成长/资源/社交全外显。

### 1.3 frame_24/26 战斗（我方已对齐的画框布局）
补充两个此前漏看的细节：
- **左下控制台第一行是"当前教学/提示"**：`看准冰块，挥棒迎击`——提示文案随战局变化，不是固定键位说明
- **状态行实时变化**：`移动中` / `金箍棒 · 向前挥击`——把玩家当前动作复述出来（极低成本的操作反馈）
- 底部中排三按钮：`可定范围 / 重新开始 / 暂停`——可定范围疑似调试开关（攻击范围可视化）

### 1.4 frame_27/28/29 Boss 战（本游戏最精彩的设计）
| 元素 | 方法 |
|---|---|
| 顶部 Boss 横幅「灵感大王 · 15 秒后上岸」+ 进度条 | **上岸倒计时**：清完小怪不马上打 Boss，先播 15s 倒计时，期间小怪继续刷——期待感+压力感的过渡幕 |
| 右卡警告切换：「鱼妖即将上岸 · 躲泡泡和闪电」→「挥棒缩小鱼妖 · 躲开蓝色光圈」 | 每个阶段把**应对口诀写在常驻位** |
| Boss 战横幅换内容：「灵感大王 · 体型 60% · 再击中 6 棒」+ 黄色进度条 | **血量=体型**：击中 Boss 变小（视觉即血条），并直接告诉你"再击中 N 棒"——零抽象 |
| 打击反馈 toast「击中鱼妖！体型剩余 60%」 | 每次命中复述结果 |
| 两种命名攻击：泡泡（可挥棒反弹，toast「泡泡反弹！」）+ 蓝色光圈（地面 AOE） | 攻击模式少而清晰，每个都有名字和应对法 |
| 状态行「加速中」 | 玩家 buff 也进状态行 |

## 3. 教育拓展：动作×词汇的内在整合（我方差异化）

对方是纯动作游戏；我们在不破坏动作手感的前提下把词汇缝进两个动作：

1. **目标选择即认词**：场上虾兵各自头顶英文词（本集词表），顶部中央中文词牌。挥棒命中"对应词"的虾兵 = 直接击退（1 击）；打错词的虾兵 = 3 击且不算目标数。玩家自然先读词再动手——攻击不再无脑。
2. **收服仪式即复习**：Boss 体型归零后时停，弹词义卡 3 选 1（本波词），答对 → 葫芦收服演出+入图鉴；答错 → Boss 残血重来一次（只此一次，不重复罚）。错词写入 `bookplay_weak_v1`。
