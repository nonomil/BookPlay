## 二、版式方案：三栏课堂（本方案核心）

用户 directive：**播放器画面保持无字幕纯净，学习内容放到画面旁边。**

```
┌───────────────────────────────────────────────────────────┐
│ topbar  ← 地图 | 第1集·The Monkey·精读课堂 |  STEP 1 OF 5  │
├──────────┬──────────────────────────────┬─────────────────┤
│ YOUR     │ 01 / WATCH   看故事           │ 学习侧栏          │
│ JOURNEY  │ Watch & Read                  │ ┌─────────────┐ │
│ 01 看故事●│ ┌──────────────────────────┐ │ │ EN 彩色词块   │ │
│ 02 学方法 │ │                          │ │ │ Monkey splash │
│ 03 练一练 │ │   无字幕纯净播放器          │ │ │ ed through... │
│ 04 理解挑战│ │  （画面上无任何字幕/词卡）   │ │ ├─────────────┤ │
│ 05 说出故事│ │                          │ │ │ 中文翻译（灰） │ │
│          │ └──────────────────────────┘ │ ├─────────────┤ │
│ 一步一步来│ ▶ ──────●──────  2:14/5:39   │ │ 当前句单词卡   │ │
│ 故事会越  │ ✓精学逐句 ✓不逐词翻译 ✓先懂故事│ │ waterfall 🔊  │
│ 来越清楚  │ [🎧 A LITTLE MISSION 三问]    │ │ 瀑布 n. …     │
│ A LITTLE │                              │ │ ◀ 上一句 下一句▶│
└──────────┴──────────────────────────────┴─────────────────┘
```

- **左栏**：YOUR JOURNEY 五步（已实现）。
- **中栏（媒体区）**：步骤标题 + **纯净播放器**（画面上没有字幕、词卡、气泡）+ 精简控制 + 规则行 + mission 卡。
- **右栏（学习侧栏，新）**：本句 EN 彩色词块（大号、可点读）→ 中文翻译 → 当前句重点词卡（发音/释义/收生词本）→ 上一句/下一句。
- 掌机/窄屏（<900px）：右栏自动落到播放器下方（即现状上下排），不丢功能。

## 四、实施步骤

1. **wala embed 双栏化**（核心，纯 CSS+少量 JS）：
   `body.embed` 时 `.w-stage` 变两列——左 `.w-frame`（纯视频，无 dock 覆盖），右 `.w-dock` 改为固定宽度侧栏（EN 词块/中文/箭头纵向排）；`#w-cards` 从画面悬浮移入 dock 底部；字幕设置在 embed 下强制 off（画面零字幕）。
2. **study.html 步骤卡**：去掉中栏标题下的全宽 iframe 单列假设，iframe 自适应双栏内容；mission 框保持 iframe 外（中栏底部）或并入 wala embed（二选一，倾向并入，避免重复）。
3. **地图弹层进度回显**：精读卡加"已到第 X 步"（读 study 信号：第一个未完成步骤索引）。
4. **文案吸收**：规则行（✓精学逐句 ✓不逐词翻译 ✓先理解故事）、"记录首次作答·答错也可以继续探索"（lesson 可后续）。
5. **后续（不在本次）**：意群三色分组着色（基于词块数据的轻规则）；retell 图排序/句子配对；lesson 纸感化。

## 五、降级与边界

- 掌机竖屏 <900px：右栏落到底部（现状纵向流），视频高度 `min(72vh,760px)` 保持。
- iframe 内双栏最小宽度 ~720px，更窄自动退化为上下排（同现状）。
- 剧情/磨耳朵/看动画路径**不变**：三栏只属于精读课堂 embed（`body.embed`），剧情遍保持字幕叠画面的观影形态。
- 不新建任何学习数据；完成信号仍全部复用既有存储。
