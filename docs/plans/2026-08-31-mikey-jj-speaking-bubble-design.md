# Mikey & JJ 播放气泡与点词学习设计

**状态：** 用户已确认

**目标：** 让 Mikey & JJ 两本已上线绘本在切换到新句时自动播放；播放期间用放大漫画气泡覆盖原图对应文字区，并提供说话者识别、重点词彩色注释、点词朗读与播放同步高亮。

## 核心体验

1. 用户进入新句或点击“下一句”后，播放器立即停止旧音频并播放新句 MP3。
2. 音频开始时，画面内出现放大气泡；它覆盖原漫画中当前气泡的文字区域，但不遮挡角色主体。
3. 气泡仅在句音频或点词音频播放期间显示。播放结束后停留 600ms，再于 180ms 内淡出；手动暂停则立即淡出，`prefers-reduced-motion` 下直接隐藏。
4. 气泡顶部显示 `MIKEY`、`JJ` 或 `旁白`。对话气泡尾巴指向角色，旁白使用无尾巴说明框。
5. 重点词使用稳定的语义颜色，英文词下方直接显示简短中文释义。播放中当前词再增加黄色进度高亮。
6. 点击重点词会暂停句音频，朗读英文单词和中文释义；结束后从原时间继续。用户原本处于手动暂停状态时不自动恢复。
7. 右侧/下方学习区继续保留完整英文、中文和词卡，悬浮气泡不是唯一字幕来源。

## 自动播放与浏览器限制

- 同一阅读会话中，句子和页面切换都自动播放。
- 首次打开绘本时直接尝试 `audio.play()`。
- 若浏览器以 `NotAllowedError` 阻止有声播放，画面中央出现一次性的“点击开启有声阅读”按钮。用户点击后播放当前句，并记住本次会话已解锁。
- 其它播放错误不伪装成权限问题：显示“本句暂时无法播放”，保留手动播放按钮。
- 打开测验、退出页面或切换书籍时立即停止自动播放和单词朗读。

## 数据模型

每个 `sentences[]` 单元必须是一条完整句子，并扩展：

```json
{
  "id": "b2-p01-s01",
  "text_en": "Warning!",
  "zh": "警告！",
  "speaker": {
    "id": "narrator",
    "label": "旁白"
  },
  "bubble": {
    "x": 0.08,
    "y": 0.06,
    "w": 0.38,
    "h": 0.18,
    "tail": "none",
    "variant": "narration"
  },
  "words": [
    { "text": "Warning", "start_ms": 0, "end_ms": 620 }
  ],
  "audio": "assets/mikey-jj/water-house-adventure/sentences/page-01-sentence-01.mp3",
  "glossary": []
}
```

- `bubble` 坐标是相对于实际漫画图像的 0–1 归一化值，不相对于整个舞台容器。
- 同一原漫画气泡拆成多句时，多条句子可以复用同一 `bubble` 坐标。
- `speaker.id` 使用稳定枚举：`mikey`、`jj`、`narrator`、`system`。
- 两本书从当前 98 个字幕/音频单元严格拆为 118 个单句单元：Zombie School 52→64，Water House 46→54。
- `words[]` 优先保存真实词级时间；无法可靠对齐时允许按词长加权生成，但必须在数据中标记 `timing_source: "estimated"`，不可冒充精确对齐。

## 视觉规则

- 气泡：暖白 `#fffdf2`、4px 深色漫画描边、轻微硬阴影；不使用玻璃拟态。
- Mikey 标签使用珊瑚红，JJ 使用草绿色，旁白使用金黄色；正文保持深色高对比。
- 气泡宽度以原气泡为基础放大 10–18%，桌面最大 48% 图宽，移动端最大 72% 图宽。
- 字号使用 `clamp(18px, 2.1vw, 32px)`；重点词中文注释为正文的 55–62%，但不得小于 12px。
- 气泡必须定位到漫画实际渲染矩形，正确处理 `object-fit: contain` 的留白。
- 气泡出现/消失只改变透明度和轻微位移，不缩放整个漫画，不造成布局跳动。

重点词结构：

```html
<button class="sb-bubble-word sb-tone-2" data-term="flood">
  <span class="sb-bubble-word-en">flood</span>
  <span class="sb-bubble-word-zh">洪水</span>
</button>
```

普通词仍参与播放进度高亮，但只有重点词可点击并显示中文注释。

## 组件与状态

- `storybook.html` 增加图像内气泡层和一次性自动播放解锁层。
- `storybook.js` 增加统一的 `playCurrentSentence()`、`renderSpeakingBubble()`、`syncBubbleWords()` 和 `speakGlossaryWord()`。
- 单词朗读复用西游记现有 TTS/音频策略；不得与句音频同时播放。
- `storybook.css` 只在 `body.sb-mj` 下启用新视觉，不能改变 Minecraft 和西游记。
- 页面/句子切换的状态顺序固定为：停止旧音频 → 更新图文与气泡数据 → 尝试自动播放 → 播放事件显示气泡 → 结束事件延迟隐藏。

## 无障碍与降级

- 气泡容器使用当前说话者和句子的可访问名称；重点词为真实 `button`，支持键盘与可见焦点。
- 不能只依靠颜色表达重点词，中文注释和下划线同时存在。
- 没有 `bubble` 数据的旧内容继续使用原右侧字幕，不显示错误位置的气泡。
- 没有 `words` 时间数据时仍显示重点词和点词朗读，只关闭逐词播放进度。
- 手机宽度 320px、390px 均不得出现横向滚动。

## 验收标准

1. 两本书所有 118 个句子都有独立 MP3、说话者和合法气泡数据。
2. 切换句子后自动播放；旧音频不会继续或叠加。
3. 播放期间气泡出现，结束 600ms 后消失；手动暂停或停止时隐藏。点词朗读期间气泡继续显示，并高亮被点击的重点词。
4. 气泡遮住对应原文字区，尾巴方向与说话者一致，旁白不乱指人物。
5. 重点词彩色、有中文下注，鼠标、触摸和键盘都能触发英文与中文朗读。
6. 逐词高亮与音频时间一致；测试至少覆盖句子首词、中间词和末词。
7. 8810 正式路径在桌面 1280×720、移动 390×844、窄屏 320×720 无横向溢出。
8. Minecraft、西游记、全屏测验、目录返回和阅读进度均无回归。
