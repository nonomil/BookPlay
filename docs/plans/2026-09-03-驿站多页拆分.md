# 白龙马驿站多页拆分实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 将伙伴首页、勋章墙、故事贴纸册和花果山小屋拆成四个轻量页面，降低单页滚动负担，同时保留原有进度、收藏和详情弹窗。

**架构：** `companion.html` 作为一页式伙伴入口，只承载小白龙、同行日记和三个大图导航卡；`medals.html`、`stickers.html` 与 `room.html` 使用同一份 `companion.js` 数据逻辑，仅提供各自需要的 DOM 容器。四个页面共享现有 localStorage 键和 `/data` 资源，不引入路由框架或新依赖。

**技术栈：** 原生 HTML/CSS/JavaScript、现有 `companion-core.js`、`episode-reward.js`、Node 内置测试、Python 内容测试。

**当前状态：** 已完成。详细交付与验收记录见 [`tasks/01-三页拆分落地与验收.md`](2026-09-03-驿站多页拆分/tasks/01-三页拆分落地与验收.md)。
