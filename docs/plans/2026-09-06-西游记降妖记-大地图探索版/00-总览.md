## 1. 玩法一图流

```
首页绘本地图 map.html 节点「🗺️ 探险」→ game.html?ep=N
   │
   ├─ 开场：NPC 对话（本集原文台词，说话人立绘）
   ├─ 探索：主角四方向移动（虚拟摇杆/D-pad/点击目的地）
   │    ├─ 小怪（头顶英文词）游荡 → 点击单词 → 金箍棒飞击 → 命中弹中文 3 选 1 → 答对爆碎掉星星/词卡，答错护盾-1
   │    ├─ NPC 站桩对话/答题（答对奖励星星与词卡）
   │    └─ 收集：星星、词卡、道具掉落
   ├─ Boss 区：走近本集反派 → 切入对战（复用 battle.html Boss 模式：血条=词数、选词球攻击、taunt 气泡）
   └─ 结算：星星 + 妖怪卡 + 错词清单 → 关底测验（episode-vocab-quiz）
```
