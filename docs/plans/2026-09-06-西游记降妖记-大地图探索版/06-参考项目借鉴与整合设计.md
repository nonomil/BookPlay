## 1. word-memory-map → 探索移动内核（已落地 `game.js`）

| 借鉴 | 落地 |

| 纯 DOM 实体 + **rAF 逐帧只改 left/top、不重建节点**（流畅关键） | `frame()/step()` 主循环 + `placeAt()`；实体按钮只建一次 |
| 归一化世界坐标 + 百分比定位（`stagePercentX/Y`） | 实体坐标一律 0-1，`left/top = x*100%` + `translate(-50%,-50%)` |

## 2. pixel-story-engine / 05-pixel-worlds-story → NPC 剧情对话（已落地 `game.js` 对话层）

> ⚠️ 用户给的 `app/explore-terminal/` 是静态视觉原型（数据写死、无播放逻辑），**运行时参照物是 `js/pixel-story-engine.js`**（767 行）+ `js/pixel-story-map.js`。

| 借鉴 | 落地 |
|---|---|
| **扁平游标状态机**：`lines[] + idx`，`advanceLine()` 双守卫（choice 未答/反馈未读时不推进） | `state.dlg = {npc, lines, idx, retried}` + `advanceDialogue()`；choice 行答完才显示 ▼ |
| 台词行类型 `narration/dialogue/activity(/choice)` | 我们收敛为 `dialogue`（原文台词）+ `choice`（答题），intro NPC = 2 句原文，quiz NPC = taunt + 1 题 |

## 4. typing-defense → 打字模式（**P2，不照搬**）

- 结论：核心乐趣绑定物理键盘逐字母输入，7 岁触屏/遥控场景不成立。
- 值得保留的外壳："怪逼近 + 时间压力 + 一击爆爆"（`progress += dt/spawnDuration`、smoothstep 逼近、超时扣心）。
- **P2 变体「听音选怪」**：TTS 朗读单词，3 只怪头顶 3 个词逼近，点（或遥控选）持正确词的怪 → 放箭爆怪，超时/选错扣心；进阶加"按顺序点字母大按钮拼词"保留 mini-arrow 逐字母反馈。
- 数据侧零成本：词库直接用 `level.previewWords`（term/zh/ipa 齐全）。

## 5. 整合后的完整游戏环节（最终形态）

```
map.html 节点「⚔️ 打怪」→ game.html?ep=N（大地图）
  ① 地图收集单词：主角四向行走；目标条给中文 → 找头顶对应英文的小怪 →
     点击 → 金箍棒飞击（CSS transform 旋转飞出/飞回）→ 命中弹中文 3 选 1 →
     答对爆碎掉星星/词卡（连击 3 横扫清场）；答错护盾-1、怪加速逃窜
  ② 小 Boss·NPC 对话答题：地图两个 NPC——intro 型播本集原文台词（像素剧情式逐句推进）；
     quiz 型 taunt 开场 + 1 题三选一，答对得 ⭐+词卡（第三颗星条件），答错给答案可重试一次
  ③ 大 Boss 对战：走近 Boss 区弹确认卡 → battle.html?ep=N&skip=intro,preview
     &wrong=错词（Boss 词序错词优先，reorderBossWords）→ 血条选词球对战 →
     妖怪卡掉落 → 结算回 game.html（from=game）
  ④ 关底测验在 battle 页内嵌（episode-vocab-quiz），错词四遍闭环：
     找词辨认 → 快卡确认 → Boss 反向 → quiz
```
