# prompts 使用说明（v2 大地图探索版）

每个 `.md` 自包含，新开对话整段粘贴执行。顺序与依赖：

1. `01-数据扩展.md`（V2-T1：level v2 字段 + maps.json + 派生脚本 --v2）
2. `02-game探索页.md`（V2-T2：核心大地图页，依赖 T1）
3. `03-NPC与Boss接入.md`（V2-T3：NPC 交互 + battle.html skip=waves + 错词传递）
4. `04-背景道具生图.md`（V2-T4：批次 B/C 生图，**独立可并行**）
5. V2-T5 收口（入口改链、打包、验收报告）写在 `02`/`03` 完成后由任一会话顺带执行，要求见 `../04-工程实现-game页.md` §验收。

先读 `../00-总览.md` 工程约定；v1 资产与模块复用清单见 `../05-资产复用与补齐.md`。
