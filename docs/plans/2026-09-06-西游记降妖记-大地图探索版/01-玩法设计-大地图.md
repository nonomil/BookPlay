# 01 玩法设计：大地图探索（参照 word-memory-map 综合安排）

## 1. 地图与移动

- **P0 单屏地图**：每集一张主题场景图（1536×1024，V2-T4 生成；未生成前用本集 adv_frames 首帧模糊放大），上面标注**可行走区域**（矩形/多边形）与三类点位：怪物出没点、NPC 站位、Boss 区。
- **主角移动**三种输入等价支持：
  - 触屏：左下虚拟摇杆（拖动方向）+ **点击地面直达**（点击处若可行走，主角自动走过去——对低幼最友好，默认方式）；
  - 键盘/D-pad：四方向按住移动；
  - 动画：主角四方向 walk GIF（资产已就绪：`jttw-player-walkers/<id>/directions/<dir>-walk-action.gif`），停下切 idle（walk 第 1 帧静止）。
- P1 九宫格拼接大地图 + 镜头跟随（照抄 word-memory-map 的 worldStage/camera 方案）。

## 2. 小怪与"点击单词 → 金箍棒飞击 → 飞回"

场上同时游荡 3-5 只小怪（本集 minor 精灵，头顶英文单词气泡，缓慢随机游走）：

1. 屏幕上方常驻**目标条**：「击败 the one who is furious（狂怒的）」——给出目标**中文**，玩家在场上找到对应**英文单词**的小怪。
2. 点击目标怪头顶单词 → **金箍棒从主角处旋转飞出**（CSS transform + rotate，约 0.45s）→ 击中瞬间怪物闪白 → **弹出中文 3 选 1 快速卡**（1 正确 + 2 干扰，干扰来自同集词）→
   - 答对：怪物爆碎（缩放+淡出+星星粒子），掉落词卡/星星，金箍棒飞回主角；
   - 答错：金箍棒弹回，怪物变红加速游走，护盾 -1；护盾扣完小怪全体重置（温和不惩罚）。
3. 连击：连续答对 3 只触发**横扫特效**（金箍棒放大旋转一圈），场上剩余小怪全灭、星星雨。
4. 设计理由：点对怪 = 英→中辨认（找词），快卡 = 中→英确认（二次复习），一次击杀两遍复习，且交互即用户描述的"点单词就飞过去打"。

低幼开关（`bookplay_lesson_settings_v1.gradeBand == g1_2`）：目标条直接高亮目标怪（弱化找词），快卡 2 选 1。

## 3. NPC 与剧情对话

- 每图 1-2 个 NPC（本集角色 walker 精灵站桩 + 头顶💬气泡），点击触发**对话框**（复用 v1 对话框样式：立绘 + 英文大字 + 中文小字 + ▶ 继续）。
- 台词来源（依次取用）：`content/game/cast.json` 的 npcByEp 指定的节点区间原文（开场剧情）→ `taunts.json` 该角色趣味台词 → 通用引导语（"往右边走，妖怪在那边！"）。
- **答题 NPC**（每图 1 个）：对话结束后弹出 1 道本集 vocab 选择题，答对奖励 ⭐（写 progress 的 `npcBonus`，用于结算凑第三颗星）+ 随机词卡；答错 NPC 给出正确答案让玩家"再读一遍"，不扣护盾。
- 开场剧情固定由图内 NPC 承担（替代 v1 的全屏 intro 对话），第一只 NPC 的对话强制触发，其余可选。

## 4. Boss 对战（复用 v1）

- Boss 区在地图深处（右下/洞口），走近弹确认卡「⚔️ 挑战 混世魔王？」→ 跳转 `battle.html?ep=N&skip=intro,preview`（v1 加 `skip=waves` 支持：探索层小怪已在地图打完，战斗页直接进 Boss 战）。
- Boss 战机制不变：血条=4 词、反向选词球、taunt 气泡、妖怪卡掉落。
- 小怪未清完也可挑战 Boss（Boss 血条每格额外 +已漏小怪数的一点点难度），不强制线性。

## 5. 特效清单（全部 CSS，零生图）

| 特效 | 实现 |
|---|---|
| 金箍棒飞行 | 固定定位元素 + `transform: translate() rotate(720deg)` 0.45s ease-in；`reduced-motion` 时直线淡入淡出 |
| 命中闪白 | 怪精灵 `filter: brightness(3)` 120ms |
| 怪物爆碎 | `transform: scale(1.4→0)` + `opacity→0` + 6 颗星星粒子（CSS 伪元素随机方向） |
| 连击横扫 | 金箍棒放大 1.5 倍 rotate(360deg) 扫过场上 + 屏幕轻微 shake（transform 抖动 200ms） |
| 掉落 | 词卡/星星从怪位置落到底部收集栏（translate + 弹跳 keyframes） |
| 护盾碎裂 | 盾图标 rotate + 灰化 + 裂纹 emoji 替换 300ms |

## 6. 结算与复习闭环（不变）

星星：⭐ Boss 通关；⭐⭐ 护盾≥2 或 quiz 通过；⭐⭐⭐ 护盾满 + quiz 通过（NPC 答题 bonus 可补一格护盾）。错词四遍闭环（找词 → 快卡 → Boss → quiz）与 v1 相同，写同一存储键。

## 7. 操作与 TV 适配

- 触屏优先（摇杆 + 点地移动 + 点怪攻击）。
- D-pad：移动主角（八向→四向）+ 焦点环选中最近小怪/NPC/Boss + OK 触发点击等效；返回键暂停。
- 所有可点元素 ≥64px、焦点环走 tv.css；`?orientation=landscape` 下 HUD 收敛到顶部。
