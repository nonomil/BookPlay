# 02 数据与关卡扩展（level JSON v2 + maps.json）

## 1. level JSON v2 新增字段（全部可选，v1 消费方无感）

```jsonc
{
  // ...v1 全部字段不变...
  "map": {
    "theme": "water-dirty-cave",            // = v1 background.theme，运行时查 maps.json
    "walkable": { "x": 0.06, "y": 0.30, "w": 0.88, "h": 0.58 },  // 归一化可行走区
    "heroSpawn": { "x": 0.12, "y": 0.62 },
    "monsterSpawns": [                       // 3-5 个出没点（怪按波次词表分配到点）
      { "x": 0.55, "y": 0.42 }, { "x": 0.72, "y": 0.55 }, { "x": 0.86, "y": 0.40 }
    ],
    "npcSpots": [
      { "role": "narrator", "sprite": "subodhi-disciple", "x": 0.30, "y": 0.50, "dialogue": "intro" },
      { "role": "quiz", "sprite": "monkey-minor", "x": 0.42, "y": 0.68, "dialogue": "quiz" }
    ],
    "bossSpot": { "x": 0.90, "y": 0.66 }
  }
}
```

## 2. content/game/maps.json（主题布局表，人工一次写好）

每主题一份布局（上面 map 结构去掉 theme），level 的 `map.theme` 运行时查这里；`maps.json` 未收录的主题回退 default 布局。这样 **108 集只需 ~16 份布局**，新增主题不改关卡 JSON。

```jsonc
{
  "schema_version": 1,
  "themes": {
    "water-dirty-cave": { "walkable": {...}, "heroSpawn": {...}, "monsterSpawns": [...], "npcSpots": [...], "bossSpot": {...} },
    "default": { ... }
  }
}
```

## 3. cast.json 扩展

- `npcByEp`：每集 NPC 阵容（角色 id + 承担职能 intro/quiz），缺省 `[intro=narrator(用 minor 精灵), quiz=hero 阵营角色]`。
- c01 参考：ep5 = `{intro: chaosdemon-minion, quiz: monkey-minor}`（被抓的水妖求饶出题，趣味合理）。

## 4. 派生脚本扩展（build_game_levels.py）

- `--v2` 开关（默认开）：构建 level 时合入 `map` 字段 = maps.json[theme]（npcSpots 的 sprite 按 cast.json npcByEp 替换），无 maps.json 主题用 default。
- `--check` 增加 v2 校验：monsterSpawns 3-5、npcSpots ≥1 且含 intro、所有坐标在 0-1、walkable 包含全部点位。
- 确定性不变（布局来自静态表，无随机）。

## 5. 生成与镜像

同 v1：写出 `content/game/levels/` 并经 junction 自动同步 `prj/data/`；`maps.json`/`cast.json` 修改后手动 `cp` 到根 `data/game/`（root data 非 junction）。
