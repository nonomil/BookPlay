# 任务 01：四页拆分与一页式入口落地验收

## 状态

已完成（2026-09-03）

## 交付范围

- `companion.html`：一页看完小白龙成长、同行日记和三个带图大卡片入口。
- `medals.html`：承载 19 枚勋章、最近获得、筛选、下一目标及详情弹窗。
- `stickers.html`：承载 108 枚故事贴纸、筛选及已获得贴纸详情弹窗。
- `room.html`：承载花果山小屋、玩具架、装饰和故事纪念品互动。
- `companion.js`：按页面容器存在性渲染，三页共享现有存档键和数据目录。
- `pack_android.py`：同步新增页面到 Android 引擎资源。

伙伴首页采用“一页式摘要”布局：成长区 + 同行日记 + 3 张带图大卡片（勋章墙、故事贴纸册、花果山小屋），详细内容进入对应页面查看。
