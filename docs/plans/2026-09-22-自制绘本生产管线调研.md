# 自制绘本生产管线调研与落地方案（参考 NotebookLM + Storybook 方法）

> 2026-09-22 · 目标：用参考文章的方法（写脚本 → 生成一致性插图 → 排版成书），
> 把 108 集课堂/绘本所依赖的 Little Fox 版权素材（`assets/lf_epN/`：音频、视频、
> 绘本页、抽帧）逐步替换为**自制原创素材**。

---

## 一、现状盘点（为什么要做）

| 素材 | 现状 | 来源 |
|---|---|---|
| 音频旁白 | `assets/lf_epN/audio_epN.mp3` ×108 | Little Fox 版权音频 |
| 视频 | `assets/video/epN.mp4` ×108 | Little Fox 版权视频 |
| 绘本页 | `assets/lf_epN/pages/pNN.png` + `storybooks/epN.json` ×108 | Little Fox 版权页图 |
| 抽帧插图 | `assets/adv_frames/epN/fN.jpg`（69 帧/集，课堂 01/05 步在用） | 视频抽帧 → 派生版权 |
| 英文脚本 | `dialogue_stories/epN.json`（text_en/text_zh/quiz） | 派生自 Little Fox 故事 |

即：**课堂五步的"图、声、文"全部踩在 Little Fox 素材上**。参考文章证明了
"一个人一个下午出一本 10 页原创绘本"可行——108 集就是这条管线的批量化。

## 二、参考文章方法 → 本项目映射

| 文章步骤 | 本项目落地 |
|---|---|
| 喂资料给 NotebookLM、列知识点 | 已有：`dialogue_stories/epN.json` 就是逐句脚本（text_en/zh） |
| 角色卡（固定外貌） | **缺**：需先写《西游记》角色卡（悟空/八戒/沙僧/唐僧 + 配角），一段固定提示词 |
| 分页脚本（正文≤40字 + 画面描述两行式） | **缺**：写 `prj/tools/gen_picture_book_script.py`，从 epN.json 生成"每页正文+画面描述"脚本（正文用现有 text_zh，画面描述由 LLM 按角色卡生成） |
| 脚本自检四问（画面无文字/角色一致/情节连贯/不示范危险） | **缺**：同脚本内置检查 + 人工过一遍 |
| Storybook 生图（免费、10-12页/次、每日限额） | 路线 A（试点用） |
| API 批量生图（角色一致性） | 路线 B/C（量产用） |
| 暖黄小贴士 / 考考你 / 写给家长页 | 课堂 03/04 已有对应玩法；绘本 PDF 可加 |
| PDF 压缩/拆页脚本 | 抄文章脚本进 `prj/tools/` |

## 三、三条路线对比

| 路线 | 工具 | 成本（1200 页估） | 优 | 劣 |
|---|---|---|---|---|
| A 手动免费 | Gemini Storybook（Gem） | ¥0 | 零代码、自带朗读、最快出样张 | 每日限额、纯手动、不能只改单页、中文效果有差异 |
| B 国内 API 量产 | 火山引擎 Seedream 4.0/5.0（即梦同源） | 约 ¥0.03–0.06/张 → **1200 张 ¥40–80** | 国内直连、组图一致性（单次≤10 参考图）、4K、按量计费 | 需写批量脚本、角色卡提示词要调 |
| C 海外 API 量产 | Gemini 3.1 Flash Image（nano-banana 后继） | 约 $0.04/张 → **1200 张 ≈ $48** | 角色一致性官方强项、多轮编辑、Codelabs 有绘本教程 | 需代理（本机 10808 已有）、外币支付 |

> 注意：`gemini-2.5-flash-image`（nano-banana）**2026-10-02 关停**，新项目直接用
> Gemini 3.1 Flash Image 系列。

## 四、分阶段落地

**阶段 0 · 角色卡（半天）**
写 `data/character_cards/jttw.md`：悟空/八戒/沙僧/唐僧/龙王/菩萨等每个角色一段
固定外貌描述（年龄、毛色、服饰、体态），中英双语。这是所有路线的一致性地基。

**阶段 1 · 单集试点（1–2 天，路线 A）**
1. `prj/tools/gen_picture_book_script.py`：epN.json → 分页脚本
   （每页：正文 text_zh ≤40 字 + 画面描述；内置自检四问；输出纯文本无 Markdown）
2. 手动走一遍 Storybook（角色卡 + 脚本整段粘贴），按文章第 7 步"其他不变"法改 2–3 轮
3. 产出：ep1 原创绘本 PDF + 拆页图；对照旧 lf_ep1/pages 逐页评审
验收：自检四问全过 + 你肉眼认可画风。

**阶段 2 · 第一辑 7 集（路线 A 或 B）**
脚本批量生成后：A 路线手动每集约 1 小时；B 路线写
`prj/tools/gen_picture_book_images.py`（火山方舟 SDK：角色参考图 + 逐页提示词 →
组图模式一次出多张），每集约 12 张。

**阶段 3 · 音频去版权化（与图像并行可缓）**
叙述音频用 Edge-TTS（repo 已有先例：minecraft book3 `audio_source: "edge-tts-sentence-clips"`），
逐句 mp3 直接对齐现有 `audio_start/end` 时间轴结构；发音单词 mp3 同法。

**阶段 4 · 全量 108 集（路线 B）**
批量脚本 + 每集人工抽检（自检四问）+ `storybooks/epN.json` 的 `pages` 指向新图。

## 五、课堂侧已就绪（无需改动）

精读课堂五步读的是 `dialogue_stories/epN.json`（文本/时间轴/quiz）与
`assets/adv_frames`（插图路径）——**替换素材文件、不动路径与结构**，课堂自动用新图。
02/03/05 的题型取自 vocab/插图/音频段，同样无感切换。

## 六、风险与边界

- **文本版权**：英文脚本派生自 Little Fox 故事，属最深的一层；替换优先级在图/音之后，
  可用官方公版《西游记》英文改写本或 LLM 重写
- **AI 内容标注**：绘本导出页脚保留"插图由 AI 辅助生成，内容经人工审核"（参考文章同款）
- **风格漂移**：每集生成后抽 2 页对照角色卡；Seedream 组图模式单次 ≤10 参考图，
  一集 12 页需分 2 批，第二批要把第一批主角图再作为参考传入
- **额度**：Storybook 免费额度每 5 小时恢复，试点够用；量产走 API

## 七、立即可以做的一件事

`prj/tools/gen_picture_book_script.py`：输入 ep 编号，输出符合文章第 4 步格式的
分页脚本纯文本（含角色卡头）。它不依赖任何外部 API，产出直接可粘贴进
NotebookLM/Storybook，是全部路线的第一块砖。
