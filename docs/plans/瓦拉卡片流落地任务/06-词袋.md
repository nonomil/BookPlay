# 任务 06 · 词袋 + 章末汇总

## 目标
右栏从"可点词卡"改为**词袋**：走过的官方生词自动变成小徽章收集，纯展示、点击发音；章末显示"本集收集 X / Y 个词"。

## 依赖
任务 04（官方词 firstSeen 扫描）。

## 改动文件
- `demo/engine/wala.js`
- `demo/engine/wala.css`
- `demo/engine/wala.html`（`#w-cards` 容器复用改名或直接复用，升 `?v=`）

## 实施步骤
1. **停用旧词卡渲染**：`render()` 里不再往 `#w-cards` 塞 `renderCard(...)`（learn/test/review 三种卡全部下线；测验能力已由任务 02/05 的整卡承接）；
2. **词袋渲染**：`#w-cards` 改为词袋容器：
   - 每当一句对白播完（`afterSentence` 入口处），把该句的官方词（无论档位、无论是否出过单词卡）追加成徽章：`🏷 split 裂开`；集内去重；新徽章加入时有一个 0.3s 的放大动画并滚动到可见；
   - 点徽章：`playSeq(termItems(term, zh))`；不给 SP；
   - 刷新重进：按当前进度 `idx` 重建（`firstSeenNode[term] <= idx` 的都算收集过）；
3. **样式**：徽章 `display:inline-flex`、圆角胶囊、金边、深底；容器改 `flex-wrap: wrap; align-content:flex-start`；小屏时移到气泡上方横向滚动条；
4. **章末汇总**：`finishEpisode()` 卡片加一行"🎒 本集词袋：X / Y"，X=已收集、Y=该集官方词总数（`official_words.length`）；点击展开全部徽章（复用知识一览的 `kcard` 亦可）；
5. 「知识一览」页单词 tab 已用官方生词册数据，保持不动。

## 验收标准
- ep1 从头自动播 5 句：右栏徽章随句累积、无重复；点徽章发音正常；
- 中途刷新重进：词袋按进度恢复（不是空的、也不是全集）；
- 播完整集：章末显示"X / 36"（ep1 官方词 36 个）且 X 与实际走过的词一致；
- 旧的 learn/test/review 词卡在任何句子都不再出现在右栏。

## 回滚
恢复 `render()` 里的 `renderCard` 循环即回到旧右栏。
