# 任务 03 · 剧情 / 精学两遍制

## 目标
顶栏新增「剧情 / 精学」开关：剧情遍只有对白卡（纯磨耳朵）；精学遍出单词卡与测验卡。首次进入某集默认剧情遍，完成过一次后默认精学遍，可手动覆盖。

## 改动文件
- `demo/engine/wala.html`（顶栏加胶囊开关，升 `?v=`）
- `demo/engine/wala.js`
- `demo/engine/wala.css`（复用 `.mode-toggle` 样式，无需新样式）

## 数据与键
- `bookplay_pass_mode`：`"story"` / `"study"` / **空**（=自动）；
- 自动规则：`progress()[ep].done === true` → `study`，否则 `story`；
- 手动点击开关 = 写入显式值（之后该用户全局按显式值，直到再次手动切换）。
  - 简化决策：显式值是**全局**的，不做逐集记忆（避免设置爆炸）；自动仅在无显式值时生效。

## 实施步骤
1. HTML 顶栏 `EN/EN+中` 旁加：
   ```html
   <div class="mode-toggle" title="剧情遍只听故事；精学遍出单词与测验">
     <button id="w-pass-story">剧情</button>
     <button id="w-pass-study">精学</button>
   </div>
   ```
2. `wala.js`：
   - 新增 `let passMode`，加载集时求值：显式 localStorage 值 > 自动规则；
   - `bindPass()`：点击写 localStorage、更新 active 态、`stopSeq()` 后 `render + playCurrentSentence` 重进当前句（形态立即生效）；
   - **门控点**（本任务只控测验，单词卡在任务 04 接入同一门控）：
     - `scheduleNextSentence()`：`passMode==="story"` 时跳过 `nodeQuiz`，直接 1s 后下一句；
     - `next()`：同上跳过 quiz 分支；
     - `startEndQuiz()`：story 遍直接 `finishEpisode()`（不出章末补题）；
   - 剧情遍完成时 `saveProgress(true)` 照常写 done → 下次自动进精学遍；
3. 章末 `finishEpisode()` 文案区分：剧情遍显示"故事听完啦，再来一遍学单词 →（切精学）"，点击 = 设 `study` 并回到本集第一句。

## 验收标准
- 清掉 ep2 进度（localStorage `bookplay_adv_progress` 删 ep2）→ 进 ep2：自动剧情遍，全程无测验卡，锚题句正常连播；
- 播完 ep2 → 重进：自动精学遍，锚题句出整卡测验；
- 手动切「剧情」再刷新任意集：仍剧情遍（显式值生效）；
- 顶栏 active 态与实际行为一致。

## 回滚
删开关与 `passMode` 门控三处判断即回到"全程精学"现状。
