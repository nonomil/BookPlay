# 任务 04 · 学习量三档 + 单词卡

## 目标
精学遍里，对白播完后先出**单词卡**（首现官方生词，自动朗读自动前进），再出测验卡；出多少由地图页的「学习量」三档控制。

## 改动文件
- `demo/engine/wala.html`（地图页顶栏加学习量胶囊；气泡内加单词卡容器可复用 `#w-puzzle` 或新 `#w-wordcard`，推荐新容器）
- `demo/engine/wala.js`
- `demo/engine/wala.css`（`card-word` 形态 + 单词卡样式）

## 数据与键
- `bookplay_learn_level`：`lite` / `std` / `max`，默认 `std`；
- 词源：节点 `vocab[]` 中 `source === "official_words"` 的卡（term/zh/phrase_en 来自官方生词册；ipa 来自精读本 `script_lexicon`）；
- **首现**：本集范围内该 term 第一次出现在某 narration 节点（加载集时预扫一遍 nodes 建 `firstSeenNode[term] = nodeIndex`）。

## 档位规则（加载集时预计算 `wordCardPlan: {nodeIndex: [term,...]}`）
- `lite`：候选 = 全部首现官方词，打分 `score = 出现次数*2 - term单词数 - (释义含"，"或"("? 1:0) - len(term)/6`，取前 **6**，再按 nodeIndex 均匀保留（每 ⌈总句数/6⌉ 句至多 1 个）；每句最多 1 张；
- `std`：每句最多 1 张（该句首现词里选 score 最高的）；
- `max`：该句全部首现词依次出卡（一张接一张）。

## 单词卡行为
1. 形态 `card-word`：隐藏对白行，显示：
   ```
   <div class="wcard">
     <div class="wcard-term">split <span class="vipa">[splɪt]</span> 🔊</div>
     <div class="wcard-zh">劈开，裂开</div>
     <div class="wcard-ex">One day the rock <b>split</b> open.</div>
   </div>
   ```
2. 进卡：画面保持本句最后一帧（视频已 pause），`playSeq([{tts: term, lang:"en-US"}, {tts: phrase_en, lang:"en-US"}])`；播完 0.8s 自动进下一幕（该句的测验卡或下一句）；
3. 点卡任意处 = 重听；长按 = 读中文释义（`zhItems(zh)`）；「下一句」= 跳过本卡进下一幕；
4. 不加 SP；给 `VSTAT[term].seen += 1`（任务 05 用）。

## 幕序编排（改 `scheduleNextSentence`）
把"播完后做什么"改成小队列：
```js
function afterSentence() {
  const acts = [];
  if (passMode === "study") {
    (wordCardPlan[idx] || []).forEach(t => acts.push({type:"word", term:t}));
    const q = nodeQuiz(book.nodes[idx]);
    if (q) acts.push({type:"quiz", q});
  }
  acts.push({type:"advance"});
  runActs(acts);   // 逐个执行：word 自动完成后下一个；quiz 答对后下一个；advance = 1s 后 goListen(next)
}
```
`stopSeq()` 时清空当前 acts 队列（token 机制沿用）。

## 学习量设置入口（地图页）
- `#wala-top` 加胶囊：`学习量 🌱轻松 / 🌿标准 / 🌳加强`，点击写 localStorage、立即高亮；
- 播放器加载集时读取，不在播放器内提供切换（保持顶栏干净）。

## 验收标准
- std 档 ep1 精学遍：含官方词的句子播完 → 单词卡自动出现并朗读 term+例句 → 自动进入下一幕；一句最多 1 张；
- lite 档：整集单词卡总数 ≤ 6，分布不扎堆在开头（人工翻 3 处确认）；
- max 档：首现词都出卡（抽一句含 2 个首现词的验证连出 2 张）；
- 「下一句」能跳过单词卡；重进该集同一句不重复出已出过的首现卡（firstSeen 按集内节点序判定，不依赖 localStorage——重进会再出，属预期，验收按此口径）；
- 剧情遍完全无单词卡。

## 回滚
`wordCardPlan` 生成与 `runActs` 独立成块，去掉 acts 中 word 项即回退。
