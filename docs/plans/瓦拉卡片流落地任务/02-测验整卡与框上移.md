# 任务 02 · 测验整卡替换 + 底部框上移

## 目标
对白播完后，测验作为**独立一幕**整框出现（对白字幕消失、画面定格）；底部框整体上移，测验卡不再撑高。

## 改动文件
- `demo/engine/wala.js`（改 `showFreezeQuiz` 与卡片切换）
- `demo/engine/wala.css`（框位置、卡片形态）
- `demo/engine/wala.html`（升 `?v=`）

## 现状
`showFreezeQuiz(q, onDone)` 已存在（任务前身）：画面定格、`#w-puzzle` 出题、答对回调。但题目是**追加**在 `.w-bubble-row`（英文句+中文句）下面 → 框过高。

## 实施步骤
1. **卡片形态类**：气泡容器 `.w-bubble` 增加形态类 `card-dialog / card-quiz`（后续任务 04 再加 `card-word`）：
   - `card-quiz`：隐藏 `.w-bubble-row`（对白行）与 `.w-nav` 里的「上一句」以外操作？——保留整个 `.w-nav`，但「下一句」在测验未答完时无效（已有逻辑）；隐藏 `#w-speak`；
   - 切回对白时移除该类恢复显示；
2. `showFreezeQuiz` 开头加 `el.bubble.classList.add("card-quiz")`，`onDone` 与被打断（`stopSeq`→`render`）时移除；`render()` 里统一 `classList.remove("card-quiz")` 兜底；
3. **框上移**：`.w-dock { margin-bottom: 10vh }`（原 1.05rem）；小屏（`max-width 860px`）降为 4vh；
4. **稳定高度**：`.w-bubble { min-height: 172px }`，避免对白卡↔测验卡切换跳动；
5. `#w-puzzle` 测验形态微调：题干 `1.15rem`、选项列间距 0.4rem（沿用现有 `.w-quiz-*` 样式），确认三行选项 + 题干在 min-height 内放得下；
6. 升级 `wala.html` 的 `wala.js?v=`、`wala.css?v=`。

## 验收标准
- ep1 播到锚了官方题的句子（如 "But the captain had magical sight."，n015）：句子播完 → 画面停 → 底部**只剩题目**（看不到英文句/中文句/再听一遍）；
- 答错：按钮红、可继续选；答对：绿、+10 SP，**停在测验框**，等右边箭头才进下一句；
- 右边箭头在题未答完时点击无效；左边箭头可退回上一句对白；
- 框离屏幕底部明显有距离（约 10vh），对白卡与测验卡切换时框顶边不跳。

## 回滚
形态类与 CSS 独立，删 `card-quiz` 相关样式与 classList 调用即回到现状。
