## 公共约定

- 本地服务（必须带 HTTP Range，否则视频无法跳转到句中，字幕会看起来早一幕）：`python demo/tools/serve.py --port 8787`，打开 `http://127.0.0.1:8787/engine/wala.html?ep=N`。不要用 `python -m http.server`（不支持 Range）。必须用 127.0.0.1，不要用 localhost（localStorage 不共享）；
- 改 `wala.js` / `wala.css` 后必须同步升级 `wala.html` 里的 `?v=` 缓存号；
- 数据文件 `demo/data/dialogue_stories/ep*.json` 全部 UTF-8，`json.dumps(ensure_ascii=False, indent=2)`；
- 批量重写 108 集前，先跑单集（ep1）验收，再全量；
- 涉及浏览器验收的：Cursor IDE 浏览器 lock → 操作 → unlock；验收集固定为 **1 / 2 / 50 / 108**；
- 不 git 提交，除非用户明确要求。

## 验收基线（全部任务完成后）

1. ep1 前 4 句：画面、语音、逐词高亮三者同步（对时修复生效）；
2. 首次进入某集 = 剧情遍：从头到尾只有对白卡；
3. 完成一遍后再进 = 精学遍：对白 → 单词卡自动读 → 官方情节题整卡出现、画面定格、答对续播；
4. 学习量切「轻松」：整集单词卡 ≤ 6 张、无复现测验；切「加强」：所有官方生词首现出卡；
5. 右栏词袋随播放增长，点徽章发音；章末显示"收集 X / Y"；
6. 顶栏「有/无标注」「EN/EN+中」在所有卡片形态下仍正常。
