# 代码仓库基线与优化实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 建立只跟踪源码、配置、测试和文档的 Git 基线，并在不改变播放器行为的前提下为后续模块化与端到端测试提供可执行路线。

**架构：** 原始素材与生成内容继续保留在工作目录，但由根级 `.gitignore` 排除。当前事实集中到根 README、文档索引和架构路线；后续重构以浏览器冒烟测试为保护，小步拆分 `wala.js`。

**技术栈：** Git、Markdown、Python/pytest、Node.js test runner、静态 HTML/CSS/JavaScript、Capacitor Android。

---

### 任务 1：冻结代码仓库边界

**文件：**

- 创建：`.gitignore`
- 创建：`.gitattributes`
- 创建：`README.md`

**步骤 1：列出必须排除的根目录**

确认 `data/`、`content/`、`release/`、`dist/`、`output/`、`node_modules/`、`.agent-control/` 不进入 Git。

**步骤 2：列出全局媒体扩展**

排除视频、音频、图片、字体、PDF、Office、APK、ZIP 和其他归档格式。

**步骤 3：初始化 Git**

运行：

```powershell
git init
git status --short --untracked-files=all
```

预期：状态中只出现源码、脚本、配置、测试和 Markdown 文档。

**步骤 4：审计大文件**

检查所有未忽略文件，预期不存在意外媒体或大型生成物。发现异常先补忽略规则，不提交。

**步骤 5：提交**

由项目所有者确认边界后执行：

```powershell
git add .gitignore .gitattributes README.md docs prj scripts android package.json package-lock.json capacitor.config.json *.bat
git commit -m "chore: establish code-only repository baseline"
```

本计划不自动创建首次提交。

### 任务 5：强化 Android 数据包门禁

**文件：**

- 修改：`prj/tools/pack_datapack.py`
- 修改：`android/app/src/main/java/com/nonomil/storyhall/DataPackStore.java`

**步骤 1：为 manifest 写失败测试**

manifest 至少包含版本、集数、必需目录和关键文件大小或摘要。

**步骤 2：打包时生成 manifest**

数据包仍不进入 Git，只跟踪生成逻辑和测试。

**步骤 3：Android 就绪检查读取 manifest**

缺视频、音频索引或集数不符时返回明确错误，不再只凭 `ep1.json` 判定成功。

**步骤 4：验证并提交**

运行 Python 测试、Android debug 构建和至少一次真机选择 ZIP 验收，再提交源码。
