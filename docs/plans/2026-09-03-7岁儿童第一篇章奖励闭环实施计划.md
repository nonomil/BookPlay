# 7岁儿童第一篇章奖励闭环实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 把现有“108 格奖励库存”改造成七岁儿童能看懂、愿意点开的篇章冒险贴纸册，并让小白龙真实出现在花果山房间中回应奖励互动。

**架构：** 保留现有 `BookPlayEpisodeReward` 存档与 108 关幂等奖励逻辑，只重组展示层。`stickers.html` 默认显示 13 张图片优先的篇章封面；通过 `?chapter=N` 进入单篇章完整页面，展示该篇章场景、7–12 枚贴纸、解锁进度和大图详情。`room.html` 继续消费同一奖励存档，在现有固定槽位上加入小白龙及按互动种类变化的舞台反馈。

**技术栈：** 原生 HTML、CSS、JavaScript；Node.js `node:test`；现有 JSON 奖励目录和透明 PNG 资产。
