# 词球、道具、NPC 与 Boss

## 1. 词球捡投与小怪

主玩法：地上的中文球对应小怪头顶英文。走近捡起，向选中的小怪投掷；正确命中有击破 / 掉落，错误命中弹回并记录错词。大地图不出现点击式快卡。

球和怪应绑定稳定 wordId，保留 term / zh 用于展示与兼容，不以中文字符串作为长期唯一 ID。长释义增加经内容审核的 shortZh；判题仍按 ID，禁止截断字符串后误判。

投掷分离三个概念：当前选中目标、投掷合法距离、NPC 对话距离。遥控可在屏内合法目标之间切换，再按 OK 投掷；不能为了投掷必须先走进怪物撞击范围。普通自动选择“最近 / 面朝方向怪”不看正确答案，葫芦效果才按词匹配。

球状态：ground → carried → flying → consumed 或 returned。每个实体有唯一 ID，一次命中只结算一次；回弹不复制球、怪死后弹道不能再领奖、最后一只怪死亡不能重复排队刷下一波。

怪物状态保持 wander / chase / attack / hurt / wrong / dead。新手引导时暂不追击，完成一次捡投才释放正常 AI；NPC 对话和暂停期间不扣盾。错误后先播放清晰的正确词 / 释义，再恢复压力。

连对 3 横扫沿用既定玩法，但结算应把“玩家正确匹配”与“道具 / 连击清场”分开统计。未主动匹配的词不能计入掌握；本局 Boss 或可选错词回顾可优先补一次。

## 2. 六道具契约

| 道具 | 保留效果 | 反馈与验证 |
|---|---|---|
| 蟠桃 | 库存可挡一次撞击，主动用加一盾 | 两种消费路径互斥，一次只能扣一个库存；满盾行为可预期 |
| 芭蕉扇 | 怪减速 | 显示剩余有效时间，暂停不耗时，结束恢复基础速度 |
| 紫金葫芦 | 接下来两次合法投掷自动匹配 | 没球 / 无合法怪时不扣次数；跨区域不吸到不可达怪 |
| 筋斗云 | 短时加速 | 起止速度明确，不带动镜头超出安全边界 |
| 紧箍咒 | 提示当前目标英文首字母 | 短释义 / 长英文都可显示，不弹快卡；可重听 |
| 金箍棒 | 下次正确命中补一盾 | 错误不消费，正确只触发一次 |

继续复用 SUPPORT_DEFS、applySupportUse、absorbHit 等纯逻辑。库存入口显示名称和数量；先修交互反馈，再把 emoji 换成统一图标 sheet。

## 3. NPC 应承担剧情任务

开场 NPC：本集已存在原文 1–2 句，记录 node_id / speaker / audioRef。旁白可以由旁白字幕展示，不能把旁白原声说成某角色本人配音。

小 Boss NPC：一句和本关目标相关的剧情 → 一题 → 对错反馈 / 带读 → 指向下一波。文案由台词数据管理，不能所有集都套同一句嘲讽。

对话播放器沿用扁平游标，增加 `idle/loading/playing/ended/unavailable` 音频状态、“重听”“下一句”。默认由孩子点下一句；音频错误不阻塞下一句。点下一句立即取消旧句播放和异步回调。

一次题答错只禁用错项，不提前直接泄露正确中文；第二次错时明确揭示、带读，提供“我明白了，继续”。记录 completed / mastered / assisted，辅助完成可推进剧情，不能伪造答对奖励。

建议主线门控：清完第一波 → 小 Boss NPC 完成（正确或带读）→ 第二波 → Boss。孩子可随时退出整个游戏；主线内不再用“随时直达 Boss”混淆顺序。扩展支线 NPC 可选，不参与 Boss 解锁。

## 4. Boss 按事件推进

复用 pet-battle 的结构化事件和动效节奏，保留本项目的词汇判定。

```text
await-answer
  → 锁定本回合 roundId
  → actor-windup
  → projectile / attack
  → hit 或 miss
  → hp/shield-change
  → 本词朗读、战报
  → next-round 或 victory
```

事件包含 id、roundId、type、wordId、actor、target、hpBefore / hpAfter。UI 不从中文战报反解析状态。动画中禁用整组选项；快速点击不同答案只接收一次。暂停冻结游戏推进，退出取消旧定时器和事件回调。

Boss 词池构造：从本集有效词库收集地图 / NPC 本局错词，再补既定 hpWords；去重，样板维持 4 个词位。超过容量的错词留在结算复习。只重排原 hpWords 不足以达成“地图错词优先”。不得引入下一集未学习的词。

答对：主角出招 → 命中 → Boss 后仰 → 血条连续减少 → 单词朗读。答错：显示提示 → Boss 反击 → 扣盾。最后一击也播放对应英文及胜利反馈，避免当前最后一词不读的问题。

血条按真实题位 / 分段推进，战报最近三条；护盾耗尽给重试和离开选择。过渡时长是演出时间，不是重复计分窗口。

## 5. 存档与跨页返回

仍只有两条游戏存储键。`progress[ep]` 扩展字段全可选：

```json
{
  "stars": 0,
  "clears": 0,
  "wrongWords": {},
  "npcDone": false,
  "npcBonus": false,
  "run": {
    "version": 1,
    "id": "一次游戏的稳定ID",
    "phase": "boss",
    "waveIndex": 2,
    "defeatedIds": [],
    "introDone": true,
    "npcCompleted": true,
    "npcMastered": false,
    "hero": {"x": 0, "y": 0},
    "bossResultApplied": false
  }
}
```

此为拟定契约，不是现有字段承诺。角色坐标只是示例结构。跨页前保存确认的世界状态；弹道不持久化，必须结清或退回手持 / 地面状态。临时 buff 到 Boss 前明确结束，不隐式带入另一套战斗规则。

写记录时 merge 旧对象，保留历史 stars / clears / NPC 字段。npcBonus 只控制奖励是否发过，不能把“本轮是否完成 NPC”直接复用为历史值。

地图 → Boss 带 `from=game` 和本次 runId；Boss → 地图带 `from=battle` 和同一 runId。结果以存储中有效 run 为依据，URL 自带 won 不能领奖。处理已消费结果幂等；旧存档没 run 时安全新开，历史统计不丢。

结算“继续学习”沿现有 lesson-core 的 next route；“重玩本集”明确重建 run；“回到本集地图”恢复完成状态。对 ep7 后尚无游戏的章节不给失效下一关按钮。
