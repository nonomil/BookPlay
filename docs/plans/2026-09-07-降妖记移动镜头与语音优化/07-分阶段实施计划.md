# 降妖记优化实施计划

> 给后续执行者：逐任务实施并在检查点提供运行证据；可使用 executing-plans 工作流。本文是计划，不代表任务已完成。

**目标：** 修正移动与镜头体验，完成巩固 → 可跳过游戏 → 地图 / NPC / Boss → 返回的语音学习闭环。

**架构：** 在现有 game / battle 页面上迭代；统一逻辑世界与视口变换，在 game-core 中实现可验证的运动和状态规则。新增薄输入 / 语音适配器，台词和音频按集数据化，共享现有内容打包管线。

**技术栈：** 原生 JavaScript / DOM / CSS、Node 测试、Python 内容生成与验证、FFmpeg、Capacitor / Android WebView。

## 0. 依赖与检查点

```text

 └→ T06 音频清点与原声审定 → T07 语音播放器
T03 → T04 整局状态与NPC → T05 Boss与返回

T08 → T09 包内资源验证 → T10 真机验收 → T11 c01推广与手册
```

这是逻辑依赖，不要求启动多个代理或新会话。先完成可试玩的 ep1 / ep5，再扩集。

| A：运动样板 | 角色等速、轻推慢走、中央不滚、边缘平滑 | 停止增加玩法，定位输入 / 坐标 / 镜头 |
