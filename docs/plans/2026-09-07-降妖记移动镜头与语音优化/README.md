## 本次证据结论

- 当前全仓 `npm.cmd test`：**357 pass / 0 fail**，本轮重新运行；交接底线 347 保留，执行基线采用当前 357，只增不减。
- 移动纯逻辑实测：摇杆输入 0.1 与 1 得到同样速度；1280×720 下当前理论水平速度 1177.6 px/s、垂直速度 662.4 px/s。
- `game.js`、`game-core.js`、`battle.js` 等有大量既有未提交修改。实施前记录差异，不覆盖其他会话产物。
- 第 1–7 集各 12 个预习词：英文和当前中文释义的索引、目标文件均可找到；共 **84 个出现项**，不是 84 个去重词。各 2 句开场英文共 **14 个出现项**也可找到既有句音频。
- 上述音频检查仅证明源码数据树中存在文件；未证明对应 APK 携带、可解码、原声准确或真机已播放。
- 本轮没有安装 APK、修改运行代码或执行视频切片；真机移动和缺声原因仍待带日志复现。

## 推荐实施顺序

先做第 1 集和第 5 集样板：移动 / 镜头 → 捡投与输入 → 整局状态与返回 → 静态语音 → 原声剧情 → 打包真机。样板过关再铺开 c01 七集。

道具图标、受击帧、听音选怪放在后续体验阶段。打字游戏保持可选扩展，不加入触屏 / 遥控主线。
