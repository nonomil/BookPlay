# 01 P0 现场整局与门控

## P0-1 包与设备

记录后写入 [launch-track.md](launch-track.md)：

1. `git status --short`  
2. 当前 APK 路径、versionName、versionCode、SHA-256  
3. `adb devices -l`  
4. 有设备则安装 `release/storyhall-jttw-mobile-debug.apk`，核对 1.0.14 / 19  
5. 无设备写「待验」，不阻塞浏览器

## P0-2 整局走查（ep1 然后 ep5）

固定 1280×720、清空该集游戏进度（不要清学习进度）：

1. 从出生点走到第一波，捡中文球，扔对应英文怪  
2. 故意扔错一次，确认弹回  
3. 故意撞一次，确认扣盾  
4. 清第一波，找 quiz NPC：对一次、错一次重试  
5. 清第二波，开战 Boss，打完返回  
6. 记下每步通过/失败/未执行，以及返回后 `mapStage/killed/npcDone/items`

无设备用本地 `启动服务.bat` + 浏览器。TV/双指标未执行。
