# 04 P0 打包与真机

依赖：P0-3 至 P0-6 的文件名单稳定。

## 三白名单逐文件

- `pack_datapack.py` `COMMON_FILES`：关卡、背景、音频索引、新引擎 js  
- APK 内置闭包：仍只 ep1  
- `pack_android.py` `ENGINE_FILES`：`game-core.js` / `game-input.js` / `game-audio.js` 必须在  

解包核对 `assets/public/engine`，不要相信拷全目录日志。

## 构建

按仓库现有 `scripts/build-apks.mjs` / `make_release.py`。构建后更新 [launch-track.md](launch-track.md) 的 version / hash。
