# 降妖记完整方案实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让孩子在知识巩固后进入同一套降妖记引擎，按「开场 → 捡投 → NPC → Boss → 返回」走完 ep1/ep5，并留下可复现证据；七集共用，不新开引擎。

**Architecture:** 继续改现有 `game.html` / `game-core.js` / `battle.html`。玩法合同见 [`../2026-09-08-降妖记完整游戏设计/README.md`](../2026-09-08-降妖记完整游戏设计/README.md)。先修整局断点与门控，再调可行走/开场对话，再语音与巩固入口，最后打包真机。美术 P1、听音选怪 P2。

**Tech Stack:** 原生 HTML/CSS/JS（`prj/engine`）、Python 打包与关卡生成（`prj/tools`）、Node test runner、Android Capacitor 三端 APK。

## 阶段顺序（一次只做一个切片）

```
P0-1 包与设备记录
  → P0-2 ep1/ep5 整局走查（浏览器可先做）
    → P0-3 门控/返回/下一集/关底测验
      → P0-4 开场自动对话 + 可行走区加宽
        → P0-5 语音断网样板（ep1/ep5）
          → P0-6 巩固入口真实题目流
            → P0-7 三白名单 + 准确 APK
              → P1 可读性
                → P2 听音选怪 / 其余集台词
```

无 ADB 设备时：P0-1 写「待验」，P0-2 起用 1280×720 浏览器，不把结果写成真机通过。
