# 03 P0 语音与巩固入口

依赖：整局步骤稳定，否则配音会对着错误台词。

## 语音（ep1/ep5）

1. `python prj/tools/build_game_audio.py validate --eps 1,5` 必须继续通过。  
2. 清点实际会读出口的句子（词球中文、命中英文、NPC 题干、Boss 词）。  
3. 已有文件直接挂索引；缺的 pending，不伪称原声。  
4. 浏览器断网：停开发服务器 TTS 后，静态 src 仍能播。  
5. 有设备再做 WebView 断网。

播放器改动只限 `game-audio.js` 的停/重听/代际令牌，不新写一套。

## 巩固入口

`lesson.js` 已有 `showGameInvite`。要验证的是**真实题目做完**，不是调用 `finishLesson` 字符串。

覆盖：

| 情况 | 期望 |
|---|---|
| ep1 通过 | 自动两按钮；进入 `game.html?ep=1&from=lesson` |
| 未通过 | 不改 passed；可练习进入但不发通关奖 |
| 未发布/未导入集 | 不强弹 |
| 最后一集 | 仍可进游戏；跳过保留学习结果 |

`from=lesson` 在 `game.js` 里至少要被读取：用于统计/不误伤 intro 规则，不要当新存档键。
