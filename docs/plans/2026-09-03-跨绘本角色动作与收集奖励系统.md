# 跨绘本角色动作与收集奖励系统

> 版本：v1.0 · 日期：2026-09-03  
> 适用范围：《西游记》参考样板、《我的世界》分级读物、Mikey & JJ 英文冒险，以及后续新增绘本。

## 1. 目标与边界

本方案把“看故事”和“学英语”串成一个可见、可收集、可复习的成长体验。西游记已经验证了“伙伴在场、每集一张贴纸、阶段勋章、房间摆件”的情绪反馈；Minecraft 和 Mikey & JJ 不直接复制西游角色，而是复用同一套交互节奏和数据合同，让每个系列保留自己的世界观。

核心边界：

- 奖励只记录故事纪念，不增加学习数值、不影响题目难度，也不替代 `drill.html` 的巩固门槛。
- 每一件奖励都必须能追溯到绘本页、句子/场景和视频时间段；无法找到证据的道具不能进入发布目录。
- 动作是播放、答题、点读、获得奖励时的视觉反馈，不作为“做得越多数值越强”的养成系统。
- 文字（中英文名称、说明、提示）由 HTML/CSS 渲染，PNG 只提供角色、道具和装饰，避免生图文字乱码。

## 2. 统一学习—奖励闭环

```text
完整故事（英文句级字幕/逐词点读）
  ↓
精学回放（只回放含目标词的小节）
  ↓
本集词卡与发音（每个词可点读，中英文按需显示）
  ↓
本集测验（默认英文；提示按钮显示中文）
  ├─ 通过：完成卡 + 礼花 + SP + 贴纸 + 道具三选一
  └─ 未通过：自动回到错题绑定的小节，学完后可再次测验
  ↓
收集册 / 房间展示 / 伙伴动作
```

奖励发放必须幂等：同一集首次通过才发 SP、贴纸和大件道具；重复复习可触发轻量庆祝和“已学习/已掌握”进度，但不重复发放大件。

建议状态字段：

```json
{
  "episode_progress": {"watched": true, "study_done": true, "quiz_passed": true},
  "vocab": {"learned": 3, "mastered": 2},
  "rewards": {"sticker_granted": true, "drop_granted": true},
  "collection": {"owned": 4, "total": 10}
}
```

## 3. 角色 Bible 与动作规范

### 3.1 跨系列共用合同

每个系列先建立一份角色 Bible，再生成动作变体。Bible 至少记录：`character_id`、年龄/物种、头身比、轮廓、脸部地标、服装层、主色（HEX）、固定配件、禁变项、正/侧/三分之四参考图。动作图只改变姿势和表情，不改变年龄、物种、服饰和比例。

动作枚举：

| 动作 | 触发 | 视觉含义 |
| --- | --- | --- |
| `idle` | 页面待机 | 轻微呼吸/眨眼 |
| `listen` | 音频播放 | 面向字幕，耳朵/眼睛跟随高亮 |
| `point` | 点击单词或提示 | 指向词卡，不遮盖绘本 |
| `think` | 题目思考 | 手托下巴，出现小星星而非文字 |
| `build` | 选中故事道具 | 搭建/整理道具，强化“故事证据” |
| `defend` | 剧情挑战小节 | 举盾或摆出守护姿态，避免攻击性血腥 |
| `rescue` | 错题补救完成 | 拉起伙伴/递出道具，表达“再试一次” |
| `high-five` | 答题正确 | 两位角色击掌 |
| `celebrate` | 本集完成卡 | 1–1.5 秒跳跃、星屑、礼花 |
| `tired` | 连续学习超过建议时长 | 打哈欠/喝水，提示休息，不扣分 |

动画实现优先级：第一期使用静态透明 PNG + CSS 位移/缩放/旋转；只有确实需要连续动作时才制作 6–8 帧 sprite，避免为每个动作新增视频。

### 3.2 Minecraft 角色设计

| 角色 ID | 定位 | 固定识别点 | 主要动作 |
| --- | --- | --- | --- |
| `mc-steve` | 玩家视角的小小建造师 | 方块蓝衫、棕发、像素化轮廓 | `idle`、`listen`、`build`、`defend`、`celebrate` |
| `mc-alex` | 讲解/协作伙伴 | 橙发、绿色上衣、紫裤 | `idle`、`point`、`think`、`rescue` |
| `mc-byte` | 忠诚狼伙伴 | 蓝色项圈、方块耳朵、尾巴上翘 | `listen`、`fetch`、`high-five`、`celebrate` |
| `mc-guide` | 非人类引导光点 | 紫色传送门粒子、圆角方块 | `point`、`think`、`unlock` |

首章情绪线：准备冒险（`listen`）→ 认识 Byte（`high-five`）→ 发现传送门（`point`）→ 完成测验（`celebrate`）。道具只使用绘本已出现的金头盔、黑曜石/传送门碎片、狼牌、宝箱，不凭空加入武器数值。

### 3.3 Mikey & JJ 角色设计

| 角色 ID | 定位 | 固定识别点 | 主要动作 |
| --- | --- | --- | --- |
| `mikey` | 冲动、好奇的行动派 | 红色连帽衫、深色短裤、卷发 | `idle`、`point`、`build`、`think`、`celebrate` |
| `jj` | 观察细致的计划派 | 蓝色上衣、黄色鞋、直发 | `idle`、`listen`、`rescue`、`high-five`、`celebrate` |
| `mikey-jj-duo` | 双人组合反馈 | 两人服装与身高差固定 | `high-five`、`defend`、`rescue`、`celebrate` |

首章情绪线：学校迟到 → 发现僵尸包围 → 前往屋顶直升机 → 用金苹果/药水解决危机 → 启动引擎离开。所有道具和动作都绑定 `b1-pXX-sYY`，不把“战斗胜利”改写成与学习无关的力量升级。

## 4. 奖励层级与解锁规则

### 4.1 四种收藏物

1. **故事贴纸（episode sticker）**：每集通过后自动获得 1 张；按章节主题换边框色/形状。贴纸是收集册主网格，可点开查看页码、句子、音频时间段。
2. **故事道具（room item）**：通过测验后从最多 3 件候选中选 1 件；放入系列专属房间。道具是非数值、可轻互动的纪念品。
3. **阶段勋章（chapter badge）**：完成一个章节/主题的全部集数和巩固后获得；只展示学习里程碑，不替代集级奖励。
4. **系列勋章（series badge）**：完成该系列全部已发布绘本与阶段巩固后获得；只发一次，重复复习不重复掉落。

### 4.2 建议节奏

| 进度 | 反馈 | 默认上限 |
| --- | --- | --- |
| 一集看完并通过 | 贴纸 + 10 SP + 三选一道具 | 每日大件掉落 2 件 |
| 连续 3 集 | “小队出发”徽章/标题 | 每系列一次 |
| 完成 5 集或一个主题 | 章节勋章 + 房间新展台 | 每主题一次 |
| 完成整套 | 系列完成勋章 + 完成卡 | 每系列一次 |
| 重做错题 | 错题对应小节回放、轻礼花 | 不增加大件奖励 |

### 4.3 设计约束

- 通过标准沿用当前年级配置（约 70%）；语音跟读是可选加分项，不设为必过条件。
- 失败时保留已学词和已得贴纸，自动定位 `source_sentence_ids` / `scene_ids`，不让孩子回看整集。
- 奖励文案同时提供中英文；测验仍默认全英文，中文只由“提示”显示。
- 奖励不改变 SP、掌握度、题目难度等学习指标，防止收集系统反向绑架学习。

## 6. 数据合同（建议作为 `storybook-collections.json`）

```json
{
  "schema_version": 1,
  "series": "mikey-jj",
  "characters": [{"id": "mikey", "bible": "...", "actions": {"idle": "..."}}],
  "action_sets": [{"id": "celebrate", "duration_ms": 1200, "loop": false}],
  "sticker_themes": [{"chapter": 1, "from": 1, "to": 10, "motifs": []}],
  "badges": [{"id": "mikey-jj.first-episode", "condition": {"type": "episodes", "count": 1}}],
  "rooms": [{"id": "room.mikey-jj", "slots": ["shelf.left", "shelf.center", "shelf.right"]}],
  "episode_rewards": [{
    "episode": 1,
    "sticker_id": "sticker.ep001",
    "items": [{"id": "mikey-jj.b1.helicopter-badge", "story_binding": {"scene_ids": ["b1-p02-s04"]}}]
  }]
}
```

字段约定：

- 所有 ID 小写 kebab-case（系列/书号可用 `mikey-jj.b1.*` 作为兼容前缀）。
- `asset` 指向运行时 `/assets/...`，源素材、prompt、报告放在 `prj/data/assets/generated/<asset-id>/`。
- `non_power: true` 表示道具不可改变数值；`display_mode` 取 `sticker-book`、`room`、`completion-card`。
- 角色动作缺图时允许 `fallback_css`，但必须在 manifest 和 review 中记录。

## 7. GPT 生图与验收流程

### 7.1 Pilot（先做 Book 1）

先做 6 个可见结果，再扩展全量：

1. Mikey/JJ 中性角色 Bible（双人同画板）
2. Mikey `idle`、JJ `listen`、双人 `high-five`
3. 直升机贴纸、金苹果贴纸、治疗药水道具
4. Book 1 完成勋章
5. Minecraft Steve/ Alex/ Byte 中性 Bible
6. Minecraft 金头盔或传送门碎片贴纸

### 7.2 生成要求

- 使用 `gpt-image-workflow` 的 `generate` 或 `asset-sheet`，provider 由 `CLIPROX_API_KEY` 自动选择；不得把密钥写入 prompt、manifest 或日志。
- 同一角色先生成中性参考，再用参考图生成动作，固定镜头、光向、画布比例和安全边距。
- 贴纸/道具使用透明 PNG；若模型返回不透明图，先保留在 `2d/`，再用 chroma-key 去背并输出到 `transparent/`。
- 每个资产目录包含 `source/`、`2d/`、`transparent/`、`manifest.json`、`review.md`；manifest 记录 prompt、模型、尺寸、hash、证据和限制。
- 禁止在图内生成可读中文/英文，名称和释义由页面叠加。

### 7.3 质量门

- 文件格式为 PNG/WebP，尺寸符合 UI 目标；贴纸缩略图在 96 px 仍能认出轮廓。
- 真正存在 alpha 通道，四角透明，无绿色/洋红色边缘残留，无裁切主体。
- 角色动作的轮廓、服饰、比例与 Bible 一致；漂移时停止批量生成，先回到中性参考。
- 浏览器完成资源加载检查和截图；收集册/房间至少验证一个拥有和一个未拥有状态。

## 9. 回滚与安全

- 新字段均为可选，旧版播放器忽略 `characters/action_sets/badges` 即可正常播放。
- 资产缺失时显示 glyph/CSS fallback，不阻塞学习流程。
- 发现证据、版权、透明度或角色漂移问题时，只回滚对应 asset-id 和 catalog 条目，不回滚已通过的题目/音频数据。
- 所有外部来源仅作为设计参考；最终素材不得声称为原作官方资产，运行时保留来源和限制说明。
