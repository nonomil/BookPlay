# 西游勋章墙与小白龙伙伴落地实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 把儿童学习奖励调研落成一条可验证的《西游记》学习闭环：每关完成自动收入一张故事贴纸，巩固达标再提供一次三选一故事纪念物，唯一伙伴小白龙在驿站中随阅读成长。

**架构：** 继续复用现有“大地图 → 场景戏 → 巩固页”三层，不引入金币、票券或支付系统。勋章由现有集/辑进度派生；纪念物使用独立奖励目录和本地幂等存档；小白龙阶段与同行日由现有学习事实派生，房间只负责展示与轻互动。

**技术栈：** 原生 HTML/CSS/JavaScript、localStorage、JSON 内容包、Node `node:test`、Python pytest、Capacitor 数据包准备脚本。

---

## 1. 决策与边界

### 已确认

- 伙伴就是西游记中的小白龙，后续在第 18 集化为白龙马；豆豆龙继续担任产品外层老师。
- 第一版采用 19 枚永久勋章：13 枚篇章章 + 6 枚旅程章。
- 首次巩固达标后提供 3 选 1；物品直接写入花果山小屋固定槽位。
- 重看、重复巩固、打开房间和照料不会重复掉落或刷币。
- 家具不锁剧情；没有金币/票券商店、随机抽卡、排行榜、饥饿、死亡、断签惩罚。

### 本轮已落地

- P2：花果山小屋固定云朵玩具架、轻装饰槽位和 15 件篇章纪念物目录。
- P2：每件纪念物带一次 1–2 秒、可跳过的轻互动；不增加钱包、价格或商城。
- P2：巩固页按候选数量显示“多选一/本集纪念”，单个篇章奖励不再误导为三选一。
- P2：保留每日大件掉落上限配置；贴纸独立记录，不占上限、不占房间槽位；旧存档仍按 `owned + placement` 读取并自动补齐贴纸字段。
- P2：每关 1 张确定性故事贴纸（装饰、玩具、动物、武器/装备等故事元素），驿站新增贴纸册与全部/已获得/待收集筛选。

### 后续可选

- P3：多房间与网格拖拽；不得改变主线解锁规则。先保持固定槽位，等真实回访后再开。

## 4. 执行规则

1. 每个任务先检查现有代码，再补失败测试或合同断言，最后才改实现。
2. 任何新增存档字段必须有旧存档回退；奖励必须可重入、永久、幂等。
3. 不覆盖旧透明素材，不把 API key、生成接口或儿童身份写进网页和数据包。
4. 页面缓存号与内容包清单同步更新；移动端通过 `npm run android:prepare` 复核。
5. 任务完成前必须运行对应的 Node/Python 测试并保存输出摘要；无新鲜证据不标记完成。

## 5. 验收出口

- `node --check prj/engine/episode-reward.js prj/engine/companion.js prj/engine/lesson.js`
- `npm test`：奖励、伙伴、地图、TV 与现有内容合同全部通过。
- `npm run test:content`：透明素材和数据包测试通过。
- `npm run android:prepare`：`dist/engine` 含伙伴页、奖励页依赖；外置数据目录由 `prj/tools/pack_android.py` / `pack_datapack.py` 负责，白名单由内容测试验证。
- 浏览器链路：`lesson.html?ep=1` 完成巩固 → 自动显示并收入本关贴纸 →（达标时）显示三选一 → 选择物品 → 进入 `stickers.html?series=jttw` 查看贴纸册；`companion.html?series=jttw` 只承载小白龙、同行日记和花果山小屋，`medals.html?series=jttw` 查看勋章墙 → 刷新仍保留。
- 空存档、重复完成、坏 JSON、缺失素材均有可理解降级，不阻塞地图和学习。
