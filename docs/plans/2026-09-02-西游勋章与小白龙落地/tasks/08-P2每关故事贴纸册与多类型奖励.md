# 任务 08：P2 每关故事贴纸册与多类型奖励

**目标：** 在不把每关变成复杂商城或房间编辑的前提下，让每一关完成都有一份可见、可回看的小礼物；同时把装饰、玩具、动物、武器、装备等大件奖励表达为故事收藏。

## 产品决策

- 每关完成巩固自动收入 1 张确定性故事贴纸；贴纸像可贴在冰箱上的小磁贴，进入独立贴纸册。
- 每辑收尾集仍按原规则提供大件纪念物；只有首次达标才出现三选一，其他关不重复弹选择面板。
- 大件目录使用 `reward_type`：`decor`、`toy`、`animal`、`weapon`、`gear`。动物/武器/装备都是故事主题收藏，`non_power: true`，不提供战斗数值。
- 继续禁止金币、票券、商城、随机抽卡、稀有度、排行榜、惩罚、饥饿、死亡和掉级；家具不锁剧情。

## 数据与幂等

- `jttw.json` 声明 `sticker_count: 108` 与 13 个章节主题；每张贴纸由章节范围、故事元素、形状、色调和 glyph 确定性生成。
- `episodeSticker()` 返回 `sticker.ep001` … `sticker.ep108`；`grantEpisodeSticker()` 只写 `state.stickers[id]` 和 `progress.episodes[key].sticker_*` 收据。
- 贴纸不写入 `rooms.*.placements`，不占 `daily_drop_cap`；重复完成返回 `already_granted`，旧存档缺少 `stickers` 时由 `normalizeState()` 补 `{}`。

## 页面行为

- 巩固完成态先显示一条“本关贴纸已收入贴纸册”轻提示；可打开 `stickers.html?series=jttw`，不强迫停留。
- 驿站贴纸册显示 `0/108` 进度，支持“全部 / 已获得 / 待收集”；未获得卡片显示集号和解锁条件，颜色/形状不是唯一状态信号。
- 贴纸册与花果山房间分区，贴纸不会把固定玩具架和装饰槽位挤满；大件仍可点一次短互动且可跳过。
