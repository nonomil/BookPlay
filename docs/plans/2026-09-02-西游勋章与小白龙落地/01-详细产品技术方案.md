# 西游勋章墙与小白龙伙伴：详细产品与技术方案

> 依据：`docs/调研/2026-09-01-儿童学习奖励与房间装饰-分析报告与方案.md`、`docs/plans/2026-09-01-西游勋章与小白龙整体优化分析.md`。
> 本文是执行期唯一的详细规格；若与早期讨论稿冲突，以本文和自动化测试为准。

## 1. 产品定义

“勋章证明我做到了，小白龙表达谁在陪我走，纪念物保存我们一起去过哪里。”

学习主路径仍然是：

```text
西游入口 → 路线图 → 场景戏 → 单集完成 → 本辑巩固 → 下一辑
                         ├─ 每拍：短反馈，不掉永久物
                         ├─ 每关完成：自动收入 1 张故事贴纸（贴纸册）
                         ├─ 每集巩固首次达标：三选一故事纪念物
                         └─ 驿站：小白龙、勋章墙、已获得物品
```

驿站是学习的回看与情感层，不是第二个首页。所有奖励均为本机、免费、无支付；贴纸与大件纪念物分开保存，避免每关都挤进房间。

## 2. 角色与世界观

| 角色 | 产品职责 | 禁止混淆 |
|---|---|---|
| 豆豆龙 | 产品外层老师、提示、朗读入口 | 不与西游伙伴共用成长阶段 |
| 小白龙 | 西游故事中的唯一伙伴 | 不称为可抛弃的普通宠物 |
| 白龙马 | 第 18 集后的小白龙形态 | 不提前于故事事实解锁 |
| 孩子 | 阅读、答题、照料、收藏 | 不被要求维持宠物生存 |

龙蛋、幼龙是面向儿童的成长想象，页面需保留“想象中的幼年阶段”提示；第 17 集与第 18 集按故事内容衔接正式角色。

## 3. 奖励分层

### 3.1 永久勋章

- 19 枚固定目录，ID 必须带 `jttw.` 前缀。
- 13 枚篇章章条件为“该辑全部集完成 + 该辑巩固通过”。
- 6 枚旅程章条件为 1/10/54/72/100/108 集；最终章另要求 13 辑巩固全部通过。
- 只记录一次收据：`at`、`seen`、`rule_version`、`source`。
- 进度回退不撤销已获得勋章；旧用户上线时一次性补发，不连续弹窗。

### 3.2 单伙伴成长

7 个阶段由 `companion-core.js` 根据学习事实派生：神秘龙蛋、龙蛋苏醒、西海小龙、小白龙现身、白龙马、腾云白龙、八部天龙。阶段不额外消耗 SP，不因漏学回退。

首版互动固定为“喂灵果、洗澡梳洗、玩云球、一起休息”。互动可重复，但同一自然日只有第一次在有效学习日之后的互动盖同行印；7/15/30 个同行日解锁非必要外观。不存在 `hunger`、`death`、`poop`、`rarity` 字段。

### 3.3 故事纪念物

当前开放第 1 集三选一和各辑收尾集篇章纪念物，目录为 15 件，使用 `reward_type` 标记 `decor`、`toy`、`animal`、`weapon`、`gear`。大件写入 `room.huaguo` 固定槽位；动物、武器、装备仅为故事收藏，不提供战斗数值、伤害、价格或稀有度。

### 3.4 每关故事贴纸

- 每关完成巩固即获得 1 张确定性贴纸，ID 为 `sticker.ep001` … `sticker.ep108`；不要求达到 70% 正确率，不占每日大件上限。
- 贴纸由章节主题与故事元素生成（仙石、云朵、小白龙、铃铛、风车、金刚圈、芭蕉扇、动物朋友等），包含 `shape`、`tone`、`glyph` 和中英文说明，视觉上像可贴在冰箱上的小磁贴。
- 贴纸只写入 `state.stickers[id]` 与集级 `sticker_granted` 收据，不写入 `rooms.*.placements`，不会挤占房间槽位；重复完成按 `already_granted` 幂等返回。
- 驿站提供“全部 / 已获得 / 待收集”筛选；未获得贴纸保留轮廓、集号和“完成第 N 集后获得”提示，颜色/形状不是唯一状态信号。

## 4. 三选一掉落规则

1. `lesson.js` 在巩固结束后计算可评分题目总数，达到 `correct / total >= 0.7` 才调用 `prepareDrop()`。
2. 巩固完成后先调用 `grantEpisodeSticker({ completed: true })`，自动写入本关贴纸；失败或重复不会阻塞巩固结果。
3. `prepareDrop()` 以 `progress.episodes[episode].drop_granted` 幂等；已拥有物品被过滤；候选最多 3 件。
4. 达到 `daily_drop_cap` 时不展示空卡，给出“明天再来”的解释；默认配置为 2，仅保护大件不被刷取，贴纸不受影响。
5. 点击候选后 `grantChoice()` 同时写入 `inventory[id].owned`、`rooms[room].placements[]` 和集级收据；任何失败都不得部分写入。
6. 选择成功后保留“去花果山看看”和“继续下一集”两个方向；默认学习主线不被奖励劫持。

内容目录与用户存档分离：目录在 `prj/data/achievements`、`prj/data/companions`、`prj/data/rewards`；存档仅在 localStorage。未来多设备同步时再迁 SQLite/账号层，不污染词库。

## 6. 页面结构与交互

### 地图

- 主 CTA 只有一个：开始/继续当前集，待巩固时改为完成本辑巩固。
- 伙伴入口作为次级入口，显示“小白龙 + 已获得勋章数”；不盖住下一集。
- 封面闪屏维持短时自动进入地图；小白龙卡可取消自动消失，但不能制造固定等待。

### 巩固页

- 完成态最多一个反馈层；题目结果、奖励和下一步不能连续弹窗。
- 三选一卡片包含图、中文名、英文名和一句故事说明，无价格。
- 选择后按钮禁用，状态文案明确写入花果山小屋。

### 驿站

1. 伙伴区：当前形态、成长提示、四个免费互动、同行日状态。
2. 房间区：花果山背景和已获得纪念物；MVP 固定槽位，不拖拽。
3. 贴纸册：108 张按章节主题生成的故事贴纸；筛选（全部/已获得/待收集），已获得显示日期，未获得显示解锁集数。
4. 勋章墙：最近获得（最多 3）、下一目标卡、筛选（全部/已获得/篇章/旅程）、完整墙。
5. 详情弹窗：名称、祝贺、条件、获得日期、英文称号朗读、返回地图。

所有按钮带中文 `aria-label`，卡片以文本同时表达“已获得/下一目标/未获得”；颜色与形状不能是唯一状态信号。

## 7. 状态机与失败降级

```text
集/辑进度
  → 巩固可用
  → 完成巩固
  → 贴纸收据（独立、永久、幂等）
  → 首次达标且未超大件日上限
  → 选物面板（可选）
  → owned + placement + drop receipt
  → 房间预览/继续学习
```

- 巩固未达标：只保存成绩，不显示奖励。
- 已发放：显示“已经放进房间”，不重复候选。
- 目录缺失或 JSON 损坏：巩固仍可完成，贴纸/大件奖励区隐藏并记录可理解提示；驿站回退到龙蛋、空房间、空贴纸册。
- 图片缺失：隐藏图片并显示 glyph/文本，不让布局塌陷。
- localStorage 损坏：使用空状态，绝不抛出阻塞地图的异常。

## 8. 性能、资产、离线

- 生图只在离线生产流程执行；网页不调用 Cliprox/API，不打包 key。
- 角色透明 PNG、SVG 回退和 manifest 位于 `prj/data/assets/companions` 与 `prj/data/assets/generated/wala-gamification`；废弃的 `doudou-dragon-companion-v1-alpha-v2.png` 不得重新引用。
- 现阶段先保持 PNG 质量；完成设备实测后再输出 512–768px WebP/AVIF，保留 PNG 回退。
- `npm run android:prepare` 只准备 `dist/engine` 的页面运行树；外置 JSON 与资产由 `prj/tools/pack_android.py` 或 `prj/tools/pack_datapack.py` 按白名单打包，不能假设它们会出现在 `dist/engine`。
- CSS 遵守 `prefers-reduced-motion: reduce`，TV 断点使用 64px 以上控制尺寸和可见焦点。

## 9. 观测与 P2/P3 边界

本轮按用户要求直接落地 P2，不等待真实回访数据：固定玩具架、轻装饰、篇章纪念物和每关故事贴纸已经接入学习闭环，但仍保持低负担、无商城、无惩罚。仅在本机记录匿名计数（如确有需要）：驿站打开、贴纸筛选、房间互动、返回地图、奖励选择。观察四项：贴纸册打开/筛选比例、去房间比例、房间停留中位数、次日继续下一集比例。

P3（多房间、网格拖拽、主题切换）仍以真实回访为开关。进入条件是孩子主动回访、能说出下一枚勋章条件并询问布置，而不是一次性领取弹窗后的短停留；P3 不得改变主线解锁和奖励幂等规则。

P2 大件纪念物在各辑收尾集（13、23、31、39、48、54、63、71、79、91、99、108）完成巩固后发放；第 1 集保留三选一作为首个房间入口。每关贴纸自动收入贴纸册，不弹三选一卡，只有完成态的一条轻提示；这样每个学习节点都有动力，但不会把每关都变成复杂布置。

## 10. 验收清单

- 空存档能看到龙蛋、0/19 和第一目标。
- 空存档能看到 0/108 贴纸、章节主题与“完成一关就收入一枚”的说明。
- 完成第 1 集并通过巩固后只出现 3 个未拥有候选，选中后写入库存与花果山槽位。
- 完成任意一关后自动收入对应 `sticker.epNNN`，重复完成不重复计数，且房间槽位和大件每日上限不变。
- 同集重复巩固不再发放；同日达到上限后安全停止。
- 勋章条件与地图解锁一致；同一收据不会重复庆祝。
- 小白龙阶段在第 17/18 集边界正确，漏学不会倒退。
- 刷新/返回后房间和勋章仍存在；素材/JSON 缺失有降级。
- `npm test`、`npm run test:content`、`npm run android:prepare` 和浏览器冒烟均有新鲜输出。
