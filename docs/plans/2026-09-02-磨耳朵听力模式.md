# 磨耳朵听力模式实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 在主动学习约 25 分钟后提供温和的休息选择，并允许进入不出题、不打断剧情的整集听故事循环模式。

**架构：** 在现有 `wala.html / wala.js / media.js` 上增加一个纯状态层：主动学习计时只统计可见播放器中的学习活动，磨耳朵模式复用现有视频和句段时间轴，从第一句开始按集循环播放。磨耳朵不写完成进度、不出词卡/测验、不发 SP 或奖励；退出后回到进入前的集和句。

**技术栈：** 原生 HTML/CSS/JavaScript、localStorage、现有 `WalaMedia` 控制器、Node 内置 `node:test`。

---

## 产品规则

- 25 分钟是“主动学习累计时长”，不是墙钟时间；页面隐藏、播放器暂停、磨耳朵和休息倒计时均不计入。
- 达到阈值后不立即打断当前句或题目，在当前句/题目结束时显示休息卡：`休息 5 分钟`、`进入磨耳朵`、`继续学习`。
- 磨耳朵默认循环 2 遍，可选 1/2/3 遍；不默认无限循环。用户可以随时暂停、退出或提前结束当前循环。
- 磨耳朵的所有用户入口（选集卡片、路线图和播放器内休息卡）都进入纯听力画面：不加载视频/绘本图，只显示听力提示、字幕和养宠物立绘。它隐藏词卡、精学卡、情节题、SP、礼花和完成判定。字幕默认 EN，卡片入口默认 EN+中，可切换并沿用语速设置。
- 磨耳朵结束后显示轻量完成提示，提供“回到刚才位置”和“再听一遍”；不得把听力循环误记成完成一集。
- 选集卡片和路线图的入口统一为 `wala.html?ep=<n>&mode=listen&loops=2&visual=audio&subtitle=enzh`；`visual=audio` 表示纯听力布局，`loops` 仍只允许 1/2/3。地图顶部入口同步使用该地址，不再依赖跳转 `storybook.html` 才能听整集。

## 结合“碎片时间听力”笔记后的调整

参考：`G:\UserCode\跨平台采集器\notes\学习\听力时间怎么挤出来？利用一切碎片时间！\听力时间怎么挤出来？利用一切碎片时间！.md`。该笔记来自个人学习经验和小红书帖子，不把其中的遍数、月份或“听不能断”当作医学/教育效果结论，只提取产品可验证的行为原则：

1. **听力紧跟最近看过的内容。** 磨耳朵入口优先推荐最近完成或最近播放的集，不做跨季随机播放；未看过的集仍可手动选择，但不算“复习”。
2. **碎片窗口优先短会话。** 在睡前、起床、洗漱、乘车等场景使用 5/10/15 分钟的听力预设；页面关闭或系统切后台后暂停，回到前台可继续。
3. **连续性优先于一次听很久。** 记录“本周听过几天”和“最近听过集”，而不是用累计分钟数制造压力；不显示排名、连续天数惩罚或必须打卡文案。
4. **看听比例只作为建议。** 不把“5:25”或“听 25 遍”写死；产品默认每集 2 遍，最多 3 遍，家长设置可以改为 1 遍，连续听满一段后给出休息提示。
5. **安全边界。** 磨耳朵不在后台偷偷播放、不绕过系统音频权限；睡前模式提供“本轮结束自动停止”，避免整夜循环。

因此，25 分钟主动学习提醒和碎片化磨耳朵是两个互补入口：前者帮助孩子休息，后者提供低负担、可理解、可随时结束的声音输入，不能把休息变成另一种强制学习。

## 不做的事

- 不重新切片或重新编码视频，不修改 `content/assets/video` 和音频包。
- 不把磨耳朵计入 `bookplay_adv_progress` 的 `done`，不触发巩固解锁、勋章、礼花或 SP。
- 不默认无限循环，不使用后台播放绕过浏览器自动播放策略。
- 不在本轮引入新的前端框架或独立播放器。

## 总体验收标准

1. 主动学习累计达到 25 分钟后，当前安全边界出现休息卡，且暂停/隐藏/磨耳朵不计时。
2. 用户选择磨耳朵后可完整播放 1/2/3 遍，画面、原声、字幕连续，期间没有学习卡片和完成奖励。
3. 退出或结束循环不会改变原学习进度；返回后仍在进入前的集/句。
4. HTTP Range 服务下 EP1 和一个高动作集均通过；桌面浏览器和 TV 遥控器焦点路径无新增错误。
5. 新增 Node 测试、既有播放器测试和语法检查全部通过；无媒体文件进入 Git。
