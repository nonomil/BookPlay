# 西游记巩固测验音频补齐 实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 让 c01–c13 巩固单元（单词/句型/测验）在 APK 端也能完整发音，覆盖全部英文/中文题干与选项音频，并修复 drill.js 播放器。

**架构：** 复用 `make_word_audio.py` 的 edge-tts 管线收集 ep1–108 的 puzzles + official_quiz 文本，写入 `sent_en`/`sent_zh` 与 `quiz_en_index`/`quiz_zh_index`；drill.js 合并加载四类索引，用 `WalaMedia` 持久 `<audio>` 播放，单词喇叭读目标词而非例句。

**技术栈：** Python edge-tts、`make_word_audio.py`、Node/pytest 静态合同测试、drill.js + media.js

---

### 任务 1：全量审计缺口

**文件：**
- 创建：`prj/tests/test_drill_audio_coverage.py`
