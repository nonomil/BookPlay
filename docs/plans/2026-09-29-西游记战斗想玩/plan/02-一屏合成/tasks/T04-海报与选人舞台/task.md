# T04 海报与选人舞台

## 目标与消费者

标题和选人不再是说明卡片。消费者是从标题走到开战的人。战斗手感以 T02、T03 为准，这一步不重做判定。

关联：需求 R1、R8、R5。验收 A5 的标题和选人部分。

## 允许改

- `#scr-title`：用一张第 1 集能对上的画面当标题底，按钮「进入游戏」留在画面上。没有新的主视觉文件时，用 `bg-ep1.jpg` 加现有悟空立绘拼一屏，不先去生图
- `#scr-pick`：四个角色改成台上的人。悟空可以确认。另外三人保持待解锁，唐僧仍有「尚未解锁」之类的一句，不进战斗
- 选人卡上的生命 1000 不再写成好像战斗里会扣的血。攻防数字若保留，只作为名号，战斗 HUD 不加这些数字
- 大厅在 T01 的「这一仗」之上，把悟空立绘放进画面中心。不把 108 集目录搬回来

- 战斗匹配、落空、过关
- 新增 VIP、货币、邮件、好友、排行
- 让八戒、沙僧、唐僧出战
- 把标题换成通天河四师徒飞天那张别人的成图。可以学它的构图，不把那张图放进仓库
