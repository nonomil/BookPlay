# 需求

来源分三列。没有写进「用户原话」的，都是本方案为了落地那两句话而选定的，改代码前可以推翻。

## 用户原话

| 编号 | 内容 |
|---|---|
| U1 | 通天河 demo 看着吸引人，游戏想玩 |
| U2 | 自己的西游记战斗看着没意思，像假的学习游戏 |

## 本方案选定，用来满足 U1、U2

| 编号 | 内容 | 落到 |
|---|---|---|
| R1 | 第 1 集打开后，第一眼是花果山这场架，不是做题说明，也不是 108 集目录 | T01 |
| R2 | 打错时游戏表现是这一棒落空、猴子还在。界面不出现「词不对」「词牌」「定额」 | T02 |
| R3 | 中文和英文是同一个意思时，这一棒才算击退。第 1 集 12 个词的对应不改 | T02 |
| R4 | 第 1 集故事仍是小猴子和猴群小头目。不改成灵感大王 | 全部 |
| R5 | 不增加 VIP、金币、钻石、体力、假世界聊天、红点邮件 | 全部 |
| R6 | 不改 `game.html`、`game.js`、`battle.html` 的捡球、扔投、Boss 抢答 | 全部 |
| R7 | Boss 血打光后直接过关，不弹三选一 | T02 |
| R8 | 战斗里玩家看见的命数就是会扣的那 5 颗心。选人卡上的生命 1000 不进入战斗 HUD | T04 |
| R9 | 计划 02 用已有黏土悟空、黏土小猴、`bg-ep1.jpg` 把人站进同一张地面。不新画 108 张背景 | T03、T04 |
| R10 | 计划 03 每集只换地方、妖怪和词表。出手、落空、过关方式沿用计划 01 | T05 |

## 明确不做

- 不把认词从击退判定里拿掉。那是待办，不是本轮需求。
- 不要求孩子读完说明才知道按哪个键。键位说明可以留在战斗底部，不能占标题。
- 不把通天河的冰原原画放进第 1 集。
