# 步骤与停止

## 顺序

```text
T01 标题与大厅
  → 打开页面，第一眼是这场架
T02 挥棒反馈
  → 打错没有「词不对」，Boss 没有三选一，打对仍要词匹配
人看过第 1 集，承认是在打
  → 才允许 T03
T03 战场落在同一张地上
  → 才允许 T04
T04 海报与选人舞台
人说第 1 集想再打一次
  → 才允许 T05
T05 其余集换地方，不换出手
```

T01 和 T02 都在计划 01，但是 T02 依赖 T01 的文案已经换掉。不要并行改同一个 `hurtFoe`。

## 每一阶停在哪里

| 任务 | 停 |
|---|---|
| T01 | 改着改着要动 `hurtFoe`、`askBossWord` 或 108 集词表。那些是 T02 / T05 |
| T02 | 为了换浮字去重写刷怪、跳跃或纵深。匹配规则只留在 `hurtFoe` 已有的 `matched` 分支 |
| T03 | 需要新画背景，或要把投影算法搬出文件才能改落点。先记到待办，不在这一步拆文件 |
| T04 | 开始做商城、资源数字、世界聊天 |
| T05 | 第 1 集还没有「想再打一次」的人话记录。或者某一集又出现「词不对」和三选一 |

## 结构债

T01、T02 留在 `proto-action.html`。超过一千行只说明以后别再往里堆新系统，不构成先拆再做的理由。计划 02 若出现第二个页面框架，按 `../solution.md` 的代码边界停。
