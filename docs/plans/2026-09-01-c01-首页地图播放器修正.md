# c01 首包资源与播放器交互修正实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 修正 c01 外置数据包缺少西游记首页/地图元数据的问题，并让整集完成后通过“下一页”进入知识巩固，同时把播放器侧边单词卡改成紧凑、无彩边、顶对齐且可关闭的布局。

**架构：** 阶段包在保留 c01 选择性媒体的前提下，额外生成只含所选集的 `storybooks/catalog.json`，并显式携带公共西游记封面；地图继续从同一目录读取中英文标题和集封面。播放器完成状态由独立状态变量驱动，完成后不再在字幕气泡中渲染跳转按钮，右侧“下一页”箭头负责进入 `lesson.html`。侧边词卡设置沿用现有 localStorage 设置合同，CSS 负责在大屏预留中间字幕空间，小屏回流到文档流。

**技术栈：** 原生 HTML/CSS/JavaScript、Python ZIP 打包器、Node/Python 测试。
