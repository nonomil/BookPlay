本文不是新开一套游戏，也不是 Phaser 新项目。它把四件事压成一份合同：

1. BookPlay「书 → 巩固 → 戏」为什么这样接  
2. `game-template` 的玩法简报栏目（不搬 Phaser）  
3. 美术/游戏设计工具的 2D 资产契约（不用 3D / img2threejs）  
4. word-memory-map / 对话剧情 / pet-battle / typing-defense 的取舍

## 一句话

降妖记是同一集「读完 → 巩固 → 用刚学的词去玩」的复习糖衣：一套引擎、c01 第 1–7 集共用；大地图玩法对齐 word-memory-map 的捡投循环；镜头与攻击维持边缘滚动和攻击停步；NPC 与 Boss 挂在同一张图上当第二、第三遍学习。

- 独立小游戏中心 / 每集新引擎 / Phaser 重写  
- 大地图点击快卡、物理键盘打字主线、pet-battle 的 2v2/换人/技能 CD  
- 母本立即居中跟随、攻击边跑边挥  
- 50 词刷图、小怪随镜头瞬移到当前屏  
- img2threejs / GLB / 四视图 3D  
- 新游戏存档键；删除 `content/game/` 手写源  
- 用 Node/浏览器结果代称真机通过  
- 整段视频均分冒充逐句原声
