## 地图上不打

第二波清完且 `npcDone` 后，Boss 区亮起。走近出确认卡，可先逛。开战：

```
battle.html?ep=N&skip=intro,preview,waves&from=game&wrong=错词
```

缺 `waves` 会让战斗页再打小怪波，禁止。

## 孩子做什么

- 血条 = 词数。选英文词攻击。  
- 地图带过去的错词插到词序前面（`reorderBossWords`）。  
- 答对：主角突进 → 命中闪光 → Boss 后仰 +「−1 单词」浮字；血条宽度过渡，不瞬间跳格。  
- 答错：Boss 回合，扣盾。玩家恒先手。  
- 左下角最近 3 条战报（打中 / 打偏 / 被反击）。  
- `roundId` + 整回合输入锁：一次点击只消费一次。  
- 打赢：妖怪卡 + 结算 → `game.html?ep=N&from=battle`。

## 从 pet-battle 借 / 砍

| 借 | 砍 |

| 事件日志增量动画 | 2v2、替补、换人 |
| 三段打击感（突进/闪光/后仰） | 四技能 CD、spd 先手队列 |

| 伤害浮字、`uiLocked` | 热座 PvP、训练关卡列表壳 |
| 结算 overlay + sfx 钩子 | 独立「闯关列表」 |

连对 3 可用更夸张的「必杀档」动画，不另做技能按钮。

## 关底测验

从大地图进来：

- 无本局错词：直接结算。  
- 有错词：最多 2–3 题，**可跳过**，不作为通关门禁（巩固已经门过了）。  

「下一集」按钮：去下一集的 `game.html` 或绘本地图，不去 `battle.html?ep=N+1`。
