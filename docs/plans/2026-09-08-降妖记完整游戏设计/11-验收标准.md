# 11 验收标准

只有同时满足：适用项有设备或可复现浏览器证据、包 hash 可追溯、关键音频逐条可播、整局返回不丢状态，才能写「阶段通过」。  
单张截图、方案写完、`npm test` 单独都不构成通过。

## 玩法

- [ ] 巩固完成出现进入 / 跳过；进入带 `from=lesson`；跳过保留学习结果  
- [ ] 走近开场 NPC 自动 2 句；战斗返回不重弹  
- [ ] 能四向走、捡中文球、扔中对应英文怪；扔错弹回  
- [ ] 大地图全程无快卡  
- [ ] 6 种道具各能触发一次对应效果  
- [ ] 第一波未清，quiz NPC 不能领奖  
- [ ] 清完第二波 + npcDone 才能开战  
- [ ] Boss 页只打 Boss（skip 含 waves）  
- [ ] 结算回地图，不重刷、不重奖  
- [ ] 「下一集」不直进下一集 battle.html  

## 运动 / 输入

- [ ] 中央区走路时地图不动，越边缘才滚  
- [ ] 攻击时停步，idle/walk/attack 资源分离  
- [ ] 摇杆单一 pointer；失焦/关对话不续走  
- [ ] 双指：第二指可投掷或点实体  
- [ ] TV：方向键走，OK 最近实体  
- [ ] 可行走区能从出生点走到 NPC 和 Boss，不是窄横廊卡住  

## 语音 / 离线

- [ ] 断网可播地图词、NPC 题、Boss 关键句  
- [ ] BGM 不盖人声  
- [ ] 未审原声仍标 pending
