# 06 参考项目取舍

> 旧文 `docs/plans/2026-09-06-西游记降妖记-大地图探索版/06-参考项目借鉴与整合设计.md` 的 §1–4 借鉴表仍可对照；**§5 快卡流程图作废。**

## 总原则

四个参考各管一层，**不要合成三个小游戏**。主循环永远是大地图捡投。

```
word-memory-map     → 大地图内核（循环 1:1，运动改编）
对话剧情系统        → 开场 + 小 Boss 弹层
pet-battle-template → 大 Boss 打击感
TypeWords           → 桌面/手机持球跟打英文（先不考虑 TV）
typing-defense      → 不上主线；以后可做听音选怪
```
