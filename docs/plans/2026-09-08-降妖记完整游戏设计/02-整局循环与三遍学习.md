# 02 整局循环与三遍学习

## 孩子看到的一条线

```
map.html / lesson 完成卡
        │
        ▼
「进入降妖记」  或  「暂时跳过」（跳过不抹学习结果）
        │
        ▼
game.html?ep=N[&from=lesson]
  ① 开场 NPC：走近自动弹 2 句本集原文；from=battle 不重弹
  ② 大地图捡投（主玩法）
        第一波清完 ──► ③ 小 Boss NPC：嘲讽 + 1 题三选一
        第二波清完 ──► ④ 走近 Boss 区，确认后
                              battle.html?ep=N&skip=intro,preview,waves&from=game&wrong=错词
  ⑤ 结算回 game.html?ep=N&from=battle
        地图保持完成态：不重刷、不重弹 intro、可逛
```

打字不进这条线。

## 三遍学习

| 遍 | 环节 | 孩子做什么 | 不做什么 |
|---|---|---|---|
| 1 | 大地图 | 手里中文球 ↔ 头顶英文怪 | 不弹中文三选一快卡 |
| 2 | 小 Boss NPC | 听一句剧情，选中文意思 | 不扣盾、不写新存档键 |
| 3 | 大 Boss | 选英文词打血条，**错词优先** | 不在地图上打 Boss |

关底测验：从地图进来时 **默认跳过或最多 2–3 个本局错词且可跳过**。无错词直接结算。禁止再打一遍小怪波。

## 门控

```text
intro 可走
  → wave1 未清：quiz NPC 头顶「…」，Boss 区不可开战
  → wave1 清完：quiz NPC 可对话
  → npcDone：刷 wave2
  → 剩余小怪 = 0 且 npcDone：Boss 确认卡
  → 打赢：mapStage = complete
```

「走到点上也能提前跟 quiz NPC 说话」已否决。必须清完第一波。

## 返回与重入

| 来源 | 行为 |
|---|---|
| `from=lesson` | 当新一局或继续未完成局；开场 intro 按规则弹一次 |
| `from=battle` 未通关 | 恢复 `mapStage / killed / npcDone / items / shield`；不重弹 intro |
| `from=battle` 已通关 | 完成态，不重打、不重发奖励 |
| 刷新页面 | 读 progress 键恢复；镜头/手里球/buff 计时不强制恢复 |

## 结算后「下一集」

必须走绘本地图或 `game.html?ep=N+1`，**禁止**结算页「下一集」直进 `battle.html?ep=N+1`（会跳过下一集探索）。

## 建议时长（样板，非已测）

| 段 | 目标 |
|---|---|
| 开场 NPC | 20–40 秒 |
| 两波地图 | 3–5 分钟，约 8 词 |
| NPC 题 | 20–45 秒 |
| Boss | 1–2 分钟，约 4 词位 |
| 整局 | 巩固后的加餐，不替代 lesson |

## 与现状差异（设计要求 vs 代码）

| 设计 | 现状 |
|---|---|
| 走近 intro 自动 2 句 | 只出横幅，要点一下 |
| 完成回图可逛 | 完成态锁死重打（可接受）；中途状态半恢复 |
| Boss 后来自地图则跳过整套 quiz | 仍 `startQuiz()` |
| 下一集进大地图 | 可能直进 battle.html |
