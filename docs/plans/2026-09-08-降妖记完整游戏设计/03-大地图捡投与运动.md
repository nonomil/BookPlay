# 03 大地图捡投与运动

参考母本：`G:\StudyCode\小游戏项目\games\word-memory-map`  
原则：**玩法循环 1:1；运动层按 7 岁触屏/TV 改编。** 只换地图皮和角色皮。

## 必须 1:1 的玩法

- 怪头 **英文**，地上 **中文球**，配对键是词 id，不是临时字符串比划。  
- 走近半径自动捡；同时只持 1 球；场上同时只飞 1 弹。  
- 持球点怪 = 追踪弹；打空落地可再捡；未持球点怪 = 预习（读英文），不算攻击。  
- 对了：消灭、掉星星/支援、连击 +1。  
- 错了：球弹回，怪变红加速逃几秒，连击清零。  
- 连对 3 横扫本波；横扫未主动匹配的词 **不算掌握**。  
- 盾制，不是血条 Game Over；撞击击退 + 短暂无敌；盾碎本波重置。  
- 四向走，斜向 `hypot` 归一，主轴定朝向。  
- 6 支援效果只换西游名（见简报）。

## 明确不 1:1（改编理由）

| 母本 | 降妖记 | 为什么 |
|---|---|---|
| 键盘 WASD，无摇杆 | 摇杆 + 键盘 + TV D-pad | 手机/电视没有物理键盘当主输入 |
| 每帧人物居中瞬跟 | **屏内先走，近边缘才平滑滚图** | 用户已确认；居中会让地图一直晃，观察角色变难 |
| 攻击不停位移 | **攻击期间 moving=false** | 走路 GIF 和挥棒必须分开看清 |
| 3×3、怪随切屏瞬移到当前屏 | **4×4，怪守出生区域** | 要「走一段」才到 NPC/Boss；瞬移会拆掉空间门控 |
| 一局最多 50 词、每波 3 | 约 8 词两波 + Boss 4 词 | 巩固后的加餐，不是刷词游戏 |
| 点空地直线扔 / 空格扔 | 触屏以点怪为主；TV OK 对最近怪 | 7 岁瞄准以「选目标」为先 |
| 选世界包 / 选英雄 | 不做 | 内容由本集绘本决定 |

## 运动参数（起始值，真机可调）

来源：006 决策 3。单位：视口比例/秒，再乘 `1 / WORLD_TILES`。

| 角色 | 起始 | 备注 |
|---|---|---|
| 主角 | `0.018` | 1280 宽约 23 px/s；允许 T10 按轨迹微调 |
| 小怪游荡 | `0.0012` | |
| 小怪追击 | `0.0024` | 须明显慢于主角 |
| 镜头死区 | 边缘约 0.32 | `edgeCameraStep` |

## 世界与可行走

- `WORLD_TILES = 4`。背景一张主题俯视图铺满，不是 9 张不同 tile。  
- 点位来自关卡 JSON（由 `maps.json` **烘焙**进 `levels/epN.json`）。改 `maps.json` 必须重建关卡，运行时不直接 fetch。  
- 可行走是矩形 clamp，不做多边形墙。  
- **设计硬要求：** 可行走区必须让孩子从出生点走到 wave1、NPC、wave2、Boss，体感是「走一段路」。当前一条 `h≈0.15` 的窄横廊不合格，要加宽/分区，而不是把世界缩回 3×3。

建议 4×4 区域叙事（编号随边长，禁止写死 `% 3`）：

```
出生区 → 波 1 → NPC → 波 2 → Boss 区
```

## 输入

- 单一活动 `pointerId`；`pointerup / cancel / lostpointercapture / blur / pagehide / visibilitychange` 清零。  
- 弹层打开清零意图，关闭后不续走。  
- 双指：摇杆不换主人；第二指点实体。  
- 攻击前摇内忽略新的移动意图。

## 小怪 AI（降妖记版）

保留现有：游荡换点、进入仇恨距离追、保持距离、贴身攻击。  
不改成母本「只追不逛 + 切屏传送」。游荡让地图有活气；守区才能配合门控。
