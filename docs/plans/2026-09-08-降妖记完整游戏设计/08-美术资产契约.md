# 08 美术资产契约

> 方法来自 `G:\AI编程--项目模板\美术和游戏设计` 与 `G:\Game\game-template\game\art\README.md`。  
> **范围：2D 俯视。明确排除 img2threejs / 四视图 3D / GLB。**

## SPEC

| 栏目 | 口径 |
|---|---|
| 类型 | 儿童英语俯视大地图 |
| 投影 | 俯视正交 |
| 平台 | Web Canvas + Android APK；序列帧 GIF / PNG |
| 画布 | 运行样板 1280×720；精灵沿用现有四向 GIF 尺寸，不无故重画 |
| 风格 | 儿童国风可爱、轻度西游；禁写实、禁商标、禁按钮烧字 |
| 透明 | 精灵/UI 真 alpha；禁止棋盘格假透明、禁止 JPEG 改后缀 |
| 命名 | kebab-case 语义名；禁止 `1.png` |
| 输出 | `assets/generated/<主题>/`，不覆盖手作 |
| 背景 | 主题俯视整图铺满世界，不是可走地面的 9 宫格换砖 |

## 现有资产策略

已有四向走路 / 攻击 GIF、6 张主题背景。P0 **不新画角色**。P1 才补：道具 sheet、受击/掉星反馈、更清楚的目标箭头、小地图。

新画必须：一张 canonical base → `image_edit` 出四向/状态；禁止每张重 `image_gen`。

## 分类与技能

| 类 | 技能 | 降妖记用法 |
|---|---|---|
| 角色 | `game-character-consistency` | 悟空/小怪/NPC 四向不换脸 |
| 动画 | `game-animation-frames` | idle/walk/attack；方向 south,west,east,north |
| 背景 | GPT 主题俯视图（已有） | 实心场景，不要假透明棋盘 |
| 地砖 | `game-tilesets` | **本游戏不用换砖**；装饰物可单独透明精灵 |
| UI/道具 | `game-ui-icons` | 托盘、确认卡、道具图标；无烧字 |
| 去背 | `transparent-image-generator` | 真 alpha 门 |

Grok Imagine：有额度时做出镜/动作连贯。  
本地 GPT/Cliprox：批量静帧、透明校验、与现有 `jttw-*` 对齐。Cliprox 仅环境变量，不写密钥。

## 验收门（Pass/Fail）

- [ ] 真 alpha（四角透明）  
- [ ] 尺寸与 manifest 一致  
- [ ] 四向并排不换脸、持物同一侧  
- [ ] 动画末帧接首帧、脚底锚点固定  
- [ ] 32px / 远距仍可辨认词牌和道具  
- [ ] 未修缺陷写入 FLAG，不得称过门  

## 不建这些目录

`3d/`、`four-view/model/`、GLB、turntable。方案阶段不要加载 `img2threejs`。
