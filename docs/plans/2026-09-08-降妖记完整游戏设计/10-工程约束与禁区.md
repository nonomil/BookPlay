# 10 工程约束与禁区

## 引擎文件（不要新开页面）

| 文件 | 职责 |
|---|---|
| `prj/engine/game.html/css` | 大地图壳、HUD、摇杆、对话层 |
| `prj/engine/game.js` | DOM 网关 |
| `prj/engine/game-core.js` | 纯逻辑：运动、道具、门控、血条 |
| `prj/engine/game-input.js` | 单一 pointer、失焦清理 |
| `prj/engine/game-audio.js` | 静态语音 |
| `prj/engine/battle.html/js` + `battle-core.js` | Boss |
| `prj/engine/lesson.js` | 巩固后邀请 |
| `prj/engine/map.js` | 绘本「打怪」入口 |
| `prj/engine/tv-remote.js` | 电视 |

脚本顺序由合同测试锁定。漏文件 = 白屏或静默缺逻辑。

手感先改 `game-core.js` 常量/纯函数，再改 DOM。

## 存储

游戏只许：

- `bookplay_battle_progress_v1`  
- `bookplay_battle_collection_v1`  

学习/音频自己的键（`bookplay_lesson_*`、`bookplay_adv_*` 等）独立存在，**不得**因为「两键」去删或迁移。

手册曾写「道具次数不落盘」；代码目前会写 `mapItems`。实施时二选一并改测试，不得两套口径并存：

- 推荐：运行中的 buff 计时不落盘；托盘数量可随 progress 走（同一键的字段，不是新 key）。

## Git

- `content/game/` 是 `git add -f` 的手写源，勿删勿移。  
- `data/`、媒体、APK、zip 默认不跟踪。  
- 当前工作区约 **70 处未提交修改**：新改动只碰本计划列出的文件，不还原别人的 diff。

## 测试基线

全仓 `npm.cmd test`：**至少 408 pass**，只增不减。  
定向 JS/Python 套件有重叠，不要把 60+37+21 加到 408 上。

## 禁区

- 覆盖未提交的无关修改  
- 大地图快卡、每集新引擎、强制打字主线  
- 恢复立即居中跟随  
- 绕过三白名单  
- 新增游戏存储键  
- 把契约测试/浏览器样板写成真机通过  
- 自动派发 ZCode（除非用户点名）  
- 加载 img2threejs 当本任务依赖  

## 设备证据等级

| 等级 | 能证明 | 不能证明 |
|---|---|---|
| Node 测试 | 纯函数、页面合同 | 手感、解码、遥控 |
| 1280×720 浏览器 | 镜头/捡投样板 | 触屏 pointer、WebView |
| 真机 APK | 手感、双指、断网语音 | — |

无 ADB 设备时只做浏览器，并明确写「待验」。
