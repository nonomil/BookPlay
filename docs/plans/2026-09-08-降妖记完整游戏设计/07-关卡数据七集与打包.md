## 关卡 JSON 最低字段

由 `prj/tools/build_game_levels.py` 从 `dialogue_stories` + `content/game/{cast,maps,taunts,sprites}.json` 派生。

必须有：`cast`、`intro`×2、`previewWords`、`waves`、`boss.hpWords`、`map`（`worldTiles:4`、`coordinateSpace: world-normalized`、regions、walkable、heroSpawn、waveSpawns、orbSpawns、npcSpots、bossSpot）。

手写增强（目前仅 ep1/ep5）：`npcDialogue`、`content/game/audio/epN.json`、`content/game/dialogues/epN.json`。

## maps.json 消费方式

**运行时不 fetch `maps.json`。** 生成时 `build_map_layer` 烘焙进 level。  
改点位 → 跑生成器 → 关卡 JSON 变更进 git（`content/game/` 手写源与产物按仓库现有策略）。  
实施时的「点位真实消费」是指游戏读 level 里的 map 字段，而不是运行时再读一份 maps.json。

## 词量

每集约 12 个预习词：地图两波约 8 + Boss 约 4。不要做成 50 词会话。

## 三白名单（漏了 = 真机静默缺文件）

1. 阶段包 `pack_datapack.py` 的 `COMMON_FILES`  
2. APK 内置数据闭包（jttw-only 仅 ep1）  
3. APK 引擎 `pack_android.py` 的 `ENGINE_FILES`  

`prepare-mobile.mjs` 拷全目录不算数。最终以白名单和 APK 内 `assets/public/engine` 为准。

新增引擎文件必须同步：`game-core.js`、`game-input.js`、`game-audio.js` 等。
