# 13 本集素材同源

> 游戏不是另开词表、另编剧情。孩子刚在绘本/巩固里见过的句子和词，才进大地图。

## 原则

学的词 = 考的词 = 玩的词。NPC 说的话必须能在本集字幕或剧情节点里对上原文。

| 游戏里出现的 | 必须来自 | 禁止 |
|---|---|---|
| 词球 / 小怪词牌 / Boss 词 | 本集 `dialogue_stories.official_words`（不足才用节点 `page_words`）；IPA 优先精读 `intensive-reader.json` | 编一套游戏专用词 |
| 开场 NPC 2 句 | 本集 `dialogue_stories.nodes[].text_en/text_zh`（即字幕/台词） | 新编旁白 |
| 小 Boss 开场句 | 同上，带 `sourceNodeId` | 只用通用 `taunts.json` 当唯一台词 |
| 小 Boss 题目 | 本集 `lesson.json` 官方测验 `sentence_choice`；没有题才退回本集词义三选一 | 脱离本集的常识题 |
| 语音 | 该句 `audioRef` / 节点 `audio_start`；词音频复用已有索引 | 均分视频冒充原声 |

## 证据字段

NPC 每句至少：

- `sourceNodeId`：对上 `nodes[].node_id`
- `textEn` / `textZh`：与该节点原文一致（允许空白折叠）
- `audioRef` 或 `audioStart/audioEnd`

测验题额外：

- `lessonCardId`：对上 `lesson_guides/epNNN/lesson.json` 的 `card_id`
- `options[].id` 与官方 `payload.answer` 一致

## 生成顺序

1. 手写 `content/game/dialogues/epN.json` 若存在且通过同源校验 → 采用（ep1/ep5 样板）。  
2. 否则由 `build_game_levels.py` 从字幕节点 + 官方测验卡派生。  
3. 通用嘲讽库只作 **Boss 战斗气泡**，不再当小 Boss 唯一剧情。

## 验收

c01 ep1–ep7 重建后：

- 每个 `previewWords.term` 能在本集 official_words 或精读 vocab 里找到。  
- 每个 intro / quiz 对白能在 nodes 里找到同句。  
- 有官方测验的集，quiz NPC 使用该集第一道 `sentence_choice`。
