# 01 剧情总纲与三幕结构

## 学习目标（不可动摇）

每个剧情节拍必须绑定 1-2 个复习词；台词中英对照；三幕 = 三次提取练习（辨认→配对→运用）。

## 三幕结构（每集通用，数据驱动）

```jsonc
// content/game/story/ep{N}.json 骨架
{
  "ep": 5,
  "title": { "zh": "三借芭蕉扇", "en": "Three Visits to the Palm-Leaf Fan" },
  "acts": [
    { "act": 1, "scene": "flame-mountain-foot",
      "beats": [
        { "speaker": "narrator", "textEn": "The flames ahead will not die.", "textZh": "前方火焰不熄。", "reviewWords": ["flame"] },
        { "speaker": "wukong", "textEn": "I will borrow the fan!", "textZh": "俺要借扇！", "reviewWords": ["borrow"] }
      ],
      "station": "orb-battle", "words": ["flame", "borrow"] },
    { "act": 2, "station": "npc-quiz", "words": ["fan", "promise"] },
    { "act": 3, "station": "boss", "words": ["wave", "cool"] }
  ]
}
```

## 台词基调

- 悟空：自信莽撞、爱用"俺"；八戒：吃货+懒但关键时刻靠谱；唐僧：温和坚定；NPC 妖怪：各自性格（见 taunts.json 已有人设）。
- 英文难度：小学级词汇+本集复习词；句长 ≤ 10 词。
- 中文：口语化，不翻译腔。

## 与玩法的绑定

- act1 → 大地图词球战斗（复习词=怪头顶词）
- act2 → NPC 问答（复习词=选择题干）
- act3 → Boss（错词优先出题）
- 剧情推进奖励：每幕完成解锁下幕；全通=本集图鉴点亮
