# 02 词球战斗反馈设计（G2 合同基础）

## 目标

命中/失误/连击的**反馈演出**从 game.js 主流程剥离为独立事件消费器 `game-feedback.js`（pet-battle 事件日志模式的游戏版），让 game.js 只发事件、反馈层做全部演出。

## 事件契约（game.js 发出）

```js
window.dispatchEvent(new CustomEvent("game-fx", { detail: {
  kind: "hit" | "miss" | "combo" | "pickup" | "levelup" | "hero-hurt",
  x, y,            // 世界坐标
  term, zh,        // 学习词
  combo            // 当前连击
}}));
```

## 反馈清单（Grok 实现范围）

| 事件 | 演出 |
|---|---|
| hit | 词球爆裂粒子 + 「term · zh」浮字 + 音调随 combo 上升（C→E→G）|
| miss | 「?」灰浮字 + 短促低音 |
| combo(3) | 全屏金色扫光 + "好！连击×3" |
| hero-hurt | 屏幕边缘红晕 300ms |
| pickup | 词球飞向 HUD 的弧线 |
| levelup/进化 | 复用 dex 仪式闪光 |

## 约束

- 只监听 `game-fx` 事件 + 只 append 到 `#game-particles`，**零耦合**（game.js 删掉此文件游戏照常运行，只是没演出）。
- `prefers-reduced-motion` 全降级；粒子上限 40（性能护栏）。
- CSS 内嵌于 JS 注入的 `<style>`（避免动 game.css）。
