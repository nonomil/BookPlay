# 03 玩法系统架构：星露谷层 × 宝可梦层 × 学习层

## 1. 全景循环（一个"游戏日"）

```
晨（进入大世界）
  ├─ 今日体力 = review-queue 到期词数（映射为体力条，最多 10）
  ├─ 词田浇水（每株=1 词复习题，答对生长）        [提取练习①]
  ├─ 采集/探索（地图找词怪，捡词球打怪）           [提取练习②]
  └─ NPC 对话答题（好感+）                        [提取练习③]
午（Boss/捕捉）
  ├─ 体力足够 → 挑战本集 Boss（combat-core v2 回合制）
  └─ 打残野生妖怪 → 投放词球捕捉 → 答对捕捉题      [提取练习④]
晚（结算）
  ├─ 收获入图鉴（新怪/进化提醒）→ 词卡入收藏
  ├─ 错词自动入 review-queue（明天的体力预算）
  └─ 存档 → 明天再来（日循环钩子：日切时词田生长/好感结算）
```

## 2. 宝可梦层（P1）

### 2.1 图鉴（collection-core）
- `dex.json`（辑→妖怪条目，schema 见 02 文档）+ 玩家侧 `bookplay_dex_v1`：`{ [dexId]: { seen, caught, stars, wordMastery } }`
- 解锁链：词进 mastered（既有 episode-reward/mastered_terms 流）→ 对应妖怪"可捕捉"→ 捕捉成功入图鉴。
- 图鉴页 `dex.html?series=jttw`：网格卡（未解锁剪影），点卡看词/属性/栖息地/进化进度。

### 2.2 回合制对战（combat-core v2，battle.html 换引擎不换 UI）
- 回合 = 玩家选招式 → 结算 → Boss 行动（效用 AI）→ 事件日志 → UI 按事件动画（pet-battle 模式，侦察结论直接落地）。
- **招式 = 题型**（复用 lesson-core 题型库注册）：
  | 招式 | 题型 | 效果 |
  |---|---|---|
  | 音波功 | listen-choice（听音选图/选词） | 普攻 ×1 |
  | 火眼金睛 | meaning-choice（看词选义） | ×1.2 |
  | 照妖镜 | context-fill（句中填词） | ×1.5 |
  | 筋斗云 | shadow（跟读） | ×1.3 + 恢复 |
- **属性克制 = 词类/主题**：`content/game/elements.json`（water>fire>forest>water …克制系数 1.3/0.75）；出题时按出战怪属性偏置词表——**选怪出战本身就是分类复习**。
- **捕捉**：野生怪 HP<30% 时可用词球 → 答对 catchQuiz.count 题 → 概率=剩余 HP 反比 + 词掌握度加成 → 入图鉴。
- **经验/升级**：对战答对 = 怪经验+；进化 = dex.json 的 evolution 阈值（requireWords/requireStars）→ 提示"可进化"→ 生成的新形态 sheet 自动经注册表接入。

### 2.3 与 v1 答题制的关系
v1（血条=词数选词球）保留为**野生小怪快速战**；v2 回合制用于 **Boss 与图鉴妖怪**。两套共用 judgeHit/错词落库。

## 3. 星露谷层（P2）

### 3.1 日循环与体力（schedule-core）
- 日状态：`{ day, energy, energyMax, actionsToday }` 写 `bookplay_farm_v1`（新键）。
- **体力 = 复习预算**：`energyMax = min(10, reviewQueue 到期数 + 4)`；每场战斗/每块田/每次捕捉耗体力 → 孩子天然在"今天复习多少"上做选择。
- 日切换：本地日期变更 → 词田生长结算、好感+（连续到访）、体力重置。

### 3.2 词田与经济（economy-core）
- 词田 6 格（stage 上划区）：种 = 从"预学词"选一词播种；浇水 = 答 1 题（释义/听音）；成熟收获 = 词卡 + 金币；枯萎 = 该词进错词队列（枯萎是温和反馈，非惩罚）。
- 商店：金币买词球/蟠桃/种子；物价全在 economy.json。
- 金币来源：战斗胜利/收获/图鉴里程碑。

### 3.3 NPC 好感
- 每日对话答题 → 好感+1；连续到访加成；好感档位解锁新台词（taunts.json 分档）——坚持即社交回报。

## 4. 学习层贯穿规则（不可妥协）

- 所有"获得"（金币/捕捉/收获/好感）的**前置都是一次提取练习**。
- 错词四遍闭环不变（找词辨认→投掷确认→Boss 反向→quiz），v2 对战把第三遍升级为策略化。
- 每局时长仍 3-5 分钟/日循环；`prefers-reduced-motion`、64px 命中、TV D-pad 合同继续有效。
