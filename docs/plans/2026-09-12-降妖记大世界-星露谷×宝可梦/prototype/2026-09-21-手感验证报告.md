## 〇、二轮重构：从"三种模式"到"一个世界"（用户反馈驱动）

用户反馈：星露谷的核心是**角色在地图中移动、走到节点才触发玩法**，页签把原型割成了三种模式。二轮重构为：

## 二、验证过的参数（直接写进任务书）

### 战斗（T01/T02）
- `BASE_DAMAGE=10`，招式威力 1.0–1.5，敌人 HP 46 / 我方 40 → 克制局 3 回合、中性局 4 回合，节奏合适（儿童注意力窗口内）
- 倍率显示三条通道全验证：绿 `克制!`（>1.05）/ 灰 `被克…`（<0.95）/ 黄普通；飘字 -17 可读性好
- 连击加成实测：×1.69 → ×2.15（1.5×1.3×1.1）→ 火眼金睛终结 ×1.87，连击 step=0.1 手感成立
- 能量（上限 6，每回合回 1）+ 冷却（0/1/2 回انه档）循环成立：保底招 sonic-wave 零费零冷却保证任何回合可出招
- 敌方 AI（期望伤害评分 + 残血击杀加成 + 吸血权重）表现合理：会吸血回 5

### 词田（T04）
- `growDays=2`（浇 2 次成熟）+ 每日限浇 1 次 → 形成"每天回来浇"的星露谷节律；重复浇水给 toast 提示即可
- 收益 `wordCard×1 + gold×4` 验证入账正确（HUD 飞字 +1🎴 +4🪙）
- 成熟作物显示**词的真配图**（adv_frames）+ 金框发光 + 词条 ✓ 徽记，"真图地块"效果达成
- 加速时钟原型用 24s=1 天；正式版接 schedule-core 现实日历

### 图鉴（T03）
- 卡框图 `content/assets/game-cards/frame-{bronze,silver,gold,jade}.png` 直接叠在卡片上（absolute + pointer-events:none）可用
- 详情卡 = 玉框 + 五行环 SVG（我→绿圈克制目标，标注 ×1.3）+ 进化路线一行字
- 剪影用 `filter: brightness(0) contrast(0) opacity(.5)` + ❓ 角标，成本极低效果足

## 三、坑与修复记录（正式实现时避开）

1. **farm-core API 接收 `{plots:[...]}` 状态对象**，不是裸数组（`createPlots` 返回数组需自己包一层）。
2. **敌回合后必须先 `busy=false` 再渲染按钮**，否则按钮按禁用态渲染且无人再刷 → 战斗永久卡死（原型已修）。
3. 结算动画期间 `state.battle` 会被置空：外部观察者需先存 battle 引用再读 `result()`。
4. dex 小妖立绘在 `assets/game-sprites/<id>/<id>-south-idle.png`（不是 jttw-player-walkers；那是主角/剧情人物）。
5. **后台标签 rAF 冻结**：主循环需 watchdog interval 兜底（>320ms 停摆就手动 step），与主游戏 game.js 同款方案；前台 rAF 主导时 interval 空转。
6. **任务引导用幂等前进式**（questAdvance(n) 只进不退）：线性下一步式（questNext）遇到乱序操作就卡死引导。
