# prompts 使用说明（大世界）

每个 `.md` 自包含，新开对话整段粘贴执行。顺序与依赖：

1. `01-P0整局闭环.md`（吸收 005 T03–T05/T08；先行）
2. `02-图鉴与数据模型.md`（P1-1，可与 01 并行——不同文件域）
3. `03-combat-core-v2.md`（P1-2，依赖 02 schema；**适合 grok-build 委派**）
4. `04-battle换引擎与捕捉.md`（P1-3/6，依赖 03）
5. `05-日循环与词田.md`（P2，依赖 01）

每个任务完成标准统一追加：`npm test` 全量不低于现场基线只增不减 + 复利检查（00-总览 §2）+ 更新 00-总览状态表。数据/资产任务另跑 `prj/tools/check_game_assets.py`（P1-1 落地后可用）。
