# TV 大屏与双 APK 实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 在保持手机版操作习惯的前提下，增加横屏 TV 十英尺界面，并输出可区分安装的 mobile 与 tv 两个 APK。

**架构：** 网页层继续共用同一套 HTML/JS，仅新增 `tv.css` 作为大屏覆盖层，并通过媒体查询限定在横屏大屏生效。Android 层新增 `mobile` 与 `tv` product flavor；TV flavor 使用独立 applicationId、横屏与 Leanback 声明，构建脚本把两个 debug APK 复制到 `release/`，不把视频、图片、音频等大资产加入 Git。

**技术栈：** 原生 HTML/CSS/JavaScript、Capacitor 8、Android Gradle Plugin、Node `node:test`、PowerShell/Gradle。

---

### 任务 1：建立 TV 适配行为测试

**文件：**
- 创建：`prj/engine/tv-ui.test.mjs`
- 创建：`prj/tools/test_android_variants.py`

**步骤 1：编写失败的测试**

覆盖以下行为：所有入口 HTML 引用 `tv.css`；TV CSS 在横屏大屏媒体查询内提供至少 64px 的可操作控件、3px 以上焦点环和安全边距；Gradle 含 `mobile`/`tv` flavor，TV Manifest 含 Leanback、非必需触摸屏和横屏；构建脚本声明两个 APK 产物。

**步骤 2：运行测试以验证它失败**

运行：`node --test prj/engine/tv-ui.test.mjs` 与 `python -m pytest -q prj/tools/test_android_variants.py`

预期：失败，提示 `tv.css`、flavor 或 TV Manifest 尚不存在。

### 任务 2：实现共享 TV 样式和焦点导航

**文件：**
- 创建：`prj/engine/tv.css`
- 修改：`prj/engine/*.html`（在现有样式后引用 `tv.css`）

**步骤 1：编写最小实现**

增加 10-foot 横屏媒体查询：内容最大宽度、48–72px 按钮/选项、3px 金色 `:focus-visible` 环、可见焦点阴影、顶部/底部安全区、播放器字幕与测验字号放大；不覆盖窄屏规则。

**步骤 2：运行测试以验证它通过**

运行：`node --test prj/engine/tv-ui.test.mjs`

预期：TV HTML/CSS 行为测试全部通过。

**步骤 3：提交**

```bash
git add prj/engine/tv.css prj/engine/*.html prj/engine/tv-ui.test.mjs
git commit -m "feat: add shared ten-foot TV interface styles"
```

### 任务 3：增加 Android mobile/tv product flavor

**文件：**
- 修改：`android/app/build.gradle`
- 修改：`android/app/src/main/AndroidManifest.xml`
- 创建：`android/app/src/tv/AndroidManifest.xml`
- 创建：`android/app/src/tv/res/values/strings.xml`
- 修改：`android/app/src/main/res/values/strings.xml`（如需区分默认名称）

**步骤 1：编写最小实现**

在 `productFlavors` 中定义 `mobile`（`com.nonomil.storyhall.mobile`）和 `tv`（`com.nonomil.storyhall.tv`）；TV Manifest 仅增加 `LEANBACK_LAUNCHER`、`android.software.leanback`、`android.hardware.touchscreen` required=false 与 landscape，复用主 Manifest 的 Activity/Provider。

**步骤 2：运行测试以验证它通过**

运行：`python -m pytest -q prj/tools/test_android_variants.py`

预期：Gradle flavor、包名和 TV 声明检查通过。

### 任务 4：构建并命名两个 APK

**文件：**
- 修改：`package.json`
- 修改：`打包APK.bat`
- 创建：`scripts/build-apks.mjs`

**步骤 1：编写最小实现**

让 `android:build` 先同步网页，再执行 `assembleMobileDebug assembleTvDebug`，将 APK 复制为 `release/storyhall-mobile-debug.apk` 与 `release/storyhall-tv-debug.apk`；构建过程不复制媒体进 APK。

**步骤 2：运行测试以验证它通过**

运行：`npm run android:build`；随后用 `aapt dump badging`（或 `apkanalyzer`）检查两个 APK 的包名、横屏/Leanback 声明和文件存在。

预期：两个命令退出码为 0，`release/` 下有两个独立 APK。
