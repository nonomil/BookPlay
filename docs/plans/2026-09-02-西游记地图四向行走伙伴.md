# 西游记地图四向行走伙伴实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 为西游记地图路线伙伴提供四向行走动画，并让小人根据折线路径的移动方向沿节点自然行走。

**架构：** 保留现有东西向 8 帧作为基础，补充南/北向 8 帧并镜像得到西向，合并成四行八列透明精灵图集。地图根据相邻路线节点的位移选择 east/south/west/north 行，继续用 CSS 位移过渡让伙伴沿 S 形折线移动。

**技术栈：** Cliprox gpt-image-2 生图、Pillow/透明去背、原生 JavaScript、CSS sprite animation、Node test。

---

### 任务 1：四向动画资产

**文件：**
- 创建：`assets/generated/jttw-route-companion/2d/wukong-walk-atlas.png`
- 创建：`content/assets/generated/jttw-route-companion/transparent/wukong-walk-atlas.png`
- 修改：`assets/generated/jttw-route-companion/manifest.json`

生成南向和北向 8 帧，复用现有东向并镜像为西向，统一 384×512 单元、脚底基线和真实 alpha，按 east/south/west/north 叠成 3072×2048 图集。

### 任务 2：方向与路径运动

**文件：**
- 修改：`prj/engine/map.js`
- 修改：`prj/engine/map.css`

根据上一个位置和当前节点位置选择方向，设置图集行；保持已有节点间 left/top transition，使小人沿每段折线运动。无位移时保留上次方向，减少布局重排造成的闪变。

### 任务 3：回归测试与版本

**文件：**
- 修改：`prj/engine/map-ui.test.mjs`

断言四向图集、行定位、方向逻辑、动画与 reduced-motion 行为，递增 map CSS/JS 缓存版本。

### 任务 4：交付验证

运行 `node --check prj/engine/map.js`、资产尺寸/alpha 校验和 `node --test prj/engine/map-ui.test.mjs prj/engine/map-optimization.test.mjs`，并在浏览器确认地图加载图集及节点移动方向。
