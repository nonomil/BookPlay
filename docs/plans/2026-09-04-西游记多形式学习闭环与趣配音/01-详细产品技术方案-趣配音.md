# 趣配音（西游记）详细产品技术方案

> 上游：[00-总览.md](00-总览.md)。本文件只展开 P0 趣配音的产品流程、数据合同、技术设计与回退策略。

## 1. 产品设计

### 1.1 一句话

孩子逐句给西游记视频"配音"：看台词提示 → 录下自己的声音 → 立刻回放"自己的声音配着画面" → 一集配完进放映厅，用自己的声音连看本集。

### 1.2 家长提示（照抄参考材料的"别焦虑"）

- 不追求发音完美，**发声就是胜利**；害羞不肯说的孩子，家长先配一句示范。
- 语速跟不上的孩子：先"听原声"两遍再录；或家长陪着一起说。
- 录完必须**陪孩子回放听一遍并鼓掌**——孩子听到自己的英语声音会很开心。
- 沉默期孩子可以只配感叹词/短句（我们按句提供，天然支持）。

### 1.3 页面流程（dub.html?ep=N[&node=nXXX]）

```
选场景列表（台词本） ──逐句工坊──▶ 听原声 → 录音 → 听我的 → ⭐评分 → 保存/重录
        │
        └──放映厅（我的声音看本集）：逐场景播放 视频切片(原声压低) + 孩子配音；未配回退原声
```

逐句工坊每个场景的交互合同：

| 控件 | 行为 |
|---|---|
| 台词卡 | speaker + text_en（大字）+ text_zh（小字）+ 插图缩略 |
| ▶ 听原声 | 播放本场景原始音频切片（`audio_start..audio_end`），可连播为示范 |
| ⏺ 录音 | 按下开始（显示录音计时/音量点），再按停止；录制中可选"画面伴录"（视频切片静音播放，孩子对着画面配）或干录 |
| ▶ 听我的 | 回放孩子录音；回放模式 = 视频切片 `volume=0.15` + 录音全量（卡拉OK压声） |
| ⭐ | 1-3 星自评/家长评，存元数据 |
| 保存/重录/删除 | 保存写 IndexedDB + 元数据；重录/删除覆盖；已配场景列表打 ⭐ 徽标 |

放映厅：顺序遍历本集可配音场景；有配音 → `video.muted` 不做、`video.volume=0.15` + 播放配音 Blob；无配音 → 原声正常播切片。支持暂停/继续/退出，结束给礼花 + SP。

### 1.4 奖励挂钩（幂等）

- 每集**首次**保存 ≥1 段配音 → `+5 SP`，标记 `bookplay_dub_reward_v1[ep]=true`，重复保存/重录不再发。
- 配完本集全部可配场景 → 放映厅结尾礼花提示"本集配音完成"（不重复发 SP）。
- 不动勋章/贴纸/房间掉落逻辑。

### 1.5 入口

1. 地图 jttw 集节点：磨耳朵 🎧 旁加 `🎙 配音`（同 `node-listen` 样式）→ `dub.html?ep=N`。
2. wala 播放器场景工具条：`🎙 配一句` → `dub.html?ep=N&node=<当前node_id>`（深链直达该句）。
3. 电视版/无麦克风：录音按钮隐藏，仅显示"已配音 N 句/放映厅"（若本地已有），不报错。

## 2. 数据合同

| 合同 | 位置 | 结构 |
|---|---|---|
| 元数据索引 | localStorage `bookplay_dub_v1` | `{ [ep]: { [nodeId]: { stars, durSec, createdAt, updatedAt } } }` |
| 音频 Blob | IndexedDB `bookplay_dub_audio_v1` / store `clips` / key `ep{ep}:{nodeId}` | `{ key, ep, nodeId, blob, mime, createdAt }` |
| 奖励幂等 | localStorage `bookplay_dub_reward_v1` | `{ [ep]: true }` |
| 场景来源 | `../data/dialogue_stories/ep{N}.json`（只读） | `nodes[]`: `node_id/speaker/text_en/text_zh/illustration/audio_start/audio_end` |

- 可配音场景 = `text_en` 非空且 `audio_start/audio_end` 存在的节点（`dub-core` 判定，TV/旧数据自动降级）。
- 单段录音时长上限：切片时长 +10s，封顶 90s；超限自动停止并保留已录内容。
- 配额：`QuotaExceededError` → 提示删除最旧配音（不自动删）。

## 3. 技术设计

### 3.1 模块拆分（零依赖 IIFE + node:test）

| 文件 | 职责 | 可测性 |
|---|---|---|
| `dub-core.js` | 纯逻辑：`buildSceneList(nodes)`、`DubSession` 状态机（idle→recording→recorded→saved，时长上限/重复启动守卫）、`normalizeDubMeta`、`rewardOnce` 幂等、`dubKey` | 纯 Node |
| `dub-store.js` | `WalaDubStore.create({indexedDB})`：IDB promise 包装 `putClip/getClip/deleteClip/count`；IDB 不可用 → 内存回退 + `available=false`（UI 提示不落盘）；永不抛未捕获异常 | 注入假 IDB |
| `dub-recorder.js` | `WalaDubRecorder.create({env})`：能力探测（`getUserMedia`+`MediaRecorder`）、mime 选择（webm;opus→webm→mp4）、start/stop→Blob、tracks 释放、稳定错误类型（`no-mic/not-allowed/busy`） | 注入假 env |
| `dub.html/css/js` | 工坊 + 放映厅 UI；只装配上述三个模块 + `media.js` 切片播放 | 静态合同测试 |

### 3.2 播放器集成点

- `map.js`：`SERIES_ID==="jttw"` 节点追加 `<a class="node-dub">🎙 配音</a>`，与 `node-listen` 同构（`map.js:1036` 附近）。
- `wala.js`：播放器工具条加一个深链按钮（读 `book.nodes[idx].node_id` 拼 URL）；不改播放序列/存储合同。
- 回放混音不侵入 `media.js`：放映厅自带 video + audio 元素自行控制 `volume`，避免污染主播放器。

### 3.3 回退策略

| 情形 | 行为 |
|---|---|
| 无 getUserMedia / MediaRecorder（电视版、旧 WebView） | 能力探测失败 → 隐藏录音 UI，页面显示"本设备不支持配音"，放映厅仍可看历史配音 |
| 拒绝权限 | 稳定提示 + "去设置开麦克风"引导文案，不阻塞浏览台词 |
| IndexedDB 不可用 | 内存会话可用（本次可听），顶部提示"仅本次有效"；不写 localStorage 元数据 |
| 录音时长超限 | 自动停，保留已录，提示"这一句到这里啦" |
| 视频缺失（`book.video` 空） | 回放退化为插图 + 音轨（图片背景 + 配音/原声），功能完整 |

### 3.4 P2/P3 预告（不实现）

- Android X5 老内核：vendor [recorder-core](https://github.com/xiangyuecn/Recorder) 输出 mp3 兜底。
- "背景不变"增强：Demucs 离线批量生成每集伴奏轨 `assets/dub_bgm/ep{N}.mp3`，放映厅切换"纯伴奏模式"（CPU 成本见总览调研，需离线批处理脚本）。
- 发音评测：录音接 ISE/OEN 网关（`voice.js` 已留 `voiceStt` 参数位）。
