# 任务 03 · 配音工坊页面（dub.html/css/js）

**目标：** 逐句录音工坊 + "我的声音看本集"放映厅。URL：`dub.html?ep=N[&node=nXXX]`。

**文件：**
- 创建：`prj/engine/dub.html`、`prj/engine/dub.js`、`prj/engine/dub.css`
- 创建：`prj/engine/dub-page.test.mjs`（静态合同）

**页面结构：**
1. 头部：返回（history.back → 无来源回 `wala.html?ep=N`）、集标题、已配 x/y、SP 徽标。
2. 场景列表（台词本）：序号、speaker、text_en、text_zh、插图缩略、已配 ⭐ 徽标；点击进入该句。
3. 逐句工坊：台词卡（大字 en + 小字 zh + 插图）；按钮 `▶听原声`（audio 切片 `../{book.audio}` from..to，复用 `media.js` 的切片思路）、`⏺录音/停止`、`▶听我的`（video.volume=0.15 + 配音 Blob）、`⭐1-3`、`保存/重录/删除`；录制中显示计时与"画面伴录"开关（视频静音播放对画面配）。
4. 放映厅（`?theater=1` 或工坊内按钮）：顺序遍历场景；有配音 → video.volume=0.15+孩子声；无 → 原声；暂停/继续/退出/进度点；结尾礼花 + "本集配音完成"。
5. 回退：无麦克风隐藏录音按钮并提示；IndexedDB 不可用显示"仅本次有效"。

**静态合同测试断言：**
- dub.html 依序引入 `dub-core.js`、`dub-store.js`、`dub-recorder.js`、`media.js`、`dub.js`（带版本参数）。
- 存在录音/听原声/听我的/放映厅入口与 `aria-live` 状态区；录音按钮初始 `hidden` 由能力探测解锁。
- dub.js 不出现 `eval/new Function`；存储仅经 `bookplay_dub_v1`/`bookplay_dub_reward_v1`/IDB `bookplay_dub_audio_v1`。

**验收：**
- `node --test prj/engine/dub-page.test.mjs`、`node --check prj/engine/dub.js` 通过。
- 浏览器手工链路：加载 ep1 → 录一句 → 回放 → 保存 → 列表打星 → 放映厅连播（Chrome/Edge 桌面先行）。
