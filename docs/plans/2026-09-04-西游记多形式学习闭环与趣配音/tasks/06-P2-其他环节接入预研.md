# 任务 06 · P2 其他环节接入预研（已升级为正式计划，见新文件夹）

> **本任务已由 `docs/plans/2026-09-04-西游记多形式学习闭环P2/` 接管**：该文件夹含 01-听音识景、02-亲子互动卡、03-词卡跟读、04-熏听清单与睡前模式、05-技术支撑的详细方案与 `prompts/` 自包含执行提示词。以下保留原始预研要点供追溯。

> 依据 [00-总览](../00-总览.md) 分析矩阵排序，按性价比依次：

1. **听音识景（对应"听音识图"，低幼最推荐）**：播放一句原声，从本集 3-4 张场景插图中选对应画面；`dialogue_stories` 的 `illustration` + `audio_start/end` 零新资产即可出题；挂 lesson 题型（`listen_picture_choice`）。
2. **亲子互动卡**：用 `patterns`（句型+term+zh）与 `text_en/text_zh` 自动生成"家长中文问、孩子指图/口答"卡片；家长面板入口 + 可打印。
3. **词卡跟读**：把 `voice.js` 跟读挂到 wala 词卡（现在只在巩固页）；复用 `voice-core` 判定，不落盘不变。
4. **熏听增强**：磨耳朵多集连播清单（睡前模式）+ 累计熏听时长统计（参考材料建议假期 1-2h/天）。
5. **recorder-core 兼容回退**：老安卓 X5 vendor [recorder-core](https://github.com/xiangyuecn/Recorder)（mp3 输出）替换 MediaRecorder 失败分支。
6. **Demucs 伴奏轨**（P3）：离线批量 `assets/dub_bgm/ep{N}.mp3`，放映厅"纯伴奏模式"，实现"背景音乐不变、旁白换成孩子"。CPU 成本 5-15min/首量级，需批处理脚本与质量抽检。
7. **不接入**：儿歌拓展（西游记无配套儿歌内容）；发音评分接 ISE/OEN 归语音评测线另行立项。
