# 任务 01 · 趣配音核心模块（dub-core）

**目标：** 无 DOM 的纯逻辑模块：从 `dialogue_stories` 节点构建可配音场景目录、录音会话状态机、元数据与奖励幂等。

**文件：**
- 创建：`prj/engine/dub-core.js`
- 创建：`prj/engine/dub-core.test.mjs`

**合同：**

```js
WalaDubCore.dubKey(ep, nodeId)                      // "ep1:n001"
WalaDubCore.buildSceneList(book)                    // [{nodeId,speaker,textEn,textZh,illustration,from,to}]，过滤无台词/无切片节点
WalaDubCore.createDubSession({ maxSec })            // 状态机 idle→recording→recorded(+saved)
//   start() 守卫重复启动；stop(elapsedSec) 校验 0.5s..maxSec；cancel() 回 idle
WalaDubCore.normalizeDubMeta(raw)                   // {stars 1-3, durSec>0, createdAt/updatedAt}
WalaDubCore.upsertDubMeta(index, ep, nodeId, meta)  // 写入并返回新索引（不可变更新）
WalaDubCore.firstSaveReward(index, rewarded)        // 每集首次有配音 → {sp:5}，幂等
WalaDubCore.dubCoverage(index, ep, scenes)          // {done,total,complete}
```

**步骤：**
1. 先写失败测试：场景过滤（缺 text_en / 缺 audio_start 的节点被剔除；narration/对白都保留）、状态机非法迁移、时长上下限、元数据归一化（星级钳制 1-3、负时长拒绝）、幂等奖励（第二次不发）、覆盖统计。
2. `node --test prj/engine/dub-core.test.mjs` 确认失败 → 最小实现 → 通过。

**验收：**
- `node --test prj/engine/dub-core.test.mjs` 全绿；`node --check prj/engine/dub-core.js` 通过。
