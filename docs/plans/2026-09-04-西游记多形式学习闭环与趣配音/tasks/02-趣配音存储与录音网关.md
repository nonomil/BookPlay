# 任务 02 · 存储与录音网关（dub-store / dub-recorder）

**目标：** 录音 Blob 落 IndexedDB（内存回退）；MediaRecorder 录音网关（能力探测/mime 协商/资源释放/稳定错误）。

**文件：**
- 创建：`prj/engine/dub-store.js`、`prj/engine/dub-store.test.mjs`
- 创建：`prj/engine/dub-recorder.js`、`prj/engine/dub-recorder.test.mjs`

**dub-store 合同：** `WalaDubStore.create({ indexedDB })` →
`{ available, memoryOnly, putClip(key, blob, meta), getClip(key), deleteClip(key), listKeys(ep), estimateCount() }`；IDB 缺失 → `memoryOnly=true` 不抛异常；配额错误归一为 `{ ok:false, reason:"quota" }`。

**dub-recorder 合同：** `WalaDubRecorder.create({ env })` →
`{ capabilities(): {mic, mime}, start(): Promise<{ok, reason?}>, stop(): Promise<{ok, blob, mime, sec}|{ok:false, reason}>, cancel() }`；
mime 依次协商 `audio/webm;codecs=opus → audio/webm → audio/mp4`；stop 后必须停止全部 MediaStream tracks；错误类型固定 `no-mic / not-allowed / busy / unsupported`。

**步骤：**
1. 失败测试：注入假 `indexedDB`（open/transaction/put/get/delete mock）与假 `env`（假 getUserMedia/MediaRecorder/MediaStream）。覆盖：IDB 缺失回退、quota 归一、track 释放、重复 start、无麦克风、拒权、stop 未 start、mime 协商顺序。
2. 实现通过；`node --check` 全部通过。

**验收：**
- `node --test prj/engine/dub-store.test.mjs prj/engine/dub-recorder.test.mjs` 全绿。
- 不引入任何第三方依赖（recorder-core vendor 留给 P2）。
