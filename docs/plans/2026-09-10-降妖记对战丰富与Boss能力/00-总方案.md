# 降妖记：整局方案与落地缺口

原则不变：**一套地图引擎 + 一套对战引擎**；每集只换词、图、Boss 套件。不搬三个参考游戏当三个小游戏。

## 孩子怎么玩（三环）

```
绘本/巩固过关
    → 大地图（word-memory-map）
         捡本集道具球 + 扔英文小怪
         走近 NPC：剧情对话（dialogue-story 交互）
         小 Boss NPC：1 题（优先本集知识巩固官方题）
         清两波 + 答完 NPC → 亮大 Boss 门
    → 大 Boss 对战（battle.html）
         题在上、选项在上、双方血条在下
         答对：我方技能打 Boss
         答错：Boss 技能打我方掉血
         题型轮换：点选 / 听音 / 跟打
    → 结算回地图，发妖怪卡
```

## 对战规则（推荐）

答题就是攻击。不另做「选技能再选答案」的两步操作（小孩会卡）。

- 默认出招：金箍棒（普攻）。连对 3：筋斗云/棒影（必杀档动画）。
- 开打前或回合间隙可点一次 **护体**（抵下一次 Boss 伤害）。
- 答对：扣 Boss 血 + 播本回合我方技能特效。
- 答错 / 跟打超时：Boss 用它的进攻技能，扣我方血；血条见底则本场重开，地图击杀保留。
- 血量：我方 3 心（现有护盾）；Boss = 本场词数（现有 hpWords）。两边都画条，不要只有盾牌 emoji。

### 题型（同一 `battle` 状态机）

| id | 孩子看到 | 来源 |
|----|----------|------|
| `zh-choice` | 大号英文，上方点中文 | 本集词 |
| `en-choice` | 大号中文，上方点英文 | 本集词 / Boss 词 |
| `listen-choice` | 听读音，点中文或图 | 本集词 + TTS/静态音 |
| `typing` | 跟打英文，倒计时条 | `typingStep`，超时=答错 |
| `official` | 巩固官方题（句子选择） | `official_quiz` / lesson card 映射 |

每场 Boss 词格轮换，不要整场一种题。
