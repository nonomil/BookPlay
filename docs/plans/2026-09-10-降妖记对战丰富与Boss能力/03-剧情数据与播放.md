# 剧情数据与播放

参考的是**格式和播放方式**，不是把森林/星港文案搬进西游记。

## 文案在哪

| 用途 | 路径 |
|------|------|
| 探险终端配套节点剧情（宠物积分） | `G:\StudyCode\宠物积分系统\data\story-packs\05-pixel-worlds-story\levels\*.json` |
| 可拷贝的对话引擎 + 章节样例 | `G:\StudyCode\小游戏项目\games\dialogue-story-template\chapters\*.json` |
| 降妖记本集原文（中英节点） | `content/dialogue_stories/epN.json` |
| 手写地图 NPC 脚本（现仅 ep1、ep5） | `content/game/dialogues/epN.json` |
| 运行时已烘焙进关卡 | `content/game/levels/epN.json` → `npcDialogue.intro/quiz` |

探险终端首页本身没有台词；台词在上面的 `levels/*.json`：`scenes[].lines[]`，类型 `narration` / `dialogue` / `choice` / `activity`。

## 降妖记怎么用

- **intro NPC**：2 句本集 `textEn` + `textZh`，带来源 `sourceNodeId` 和 `audioRef`。
- **quiz NPC**：1 句本集原文 + 1 题。题优先 `official_quiz` / lesson card 的 `options`。
- 播放：一句一句；选择题未答完不能翻（已有 `awaitingChoice` 守卫）。
- 旁白行显示「旁白」；选项可带 `feedback`（与 dialogue-story-template 的 `opt.feedback` 同类）。

不要：导入森林脚印/星港台词，不要 80 节点世界 tab。
