# 西游记首页改版：进场背景 → 合辑路线图 → 巩固单元

设计日期：2026-08-30  
参考：瓦拉英语（Unit 地图、知识巩固、单词补全、句型点选）  
当前版本：0.1.5（首页仍是封面 + 108 集网格）

## 1. 目标

把西游记入口从「封面 + 集数网格」改成瓦拉那种闯关地图：

1. 点「西游记」→ 先显示本合辑背景图（约 1.4 秒，可点击跳过）→ 自动落到路线图。
2. 路线图**左右滑动**切换合辑，一屏一辑，路上是本辑各集的关卡圆点。
3. **学完一集才解锁下一集**；没解锁的圆点灰掉、点了不跳转。
4. 集按剧情分成**合辑**（如「大闹天宫」）；**学完一辑（含巩固）才解锁下一辑**。
5. 每辑末尾一个**巩固提高**关卡：把本辑的测验题、生词做成题目，含单词补全、句型点选排序。

### 6.1 map.html 结构

```
#splash        全屏背景图 + 合辑名淡入，1.4s 后淡出（点击立即跳过）
#map-top       返回首页 | 当前合辑名 | SP 积分 | 列表 | 设置
#map-track     横向 scroll-snap 容器，一页一辑
  .map-page    背景图 + 走线 + 圆点
    .node      一集一个圆点（状态：done / current / locked）
    .node.drill 本辑最后一格：巩固提高
#map-hint      「← 左右滑动切换合辑 →」
```

滑动用 CSS `scroll-snap-type: x mandatory`，不引第三方库。触屏原生滑动，桌面加左右箭头按钮。

### 6.2 解锁规则

沿用现有 `localStorage`：

- `bookplay_adv_progress` = `{ "3": { node: 12, total: 74, done: false } }`
- 新增 `bookplay_drill` = `{ "c02": { done: true, words: 11, puzzles: 6, at: 1756... } }`

判定：

```js
epDone(n)        = !!progress[n]?.done
colDone(c)       = 本辑每集都 epDone
drillDone(c)     = !!drill[c.id]?.done
colUnlocked(c)   = c.index === 1 || (colDone(prev) && drillDone(prev))
epUnlocked(n, c) = colUnlocked(c) && (n === c.from || epDone(n - 1))
drillUnlocked(c) = colUnlocked(c) && colDone(c)
```

锁住的圆点：灰底 + 🔒，无 `href`，点击抖动一下并提示「先学完上一集」。  
可以滑到**第一个未解锁的合辑**看背景（整页压暗 + 「学完上一辑解锁」），不能再往后滑。

### 6.3 drill.html 结构（对标参考图）

顶栏 4 个标签，样式照参考图：

```
U12 · 巩固    [知识回顾] [单词 0/12] [句型 0/6] [错题回顾 0/N]    离开
```

1. **知识回顾**：本辑生词卡网格（`term` + `pos` + `zh`），一屏 6–8 张，底部「继续 4S」倒计时按钮。取词优先级：`bookplay_adv_vocab_stat` 里 `wrong > 0` 的 → 本辑 `official_words` 随机补足。
2. **单词补全**：取 `official_words[].example`，把 `term` 挖空成 `_____`，给 3 个选项（正确项 + 本辑同词性/近长度干扰项 2 个）。有喇叭读整句。默认 12 题。
3. **句型排序**：取本辑 `puzzles[]`，打乱的 `words[]` 做成可点按钮，按顺序点出整句，点「确定」判定。默认 6 题。
4. **错题回顾**：本辑范围内 `bookplay_adv_vocab_stat.wrong > 0` 的词，重问词义，答对清掉错次。没有错题就显示「还没有错题，太棒了」。

**剧情测验**（`official_quiz`，本辑约 40–60 题）按现有「学习量」设置取量，避免一次做太多：

| 学习量 | 每集取题 | 一辑约 |
| --- | --- | --- |
| 轻松 | 1 | 8 |
| 标准 | 3 | 24 |
| 加强 | 5（全部） | 40+ |

沿用现有 `bookplay_learn_level`，不新增设置项。

**通过条件**：单词 ≥ 10/12 且 句型 ≥ 5/6 → 写 `bookplay_drill[c.id].done = true`，加 SP，下一辑解锁。未通过可重做，已答对的题不重复出。

## 7. 实施顺序

7. **重打包**：`npm run android:build` → `make_release.py --version 0.1.6 --pack`。
