# 10 流程一套，资产按集换

孩子每一集都走同一条玩法；变的是皮、词、人和场地。

```
选关点「打怪」
  → 大地图三站（开场 → 小妖捡投 → NPC 原题）
  → 擂台（点英文 / 点中文 / 听音 / 跟打或原题）
  → 结算回地图
```

不要为第 N 集复制 `game.js` / `battle.js`。新集只换数据。

## 什么必须一样（流程架构）

| 层 | 复用什么 | 文件 |
|---|---|---|
| 世界门控 | 两波、NPC 开门、Boss 确认 | `game-core.js` |
| 运动捡投 | 走、捡、扔、散开追击 | `game-core.js` + `game.js` |
| 对话 | 一句一句、选项守卫、feedback | `game.js` 对话层 |
| 擂台 | 椭圆台、双方血条、答题出招、护体 | `battle.js` + `battle-core.js` |
| 题型轮换 | en / zh / listen / typing / 最后一格官方题 | `buildBossRound` |
| 存档 | 只有两键 | `bookplay_battle_progress_v1` / `bookplay_battle_collection_v1` |

## 什么按集可以不同（资产与内容）

| 内容 | 数据入口 | 故意复用的粒度 |
|---|---|---|
| 字幕 / intro 两句 | `dialogue_stories/epN.json` | 每集一份 |
| 单词 | 同上 → `previewWords` / waves / hpWords | 每集一份 |
| 官方题 | `lesson_guides/epNNN/lesson.json` | 每集一张 sentence_choice |
| 英雄 | `cast.hero` 默认悟空 | 以后可换 id，走同一套四向槽 |
| 小怪 | `minorsByEp` | 同一 sprite id 多集共用 |
| Boss 名与立绘 | `bossByEp` | 同一 Boss id 多集共用立绘 |
| Boss 技能 | `boss-kits.json[id]` | **按 Boss id**，不是按集复制四招 |
| 地图主题 | `themesByEp` + `maps.json` + `epN.jpg` | 主题布局复用，后集用本集俯视图 |
| 投掷物 | `pickups.json byEp` | 图按集换，捡投规则不换 |
| 嘲讽 | `taunts.json` | 按 Boss 角色 |

同一 Boss 再出现（如混世魔王多集），技能和立绘跟着 id 走，词和字幕仍是本集的。
