# 02 关卡内三站

像素世界点节点 → 播 11 句 + 1 次 activity。  
降妖记点「打怪」→ **同一张大地图上的三站**，HUD 已标：小妖 / 问答 / 大战。

页面：`prj/engine/game.html` + `game.js` + `game-core.js`。

## 三站 = 三遍学习

| 站 | HUD | 孩子做什么 | 像素 activity 的类比 | 不做什么 |
|---|---|---|---|---|
| 小妖 | 第 1 站 | 捡本集中文球，扔头顶英文怪；可持球跟打英文 | `collect`（捡）+ 战斗，不是扫描小游戏 | 不弹中文三选一快卡 |
| 问答 | 第 2 站 | 清完第一波后，走近 quiz NPC：1 句原文 + 1 题 | `activity`/`choice`：点选项看出 feedback | 不扣盾、不 `goto` 换场 |
| 大战 | 第 3 站 | 两波清完且 `npcDone` → 确认进 `battle.html` | 像素包没有 Boss 战 | 不在大地图上打 Boss 血条 |

开场还有 intro NPC（出生点附近，自动 2 句），不算第四玩法，算进图说明书。

## 像素六种 activityType 怎么消化

`levels/*.json` 的 `activityType` 只有六值，每关正好 1 条、2 个无对错按钮：

| activityType | 像素语义 | 降妖记落地 |
|---|---|---|
| `scan` | 观察找线索 | **不建扫描器。** 开场 2 句里用本集画面说明「看见了什么」 |
| `collect` | 收集物件 | 大地图捡本集道具球（已有 `pickups.json`） |
| `route` | 选路/登车 | 走可行走区 + 三站路线 HUD，不另做岔路关 |
| `repair` / `build` / `care` | 修、搭、照料 | **不建。** 需要互动拍时用 quiz 一题 |

禁止按这六个字各写一套 JS。

## 门控（保持 09-08）

```text
intro 可走
  → wave1 未清：quiz 头顶「…」，Boss 不可开战
  → wave1 清完：quiz 可对话
  → npcDone：刷 wave2
  → 小怪清零且 npcDone：Boss 确认卡
```

「走到点上提前跟 quiz 说话」已否决。

## 运动与镜头（保持已改手感）

- 世界：`WORLD_TILES=4`，同一张主题图铺满，不是 9 宫换砖
- 镜头：边缘滚动，不立即居中跟随
- 攻击：停步再挥
- 小怪：追击半径 + 占位散开，不挤成一堆、不随镜头瞬移

常量在 `game-core.js`；先改纯函数再改 DOM。

## 对话层（已按终端条落地）

- 霜玻璃底栏；旁白显示「旁白」
- 一句一句；`awaitingChoice` 未答完不能翻
- 选项可带 `feedback`（对/错各一句）
- 人还在大地图上，不新开剧情页
