# 04 背景与舞台

像素世界：每个 node 一张场景 webp + 一张 icon + 地图大底图。  
降妖记：背景分 **三层**，不要每集再做第四套「星港式场景包」。

美术总契约仍是 09-08 [`08-美术资产契约.md`](../2026-09-08-降妖记完整游戏设计/08-美术资产契约.md)：2D 俯视、真 alpha、禁 3D / img2threejs。

## 三层

```text
① 选关舞台     合辑一张封面，13 辑共用现成图
② 大地图世界   主题俯视图 4×4 平铺（可多集共用一张主题）
③ 对话/词卡插图 本集 adv_frames / 绘本帧，给 NPC 与词卡
```

Boss 战目前叠在战斗页上，用主题图或本集帧，不另开「星港舱内立绘切换」。

## 生产规则

- 新画：一张 canonical → `image_edit` 出变体，禁止每张重 `image_gen`
- 透明 PNG 真 alpha；JPEG 不得改后缀冒充透明
- 命名 kebab-case；输出 `assets/generated/<主题>/`，不覆盖手作
- 选关钉点只有封面先画出路线才值得填；否则继续 S 折线

## 和像素背景字段的关系

| 像素 | 降妖记放哪一层 |
|---|---|
| `worlds[].background` 大地图 webp | ① 合辑封面 |

| `nodes[].background` / `levels.scenes[].background` | ③ 本集帧，或 ② 若该集有独立俯视图 |
| `sceneAssets.props` | 道具球 / 场景装饰精灵，不进口 sf-01.webp |
