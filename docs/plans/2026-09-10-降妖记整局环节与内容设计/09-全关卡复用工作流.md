# 09 全关卡复用工作流

后面每一集都走这一条，不要新开引擎、不要为某一集复制 `game.js` / `battle.js`。

## 一套体系，三层换皮

```
世界  game.html + game-core     走 / 捡 / 扔 / NPC
擂台  battle.html + battle-core 题型轮换 / 血条 / 套件出招
数据  build_game_levels.py      词、官方题、地图点、Boss 皮
```

换集 = 换 JSON 和图片。判定、门控、擂台镜头、题型轮换已经写死在核心里。  
合同细则：[10-流程一套资产按集换](10-流程一套资产按集换.md)。

## 一集从哪来（默认全自动）

| 输入 | 路径 | 谁维护 |
|---|---|---|
| 本集字幕与词 | `content/dialogue_stories/epN.json` | 书线已有 |
| 官方题 | `content/lesson_guides/epNNN/lesson.json` 第一张 `sentence_choice` | 巩固线已有 |
| 角色/主题 | `content/game/cast.json` `bossByEp` / `minorsByEp` / `themesByEp` | 人工分派，多集复用同一 id |
| 地图布局 | `content/game/maps.json` 的 theme | 能复用就不新画 |
| 投掷物 | `content/game/pickups.json` | 按集换图，规则同一套 |
| Boss 技能 | `content/game/boss-kits.json` | **按 Boss id**，不按集复制 |
| 手写对白（可选） | `content/game/dialogues/epN.json` | 仅当要改 2 句 intro / 指定原题；**必须带 options** |

命令：

```
python -X utf8 prj/tools/build_game_levels.py --eps N
python -X utf8 prj/tools/build_game_levels.py --eps N --check
```

现行游戏圈：**ep1–54**。一次刷圈：

```
python -X utf8 prj/tools/build_game_levels.py --eps 1-54
python -X utf8 prj/tools/build_game_levels.py --eps 1-54 --check
```

不要为 c08（ep55+）生成新主题大地图，除非用户点名。

## 跑完必须长这样

`content/game/levels/epN.json` 里：

- `previewWords` ≥ 8，地图两波 + Boss 四词
- `npcDialogue.intro.lines` 2 句，带 `sourceNodeId` / `audioRef`
- `npcDialogue.quiz.options` 且恰好 1 个 `correct`（来自本集官方题）
- `npcDialogue.quiz.lessonCardId`
- `map.theme`（ep8+ 多用 `episode-scene` + `epN.jpg`）

擂台上：词格 1 点英文、2 点中文、3 听音、最后一格若有官方题则出原题。触屏没有键盘时跟打退回点选。

## 新开一集（ep55+ 或补洞）时只做这些

1. 确认 `dialogue_stories/epN.json` 和 `lesson_guides/epNNN/lesson.json` 已有  
2. `cast.json` 写上 `bossByEp` / `minorsByEp` / `themesByEp`（Boss id 尽量复用已有套件）  
3. 跑生成器 `--eps N --check`  
4. 浏览器：`game.html?ep=N` 走完三站，`battle.html?ep=N&skip=intro,preview,waves,quiz` 看最后一格是不是原题  
5. 三白名单：`game/` 目录已进数据包；新 GIF/背景才需要追加文件名  

禁止：新建 `game-epN.js`、新存档键、把像素世界 80 关文案拷进来。

## 手写对白什么时候才要

只为改开场两句或指定另一张官方题。模板：`content/game/dialogues/ep1.json`。  
没有 `options` 时生成器会从巩固卡补上，但手写稿仍应写全，避免审稿时以为没有原题。
