## 对白怎么写（手写增强）

模板看 `content/game/dialogues/ep1.json`：

```text
intro.lines[2]  { sourceNodeId, speaker, textEn, textZh, audioRef }
quiz.lines[1]   同上
quiz.word / quiz.question
quiz.options[]  { textEn, textZh, correct, feedback }  ← 优先官方题
```

规则：

1. 句子必须能在 `dialogue_stories/epN.json` 找到同一 `sourceNodeId`
2. 中英是本集字幕，不是新编星港台词
3. quiz 题优先知识巩固 `official_quiz` / lesson card
4. **默认不要手写。** 生成器从本集字幕抽 2+1 句，从 `lesson.json` 第一张 `sentence_choice` 带上 `options` / `lessonCardId` / `feedback`。
5. 手写 `dialogues/epN.json` 只覆盖 intro 台词；缺 `options` 时生成器会补官方题，不再盖掉。
6. 54 集同一命令：`build_game_levels.py --eps 1-54`。详见 [09-全关卡复用工作流](09-全关卡复用工作流.md)。

## 小怪与 Boss 皮

- 小怪：**按剧情族**换精灵，不给 54 集各做一套 AI（09-10 `02-小怪立绘清单.md`）

## 像素包不要当素材库

禁止：

- 复制 `sf-01.json` 当 `ep1` 剧情
- 用 `forest-01.webp` 当花果山
- 用 detective 20 关当第四合辑
- 为凑「每关一个 activityType」而造扫描/修理小游戏

允许：

- 对照 `sf-01.json` 检查自己的 intro/quiz 是否「入场 → 互动 → 收束」结构完整
- 对照 manifest 的 node 字段，检查选关是否有标题/图标/位置
