## 参考单关长什么样

文件：`…/05-pixel-worlds-story/levels/sf-01.json`（forest/block 同构）

```text
levelId, chapterId, worldId, title, rewards.growthPoints,
scenes[1] {
  sceneId, background, sceneAssets,
  lines[11]: narration×1, dialogue×3, activity×1, narration×1, dialogue×5
}
icon, background?, storyVersion
```

- 像素 `levels/` **没有** `choice`（choice 在 `dialogue-story-template`）
- `activity.actions[]` **没有** `isCorrect`，两点都推进
- `storyText` 不在 level 里，只在晚关的 manifest 节点摘要里

## 西游真源（三层，不要第四套 scenes）

| 层 | 路径 | 谁写 | 谁读 |
|---|---|---|---|
| 字幕/节点原文 | `content/dialogue_stories/epN.json` | 手写/既有书线 | 生成器抽 intro/quiz 句 |
| 地图 NPC 手写 | `content/game/dialogues/epN.json` | 目前仅 ep1、ep5 | `build_game_levels.py` → `npcDialogue` |

`npcDialogue.intro/quiz` 与 `dialogues/epN.json` 同构，不是第三套剧情。

## 字段映射

| 像素 | 降妖记 | 规则 |
|---|---|---|
| `levelId` `sf-01` | `ep: 1` / `ep1.json` | 一集一关 |
| `worldId` | `collection: "c01"` 或 `map.theme` | 不是 sci-fi |
| `title` | `title.zh` / `.en` | 用目录集名 |
| `scenes[].lines[]` | **抽 2+1 句** 进 `npcDialogue` | 禁止整场 11 行 |
| `type: narration` | `speaker: "narrator"` + 底栏「旁白」 | 已落地 |
| `type: dialogue` | `textEn` + `textZh` + `sourceNodeId` + `audioRef` | 必须能对上字幕节点 |
| `type: activity` | 不建六小游戏；互动 = quiz 点选 | 见 02 |
| 模板 `type: choice` | `quiz.question` + `options[{textEn,textZh,correct,feedback}]` | `awaitingChoice` |
| `actions[].feedback` | 选项 `feedback` | 对/错各一句 |
| `rewards.growthPoints` | `npcBonus` / 星 | 不加积分系统 |
| `icon` / scene `background` | 选关封面 / `background.illustration` | 见 04 |
| line.`position` left/right | 不存；UI 固定左立绘+底栏 | |
| `goto` | **禁止** | 09-08 已砍 |

## 推荐节拍（11 拍压成 2 个 NPC）

像素：入场旁白 → 三人对话 → activity → 揭示旁白 → 五句「下一站亮了」。

降妖记：

1. **intro NPC**（出生点，走近自动一次）  
   2 句本集原文。点继续。末句「出发」。  
   `from=battle` 不重弹。
2. **quiz NPC**（第一波清完）  
   1 句本集原文 + 1 题。  
   题优先 `official_quiz` / lesson card `options`；没有才词义三选一。  
   答对：词卡 + `npcBonus`。答错：禁错项，可再试；两次都错揭示带读，不扣盾。
3. 关对话回探索。**不要**再写五句「入口亮起」——大战站的门控已经表达「下一站」。

## 生成器合同

`prj/tools/build_game_levels.py`

- 从 `dialogue_stories` 抽 intro/quiz 句，保留 `sourceNodeId`、`audioRef`
- 手写 `content/game/dialogues/epN.json` 覆盖烘焙对白
- `normalizeNpcDialogue`（`battle-core.js`）必须保留 `options` 与 `lessonCardId`（已修）
- 选项 `feedback` 一并拷贝
- **手写 `dialogues/epN.json` 会盖掉生成器。** ep1 手写 quiz 目前没有 `options`，运行时仍会退回词义三选一。补集时把官方题 options 写进手写文件。
