# 00 总方案与环节

孩子打的是 **西游记这一集**，不是像素世界的回家任务。整局只有一条线。

## 孩子怎么走

```
绘本 / 巩固过关
        │
        ▼
map.html                     【选关世界】
  合辑世界卡（c01 石猴出世…）
  16:9 舞台 + 本辑各集节点
  节点：第 N 集 · 集名 · 完成贴纸
  「⚔️ 打怪」→ game.html?ep=N
        │
        ▼
game.html?ep=N               【关内三站，同一张 4×4 大地图】
  ① 开场 NPC（走近自动 2 句本集原文）
  ② 小妖：捡本集道具球，扔头顶英文小怪（两波）
  ③ 问答：第一波清完 → 小 Boss NPC 1 句 + 1 题
  ④ 大战：两波清完且答完 → 确认后进 battle.html
        │
        ▼
battle.html?ep=N&from=game   【大 Boss，同一套对战引擎】
  题在上、选项在上、双方血条在下（设计；UI 增量见 05）
  答对打 Boss；答错 Boss 反击
        │
        ▼
回到 game.html?ep=N&from=battle
  不重弹 intro；完成态目前锁死重打（弹层回 map 或清进度），09-08「可逛」尚未做
  「下一集」走 game.html?ep=N+1（已落地，禁止直进 battle.html?ep=N+1）
```

磨耳朵 / 趣配音 / 绘本播放走原来的 `wala.html` / `dub.html` / `storybook.html`，**不是**降妖记主循环。选关节点上保留这些入口。

## 三层各管什么

| 层 | 页面 | 像素世界对应 | 降妖记对应 |
|---|---|---|---|
| 选关 | `map.html` | explore-terminal 三世界首页 | 13 个合辑世界；节点=集 |
| 关内探索 | `game.html` | 点节点后播 `levels/*.json` 11 句 | 不播长剧；走捡投 + 两个 NPC |
| 对战 | `battle.html` | 无（像素包没有 Boss 血条战） | 本集词打 Boss |

参考项目继续 **各管一层**，不要合成三个小游戏：

| 参考 | 管哪一层 |
|---|---|
| explore-terminal + manifest | 选关外观与节点字段 |
| pixel-worlds `levels/*.json` + dialogue-story-template | 对话一句一句、选择题守卫 |
| word-memory-map | 大地图捡投、追击 |
| pet-battle-template | Boss 打击感、双方血条 |
| typing-defense | Boss 的一种题（跟打），不上独立引擎 |
| 知识巩固 official_quiz | NPC / Boss 题库 |

## 一集在环节里的角色

像素：`sf-01` 是「星港登船舱」这一站。  
西游：`ep=1` 是「石猴」这一集，同时是：

- 选关节点（c01 舞台上的第 1 站）
- 一张 4×4 大地图（主题花果山）
- 一套本集词（预习约 12：地图 ~8 + Boss ~4）
- 两段 NPC（intro / quiz）
- 一个 Boss id（可多集复用）

换集只换数据，不换引擎。

## 门控（关内）

```text
intro 可走
  → wave1 未清：quiz NPC 头顶「…」，Boss 区不可开战
  → wave1 清完：quiz NPC 可对话
  → npcDone：刷 wave2
  → 剩余小怪 = 0 且 npcDone：Boss 确认卡
  → 打赢：mapStage = complete（bookplay_battle_progress_v1）
```

选关侧：西游 `OPEN_SELECT`，集全开，贴纸分完成/未完成。巩固关仍按辑锁。

## 时长（目标，非实测）

| 段 | 目标 |
|---|---|
| 选关找节点 | < 15 秒 |
| 开场 NPC | 20–40 秒 |
| 两波地图 | 3–5 分钟 |
| NPC 题 | 20–45 秒 |
| Boss | 1–2 分钟 |
| 整局 | 巩固后的加餐，不替代 lesson |
