# 01 选关世界与节点

参考首页：`G:\StudyCode\宠物积分系统\app\explore-terminal\`  
参考数据：`05-pixel-worlds-story/manifest.json` 的 `worlds[]` / `nodes[]`

09-08 砍的是「像素三世界 tab + 80 关」。本页做的是 **同一张 `map.html`** 上的西游合辑舞台。

## 字段对照

| 像素 `worlds[]` / `nodes[]` | 降妖记 | 现状 |
|---|---|---|
| `world.id` | `collections[].id` | c01…c13 |
| `world.title` / `subtitle` | `title.zh` / `summary.zh` | 已有 |
| `world.background` | `background` → 舞台图 | `assets/collections/normalized/c0N.jpg` |
| `world.tone` | **不补** | 只服务参考 CSS 主题 |
| `node.levelId` | 集号 `n` | 数字，不要 `sf-01` |
| `node.order` | 辑内顺序 | `from`–`to` |
| `node.label` / `subtitle` | `catalog.title.zh` / `.en` | 运行时 `epMeta` |
| `node.position.{x,y}` 0–100 | 运行时 S 折线写 `left/top %`；可选 `nodes[].position` 或 `route.anchors`（0–1） | 未手填点位 |
| `node.icon` | 集封面 | `catalog.cover` |
| `node.background` / `sceneAssets` | 关内资源，不在选关页 | 见 04 |

适配函数（已落地）：`collectionWorld(c)`、`worldNodeAnchors(c, nodeCount)`，在 `prj/engine/map.js`。

## 孩子看到的

1. 顶栏仍是首页 / 驿站 / 列表。
2. **合辑世界卡**横滑：封面缩略 + 辑名 +「第 x—y 集 · N 站」。
3. 点世界卡 → 切到该辑舞台（原来的左右滑页仍可用）。
4. **16:9 舞台**铺合辑封面；集节点是毛玻璃条：图标、第 N 集、中文名、磨耳朵 / 配音 / 打怪。
5. 完成贴纸：已完成 / 未完成（`OPEN_SELECT`，不锁集）。

Minecraft / Mikey 路线 **不加** `map-terminal`，仍走封面卡 + S 折线。

## 坐标策略

像素 20 点是为那张手绘地图钉的，不能套到西游封面上。

| 策略 | 何时用 |
|---|---|
| 默认 S 折线（1–3 排） | 现在。按视口和卡片尺寸防重叠 |
| `route.anchors` 0–1 | 某辑封面先画出可见路径后再填；长度必须等于 DOM 节点数（含巩固点则对不上就不用） |
| `collections[].nodes[].position` | 可选；`worldNodeAnchors` 把 0–100 转 0–1 |

**不要**为 c08 手填 anchors 或新画选关图。
