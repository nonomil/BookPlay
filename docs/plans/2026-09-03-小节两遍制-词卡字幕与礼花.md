# 小节两遍制：词卡字幕、测验与故事驱动奖励实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 为西游记、Minecraft 分级读物、Mikey & JJ 英语冒险建立同一套“整集观看 → 精学回放 → 词卡测验 → 完成奖励”闭环，同时让每集奖励和生图资产都来自该集真实绘本页、字幕和视频内容。

**架构：** 播放器只负责呈现通用的 `scene/replay/vocab/quiz` 合同，系列数据适配器负责从各自的书本 JSON、页面图和视频/音频清单生成合同。精学回放不新增视频文件，复用已有媒体时间轴；奖励通过现有 `prj/engine/episode-reward.js` 的幂等接口发放，视觉资产通过带证据清单的 GPT/Cliprox 管线生成并由 manifest 引用。

**技术栈：** 原生 HTML/CSS/JavaScript、Node.js 内置 test runner、Python 资产/数据脚本、ffmpeg（若可用）、Edge TTS、现有 `gpt-image-workflow`（Cliprox 固定 CA 校验）。

## 0. 范围、原则与不做事项

### 0.1 范围

- 首个验收对象：每个系列第 1 集（西游记 EP1、Minecraft Book1、Mikey & JJ Book1）。
- 通过后批量覆盖：西游记 108 集、Minecraft 5 本、Mikey & JJ 当前目录中已发布的 10 本。
- 三个系列共享播放器流程和状态字段；字幕、页面布局、角色皮肤、奖励目录和生图风格按系列分开。

### 0.2 不变原则

- 第一次播放必须连续看完整集，不插入教学弹窗或题目。
- 精学只进入包含目标词的小节；每节 1–3 个词，最多重复一遍。
- 词卡音频、句子音频、视频时间轴必须有来源；不能为了填字段伪造释义、角色、时间或画面内容。
- 生图只生成纯视觉资产，禁止在图内生成英文/中文文字、Logo、水印；标题、释义、题目由网页叠加。
- 继续复用 `prj/engine/episode-reward.js` 的幂等逻辑；刷新、重播、重复测验不能重复发放大件奖励。
- 每集 `prj/engine/drill.html` 的解锁门槛独立保留，不能被本集词卡测验替代。

### 0.3 明确不做

- 不在本阶段裁切或重编码原漫画/动画视频。
- 不为每个词新切一份视频；词级点读只使用已有静态词音频或句子时间轴。
- 不把“听过”直接当成“掌握”；不以语音识别失败阻塞低龄用户通关。
- 不把外部产品或 X 索引摘要当成项目数据来源；外部资料只用于交互启发。

## 1. 用户流程与状态机

### 1.1 主流程

```text
完整剧情播放（原字幕/原声）
  ↓ 播放到末尾，写入 episode_complete
精学回放队列（仅含有目标词的 scene）
  ↓ 每节：原句一遍 → 词卡轮播 → 可跳过/再听
词卡学习进度（seen / learned）
  ↓ 队列完成或用户主动进入
本集词卡测验（按年级和难度出题）
  ├─ 未通过：错词小节回放 → 只重测错词
  └─ 通过：完成卡 → 礼花 → SP/贴纸 → 首次掉落房间物品 → 下一集提示
```

### 1.2 状态转移与幂等边界

| 状态 | 触发条件 | 可逆操作 | 允许发放的奖励 |
|---|---|---|---|
| `watching_full_episode` | 进入播放器 | 暂停、退出、从断点继续 | 无 |
| `episode_complete` | 媒体自然结束或完成按钮确认 | 可重新观看 | 无 |
| `study_replay` | 存在目标词 scene | 跳过当前节、再听 | 仅显示进度 |
| `vocab_learned` | 词卡音频播完或用户点“学会” | 可回放 | 无大件 |
| `quiz_in_progress` | 精学队列结束/手动开始 | 重做当前题 | 无 |
| `quiz_passed` | 达到年级通过线 | 可复习错词 | 首次通过资格 |
| `completion_card` | 通过结果写入后展示 | 关闭/重新查看 | 不重复发放 |
| `reward_granted` | 完成卡确认后调用奖励接口 | 查看库存/房间 | SP、贴纸、首次房间物品 |

### 1.3 推荐存档合同

播放器当前实际使用 `bookplay_story_progress`；实现时在该键的 `progressKey` 记录下增加以下字段，并提供与 `bookplay_lesson_progress_v1` 的只读兼容迁移（如果旧课件已有记录）。不新建互相竞争的完成键：

## 2. Scene 与精学回放合同

### 2.1 Scene 生成规则

- 优先使用数据中的句子/页级时间轴：Minecraft 使用 `prj/data/storybooks-minecraft/book*.json` 的 `pages[].sentences[]`；Mikey & JJ 使用 `prj/data/storybooks-mikey-jj/book*.json` 的 `pages[].sentences[]`；西游记使用 `prj/data/storybooks/ep*.json` 与 `prj/data/dialogue_stories/` 的句段。
- 相邻 2–4 个对白节点合并为一个 scene；目标时长 3–8 秒，超过 12 秒拆分，低于 2 秒可与相邻句合并。
- scene 必须保存 `id`、`page_no/source_page`、`start_ms/end_ms`（或秒）、`sentence_ids`、`target_terms`、`image`、`video`/`audio` 来源。
- 若没有可靠视频区间，使用页面图定格 + 句子音频；不能猜时间。
- 没有目标词的 scene 不入精学队列。

### 2.2 两遍呈现

第一遍保留原页面/动画、原英文句子和中文字幕；第二遍复用同一画面和时间轴，上层仍显示短英文原句并高亮目标词，下层字幕位显示词卡：`term`、IPA（有来源才显示）、中文释义、英文/中文播放按钮。

每节顺序固定为：

1. 原句自然播放一次；
2. 目标词依次自动播放 `term → 原句 → 中文`；
3. 每卡间隔约 0.8 秒，显示 `本节词卡 1/3`；
4. “再听一次”“跳过本词卡”“跳过本节”始终可用；
5. 词卡全部完成后写入 `learned_terms`，进入下一节。

### 2.3 词点击与音频优先级

```text
静态词音频（若 manifest 命中）
  → 句子音频的 word start/end seek
  → /api/tts 运行时兜底
```

点击任意句子中的任意单词都应可点读，不限重点词；重点词额外显示中文和目标词样式。Mikey & JJ 普通词也必须与重点词一样是独立可点击 token。

## 3. 词卡测验、分级与掌握度

### 3.1 题量与题型

| 年级 | 题量 | 首选题型 | 可选题型 |
|---|---:|---|---|
| 一–二年级 | 3–5 | 听音选词、图片/词义三选一 | 原句跟读（不计入必过） |
| 三–四年级 | 5–9 | 词义选择、听音认词 | 原句缺词、句子理解 |
| 五–六年级 | 7–14 | 语境选择、句子填空 | 跟读、短听写 |

题目必须携带 `term`、`sentence_id`、`audio`、`correct_option`、`distractor_source`；干扰项优先从本集词池抽取，避免跨主题混淆。

### 3.2 通过线与错词回放

- 默认通过线 70%，由现有年级/难度设置覆盖。
- 低于通过线只将错词放入 `last_wrong_terms`，不清空已掌握词、不锁死下一次复习。
- 错词回放只播放包含该词的 scene；重测只出错词与必要的同句语境。
- 语音识别跟读为可选加分，不进入必过判定。

### 3.3 进度显示

同时展示两组数字，避免把学习和掌握混淆：

```text
本集重点词：已学习 3 / 5
本集重点词：已掌握 2 / 5
```

完成卡使用测验实际结果，不能用“播放过词卡”冒充掌握数。

## 4. 奖励机制与完成卡

### 4.1 分层奖励表

| 里程碑 | 视觉反馈 | 数据写入 | 奖励规则 |
|---|---|---|---|
| 单词卡完成 | 词袋点亮、进度条前进 | `learned_terms` | 不发 SP/物品 |
| 精学队列完成 | 轻量“词卡学完啦”动效 | `study_replay.completed` | 每次最多显示一次，可关闭 |
| 测验通过 | 完成卡 + 1–1.5 秒礼花 + 豆豆龙庆祝动作 | `quiz.passed`, `completion.card_shown` | 每集首次通过触发 |
| 首次通过确认 | SP、故事贴纸、3 选 1 房间物品 | `*_granted`、库存、房间槽位 | 复用 `episode-reward.js`，幂等 |
| 重复复习 | 掌握度更新、错词减少 | VSTAT | 不重复大件奖励 |
| 系列/篇章完成 | 篇章徽章或主题房间装饰 | 独立 series/chapter 状态 | 不与单集掉落混用，后续 P2 |

### 4.2 完成卡内容

完成卡必须是全屏内容层，不挤在右侧栏，包含：本集封面/主视觉、本集标题、“掌握 X / Y”、正确率、新掌握词、豆豆龙庆祝、礼花、`再复习错词` 和 `继续下一集` 两个按钮。

奖励顺序必须是：先写入测验结果 → 再显示完成卡 → 用户确认或自动确认后调用贴纸/SP/掉落接口 → 更新库存和房间预览。页面刷新时根据幂等字段恢复卡片，不重复播放大礼花。

### 4.3 奖励目录

- 保留 `prj/data/rewards/jttw.json` 作为西游记既有目录，不修改其 108 集贴纸与房间规则。
- 新增通用系列目录 `prj/data/rewards/storybooks.json`，按 `minecraft`、`mikey-jj` 分组，物品必须含 `id/title/asset/room/slot/source_episode/reward_type/non_power`。
- Minecraft 物品来自本集方块、工具、生物或场景；Mikey & JJ 物品来自本集冒险道具、角色伙伴或地点标志。奖励只收藏，不改变学习数值。
- 每日大件掉落上限沿用现有 catalog 机制；贴纸不占大件上限。

## 5. 故事驱动生图资产管线

### 5.1 证据优先的输入顺序

```text
本集书本 JSON / 字幕句子 / 词卡
      + PDF 页面图
      + 同名 MP4 视频（抽帧）或已提取 MP3
        ↓
故事事实表（角色、地点、动作、关键物件、情绪、重点词）
        ↓
视觉 brief 与构图安全区
        ↓
GPT/Cliprox 纯画面生成
        ↓
尺寸/透明度/文字污染检查
        ↓
资产 manifest + 播放器引用
```

### 5.2 每集事实表最低字段

```yaml
series: minecraft | mikey-jj | jttw
episode: 1
title_en: ...
title_zh: ...
source_pages:
  - prj/data/storybooks-minecraft/book1.json#pages[0]
source_video: 书籍资料库/.../MikeyJJ Audio Books/....mp4
source_audio: prj/data/storybooks-mikey-jj/source-audio/....mp3
characters: []
location: ...
actions: []
props: []
target_terms: []
text_safe_zone: "下方 28% 保持低细节，不放关键角色"
aspect_ratio: 1536x1024
```

事实表只能引用已存在的字段或人工审核记录；不确定的角色/动作必须标 `unknown` 并停止自动生成，不能让模型补写剧情。

EP1 事实表示例（仅展示字段如何从证据填入，不直接当作新剧情）：

| 系列 | 证据入口 | 可用于生图的事实 | 禁止越界的内容 |
|---|---|---|---|
| Minecraft Book1《Escape from the Nether!》 | `prj/data/storybooks-minecraft/book1.json#pages[0]` + 对应页面图 | Emmy、Birch；新头盔/金靴、铁剑；“准备冒险”的动作与本页场景 | 未在页面或字幕出现的怪物、武器升级、额外角色 |
| Mikey & JJ Book1《Zombie School Adventure》 | `prj/data/storybooks-mikey-jj/book1.json#pages[0]` + 同名 MP4 对应帧 | Mikey、JJ；学校上课迟到、寻找同学、可能的僵尸校园氛围（以视频帧为准） | 从标题推断未出现的 Boss、道具或结局 |
| 西游记 EP1《The Monkey》 | `prj/data/storybooks/ep1.json#pages[*]` + `prj/data/dialogue_stories/ep1.json` | 山顶仙石、裂石出猴、眼中射光、天庭观察（只使用有页图/句子证据的元素） | 添加原文没有的法术、服饰或人物关系 |
 
事实优先级固定为：结构化 JSON 的标题/词/时间轴 > PDF 页面图的角色与构图 > 视频帧的动作与光色 > 人工审核备注。模型不得把“看起来像”写回事实表；无法证实的视觉元素只能放在 `rejected_candidates`。

### 5.3 资产类型与命名

每集至少规划以下资产，按系列和集数隔离：

```text
docs/generated/storybooks/<series>/ep<NNN>/references/
  page-<source_page>.png
  video-frame-<time>.jpg
  evidence.json
docs/generated/storybooks/<series>/ep<NNN>/prompts/
  completion-card.prompt.txt
  quiz-background.prompt.txt
  sticker.prompt.txt
  room-reward-<id>.prompt.txt
docs/generated/storybooks/<series>/ep<NNN>/final/
  completion-card-bg.png
  quiz-background.png
  sticker-<id>.png
  room-reward-<id>.png
  manifest.json
```

运行时复制/打包到 `prj/assets/generated/storybooks/<series>/ep<NNN>/`，不直接从 `docs/generated` 读取。

### 5.4 生成规则

- 先做页面缩略图/视频代表帧，选出的参考图在 `evidence.json` 记录文件路径和时间/页码。
- prompt 必须写明本集真实场景、角色外观、动作、重点词所对应的物件、画面比例、文字安全区和负面词：`no text, no letters, no logo, no watermark`。
- Minecraft 使用方块化、体积光、像素材质；Mikey & JJ 使用原漫画的构图/角色比例和明快色彩；西游记保持现有国风绘本资产，不跨系列混风格。
- 通过 `C:\Users\No'mi'l\.codex\skills\gpt-image-workflow\scripts\bee_image_workflow.py` 调用 Cliprox，默认直连并固定 CA，不使用 `verify=False`、`-k` 或环境代理绕过。
- 横版资产实际宽高比低于 1.4 时判为失败并删除重试；生成图内不得出现可读字幕，OCR 命中需返工。
- `manifest.json` 保存 prompt hash、参考证据、生成时间、尺寸、SHA-256、审核状态和运行时目标路径，便于复现与回滚。

### 5.5 奖励与故事绑定检查

每个奖励物品必须能回答：“它在本集哪一页/哪一秒出现或由哪句对白明确提到？”若不能回答，只能作为未采用候选，不得进入 `storybooks.json`。

### 5.6 生图审批状态

资产 manifest 的 `asset_status` 只能按以下顺序推进：

```text
evidence_collected → prompt_reviewed → generated → visual_checked → approved
                                           └→ rejected / fallback
```

- `evidence_collected`：页码、视频时间、句子 ID 和文件 hash 齐全。
- `prompt_reviewed`：角色、动作、重点词、构图安全区和负面词经过人工检查。
- `visual_checked`：尺寸、比例、alpha、OCR、文字/Logo/水印检查通过。
- `approved`：只有此状态的资产可复制到 `prj/assets/generated` 并被播放器加载。
- `rejected`：保留响应和原因，禁止运行时引用。
- `fallback`：生成失败或审核未完成时使用系列默认背景，不能阻塞学习闭环。

完成卡、测验背景、贴纸、房间奖励均要有独立的 `evidence_ids`；不能只给一个“本集”标签来掩盖没有页图/视频证据的问题。

## 6. 数据流水线与系列适配

### 6.1 Minecraft

- 输入：`prj/data/storybooks-minecraft/book1.json` 至 `book5.json`、`sentence-annotations-book*.json`、`prj/assets/minecraft/vocab/index.json`。
- 词音频：优先使用已生成的静态 Edge TTS；检查英文/中文音频 manifest，不重复生成。
- 场景证据：页面图作为主参考；若存在配套视频，抽取与句子时间轴重合的代表帧。
- 视觉重点：本集生物群系、方块工具、角色装备必须从页面/字幕事实表派生。

### 6.2 Mikey & JJ

- 输入：`prj/data/storybooks-mikey-jj/book*.json`、`catalog.json`、`audio-manifest.json`、`speaking-annotations*.json`。
- 视频/音频：源 MP4 只读；已有 MP3 与 `source-audio` manifest 作为音频来源，句级切分沿用 `prj/tools/mikey_jj_vocab_audio.py` 和现有音频清单。
- 普通词和重点词都需 token 化；重点词额外进入 scene `target_terms`。
- 视觉重点：从漫画页和同名视频抽取角色动作、地点、道具，不能生成与本集无关的泛化 Minecraft 背景。

### 6.3 西游记

- 输入：`prj/data/storybooks/ep*.json`、`prj/data/dialogue_stories/ep*.json`、`prj/data/rewards/jttw.json`。
- 保留现有 108 集贴纸与房间目录，只把完成卡/生图 manifest 接入同一奖励接口。
- 若老数据没有 scene，先由 `pages[].start_sec/end_sec` 生成页级 scene，再按句子数量拆分；不猜测原音频边界。
