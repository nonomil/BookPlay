# Mikey & JJ 体验修正：地图小人生图（GPT）+ PDF 气泡改大弹窗

> 反馈：① `map.html?series=mikey-jj` 的地图小人是占位图形，要求用 GPT 生图换成 Mikey 走路精灵；② 绘本 unified-v3 里按 PDF 坐标画的红框（`sb-bubble-locator`）位置不准，要求弃用，改为大弹窗气泡。

## 1. PDF 气泡 → 大弹窗（已改完）

- `storybook.js`：v3 的 `showSpeakingBubble` 不再调用 `updateBubbleLocator`（红框），改为 `renderSpeakingBubble + positionPopupBubble`——气泡贴舞台底部居中、宽度约 92%（≤680px），显示说话人徽章、逐词卡拉OK高亮、可点词查义（`syncBubbleWords` 原本就消费 `#sb-speaking-bubble`，v3 显示后自动生效）。`hideSpeakingBubble` 统一走淡出路径并隐藏红框。
- `storybook-v3.css`：解除 `#sb-speaking-bubble { display:none }`，新增弹窗布局样式；`#sb-bubble-locator` 彻底 `display:none`。漫画外观沿用 `body.sb-mj .sb-speaking-bubble`（v3+mikey-jj 时 body 同时带 `sb-mj`）。
- 版本号：`storybook.js?v=popup-bubble1`、`storybook-v3.css?v=8`。
- 影响面：仅 unified-v3；minecraft 的句子无 speaker/bubble 字段，不会弹气泡；legacy 阅读器路径未动。

## 2. 地图小人（GPT 生图 SOP）

地图已接线：`map.js` 的 `routeCompanionSpriteUrl()` 指向 `/data/assets/generated/mikey-jj-route-companion/transparent/mikey-walk-atlas.png`，启动时用 `Image` 探测——**生成前显示原占位小人，生成成功后自动原位切换为精灵图**，无需再改代码。

### 2.1 生成步骤（你操作 GPT）

1. 用 `prj/prompts/mikey_base.txt` 生成 Mikey 全身立绘 → 存 `assets/generated/mikey-jj-route-companion/2d/mikey-base.png`。
2. 以立绘为参考图，分别用 `mikey_walk_side_sheet.txt`（ east 右侧走）、`mikey_walk_front_sheet.txt`（south 正面走）、`mikey_walk_back_sheet.txt`（north 背面走）生成三张图：
   - east 存 `tmp/imagegen/mikey-jj-route-companion/four-dir/mikey-walk-east-raw.png`
   - south 存 `tmp/imagegen/mikey-jj-route-companion/four-dir/mikey-walk-south-raw.png`
   - north 存 `tmp/imagegen/mikey-jj-route-companion/four-dir/mikey-walk-north-raw.png`
   - 注意：横排 sheet（east）是 1 行 × 8 帧；front/back 是 4 列 × 2 行 = 8 帧。若 GPT 出图不是标准网格，重roll或手动裁齐。
3. 抠掉绿底（任意图像工具，导出透明 PNG，文件名把 `-raw` 换成 `-transparent`，即 `mikey-walk-east-transparent.png` 等）。
4. 合成图集（脚本已参数化，与悟空同一套对齐/基线/镜像逻辑）：
   ```
   python prj/tools/build_jttw_route_atlas.py --character mikey
   ```
   产物自动落到 `content/assets/generated/mikey-jj-route-companion/transparent/mikey-walk-atlas.png`（即 `/data/assets/...`），刷新地图即可看到 Mikey 走路。

### 2.2 质量门（对照悟空图集 3072×2048）

- [ ] 图集尺寸 3072×2048（8 帧 × 384px，4 向 × 512px），行序 east/south/west/north。
- [ ] 每帧只有角色本体（最大连通域），无绿边、无分隔线残留。
- [ ] 八帧脚部基线一致（脚本按 BASELINE_Y=466 对齐），行走时脚下不跳动。
- [ ] east 为朝右侧面；west 由脚本自动镜像，不用单独生成。
- [ ] 透明背景（alpha 通道干净）；角色风格与漫画页一致（红帽衫/牛仔裤/紫鞋）。
