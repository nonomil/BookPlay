> **给 Claude / DSH 执行器：** 必须通过 `dsh-execute` 按任务切片实施；实现与修复遵循测试先行，并在每个批次后执行验证命令。

**目标：** 将 108 集课件图片与文字、540 道官方测试题、216 份带标注精读 PDF 的侧边词汇完整结构化，并让播放器在整集结束后按年级和难度选择一次知识巩固题。

**架构：** 原始文件只读，生成数据写入被 Git 忽略的 `content/lesson_guides/`；Git 只跟踪提取器、schema、测试、播放器代码和文档。所有题目进入全集题库，年级与难度 profile 只决定本轮展示数量和题型，不删除高阶题。播放器通过独立的课程数据加载、选题和进度模块消费 `lesson.json`，逐步减少 `wala.js` 的职责。

**技术栈：** Python 3、`pypdf`/Pillow、JSON Schema、Node.js 原生测试、HTML/CSS/JavaScript、现有 BookPlay 数据包工具。

## 不可变产品规则

1. 普通字幕结束后立即播放下一句，不出现题目。
2. 最后一句结束只触发一次 `episode_complete`，随后进入一次知识巩固。
3. 完成或明确跳过知识巩固后，才进入本集结果/下一集。
4. 540 道官方题、课件题、侧边词汇全部入库；低年级模式只少展示，不删除数据。
5. 原始 `data/`、生成图片、视频、PDF、`content/` 不进入 Git。
6. 未取得可追溯答案证据的客观题必须标记 `needs_review`，不得伪装为正式判题。

## 与现有“每辑巩固单元”的关系

现有 `drill.html?c=cNN` 是每一辑的必做解锁门禁；本计划新增的是每一集看完后的知识巩固。两者并存：

- 每集知识巩固由 `wala` 在 `episode_complete` 后进入，可完成或明确“稍后巩固”；
- 每辑巩固继续读取 `content/dialogue_stories/drill/cNN.json`，通过后写 `bookplay_drill[cid].done` 并解锁下一辑；
- 新数据管线只复制和增强题库到 `content/lesson_guides/`，不删除或改写现有 `official_quiz`、`puzzles`、`official_words`，避免破坏已建好的每辑题包；
- 交接包 `docs/handoff/001_西游记巩固单元交接_20260830/` 记录的 P0 端到端通关闭环，是修改播放器巩固 UI 或打 APK 前的硬门禁；它不阻塞纯数据资产提取与校验。

## 统一题库合同

每集 `lesson.json` 保存完整卡池：

```json
{
  "card_id": "ep001-official-quiz-001",
  "type": "sentence_choice",
  "stage": "episode_complete",
  "order": 1,
  "difficulty": 2,
  "grade_bands": ["g1_2", "g3_4", "g5_6"],
  "skills": ["story_comprehension"],
  "prompt": {"en": "What did Monkey come out of?", "zh": "猴子从哪里出来？"},
  "payload": {
    "choices": [
      {"id": "a", "en": "a rock", "zh": "一块岩石"},
      {"id": "b", "en": "a tree", "zh": "一棵树"},
      {"id": "c", "en": "a river", "zh": "一条河"}
    ],
    "answer": "a",
    "answer_evidence": [{"node_id": "ep001-n001", "quote": "a rock had sat high on top of a mountain"}]
  },
  "sources": [{"kind": "official_quiz_pdf", "page": 1, "sha256": "..."}],
  "review_status": "machine_verified"
}
```

必需规则：

- `card_id` 跨全集唯一且稳定；`stage` 固定为 `episode_complete`。
- 客观题必须有合法 `answer`、非空 `answer_evidence`、来源页与来源哈希。
- `review_status` 只允许 `machine_verified | human_reviewed | needs_review`。
- `needs_review` 题保留在全量题库和审核报告中，但不进入默认可判分卡池。
- 原 `nodes[].quiz_after` 只作为迁移输入；运行时不再以字幕节点调度。
- 相同题面只保留一个 UI 实例，`sources` 可合并多来源。

## 年级与难度 profile

设置分为两个维度：年级段决定可用题型与认知门槛，巩固强度决定本轮题量。首次运行默认 `g3_4 + standard`，用户选择保存到 `bookplay_lesson_settings_v1`。

| 年级段 | 默认题量 | 允许题型 | 交互特征 |
| --- | ---: | --- | --- |
| `g1_2` 一二年级 | 4 | `word_review`、`image_choice`、简单 `sentence_choice` | 默认显示中文提示、图片优先、不含自由书写 |
| `g3_4` 三四年级 | 7 | 上述 + `sequence`、一般剧情理解 | 中英提示可切换，包含 3 选 1 |
| `g5_6` 五六年级 | 10 | 上述 + `grammar`、`expression`、`free_talk` | 更多英文题面、推理和表达 |

强度乘数：`light = 0.7`、`standard = 1.0`、`challenge = 1.3`，最终数量受可用且已验证卡数限制。选择器必须稳定、可测试，并优先覆盖不同题型和未掌握题。
