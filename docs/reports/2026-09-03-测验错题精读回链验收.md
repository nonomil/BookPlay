# 测验错题精读回链验收

日期：2026-09-03  
范围：巩固页单词/剧情测验错题 → 对应画面 → 精读模式 → 返回原题

## 已落地

- `drill.js` 为每道剧情题保留来源集数，并按对白节点的 `quiz_after.q` 精确定位 `node_id`。
- 答错后停留在当前题，显示正确答案、“再学一次”和“下一题”；不会自动跳过错题。
- “再学一次”打开 `wala.html`，强制携带 `mode=study`、`subtitle=enzh`、`sidecards=1`、`review=1`，并带回题目地址。
- Wala 复习上下文显示“返回当前测验题”，不写入正式集进度，也不永久覆盖用户的字幕/词卡/模式设置。
- 使用 `sessionStorage` 保存本次巩固的答题计数；返回后恢复已答对数量，并通过 `quizId` 回到同一道题。
- 单词题“再学一次”使用题目自身的 `review.node_id`（旧数据则按例句匹配对白节点），携带 `wordId` 返回参数，跳回原单词题。
- 单词回链强制携带 `mode=study`、`subtitle=enzh`、`sidecards=1`、`annot=1`，因此会显示双语字幕、词下标注和侧边词卡。

## 浏览器验收

服务：`http://127.0.0.1:8810`

页面：`/engine/drill.html?c=c01&tab=quiz`

- 答错后出现“再看一眼这段故事 / 再学一次 / 下一题”。
- 点击“再学一次”示例跳转：`wala.html?ep=6&node=n013&mode=study&subtitle=enzh&sidecards=1&review=1`。
- 精读页同时显示双语字幕与侧边词卡，顶部按钮为“返回当前题目”。
- 返回后题干仍为原错题，测验计数保留（示例：`1/21`），可重新作答。
- 单词回链示例：`wala.html?ep=1&node=n003&mode=study&subtitle=enzh&sidecards=1&annot=1&review=1`；页面显示完整播放器、双语字幕、精读词卡，返回按钮为“返回当前题目”。
