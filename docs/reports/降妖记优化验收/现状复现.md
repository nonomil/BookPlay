## 3. 本轮速度、四向与动作分离修复（T02）

- 根因：旧版 `HERO_SPEED=0.92` 视口比例/秒；在统一世界换算后，1280px 视口的视觉速度约 1177px/s。小怪也沿用过快档位，且创建/更新始终使用 `south` GIF。
- 修复：`game-core.js` 提供可观察的视口比例速度档 `MOVEMENT_SPEEDS = { hero: 0.018, monsterWander: 0.0012, monsterChase: 0.0024 }`，`game.js` 再乘 `NU = 1 / WORLD`；同时按运动主轴调用 `directionFromDelta` 和 `setMonsterDir`，停止时保持最后方向。
- 修复动作耦合：主角和小怪均使用独立的 `idle / walk / attack` 三态四向资源；攻击开始即停止移动，攻击结束恢复 idle，不再把挥棒帧混入走路帧。
- 以当前 4×4 世界和 1280×720 视口计算，主角约 23px/s，小怪游荡约 1.5px/s、追击约 3.1px/s；比旧版约 1177px/s 的冲刺速度可观察得多。浏览器 ep5 主角下移切换 `wukong-south-walk.gif`，小怪运行中观察到 `east`/`north`/`west` 资源切换；攻击时 `moving=false` 且使用 `*-attack.gif`。GIF 素材为 8 帧×150ms（1.2s/循环），本轮未改素材帧率。
- 对话实际复测：点击 ep1 NPC 后弹层 `hidden=false`、输入 `locked=true`；点击“关闭”后 `hidden=true`、`locked=false`、`dlg=null`、方向意图清零，句子弹窗不会继续停留或带着旧输入续走。
