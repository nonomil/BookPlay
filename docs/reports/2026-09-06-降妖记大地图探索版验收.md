## 已验证（浏览器 E2E，ep5 混世魔王集）

- **① 地图收集单词**：单屏主题地图（water-dirty-cave 布局坐标精确生效）；8 只小怪头顶英文词牌游荡，目标条给中文 + 🎯 标记目标怪；点击 → 金箍棒旋转飞出 → 中文 3 选 1 快卡 → 答对爆碎+星星粒子+词卡入收集栏，进度 1/12、目标自动推进；答错护盾-1、怪变红加速逃窜、错词即答即存。
- **② 小 Boss·NPC 对话答题**：intro NPC 走近自动逐句播本集原文（扁平游标+▼推进）；quiz NPC taunt 开场 + 选择题，**答错→禁用该项+提示可重试**→再选对 → `npcBonus=true` + 词卡 + NPC 头顶 💬 变 ⭐。
- **③ 大 Boss 对战**：走近/点击 Boss 区 → 门卡"⚔️ 挑战 混世魔王？"→ 开战跳转 `battle.html?ep=5&skip=intro,preview,waves&from=game&wrong=mountain`；**直达 Boss**（跳过剧情/预习/波次）→ 血条选词球 → 每格命中触发**主角突进→命中闪光→Boss 后仰→"−1 单词"伤害浮字**（pet-battle 三段式）；结算卡新增"回地图继续探险 🗺️"按钮（from=game 时）。
- **复习闭环**：错词四遍（找词辨认→快卡确认→Boss 反向→quiz），错词经 URL 传入 Boss 战并 `reorderBossWords` 插队。
- **音效**：game 页接入 `app-audio`（attack/correct/retry/shield/reward）。
- **零页面错误**：全部 E2E 过程 window error 监听无捕获。
