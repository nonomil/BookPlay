# 语音跟读 MVP 验收记录

日期：2026-09-01  
范围：西游记知识巩固页与整辑巩固单词题  
版本：MVP（文本命中，不是发音质量评分）

## 1. 本次落地

- `voice-core.js` 提供供应商无关的结果合同：英文归一化、单词精确命中、句子 `match / partial / mismatch`、`no-speech / permission-denied / unsupported / network-error / timeout` 等稳定状态。
- `voice.js` 提供浏览器端适配：优先 Web Speech API；只有 URL 显式传入 `voiceStt` 且设备具备录音能力时，才启用 `getUserMedia + MediaRecorder` 网关；结束后释放所有 tracks，不写 `localStorage`。
- `lesson.html/js/css` 每集最多出现一张可选跟读卡，包含“听示范 / 跟读 / 再试一次 / 跳过”和 `aria-live` 状态。跟读失败、拒绝权限或设备不支持时，仍可照常答题并完成本集。
- `drill.html/js/css` 在本轮首个单词题提供一张可选跟读卡；切换标签后回到首题会恢复卡片，后续单词不重复弹出；语音状态不参与 `bookplay_drill[cid].done` 判定。
- 修复 Web Speech 网络错误回退缺陷：回退到网关时不再先用 `null` 解析 Promise，网关结果可以正常返回。

## 2. 结果合同边界

本 MVP 的“成功”只表示识别文本命中了目标词/句子，不代表儿童的音素、重音、语调或发音质量正确。所有结果的 `scores` 保持 `null`，界面不会把 ASR 命中写成“发音准确”。

没有麦克风、用户拒绝权限、浏览器不支持、网关不可用或断网时，界面明确提示“可以点选完成”，不阻塞巩固通关，也不保存原始录音。
