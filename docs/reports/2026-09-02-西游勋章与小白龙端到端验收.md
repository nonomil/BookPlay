4. 点击“去花果山看看”，导航到 `engine/companion.html`；房间文本包含“花果山小屋 / 1 件纪念品 / 仙石碎片”。
5. 刷新驿站后，房间仍包含“仙石碎片”；`#companion-error` 的实际可见性为 `false`，控制台 error/warn 数量为 0。

## 2. 发现并修复的问题

首次验收发现 `.companion-error { display: grid }` 会覆盖 `hidden` 的默认显示规则，导致成功加载时错误条仍可见。已增加：

```css
.companion-error[hidden] { display: none !important; }
```

同时将 `companion.html` 的样式缓存号从 `v=4` 更新为 `v=5`，并补充静态合同测试。
