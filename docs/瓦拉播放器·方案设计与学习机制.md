# 瓦拉播放器 · 方案设计与学习机制

日期：2026-08-29
范围：对话冒险层（`prj/engine/wala.html / wala.js / wala.css`）
素材：Little Fox《西游记》108 集 —— 官方外挂字幕与无字幕视频（data/03）、精读版台词本（data/02）、官方生词册（data/生词，3027 词）、官方测试题（data/测试题，540 道）、中英对照词汇（data/05）

---

## 1. 产品定位

瓦拉层是"**看动画 → 磨耳朵 → 顺手学词 → 剧情测验**"的一体化播放器：
孩子的注意力永远在画面和画面下方那一条字幕上，所以**所有学习内容都发生在这一条字幕轨里**，不依赖孩子主动去点旁边的任何按钮。

三层产品关系（已锁定）：

| 层 | 页面 | 定位 |
|---|---|---|
| 绘本 | `storybook.html` | 翻页有声绘本 |
| **对话冒险（本方案）** | `wala.html` | 逐句视频 + 卡片流学习 |
| 石猴 VN | `index.html` | 交互式对话故事 |

```

│   └──────────────────────┘   └────────┘      │
│                                              │
│  ┌──────────── 字幕轨（一次只显示一张卡）────────────┐ │
│  │  对白卡 / 单词卡 / 测验卡（整框轮播，框整体上移） │ │
```

- 底部框离底约 10~12vh（原来贴底），测验卡设最小高度，切卡不跳动；
- 右栏从"可点的词卡"改为**纯展示的词袋**（见 §5）。

## 3. 核心机制：字幕卡片流

同一时间底部只有一张卡，按幕自动轮播。一句话最多展开 3 幕：

```
对白卡 ──播完+1s──▶ [单词卡] ──自动读完──▶ [测验卡] ──答对──▶ 下一句对白卡
```

### 3.1 对白卡
- 视频播放本句切片（`audio_start ~ audio_end`），逐词卡拉OK高亮；
- 「有标注」模式：词下出精读本的中文小字（`script_gloss`），三色底纹；
- 「EN+中」模式：句下出整句中译；
- 「再听一遍」只重播本句；长按句子重播；长按中文读中文。

### 3.2 单词卡（首现词，自动进行，不需要点击）
- 触发：本句含**官方生词册的词**且为本集**首次出现**；出多少由「学习量」档位决定（§4.2）；
- 画面定格在本句最后一帧，整框显示：

  ```
  大字 term   [音标]   🔊
  中文释义（官方生词册）
  原句（term 高亮）：One day the rock split open.
  ```
- 进卡即自动朗读：term → 例句；读完 0.8s 自动进下一幕；
- 点卡重听；长按读中文释义；「下一句」= 跳过本卡；
- 不给 SP（防挂机刷分）。

### 3.3 测验卡（整框替换，画面定格）
对白播完 → 画面停住 → 底部**整框换成题目**（对白字幕消失）。两个题源：

1. **官方情节题**（每集 5 道，已逐题锚定到对应剧情句之后；锚不上的约 50 道题在本集最后一帧连续出完）；
2. **复现词测验**：官方生词第 2 次及以后出现、且未掌握（答错过或从未答对）时，本句播完出一道三选一（"gibbon 是什么意思？"），干扰项取本集词池。

规则：答对 +10 SP，0.8s 后续播；答错标红禁用、必须选到对；「下一句」在测验卡上无效（防连点跳题）。

## 4. 两遍制与学习量

### 4.1 剧情遍 / 精学遍（顶栏开关）

| | 剧情遍 | 精学遍 |
|---|---|---|
| 对白卡 | ✔ | ✔ |
| 单词卡 | ✘ | ✔ |
| 测验卡（情节+复现） | ✘ | ✔ |
| 章末补题 | ✘ | ✔ |

- **默认策略**：某集第一次进入 → 剧情遍（先完整享受故事）；该集完成过一次 → 自动默认精学遍；随时手动切换；
- 「单词字幕开关」不单独做：模式即开关。

### 4.2 学习量三档（地图页顶栏设置，全局记忆）

| 档位 | 适合 | 单词卡 | 复现词测验 | 情节题 |
|---|---|---|---|---|
| 🌱 轻松 | 低年级，剧情连贯优先 | 每集最多 **6** 张，全集均匀分布 | 关 | ✔（剧情互动，不算负担） |
| 🌿 标准 | 默认 | 首现词每句最多 1 张 | ✔ | ✔ |
| 🌳 加强 | 高年级，词汇冲刺 | 所有官方生词首现都出卡 | ✔ 且答错的词下集再考 | ✔ |

- 轻松档选词：按"词短 + 释义单一 + 本集出现次数多"打分取前 6，均匀铺在整集；
- 档位只影响精学遍；剧情遍任何档位下都是纯对白。

## 5. 词袋（右栏）与记忆闭环

- 播放中：走过的官方生词变成小徽章（词+中文）收进右栏词袋，纯展示、点一下发音；
- 轻松档没出卡的词**也收**，升档后自动成为复现测验题源；
- 章末：词袋汇总"本集收集 X / Y 个词" + 官方情节题成绩；
- 记忆数据存 `VSTAT`（localStorage）：每词 `seen / right / wrong`，复现测验只考未掌握的词，形成"首现学习 → 复现检测 → 错词再考"的间隔复习闭环。

## 6. 对时修复：字幕早一幕（前置 bug）

### 现象与证据
- 官方 SRT 第 1 条 `11.073–22.248` = "From the beginning of time…"，但 whisper 听写显示这句实际在 **21.8–26.4s** 说出；
- 规律：**第 i 条字幕的文字，是在第 i+1 条的时间窗里说的**（文字相对时间窗整体提前一条；第 1 条时间窗对应片头章节名/空镜）。

### 修复原理
逐集用 faster-whisper 判定是否移位（防个别集无此缺陷），移位集把第 i 句的时间改用第 i+1 条 SRT 的时间窗；末句用 whisper 末段兜底。**只重写 ep*.json 的 `audio_start/audio_end`，不动任何词汇/测验数据**。
详细步骤见任务文件夹 `docs/plans/瓦拉卡片流落地任务/01-对时修复.md`。

**播放条件：** 必须用根目录 `启动服务.bat`，或执行 `python prj/tools/serve.py` 打开（支持 HTTP Range）。`python -m http.server` 不能 Range，浏览器无法跳转到句中，视频会一直停在片头，看起来像「字幕早一幕」。

## 7. 设置与存储键

| 键 | 含义 | 取值 |
|---|---|---|
| `bookplay_read_mode` | 朗读模式 | `en` / `enzh` |
| `bookplay_annot` | 词下标注 | `1` / `0` |
| `bookplay_pass_mode`（新） | 剧情/精学（手动覆盖值） | `story` / `study` / 空=自动 |
| `bookplay_learn_level`（新） | 学习量 | `lite` / `std` / `max` |
| `bookplay_adv_progress` | 每集进度 | `{ep: {node, total, done}}` |
| `bookplay_adv_vocab_stat` | 词记忆 | `{term: {seen, right, wrong}}` |
| `bookplay_sp` | SP 积分 | int |

## 9. 已拍板结论

1. 测验不挂在句子下面：**整框替换成测验卡**，画面定格，框上移；
2. 两遍制：**自动**——首刷剧情遍、二刷起默认精学遍，可手动切；
3. 右栏：**词袋收集**（纯展示）；
4. 单词密度：**学习量三档设置**（轻松/标准/加强），低年级少学保兴趣、高年级多学；
5. 对时 bug 最先修。
