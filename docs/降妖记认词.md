# 降妖记 · 洞中认词

大班到一二年级的三种认词，挂在现有降妖记里，不另开合辑，也不改扔球。

## 怎么打开

桌面仍用仓库根目录的 `启动服务.bat`（HTTP Range）。不要用 `python -m http.server`。

- 首页进西游记，打开 `game.html` 后点暂停，选「洞中认词」
- 或直接打开 `http://127.0.0.1:8810/engine/word-quiz.html`
- 带集数：`/engine/word-quiz.html?from=game&ep=1`。有 `content/game/levels/ep1.json` 就用这一集的词；没有就用花果山短词（sun、moon、rock、monkey…）

## 三种题

1. 补字母：词中间空一格，点缺的字母
2. 看图选词：看汉字词牌，选英文。剧情帧不是这个词的照片，所以不拿来当图；以后若有 `assets/.../words/` 词图，才会显示那张图
3. 听音选图：听单词，选词牌。没有原声时页面写明「看大字再选画面」，不会假装听见了

五题里三种都会出现。对 70% 及以上才记「记住了」。不到线显示「还没记住，再考一次」，`quizPassed` 保持 false，也不会写成闯关成功。
