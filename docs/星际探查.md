# 星际探查 · 今日任务

大班到一二年级的舱内任务，不是西游记的主包装。西游首包在降妖记里：任务卡加选词降妖。

## 怎么打开

桌面用仓库根目录的 `启动服务.bat`（HTTP Range）。不要用 `python -m http.server`。

- 首页「星际探查」
- 或直接打开 `http://127.0.0.1:8810/engine/scout-orbit.html`

四站按顺序开：阳光农星、月园站、蓝海星、彩虹补给日。上一站任务星没点亮时，下一站不能起飞。

## 一轮舱务

每站五件舱务，三种都会出现：

1. 补字母：控制板上的英文缺一笔，点上那一笔，设备才接得上
2. 看图选词：看舱壁牌子，扳对应的英文开关
3. 听音选图：听机甲说的词，点亮对应的舱板。没有原声时写明「看大字再点舱板」，并露出英文，不会假装听见了

做对立刻亮灯，并加上一颗任务星。没接上就告诉你这件要接哪个词，然后继续下一件，不倒计时，也不用「不及格」这种话。

五件里接上不少于 70%（五件要四件）才点亮这一站。不到线时显示「这一站先不往前开」，`quizPassed` 保持 false，下一站仍然锁着。
