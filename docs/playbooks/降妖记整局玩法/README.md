## 地图长什么样（GPT + 放大探索）

当前章回（c01）**不是每集一张独立大地图**，而是：

- GPT（cliprox / `gpt-image-2`）按**主题**画了 **6 张**俯视背景：花果山、水帘洞、三星洞、水脏洞、龙宫、幽冥界。
- 第 1–7 集套这 6 张（第 3、4 集共用三星洞）。
- 运行时把这一张图铺成 **4×4 视口**的大世界（同一张图重复铺开），镜头跟随走。小怪、词球、NPC、Boss 分在不同格子，需要走一段路。

后续其它章回**同样改法，并且要用 GPT**：

1. 新场景才新画主题图（能复用花果山/龙宫等就复用，不要无故每集一张）。
2. 提示词写实心俯视场景，不要假透明棋盘格。
3. 世界继续 4×4，不要缩回 3×3。
4. 登记 `maps.json` 主题 + `COMMON_FILES` 背景 JPG。

生图工作区：`assets/generated/jttw-game-sprites/backgrounds/<theme>/`  
运行时：`content/assets/game-backgrounds/<theme>.jpg`
