# 方法思路

后续集只换地图皮、角色、词库，不换玩法。

## 一局五步

```
map.html「⚔️ 打怪」→ game.html?ep=N
  1. 开场 NPC：走近自动弹一次，本集原文 2 句。from=battle 回来不重弹。
  2. 大地图捡投（主玩法，对齐 word-memory-map）
  3. 小 Boss NPC：清完第一波才可对话；嘲讽 + 1 题三选一。
  4. 走近 Boss 区 → battle.html 只打 Boss（skip 开场/预习/小怪波）
  5. 结算回 game.html?from=battle
```

## 大地图手感（必须对齐参考）

参考：`G:\StudyCode\小游戏项目\games\word-memory-map`

- 世界 **4×4 视口**（比原先 3×3 更大，要走一段才到下一波 / Boss）。
- 背景是 GPT 主题俯视图，同一张图铺满世界；不是 word-memory-map 那种 9 张不同 tile。
- 四向走，斜向 hypot 归一，主轴定朝向。
- 小怪游荡 / 追 / 撞，扣盾；盾碎本波重置。
- 中文球躺地上，走近捡，对准对应英文怪扔。对上爆；扔错弹回，怪变红加速。
- 连对 3 横扫本波。

## 六种道具（只换西游皮）

| 效果 | 西游名 | 行为 |
|------|--------|------|
| 挡下一次撞击 | 蟠桃 | 托盘里的蟠桃可挡伤；点用则 +1 盾 |
| 减速 | 芭蕉扇 | 小怪慢几秒（不再横扫清场） |
| 自动瞄准 | 紫金葫芦 | 接下来 2 发自动找对怪 |
| 加速 | 筋斗云 | 主角快跑一小段 |
| 首字母提示 | 紧箍咒 | 点用后提示目标词首字母 |
| 打对补盾 | 金箍棒 | 下一次打对额外 +1 盾 |

第一版用 emoji。道具 sheet 不挡玩法。
