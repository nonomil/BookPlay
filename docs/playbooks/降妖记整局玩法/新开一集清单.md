# 新开一集清单（ep8+ / 新章节）

不要复制 `game.js` / `battle.js`。只补数据和白名单。以第 8 集为例，把 `8` 换成目标集号。  
整套合同：[全关卡复用工作流](../../plans/2026-09-10-降妖记整局环节与内容设计/09-全关卡复用工作流.md)。现行游戏圈 ep1–54 已走同一生成器；**不要为 c08 新画主题大地图**，除非用户点名。

## 0. 先确认故事侧已有

- [ ] `content/dialogue_stories/ep8.json` 有 `official_words`（建议 ≥ 12）和 intro 台词
- [ ] 本集插图 / walker 角色在 `walker-cast.js` 能 resolve 到主角

## 1. 分派角色与主题（手写）

改 `content/game/cast.json`：

- [ ] `bossByEp["8"]` — id、mode（`villain` 或 `sparring`）、nameZh
- [ ] `minorsByEp["8"]` — 小怪 sprite id 列表
- [ ] `npcByEp["8"]` — `intro` 与 `quiz` 的 sprite id
- [ ] `themesByEp["8"]` — 主题键

若是新场景（不是现有 6 个主题）：

- [ ] `content/game/maps.json` 的 `themes` 加一份布局（出生 / 怪点 / 两 NPC / Boss 点，坐标 0–1）
- [ ] **用 GPT**（cliprox / gpt-image-2）生成俯视背景 `content/assets/game-backgrounds/<theme>.jpg`（提示词写实心场景，不要假透明棋盘格；参考 `assets/generated/jttw-game-sprites/backgrounds/`）
- [ ] 世界保持 4×4，不要改回 3×3
- [ ] `sprites.json` 补小怪 / Boss 的 gif 或 walkGifs
- [ ] 需要嘲讽则改 `taunts.json`

## 2. 派生关卡 JSON

```
python -X utf8 prj/tools/build_game_levels.py --eps 8
python -X utf8 prj/tools/build_game_levels.py --eps 8 --check
```

- [ ] 生成 `content/game/levels/ep8.json`
- [ ] 文件里有 `map.theme`、`previewWords`、`waves`、`boss.hpWords`
- [ ] `npcDialogue.quiz.options` 恰好 1 个正确项，且有 `lessonCardId`（来自本集 `lesson.json` 第一张 sentence_choice，不要手编词义三选一）
- [ ] 浏览器 `battle.html?ep=N&skip=intro,preview,waves,quiz` 最后一格是本集原题
- [ ] `git add -f content/game/levels/ep8.json`（以及你改过的 cast/maps/sprites）

## 3. 三白名单（漏了真机没有）

- [ ] `pack_datapack.py` 的 `COMMON_FILES` 增加 `game/levels/ep8.json`
- [ ] 新背景 / 新 GIF 也逐文件进 `COMMON_FILES`
- [ ] 引擎若新增了 js/html：`pack_android.py` 的 `ENGINE_FILES`（现有 game-core 已加，不必重复）
- [ ] 若希望 **APK 开箱就能玩第 8 集**：改 `available_for_profile` 的 `episodes`（默认只内置 ep1，一般不要扩，用数据包解锁）

## 4. 测试与手感

- [ ] `node --test prj/engine/battle-core.test.mjs prj/engine/game-core.test.mjs`
- [ ] 浏览器打开 `game.html?ep=8`：走、捡、扔、NPC、Boss 门
- [ ] 确认没有快卡弹层
- [ ] `npm test` 数量不低于当前基线

## 5. 章节扩一批（c02）

```
python -X utf8 prj/tools/build_game_levels.py --eps 8-14
```

然后对每个新 ep 重复第 1、3 步。主题能复用就复用 `maps.json` 已有键，不要无故新画 6 张背景。

## 反例

- 为第 8 集新建 `game-ep8.js`
- 把点击选词快卡加回大地图
- 新增第三个 localStorage 键
- 只改 `content/` 不改 `COMMON_FILES`（zip / APK 里会缺关卡，页面像「没解锁」）
