# 代码接线

引擎按集号读数据，**加集不要新开页面。**

## 运行时文件

| 文件 | 职责 |
|------|------|
| `prj/engine/game.html` | 大地图壳：场景、HUD、摇杆、对话层、Boss 门 |
| `prj/engine/game.css` | 大地图样式；扬尘、投掷姿势、`prefers-reduced-motion` |
| `prj/engine/game.js` | DOM 网关：镜头、输入、刷怪、捡投、掉落、对话、跳转 |
| `prj/engine/game-core.js` | **纯逻辑**：朝向、步进、6 道具、NPC 门控、血条比例、战报 |
| `prj/engine/battle.html` | Boss 对战壳 |
| `prj/engine/battle.js` | 阶段机；从地图进来时 `skip=intro,preview,waves` |
| `prj/engine/battle-core.js` | 关卡构建、出题、命中、错词优先、结算星星 |
| `prj/engine/tv-remote.js` + `tv.css` | 电视方向键移动、OK 交互 |

脚本顺序（合同测试会锁死，漏文件页面白屏或静默缺逻辑）：

- 大地图：`app-audio.js` → `tv-remote.js` → `battle-core.js` → **`game-core.js`** → `game.js`
- 对战：`app-audio.js` → `tv-remote.js` → `episode-vocab-quiz.js` → `battle-core.js` → **`game-core.js`** → `battle.js`

## 关键函数（后续改手感先改 core）

`game-core.js`

- `WORLD_TILES` / `regionOrigin` — 4×4 世界格，区域编号随边长变，禁止写死 `% 3`
- `facingFromIntent` / `moveStep` — 运动
- `emptyItems` / `addItem` / `nextDropType` / `applySupportUse` — 道具
- `absorbHit` / `onCorrectHit` / `heroSpeed` / `monsterSpeed` / `consumeAutoAim` / `hintLetter` — 战斗修正
- `canTalkQuizNpc(waveIndex)` — 第一波未清不可对话（`waveIndex >= 1`）
- `shouldAutoIntro(fromBattle, introAutoPlayed)` — 战斗返回不重弹
- `canAdvanceDialogue` — choice 未答完不翻句
- `pushBattleLog` / `bossHpRatio` — Boss 战报与血条

`game.js` 只把上面的结果画到 DOM。词对错仍走 `BookPlayBattleCore.judgeHit`。

`battle.js`

- `startBoss` / `syncBossHpBar` / `pushBattleLog`
- 开战 URL：`battle.html?ep=N&skip=intro,preview,waves&from=game&wrong=错词`

## 入口

绘本地图节点「⚔️ 打怪」链到 `game.html?ep=N`（`map.js`）。不要改成每集一个 html。

## 测试

- `prj/engine/game-core.test.mjs` — 道具与门控
- `prj/engine/game-page.test.mjs` — 脚本顺序、存储键、无快卡
- `prj/engine/battle-page.test.mjs` — 对战页引入 game-core、战报/血条节点
- `prj/engine/battle-core.test.mjs` — 关卡/错词/星星

命令：`node --test prj/engine/game-core.test.mjs prj/engine/game-page.test.mjs prj/engine/battle-page.test.mjs prj/engine/battle-core.test.mjs`

全仓 `npm test` 基线只增不减。新文件用合同测试锁白名单，不要只靠手点。
