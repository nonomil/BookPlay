# 数据与打包

漏登记 = 真机静默缺文件。加集时这页比改 JS 更危险。

## 关卡从哪来

手写源（`git add -f`，勿删）：

- `content/game/cast.json` — 每集 hero / boss / 小怪 / NPC / 主题
- `content/game/maps.json` — 主题布局（出生点、怪点、NPC、Boss 点）
- `content/game/sprites.json`、`taunts.json`
- `content/dialogue_stories/epN.json` — 词库与开场台词

派生：

```
python -X utf8 prj/tools/build_game_levels.py --eps 1-7
```

写出 `content/game/levels/epN.json`（含 v2 `map` 字段）。只校验：`--check`。

## 一集运行时读什么

`game.js` boot：

- `../data/game/levels/epN.json`
- `../data/game/sprites.json`
- `../data/game/taunts.json`

主题背景：`content/assets/game-backgrounds/<theme>.jpg`（打包后在 data 树里）。

## 存储

只有两键：

- `bookplay_battle_progress_v1` — 含 `wrongWords` / `npcBonus` / `npcDone` / `stars`
- `bookplay_battle_collection_v1` — 妖怪图鉴

道具次数不落盘。新字段必须可选、向后兼容。不要新建 `bookplay_adv_*` 以外的游戏键。

## 打包三白名单

### 1. 阶段数据包（`--collections c01`）

`prj/tools/pack_datapack.py` 的 **`COMMON_FILES` 逐文件**。  
引用闭包扫不到「按固定路径 fetch 的 JSON」。`game/levels/epN.json`、`game/cast.json`、`sprites.json`、`taunts.json`、背景图、四向 GIF 漏一行 = zip 里没有。

`COMMON_DIRS` 已含 `game/`、`assets/game-sprites`、`assets/game-fx`、`assets/game-backgrounds`、`assets/game-pickups`，关卡 JSON 不必再逐文件加到 ep54。打主包：

```
python -X utf8 prj/tools/pack_datapack.py --collections c01,c02,c03,c04,c05,c06,c07 --published none --version 1.0.15 --out release/西游记数据包-1.0.15.zip
```

### 2. APK 内置数据

`pack_android.py --builtin` 走阶段包闭包。  
jttw-only 档案 **只放第 1 集**（`available_for_profile` → `episodes: [1]`）。  
开箱只能玩 ep1。2–54 靠导入**一份** `西游记数据包-{version}.zip`（`c01–c07`，含 `game/` 与 `assets/game-*` 整树）。不要再把多份 c01/c02 小包当主发布物。

### 3. APK 引擎

`pack_android.py` 的 **`ENGINE_FILES`**。  
`game-core.js` 必须在名单里，和 `game.html/js/css`、`battle*` 写在一起。新页面同样要登记。

`scripts/prepare-mobile.mjs` 会把整个 `prj/engine` 拷到 `dist/engine`，但 **Android 最终以 ENGINE_FILES 为准**，不要以为拷了目录就进包。

## 打包命令

西游记专用三端 debug APK（会自动 +1 versionPatch / versionCode）：

```
npm run android:build:jttw
```

产物：

- `release/storyhall-jttw-mobile-debug.apk`
- `release/storyhall-jttw-tv-debug.apk`
- `release/storyhall-jttw-handheld-debug.apk`

## `content/` 注意

`content/` 整体在 `.gitignore`。`content/game/` 是强制纳入的手写源。不要删、不要挪到未跟踪目录后指望 APK 还能读到。
