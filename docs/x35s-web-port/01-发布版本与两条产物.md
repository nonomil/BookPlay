# 01 发布版本与两条产物

同一套书戏源码，打出 **两条互不相通的安装形态**。

| | Android APK | X35S Port（当前入口） |
|---|---|---|
| 是什么 | 豆豆龙英语 Capacitor 壳 | 「西游记vs我的世界」HTML + retsurf |
| 命令 | `npm run android:build` | `python scripts/copy-x35s-jttw-launcher.py --install-card` |
| 产物 | `release/v1.0.17/apk/*.apk` | 卡 `ports/西游记vs我的世界.sh` + 文件夹 |
| 版本 | 1.0.17 / versionCode 22 | 启动层 2026-09-19 |
| 运行 | WebView | retsurf / Servo，640×480，无网 |
| 网页入口 | `android/.../assets/engine/` | `gamedata/index.html` → `engine/home.html` |

## 不要混用

- 不能把 APK 装到 X35S。
- 不能只拷文件夹：必须有 `ports/西游记vs我的世界.sh`。
- 不要用 `ports/bookplay` 当玩家入口（同一套网页的英文名）。
- **不要用 `ports/方块学园`。** 那是 blocklegend，不是这本书戏。
- 桌面 / APK **不含** 掌机启动层。`handheld-controls.js` 在 `prj/engine/`，掌机包拷进 `gamedata/engine/`。
