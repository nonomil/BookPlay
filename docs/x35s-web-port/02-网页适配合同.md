# 02 网页适配合同

真机是 **640×480、Servo、无触控依赖、无网**。适配不是把桌面页 `transform: scale` 假装缩小。

| 合同 | 落点 |
|---|---|
| 视口 640×480、30fps、GLES | `发布/西游记vs我的世界-x35s/config.toml` `[display]` |
| 按钮 ≥44px，禁止 backdrop-filter | `prj/engine/handheld.css` |
| 学习卡十字键选 / A 确定 / B 我不会 | `prj/engine/handheld-controls.js`（`data-app=bookplay`） |
| ABXY → F1–F4，右摇杆不当鼠标 | `x35s.gptk` |
| 默认无虚拟光标，L3 才开 | `config.toml` `[input]` + `bindings.toml` `l3 = "scroll"` |
| HTML/JS/ESM 可被 Servo 当网页 | `httpd.conf` MIME；httpd **必须** `-c` |
| 打开的是游戏页不是空白 tab | wget 成功后 `"$BIN" "$URL"` |
| 相对路径 + HTTP | `http://127.0.0.1:18787/`，禁止 `file://` |

## 必须遵守

1. **Canvas2D。** `webgl2 = false`。
2. **相对路径 + HTTP。**
3. **Servo 不支持当功能依赖：** `:has()`、`backdrop-filter`、系统 TTS、PointerLock、右摇杆鼠标。
4. **命中区 44px。**
5. **输入分层。** gptokeyb 只翻译成键盘；动作在 `handheld-controls.js` 的 `data-app=bookplay` 里解释。
6. **适配层只进移植包。** 不要把掌机启动脚本写进 APK。

## 不要改的

- 不要为掌机重写整套 `prj/engine/game.js`。
- 不要把启动器拷到 `ports/方块学园/`。
- 不要默认打开 retsurf 虚拟鼠标。
- 不要改 ROCKNIX `disk=`。

plainland 已验证：缺 MIME 时 Servo 把页面当二进制 → **白屏带鼠标**。见 [04](./04-空白页与日志.md)。
