## 仍空白时的顺序

1. 确认开的是「西游记vs我的世界」，不是 BookPlay，也不是方块学园。
2. `.sh` 和文件夹都在。
3. `log.txt` 有没有 `ready=1`。
4. 能看见绿页字 → MIME 已好，再点绘本馆 / 降妖记。仍白 → httpd/retsurf。
5. 默认光标关。点不到时按 **L3**。

APK 空白与此无关。
