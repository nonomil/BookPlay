# 03 从文件到上卡

书戏仓库没有 `npm run port:build`。掌机当前入口是 **西游记vs我的世界**（书戏网页）。

## 启动层

快照：`发布/西游记vs我的世界-x35s/`。

卡挂成 `L:` 或 `K:` 时：

```bash
npm run x35s:check
python -X utf8 scripts/copy-x35s-jttw-launcher.py --install-card
```

```text
发布/西游记vs我的世界-x35s/西游记vs我的世界.sh
  →  <盘>:\ports\西游记vs我的世界.sh

发布/西游记vs我的世界-x35s/inner-西游记vs我的世界.sh
  →  <盘>:\ports\西游记vs我的世界\西游记vs我的世界.sh
```

`.sh` 必须 Unix 换行（无 `\r`）。

启动器顺序：chmod 二进制 → busybox httpd `127.0.0.1:18787` **带 `-c httpd.conf`** → wget 探活 → gptokeyb → `retsurf "$URL"`。

## 游戏网页层

源在 `prj/engine/`。卡上是 `西游记vs我的世界/gamedata/engine/`。改完引擎再拷这一层，不要手改卡当唯一源。

## 本机先验收

```bash
python -X utf8 prj/tools/serve.py --port 8810
npm run x35s:demo
npm run x35s:check
```

打开 `http://127.0.0.1:4180/`。视口：44px 按钮、无 scale。学习卡：左右选、Enter/F1 确定、F2 我不会。模块：无 `?v=feel` 的 ESM 能加载。
