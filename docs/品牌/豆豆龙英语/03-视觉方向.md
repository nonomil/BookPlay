# 03 · 视觉方向

## 设计关键词

**圆、暖、亮、软** —— 不要冷淡、不要高级黑金、不要科技感。**豆豆必须是一眼能认出的"龙"**（有龙角、龙须、爪子、尾巴）。

## 主色板

| 颜色 | 色值 | 用途 |
|---|---|---|
| 豆豆绿（主色） | #58B368 | Logo 主色、按钮、背景块 |
| 奶油黄（辅色） | #FFD867 | 背景、高亮、贴纸 |
| 草莓橙（点缀） | #FF8A5C | CTA 按钮、徽章、小箭头 |
| 云朵白 | #FFFFFF | 卡片底色 |
| 可可棕（文字） | #5B4636 | 正文，避免纯黑太硬 |

## Logo 方向（给设计师 3 选 1）

1. **龙头 + 气泡**：豆豆的圆脸（带龙角+龙须）+ 一个英语对话气泡，气泡里一个 "Hi!"——最直接，龙形特征必须保留
2. **豆豆抱单词卡**：豆豆（带角带爪）抱着写有字母 D 的单词卡，卡是奶油黄——可爱且带"学"的意思
3. **豆豆 + 耳机**：豆豆戴耳机张嘴说，体现"听说"——跟产品核心（听+说）最贴

要求：

- 圆角优先，禁止尖角；龙角和龙须不可省略（那是"龙"的身份证）
- 图标 512px 圆形底（应用商店要求），绿底可加白色豆豆脸
- 小尺寸（16px）也能认出是"一张带角的圆脸"

## 字体

- **标题**：圆体/卡通体（如站酷快乐体、得意黑——注意商用授权），禁止用书法体
- **正文**：无衬线（思源黑体/阿里巴巴普惠体），字号大、行距宽
- **英文示范句**：等宽圆体或手写感字体，突出"句子"的存在感

## 界面风格（产品内）

- 圆角卡片（16–24px 圆角），大按钮（至少 56px 高，孩子手指好点）
- 句子区：白底卡片 + 奶油黄高亮关键词
- 跟读按钮：草莓橙大圆形，豆豆在旁边张嘴
- 动效：豆豆有小弹跳动效；禁止生硬切换
- 背景：浅绿到奶黄的柔和渐变，不要纯白

## 吉祥物使用规范

- 豆豆头（含角+须）+ 文字（作为灯箱/角标/按钮装饰）；全身豆豆（开场动画、结尾、庆祝）
- 豆豆不得用于：哭泣、生气、翻白眼等负面表情
- 豆豆夹克/帽子等变装可以，但必须保留：龙角、龙须、绿、大眼睛——**任何时候不能画成无角的圆球**

## 封面/截图方向（应用商店）

截图 6 张建议（宝妈视角）：

1. 主界面：豆豆龙招手 + 一集动画大卡片

5. 测验页：豆豆问问题 + 三个大选项
