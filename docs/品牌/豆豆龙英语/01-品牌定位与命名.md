# 01 · 品牌定位与命名

## 产品的本质（先说清楚）

这不是"书"，也不是"游戏"。它是一个**英语动画学习产品**：

- 每集是一个 1–3 分钟的动画小剧场（对话冒险）
- 关键句子有英文原声 + 中文对照（随时听）
- 单词有原声截取、释义有中文音频
- 看完有测验，句子能跟读

所以名字里不能有"书""戏""play"这类字，误导用户。

## 为什么叫「豆豆龙英语」

| 要素 | 理由 |
|---|---|
| 豆豆 | 叠字、可爱，是宝妈对孩子说话的语气（"豆豆，来学英语"）；也好写、好打字 |
| 龙 | 孩子喜欢的形象；中国家长认可"龙"的吉祥感；没有负面联想 |
| 英语 | 直接说清楚学科——宝妈搜索"英语"是最强的购买信号 |
| 整体 | 三个词都是高频字，孩子说得出口，妈妈记得住，搜得到 |

对比之前候选（泡泡/咚咚/丫丫/皮皮/豆豆）：**豆豆龙** 有完整形象感（一个名字=一个角色），其它只有语气感。有角色就能做吉祥物、动画、贴纸、IP。

## 为什么不用好听的"雅"名字

我们讨论过 StoryEcho、声临其境这类名字——太文绉绉：

- 宝妈没时间解读你的名字
- 孩子念不出来
- 应用商店里搜"英语"搜不到你

豆豆龙英语的路线是：**名字就是品类词 + 形象词**，跟"斑马英语""洪恩英语"一个路数，一看就懂。

## 品牌定位一句话

> **看动画小剧场，学得会、说得出的英语启蒙。**

## 目标用户

- **付费决策人**：宝妈（3–10 岁孩子），关心"孩子爱不爱看""有没有效果""要不要陪"
- **使用者**：孩子，关心"好看不好看""好不好玩"
- **反感点**：枯燥刷题、家长必须全程陪着、上来就背单词

## 价值主张（对宝妈说人话）

1. **孩子自己愿意学** —— 动画小剧场，不用催
2. **开口有用** —— 学完的句子能跟读、能测验，不是光看
3. **家长省事** —— 一句英文配一句中文，听不懂也有兜底
4. **看得见的进步** —— 每集都有测验和跟读记录

## 差异化位置

| 产品类型 | 给孩子的 | 我们的位置 |
|---|---|---|
| 儿歌/磨耳朵 | 只听不学 | 有剧情、有句子目标 |
| 绘本 App | 看图识字 | 动画 + 原声 + 跟读 |
| 外教课 | 真人互动 | 便宜、每天一集、不用约课 |
| 刷题软件 | 应试 | 兴趣先行，句子会说话 |

**一句话差异化：别人让孩子"看"，我们让孩子"看完会说"。**

## 命名相关的坑（必须记住）

- **豆豆龙** 这个名字大概率在应用商店/公众号有同名或近似（"豆豆龙"曾是常见动画系名），上架前必须查重——见 `08-落地任务清单.md`
- **同名歌曲**：《豆豆龙》是范晓萱演唱的《龙猫》主题曲中文版，已经有版权且形象关联龙猫；我们**只借名字的记忆点，不碰原曲、不碰龙猫形象**，主题曲必须原创——见 `09-品牌主题曲.md`
- 英文名备选（Doudou / DoudouLong / Dodo / DD English）**优先选短的好记的**，确认后所有文案统一，不许混用
- 正式对外之前，中文名保持「豆豆龙英语」完整四字，不要拆开用"豆豆龙"单独做品牌，降低撞名风险（除非查重后确认可独占）
