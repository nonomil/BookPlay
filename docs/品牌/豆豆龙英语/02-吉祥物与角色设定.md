# 02 · 吉祥物与角色设定

## 一句话

**一条小绿龙「豆豆」(Doudou the Dragon)** —— 圆乎乎的东方小龙，英语说得比中文慢一点，但永远想学。

## 形象设定（给设计/动画师）

**豆豆是一条龙，必须看得出一眼是"龙"：**

- **物种**：东方幼龙造型——有龙角、有龙须、有尾巴、有爪爪
  - 头部：圆脸 + 一对短短的小龙角（必画，龙的标志）
  - 龙须：两撇短短的须子（可做成小卷须，萌感来源）
  - 身体：一条完整的卡通东方长龙，细长身子能盘成圈或拉成 S 形，短手短脚 + 小爪
  - 尾巴：长尾收成小豆豆尖
  - 不要翅膀（东方长龙，不是西方幼龙）
- **颜色**：豆豆绿（#58B368）为主，肚皮奶油黄（#FFD867），腮红草莓橙
- **鳞片**：肚皮/尾巴上有淡淡的鳞片纹（Q 版要"有鳞片感但别写实"）
- **体型**：一条龙，头圆身子长；图标可盘成圈。不许画成圆球/猫形/兔形/西方短龙
- **标志物**：脖子上挂一个小耳机（听音色的象征）
- **动作习惯**：说话时小尾巴一翘一翘；听到英文会竖耳朵（龙角还会跟着一抖）；跟读时拍爪打拍子

## 性格

- **勇敢**：敢开口，不怕说错（核心人设——鼓励孩子开口）
- **好奇**：每集开头都会问 "What's this?"
- **小倔强**：说错了自己会重来一遍 "Let me try again!"
- **慢热但爱学**：中文流利、英文慢慢来，跟孩子一样

## 口头禅（双语）

| 中文 | 英文 | 场景 |
|---|---|---|
| 听！ | Listen! | 句子音频播放前 |
| 跟我读！ | Repeat after me! | 跟读环节 |
| 我也会说！ | I can say it! | 孩子跟读成功后豆豆庆祝 |
| 再试一次！ | Try again! | 答错鼓励 |
| 太棒啦！ | Awesome! | 答对庆祝 |
| 今天学了什么？ | What did we learn? | 每集结尾复习 |

## 角色分工（产品内怎么用）

- **开场**：每集动画前豆豆出镜 3 秒，说 "今天我们学……"
- **跟读**：豆豆作为示范声（示范英文句子）
- **测验**：答对豆豆蹦跳鼓掌；答错豆豆挠头（不批评）
- **激励**：连续答对 3 题，豆豆送你"小豆豆徽章"
- **再见**：每集结束 "Bye bye, see you next time!"

## 声音设定

- 音色：元气、偏高、语速适中（参考儿童节目主持感），中文清晰、英文标准
- 语速比成人慢 10–15%，但不要拖腔
- 永远正面、不阴阳怪气，不能有"惩罚感"
