# 07 · 产品内文案替换方案

> 目标：**用户看得见的文字全部换成豆豆龙英语**；代码、目录、仓库名不动。

## 替换范围分级

| 级别 | 位置 | 处理 |
|---|---|---|
| A（必改） | App 显示名、启动页、首页标题、关于页 | 对外名称改为"豆豆龙英语" |
| A（必改） | 版本说明.md（release 里） | 抬头/品牌描述改"豆豆龙英语" |
| A（必改） | 分享文案、更新弹窗 | 改为豆豆龙英语 |
| B（建议） | 数据包文件名「故事馆数据包-0.1.x.zip」 | 从 v0.2.0 起改为「豆豆龙数据包-vX.Y.Z.zip」（改文件名需同步改脚本与发布检查，见下） |
| B（建议） | 内部脚本注释/日志 | 不强制，但新代码统一用新名 |
| C（不动） | 目录名 docs/需求/*BookPlay书戏--需求.md、仓库名、包名 | 保留（历史文档不追溯改名，避免 git 混乱） |

## 具体替换对照表

| 旧文案 | 新文案 |
|---|---|
| BookPlay | 豆豆龙英语 / Doudou English |
| 书戏 / 书游 | （对外全部删除，不单独使用） |
| 故事馆（作为产品名） | 豆豆龙英语 |
| "故事馆数据包-0.1.x.zip" | "豆豆龙数据包-vX.Y.Z.zip"（v0.2.0 起） |
| 关于页"版本说明" | 正常保留，但内容品牌名替换 |

## 实施步骤（给开发者）

1. **搜索范围**：`prj/`、`content/`、`scripts/`、`android/` 里所有用户可触达字符串
   - 搜索关键词：`BookPlay`、`书戏`、`书游`、`故事馆`
   - 排除：`docs/` 历史文档、`.git`、`node_modules`、`release/` 已发布产物
2. **修改点**：
   - Android `strings.xml` / app label → `豆豆龙英语`
   - 启动页/首页 header 文案
   - `版本说明.md` 模板（在 `prj/tools/` 里找生成处）
   - 分享/弹窗文案
3. **数据包改名**（v0.2.0 做）：改 `make_release.py` / `finish_*_pack.py` 中的 zip 命名，同步改打包检查逻辑，别只改一半导致产物名不一致。
4. **验证**：
   - 打包后解压 zip，确认无"故事馆/书戏/BookPlay"字样出现在用户可见文件（apk 内 strings、版本说明覆盖内容）
   - 启动 App 截图确认显示名

## 保留英文品牌名的建议

- 对外统一：**Doudou English**（暂定；提交前确认，别在文案里混用 Doudou/DoudouLong/Dodo）
- 吉祥物：**豆豆（Doudou）**

## 注意事项

- 不要动数据库内的故事内容字段（内容是西游记等故事本身，与品牌无关）
- 版本号 0.1.x 已发布的不回改；从下一个发布开始执行 A 级替换
- 一切以"用户能看到的"为准，内部代码里残留旧名不影响上线
