## 一句话

**豆豆龙英语 = 看动画小剧场，听句子、跟读、开口说英语。**

面向宝妈和孩子：每集一两分钟的小动画，句子有原声音频，孩子听完就能跟着说。

## 核心决策（先记住这几点）

1. **品牌名**：豆豆龙英语（中文）/ Doudou English（英文使用名）
2. **吉祥物**：一条小绿龙「豆豆」——必须带龙角、龙须、爪、尾巴，一眼是"龙"，爱说 "Listen! / I can say it!"
3. **主 Slogan**：每天一小集，句子开口说
4. **默认配色**：豆豆绿（主色 #58B368）+ 奶油黄（辅色）+ 草莓橙（点缀）
5. **面向用户**：3–10 岁孩子的宝妈（付费决策人），孩子（使用者）
6. **主题曲**：原创《豆豆龙之歌》，不用现成《豆豆龙》（那是龙猫主题曲中文版，有版权）
