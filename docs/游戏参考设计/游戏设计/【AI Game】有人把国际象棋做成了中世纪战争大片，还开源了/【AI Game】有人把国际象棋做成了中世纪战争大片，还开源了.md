# 【AI Game】有人把国际象棋做成了中世纪战争大片，还开源了

> 作者: 辕记 | 平台: 微信公众号 | 日期: 2026-08-06 01:06 | 原文: https://mp.weixin.qq.com/s/yAzHC28kT_RKAMREleZ-Yw

> **摘要**: 有人把原本安静的国际象棋，直接做成了中世纪战争大片。

1小时AI的作品，我是不信的。 有人把原本安静的国际象棋，直接做成了中世纪战争大片。
 骑士会冲锋，法师会远程施法，士兵吃子时不是“消失”，而是真的冲过去打。

它把普通国际象棋做成了中世纪3D战场。棋子不再滑动，而是骑士冲锋、法师远程施法、士兵挥剑厮杀；吃子时还有镜头推进、震屏、火焰和死亡动画。

游戏支持欧洲王国、太阳帝国、拿破仑军团三套阵营，也能开启 AI vs AI，让两台电脑自动对战。最夸张的是，它直接运行在浏览器里，不要后端，也不用注册。

喜欢3D游戏、国际象棋，或者正想找开源项目练手的，可以直接抄作业。
