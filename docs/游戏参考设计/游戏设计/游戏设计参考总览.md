# 游戏设计参考总览

这是一组面向儿童、学习和亲子场景的游戏设计案例。重点不是照搬某个视觉风格，而是观察学习目标如何进入玩法、反馈、关卡和叙事。

## 先看结论

- 学习目标要进入核心循环：答题、拼读、听读或表达应当改变游戏状态，而不是只作为“答对才能前进”的外挂题目。
- 即时反馈比单纯积分更重要：音效、动画、角色反应、地图变化和可见进度共同告诉孩子“我做了什么、结果怎样”。
- 短回合、低门槛、可重复：贪吃蛇、坦克、乘法闯关和单词小游戏都把一次练习压缩成几十秒到几分钟，适合反复游玩。
- 长期动机来自成长与内容解锁：RPG 等级、错题复习、皮肤、植物养成、排行榜和故事推进，承担的是持续回访，不应替代学习本身。
- 儿童项目要保留创造权：猫猫村庄和 8 岁儿童项目都体现了 AI 做实现助手，孩子保留主题、角色、玩法和选择权。

## 参考矩阵

| 参考方向 | 可观察机制 | 适合借鉴的部分 |
|---|---|---|
| 英语学习 RPG / 像素风 | 地图、任务、经验、等级、语法塔、每日任务 | 把学习内容组织成冒险路径和阶段目标 |
| 贪吃蛇 / 坦克记词 | 移动、收集、射击、播报、即时得分 | 把重复记忆变成高频短回合动作 |
| 乘法与拼音工具 | 题目挑战、错题本、闯关、规则训练 | 让练习、复习和难度提升形成闭环 |
| 数感星球 / 作业工作台 | 闯关赛道、资源、植物、奖励、打卡 | 把日常任务转化为可见的成长状态 |
| 猫猫村庄 / 互动绘本 | 探索、角色、对话、收集、故事目标 | 给学习任务增加情境和情绪记忆 |
| 侦探游戏 / 教育桌游 | 线索、观察、推理、决策后果 | 让玩家的判断本身承载学习，而不是贴题目 |
| 排行榜与复盘 | 个人最佳、历史成绩、错题重练 | 用自我进步替代单纯外部竞争 |

## 设计检查清单

### 学习目标

- 玩家在一局中具体练习什么能力？
- 玩家做出的选择是否与这个能力直接相关？
- 去掉学习内容后，核心玩法是否会失去意义？

### 核心循环

`发现任务 → 做出选择 → 获得即时反馈 → 改变状态 → 解锁下一步`

每个环节都应该能回答：孩子为什么继续玩？下一次要变得更好在哪里？

### 难度与复习

- 是否有从模仿到独立完成的渐进难度？
- 错题是否能快速回到具体知识点，而不是只显示扣分？
- 是否支持短回合重试，避免一次失败终止兴趣？

### 反馈与奖励

- 反馈是否说明“哪里做对/做错”，而不只是加分或扣分？
- 奖励是否服务于下一次学习，例如解锁场景、角色或新挑战？
- 是否有个人成长记录，让孩子看到自己变好了？

### 儿童体验

- 首次进入是否能在几十秒内完成一次成功操作？
- 字体、按钮、对比度和触控区域是否适合儿童？
- AI 是否辅助实现，而不是替孩子决定全部内容？
