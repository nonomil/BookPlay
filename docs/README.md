## 文档维护规则

- 当前行为以运行代码、验证脚本和本索引列出的权威文档为准。
- 新的架构决策先更新 `项目架构与优化路线.md`，再修改实现。
- 历史文档保留原始决策语境，不做大规模追溯改写；发现失效内容时在索引或文首标注。
- 命令默认从仓库根目录执行，路径统一写成 `prj/...`、`content/...`、`data/...`。
- 生成数据、音视频和图片不写入 Git 历史。
