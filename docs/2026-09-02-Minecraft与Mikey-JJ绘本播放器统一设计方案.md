# Minecraft 与 Mikey & JJ 绘本播放器统一设计方案

> 日期：2026-09-02  
> 状态：可实施规格（实施前仍需通过 `ui=unified-v3` 预览验收）  
> 适用范围：`series=minecraft`、`series=mikey-jj`  
> 参考但不照搬：西游记主播放器 `engine/wala.html?ep=1`

## 1. 结论

两类漫画绘本不应复制西游记的画面覆盖方式，但应复用西游记已经验证过的学习流程与交互骨架。

最终产品结构定义为：

```text
统一学习骨架
├─ 顶栏：目录 / 标题 / 剧情-精学 / 播放 / 生词本 / 设置
├─ 播放状态：句级播放、逐词点读、暂停恢复、进度
├─ 学习栏：当前句、中文、重点词、反馈、句导航
├─ 阅读结束：词卡复习、全屏小测、错题回看
└─ 平台适配：桌面、手机/平板、电视/遥控器

差异化画布
├─ Minecraft：完整跨页插图 + 右侧学习栏，不在原图上叠字幕或词卡
└─ Mikey & JJ：完整漫画页 + 播放时原气泡细描边，不复制气泡文字
```

统一的是控制位置、学习步骤、数据状态和反馈方式；差异化的是画面主题、说话人表达和气泡定位。

## 2. 实际基线与约束

### 2.1 当前消费者

| 消费者 | URL | 主要文件 |
|---|---|---|
| Minecraft | `engine/storybook.html?series=minecraft&book=1` | `storybook.html`、`storybook.js`、`storybook.css` |
| Mikey & JJ | `engine/storybook.html?series=mikey-jj&book=1` | 同一套 storybook 消费者，使用 `body.sb-mj` 主题 |
| 西游记主播放器 | `engine/wala.html?ep=1` | `wala.html`、`wala.js`、`wala.css` |

### 2.2 内容数据审计

| 能力 | Minecraft | Mikey & JJ | 设计影响 |
|---|---:|---:|---|
| 已发布书数 | 5 | 10 | 两套目录必须继续复用同一播放器入口 |
| 页面数 | 75 | 100 | 页面必须懒加载、保持固定画面比例 |
| 原子句数 | 367 | 458 | 句导航是主导航，不应只显示页码 |
| 平均每页句数 | 4.9 | 4.6 | 一页对应多次播放，不可把整页当一个音频单元 |
| 单页最多句数 | 8 | 11 | 必须显示“第 N 句 / 共 M 句” |
| 有整句中文 | 0 / 367 | 458 / 458 | Minecraft 中文是独立数据任务，UI 不能假装已有 |
| 有词级时间 | 0 / 367 | 458 / 458 | Mikey 可精确卡拉 OK；Minecraft 当前只能句级可靠同步 |
| 有说话人 | 0 / 367 | 458 / 458 | 说话人标签只在 Mikey 强制显示 |
| 有气泡坐标 | 0 / 367 | 458 / 458 | 原气泡定位只用于 Mikey |
| 有句级音频 | 305 / 367 | 457 / 458 | 缺音频必须诚实降级，不能使用上一句音频 |

Minecraft 的 62 个无音频句主要来自整本无可信音频的 book 3，另有 book 4 的明确缺失句。Mikey & JJ 的已知无音频句为 book 6 第 9 页 `b6-p09-s01`（`KABOOM! The nuclear blast fills the sky.`）。

### 2.3 为什么不能照搬西游记画面

西游记主播放器的媒体画面是视频帧/场景图，画面本身没有需要保留的整页英文排版，因此可以在画面上放字幕卡和左右生词卡。

Minecraft 与 Mikey & JJ 的原图本身就是学习内容：

- Minecraft 跨页里包含正文、人物与连续动作。
- Mikey & JJ 一页包含多个分镜、多个气泡、阅读顺序和气泡尾巴。
- 大字幕卡、侧边词卡或遮罩会覆盖原有文字和分镜线索。
- 自动裁切会破坏整页阅读顺序；用户已明确否定大悬浮窗和遮罩式聚焦。

因此默认必须保留整页，画面上的动态元素只允许：进度小标签、Mikey 气泡细描边、系统必要的首次播放授权提示（但该提示应移出画面）。

## 3. 产品目标与非目标

### 3.1 目标

1. 两套绘本使用同一套顶栏、播放状态、学习栏和练习出口。
2. 每个英文单词均可点击/键盘点读；普通词只读英文，重点词按英文后中文播放。
3. 剧情模式适合连续听；精学模式适合逐句停、点词、看中文和重点词。
4. Mikey 播放时能看出谁在说话、原气泡在哪里，但不覆盖漫画文字。
5. Minecraft 保留完整跨页，并在数据允许时提供整句中文和精确词级同步。
6. 桌面、手机/平板、电视都不出现横向溢出、滚动陷阱或焦点丢失。
7. 小测验和巩固练习使用独立全屏阶段，不挤在右侧学习栏。

### 3.2 非目标

- 不重新裁切全部 PDF 页面。
- 不在网页运行生图或调用外部图像 API。
- 不伪造 Minecraft 说话人、气泡位置、中文或词级时间。
- 不恢复已否定的焦点遮罩、大浮窗、复制气泡文字。
- 不把西游记的金币、装备或奖励系统同时塞入本轮播放器改造。
- 不在第一阶段重写为 React/Vue；继续使用原生 HTML/CSS/JavaScript。

## 4. 信息架构与模式状态机

### 4.1 三阶段学习流程

```text
进入书籍
  ├─ 剧情模式：用户首次点击解锁声音 → 连续播放当前页各句 → 自动翻页
  └─ 精学模式：播放本句 → 本句结束停住 → 点词/看中文/收词 → 手动下一句

最后一句完成
  → 重点词快速复习
  → 全屏小测验
  → 错题/生词回看
  → 下一本或返回目录
```

### 4.2 剧情模式

- 顶栏模式按钮为“剧情”。
- 学习栏只显示当前英文句、可选整句中文、播放状态和句进度。
- 重点词卡默认折叠，点击句内重点词仍可点读和收入生词本。
- 在一次有效用户手势解锁音频后，下一句和下一页自动播放。
- 缺失音频时停住并显示“本句无可信原音”，不得自动跳过后伪装连续。

### 4.3 精学模式

- 顶栏模式按钮为“精学”。
- 每句自然结束后停住，不自动进入下一句。
- 显示整句中文、重点词卡、加入生词本反馈和句导航。
- 点击普通词：暂停主句 → 英文点读 → 回到原时间继续（仅当点读前正在播放）。
- 点击重点词：暂停主句 → 英文 → 中文 → 回到原时间继续。
- 模式切换保持当前页和当前句，不重置学习进度。

### 4.4 模式存档

使用独立键保存显示偏好，不污染阅读完成进度：

```json
{
  "key": "bookplay_storybook_preferences_v1",
  "value": {
    "minecraft": {"mode": "study", "translation": "show"},
    "mikey-jj": {"mode": "story", "translation": "show"}
  }
}
```

旧存档无此字段时安全使用默认值。损坏 JSON 回退默认值，不阻塞读书。

## 5. 统一桌面布局

### 5.1 结构

```text
┌ 目录  书名       [剧情] [精学]      播放  生词本  设置 ┐
├──────────────────────────────┬────────────────────┤
│                              │ 第2页 · 第1/3句     │
│                              │ [MIKEY / JJ]        │
│       完整原书/漫画页面       │ 英文逐词点读         │
│                              │ 中文整句             │
│ Mikey 播放时仅描边原气泡      │ 本句重点词（单列）    │
│                              │ 状态反馈             │
│                              │ 上一句  进度  下一句 │
└──────────────────────────────┴────────────────────┘
```

### 5.2 尺寸

- 顶栏：桌面 60–68px，电视 78px 以上。
- 学习栏：`clamp(380px, 32vw, 480px)`；媒体区使用剩余宽度。
- 1024–1279px：学习栏允许缩到 340–400px，重点词仍保持单列。
- 媒体区：`object-fit: contain`，不裁切；黑边/背景属于舞台，不属于图片。
- 学习栏内部水平 padding 20–24px，模块间距 16px。
- 句子英文：桌面 22–28px；电视 28–36px；手机 20–24px。
- 中文整句：英文的约 72–78%，颜色对比不低于 4.5:1。
- 交互目标：手机至少 44×44px；电视至少 64px。

### 5.3 顶栏顺序

从左到右固定为：

1. 目录/返回系列。
2. 当前书名，超长时单行省略。
3. 剧情/精学分段按钮。
4. 播放/暂停本句。
5. 生词本。
6. 设置（翻译显示、语速；P1 不加入更多复杂开关）。

手机端允许顶栏两行：第一行返回与书名，第二行模式和播放控制。不能通过缩小到低于 44px 来塞在一行。

## 6. 学习栏信息层级

### 6.1 固定顺序

1. 单元头：`第 2 页 · 第 1 / 3 句`。
2. 说话人：仅 Mikey 显示；Minecraft 不显示虚构说话人。
3. 当前英文句：每个词可点，保持原标点。
4. 整句中文：独立一行，带“中文”视觉标签或分隔线。
5. 重点词：0 个时整个区域隐藏；1–4 个时单列显示。
6. 非阻塞反馈：点读、加入生词本、缺音频等。
7. 句导航：固定在学习栏底部或移动端内容流底部的 sticky 区域。

### 6.2 英文与中文

- 默认不在每一个英文单词下面显示中文。
- 整句中文放在英文句下方，避免用户把逐词释义误当成句子翻译。
- 句内重点词使用下划线/底色标识，但颜色不是唯一交互信号；鼠标和键盘均有明确焦点框。
- “EN+中”若后续开启，只给有可靠词义的重点词显示小注释，普通功能词不随意翻译。

### 6.3 重点词卡

学习栏宽度不足以使用当前双列卡片。P1 改为单列紧凑卡：

```text
adventure  /ədˈventʃər/  N                 ▶
冒险
例句：Emmy and Birch were ready for adventure!
```

规则：

- 第一行 English + IPA + POS + 点读按钮。
- 第二行中文释义。
- 第三行为当前真实例句；窄屏最多两行，提供展开而不是硬截断。
- 卡片整体可点击，但点读按钮保留可理解的 `aria-label`。
- 0 个重点词时不显示空卡和“本句没有重点词”的长期占位。

### 6.4 反馈

- “已加入生词本”显示 1.5–2.5 秒后淡出，或在卡片内显示持久勾选。
- 缺音频、网络/本地 TTS 失败属于错误状态，必须保留到下一次操作并通过 `aria-live` 宣告。
- 不能用长期文本占据学习栏中央，造成像正文一样的视觉权重。

## 7. Minecraft 专属设计

### 7.1 画面

- 完整跨页始终可见；不自动裁切，不遮罩其它区域。
- 支持用户主动进入“查看大图”：桌面打开无覆盖文字的全屏查看，移动端允许双指缩放。
- 画面上只保留小型页进度；进度不得盖住原书正文。
- 没有可靠 OCR 坐标前，不显示句子定位框。

### 7.2 音频与同步

- 句级音频是可信主同步单位。
- 当前按句长比例推算逐词高亮只能视为过渡，不得在文档或 UI 中声称“精确词级对齐”。
- P1 可以保留柔和的播放推进效果；P1 数据任务完成后再启用硬边界的 `active/done/wait` 词级状态。
- book 3 没有可信原音：播放按钮禁用并明确显示“本书暂无原音”；逐词 TTS 仍可用。
- book 4 明确缺失句：只禁用该句的原音按钮，不清除其它句音频。

### 7.3 中文补全

Minecraft 的 367 句目前都没有 `zh`。实施必须：

1. 给每句增加整句中文，保持角色名、Minecraft 专有名词和标点一致。
2. 不把重点词中文机械拼接成整句翻译。
3. 每本抽查第一页、剧情转折页、最后一页；专名建立统一表。
4. 自动测试要求 367/367 非空，且没有明显占位符、HTML 或上一句复制。

### 7.4 视觉主题

- 深森林背景、暖白正文、草绿色交互色继续保留。
- 重点词卡由双列改为单列；边框、按钮和高亮遵守统一尺寸。
- UI 正文优先使用本地可用的 `Lexend, "Noto Sans SC", system-ui, sans-serif`；若未打包 Lexend，则不得依赖联网字体。
- Minecraft 像素感只用于边框、进度和少量装饰，不能降低正文可读性。

## 8. Mikey & JJ 专属设计

### 8.1 说话人

- 学习栏显示说话人标签：Mikey、JJ、旁白、系统声。
- 颜色映射固定，并同时显示文字：Mikey 红、JJ 绿、旁白黄褐、系统灰。
- 颜色不能是唯一身份线索。

### 8.2 原气泡定位器

播放句子或点读词时，允许在原漫画气泡外显示透明定位器：

- 2–3px 描边，外扩 4–6px。
- 无填充、不模糊、不复制英文或中文。
- `pointer-events: none`，不阻断图片缩放。
- 只在句子/词音频实际播放时出现；暂停立即隐藏，自然结束可延迟 300–500ms 淡出。
- 尊重 `prefers-reduced-motion`，减少动态时只切换可见性，不脉冲。

### 8.3 含 `object-fit: contain` 的坐标换算

现有实现直接使用 `<img>` 元素矩形，会在图片出现上下/左右留白时偏移。必须先计算图片实际显示矩形：

```js
const scale = Math.min(boxWidth / naturalWidth, boxHeight / naturalHeight);
const width = naturalWidth * scale;
const height = naturalHeight * scale;
const left = boxLeft + (boxWidth - width) / 2;
const top = boxTop + (boxHeight - height) / 2;

const locator = {
  left: left + bubble.x * width,
  top: top + bubble.y * height,
  width: bubble.w * width,
  height: bubble.h * height,
};
```

该计算必须成为纯函数并覆盖横向留白、纵向留白、无自然尺寸三种单元测试。

### 8.4 首次播放授权

- 浏览器阻止自动播放时，提示移动到学习栏播放区，文案为“点击开始有声阅读”。
- 不再把授权按钮放在漫画中央。
- 一次用户手势解锁后，剧情模式可自动播放后续句；精学模式仍按句停住。

### 8.5 已知无音频句

`book6/page9/b6-p09-s01` 无句级音频时：

- 保留文本、中文、说话人与气泡定位数据。
- 本句原音按钮禁用，显示原因。
- 普通词/重点词 TTS 可继续使用。
- 不播放上一句或下一句音频作为替代。

### 8.6 视觉主题

- 白纸/奶油底、黑色漫画描边、黄色和草绿色继续保留。
- 硬阴影只用于按钮和重点词卡，不用于长段正文。
- 学习栏句子使用高可读圆体/系统无衬线，避免大面积 Comic 字体影响识读。

## 9. 单词点读与播放合同

### 9.1 DOM 合同

每个词：

```html
<span
  class="sb-sentence-word"
  role="button"
  tabindex="0"
  data-speak="ready"
  data-zh=""
  aria-label="朗读 ready"
>ready</span>
```

重点词的 `data-zh` 使用真实 glossary 中文；普通词必须为空。

### 9.2 行为合同

| 场景 | 行为 |
|---|---|
| 普通词点击 | 英文 TTS，不能额外播放中文 |
| 重点词点击 | 英文 TTS → 中文 TTS → 结束 |
| 主句正在播放 | 暂停并记录时间；点读完成后恢复 |
| 主句未播放 | 点读完成后保持暂停 |
| 连续快速点两个词 | 后一次取消前一次，不能串入前一个词的中文 |
| Enter/Space | 与鼠标点击一致，且不触发全局“下一句”快捷键 |
| 页面/句子变化 | 取消正在播放的点读，清除旧高亮 |

### 9.3 同步精度

- Mikey：使用 sentence-local `words[].start_ms/end_ms` 精确驱动。
- Minecraft 未补数据前：句子整体为播放态，逐词推进使用弱视觉，不宣称精确。
- Minecraft 补齐词级时间后：切换到与 Mikey 相同的精确驱动。
- 任何 `word.end_ms` 不得超过句段实际时长；失败时修数据，不在播放器里钳制伪装通过。

## 10. 巩固与全屏小测

### 10.1 阅读结束流程

1. 显示本书重点词快速复习，最多先展示 6 个，其余可展开。
2. 点击“开始小测”进入全屏，不保留右侧栏。
3. 每次只显示一道题；答题后给文字和图形反馈。
4. 完成后显示正确数、错题词和“再听一次/下一本/返回目录”。

### 10.2 题型

Minecraft 首版：

- 看英文选中文。
- 听单词选词义。
- 句子缺词选择。
- 有可靠题图时才做看图选词，不临时生图填充。

Mikey & JJ 首版：

- 谁说了这句话（Mikey/JJ/旁白）。
- 听句子选中文。
- 气泡句排序。
- 重点词义选择。

### 10.3 约束

- 测验不出现在右侧栏滚动区域。
- 选项触控目标至少 44px，电视至少 64px。
- 正误不能只靠红绿；同时显示符号和文字。
- 缺少可信题目数据时减少题数，不生成污染干扰项。

## 11. 响应式与电视

### 11.1 手机（320–599px）

- 顶栏两行；标题截断，模式按钮和播放保持可见。
- 页面图在上，学习栏在下，全部属于正常文档流。
- 图片最大高度约 `56svh`；不让学习栏变成图片内部浮层。
- 句导航可 sticky 在底部，但必须预留等高 padding，不覆盖内容。
- 重点词单列；无横向滚动。

### 11.2 平板（600–899px）

- 竖屏采用上下结构。
- 横屏在宽度允许时进入窄侧栏结构；学习栏不低于 340px。
- 图片支持用户主动放大，不自动裁切。

### 11.3 桌面（900px 以上）

- 媒体 + 学习栏双列。
- 学习栏内部允许纵向滚动，句导航保持可达；不能产生页面和学习栏双重滚动陷阱。
- 1440px 以上媒体约 68–72%，学习栏约 28–32%。

### 11.4 电视（1000px 以上横屏）

- 复用 `tv.css` 的安全边距和 64px 控件尺寸。
- DOM 焦点顺序：目录 → 模式 → 播放 → 生词本 → 当前句词 → 重点词 → 上/下一句。
- 当前句 28–36px；中文 22–28px。
- 遥控器箭头不能把焦点困在学习栏滚动容器。
- Mikey 气泡定位器不获取焦点。

## 12. 可访问性与视觉质量门

- 正文对比度至少 4.5:1；关键控制尽量达到 7:1。
- 所有可点击词、卡片和按钮有可见焦点。
- 点击目标移动端至少 44×44px，相邻目标至少 8px 间距。
- 不依赖 hover 触发核心功能。
- 不用颜色单独表达说话人、播放态、正确/错误。
- 图片 `alt` 至少包含书名和页码；气泡定位器对屏幕阅读器隐藏。
- `aria-live` 只宣告必要反馈，避免逐词高亮持续打断。
- 所有动画遵守 `prefers-reduced-motion`。
- 不使用 emoji 作为正式控制图标；统一使用项目 SVG 图标或纯文字按钮。

## 13. 技术结构

### 13.1 预览隔离

### 13.3 系列能力对象

播放器不能通过猜字段决定 UI。加载 book 后构建：

```js
{

  hasSpeaker: true,
  hasBubbleLocator: true,
  hasExactWordTiming: true,

```

Minecraft 在数据补齐前相应能力为 false；数据任务完成后按实际字段启用。

## 15. 验收矩阵

### 15.1 功能

- 剧情/精学切换不丢当前句。
- 句内每个词可点击、Enter、Space 点读。
- 普通词只播放英文；重点词播放英文后中文。
- 播放中点词能暂停并恢复；快速连续点词没有竞态串音。
- 句/页切换取消旧点读和旧高亮。
- 无重点词时不显示空区域。
- 无音频时不复用上一句音频。
- 小测验全屏且可退出/完成。

### 15.2 视觉抽样

至少检查：

- 390×844 手机。
- 768×1024 平板竖屏。
- 1115×864 当前桌面窗口。
- 1440×900 桌面。
- 1920×1080 电视布局。

每个尺寸抽样：Minecraft book 1 page 2、Minecraft 无音频书、Mikey book 1 page 1、Mikey 单页 11 句页面、Mikey 缺音频句、全屏小测。

## 16. 发布与回滚

1. v3 只通过 `ui=unified-v3` 访问，旧入口不变。
2. 完成自动化与五档视口验收后，在系列入口默认追加 v3。
3. 保留 `ui=legacy` 一个发布周期；进度和偏好键必须与 UI 版本解耦。
4. 发现布局回归时只撤销默认路由，不删除 v3 文件或用户学习进度。
5. promotion 前不得把“候选版本”写成“全量完成”。

## 17. Definition of Done

只有同时满足以下条件才算完成：

- 两个系列都通过统一顶栏、模式和学习栏。
- Minecraft 保留完整跨页；Mikey 没有复制气泡浮窗。
- Mikey 气泡定位在含 letterbox 的实际图片矩形内。
- Minecraft 翻译覆盖 367/367；精确词级高亮只有在证据数据完成后启用。
- 所有已发布 Mikey 句子保持现有说话人、气泡和词级时间，不批量重写可靠数据。
- 功能、内容、TV、Android 准备和真实浏览器验收均有新鲜证据。
- 用户在当前 1115×864 窗口确认视觉方向后，才把 v3 升为默认。
