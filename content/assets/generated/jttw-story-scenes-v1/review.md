# JTTW story scene thumbnails v1

These 108 compact JPEGs are deterministic crops of the illustration panel on
each episode's authored `p03.png`. The crop ends before the English paragraph,
so cards show a character/action snapshot rather than an unreadable page.

They are deliberately not AI-generated: the source page is the provenance
anchor used when a GPT keepsake prompt is reviewed. A future regenerated object
must retain the same episode/page/scene binding and pass the transparent-image
quality gate before replacing a thumbnail.

Checked locally:

- all 108 episodes produced;
- each output is 512×399 JPEG and below the pack size budget;
- page text is outside the crop for the standard storybook template;
- chapter map and detail scene no longer overlay generic motif art on faces.
