# 龙宫借宝 · 项目简报（intake）

- 目标年龄：5-10 岁中国儿童
- 学习目标：认读《西游记》章节高频英语词（看中文词牌 → 找对应英文目标）
- 核心动作：横版动作战——WASD 移动 / J 挥棒 / K 跳；只打中"词牌对应英文"的妖怪才算击退
- 关卡：1 花果山称王 · 2 龙宫借宝 · 3 水脏洞除妖 · 4 幽冥除名（每关一 Boss）
- 对标：《通天河之战》（Codex 鲤鱼精游戏）的场景美术与外壳；教育层为我方差异
- 运行时：静态 HTML/JS（prj/engine/proto-action.html），资产经 /assets/ 静态服务加载，运行时无网络
